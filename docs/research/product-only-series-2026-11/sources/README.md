# 研究ソースの配置

ここは一連の「商品紙だけで背景を兼務する」実験の**当時の原本**を保管する場所です。実験機能フラグ、未使用経路、既知の構築失敗を持つものがあります。**このフォルダの全ソースを提出可能と解釈しないでください**。

- `v1/`: 汎用紙0枚の初期検証（商品紙補完、追加穿孔、階段構造）、独立操作検証器。
- `v2/`: 常設3列（2枚ずつ）と改良相互補完の選択、各実装。
- `v3/`: 6枚1列・720順列の比較器、通常版と軽量版。
- `v4/`: 2枚の商品紙の共同差込み、強化版・軽量版、v3からの差分。
- `v5/`: 重複担当の強化・軽量版と一意担当の対照。
- `v6/`: 強化版は `solutions/product-only-v6-research/main.cpp` にあり、ここには軽量版とv5からの差分。
- `research-a/`: 常設商品紙・7枚正確費用・追加穿孔の試作（レポート `ahc074_v6_research`）。
- `research-b/`: 協力共有ペア・主紙複製・7枚比較器の試作。
- `research-c/`: 5枚比較器、補完需要列設計、多枚印刷＋共有再設計、5枚の距離検証。
- `research-d/`: 協力必須ペアの成立、分割背景、5枚背景試作（構築失敗あり）。

## 注意

- 当時の報告で「v5が最良」と誤記された回は、最終的には **v6が本シリーズの最良**。今のGitHub本流で最良な解法を主張するものではありません。
- 元の問題のソース上限は512 KiB（524,288バイト）。**v6強化版は532,156バイトで上限超過**。コンパイル可能性とAtCoderへそのまま提出できるかは別問題。
- `research-b/seven_exact.cpp` などは大規模な距離表生成を行うため、メモリ・時間を確認してから実行すること。
- 数値と不採用理由は [研究インデックス](../README.md) および各詳細レポートを参照。リポジトリの2000ケース評価による裏付けを新規に得たわけではない。
