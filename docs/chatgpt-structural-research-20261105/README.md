## 3. 厳密部分問題：選んだ r 枚を各1回動かす

### 3.1 前提

選ぶ紙は既知であり、最終的な上下順序を `X_0, ..., X_{r-1}` に固定します。それ以外の紙は一切動かしません。選択した各紙は、可視な状態でちょうど1回選びます。可視紙を同じ位置へ差す操作は許します。不要な選択紙を動かさない解も含めたい場合は、選択集合そのものを変える必要があります。

コードは r≤8 を扱います。これは実装上の制限で、数学的な条件の制限ではありません。全選択集合・全最終順序を無制限に列挙しても2秒に収まる、という主張はしません。

### 3.2 最終表示の必要十分条件

選択紙をすべて抜いた残りを基底スタックとし、紙数を n、表示を B、目標を A とします。窓 j の基底で最初に不透明な紙の位置を t_j とします。最後まで不透明紙がなければ t_j=n、表示色は白です。

選択紙 X_i の不透明集合を O_i、黒集合を C_i とし、

```
E = B XOR A
D_i = O_i AND NOT (O_0 OR ... OR O_{i-1})
W_i = D_i AND (C_i XOR A)
```

とします。D_i は、選択紙の中では X_i が最も上で不透明になる窓です。

次のいずれかがあれば不可能です。

```
E AND NOT (O_0 OR ... OR O_{r-1}) != 0
E AND W_i != 0
```

それ以外では、X_i を挿入する基底の隙間 p_i に対し、

```
L_i = max_{j in W_i} (t_j + 1)      # 空集合なら0
U_i = min_{j in E AND D_i} t_j      # 空集合ならn
L_i <= p_i <= U_i
p_0 <= p_1 <= ... <= p_{r-1}
```

が必要十分条件です。同じ隙間では固定した最終順序で積みます。

理由は、各窓について選択紙の最初の不透明紙だけを見ればよいからです。その色が正しければ、基底が誤っているときだけ基底の表示紙より上へ置く必要があります。その色が誤っていれば、基底が正しく、かつ基底の表示紙より下へ置かなければなりません。下側の選択紙の色は、上側の選択紙に隠れている窓では無関係です。

### 3.3 最も深い解だけで可視性の可否を判定できる

最終表示の条件を満たす、成分ごとに最大の隙間は、後ろから

```
p_{r-1} = U_{r-1}
p_i = min(U_i, p_{i+1})
```

と求まります。どこかで p_i<L_i なら不可能です。

ここからが可視性に関するポイントです。動かし終えた紙は、既にその最終的な基底の隙間へ置かれています。未移動の紙は元の基底の隙間に残っています。同じ基底の隙間に両者がいる場合は、**未移動の紙を先、移動済みの紙を後**に置きます。未移動紙同士は元の順序、移動済み紙同士は固定した最終順序です。

ある未移動紙を見ると、移動済み紙をより深い隙間へ置くことによって、その未移動紙が新たに隠れることはありません。同じ隙間で移動済み紙を後ろへ置くことも、未移動紙の可視性を悪化させません。

したがって、ある挿入位置の組とある操作順で実行できるなら、成分ごとに最大の隙間の組でも、その操作順を実行できます。逆は自明です。

**「最大の隙間だけを調べれば、少なくとも1つの合法解が存在するかは厳密に分かる」**という結論になります。ただし、最大の隙間が次注文の期待手数を最小にするとは限りません。可否と状態価値最適化は別です。

### 3.4 操作順は部分集合DP

動かし終えた紙の集合を S とします。最大隙間と上述の同一隙間内の順序を固定すると、S から現在のスタックが一意に決まります。

```
reachable[0] = true
reachable[S] から、現在見えている未移動紙 i について
reachable[S union {i}] = true
```

全紙を移動済みにできれば合法解があります。親を記録して操作順を復元し、紙を取り出した後の正しい挿入位置を返します。

任意の可視紙を貪欲に選んでよい、とはしていません。移動した紙が別の未移動紙を隠す可能性があるため、操作順はDPで調べます。

固定した選択集合・最終順序の下で、前計算は概ね O(K+64r)、部分集合DPは O(2^r(K+r log r)) です。最終順序まで全探索する場合には r!、選択集合まで探索する場合にはその組合せ数が別途掛かります。

## 5. 商品紙を比較層の途中に入れる自由化

「商品紙は必ず比較層の上」という制約を外すことも考えました。しかし、既存の印刷模様のままでは、まず必要条件が非常に厳しいことが分かりました。

比較層と1枚の商品紙だけで一般窓を表示し、商品紙より上に比較紙を置く場合、その中で一番上の比較紙は、不透明な一般窓すべてで目標色と一致しなければなりません。

```
(comparator.black XOR target) AND comparator.opaque == 0
```

20設計・5,120商品を調べた結果、この必要条件を満たす比較紙が1枚以上ある商品は **35個、約0.684%** だけでした。これは実現可能性の十分条件ではありません。比較紙の上に別の補助商品紙を置いて誤色を隠す構成には、この条件をそのまま適用できません。

また、これは全体の最適手数の下界ではなく、現在の紙設計における候補の少なさの監査です。自由化そのものを否定するのではなく、効果を出すには印刷設計との同時変更が必要だと判断します。

## 6. 比較窓を3枚以上の紙で表す探索

前回は1窓の変更を即座に合法性で拒否していました。今回は、全15組の可視性の証人窓を固定して残し、それ以外の23窓について、6枚の各セルを0/1/穴に変える焼きなましを試しました。一時的に商品が表示不能になる状態も許します。

各商品の穴に対し、720順序それぞれの不一致数 v_s を持ち、

```

```

を滑らかな代理目的として使います。紙の変更で影響する状態だけ更新します。最終採用には、すべての担当商品を表示できることを要求します。商品ペアリングとアクセス列は固定です。

## 9. 残る有望方向

単にオンライン探索を広げるだけでは、大幅改善に必要な候補そのものが少ないようです。ただし、ここまでの否定的結果は、10手未満の構造が存在しないという主張ではありません。

特に残るのは、**商品紙の印刷模様・商品共用・補助紙としての役割を共同で設計すること**です。1枚ずつ有用な紙を選ぶのではなく、下側紙の誤色を上側紙や通常の列頭が隠す組を設計します。評価には、共同修復の利益から、両紙の露出、配置、返却、担当商品を表示する際に増える穴、次注文への影響を引く必要があります。

今回の一回移動部品は、そのような少数紙の共同作用を非合法な操作なしで評価するために利用できます。候補集合と最終順序が与えられれば可否は厳密ですが、設計探索そのものや長期状態価値まで解いたわけではありません。現時点で9.5手や2〜3%改善を予測する数値的根拠はありません。
