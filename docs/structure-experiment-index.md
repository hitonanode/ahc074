# 全実験の索引

11月3〜4日の今回の作業で新設した199ディレクトリを、検証した問いごとに整理した。同じ案の模型・提出実装・追試は一行にまとめた。各解法名のリンクは設計または実験の説明に、右列はrun-id、seed、標準誤差、採否を記した個別記録に進む。正式比較はローカルテスターの同時比較を指す。[全体の結果と残る仮説](structure-experiments.md)

採用版の実装は各ディレクトリの `main.cpp`。研究用ディレクトリでは `main.cpp` が親の控えで、実験本体が別のC++・Pythonにある場合がある。リポジトリにはコード、設計表、学習係数、比較・検証の集計を収録した。実験記録に登場するseed別のJSON、標準エラー、模擬入出力はスクリプトが生成するローカルファイル。最終比較の統計は、共有の評価履歴にある2本のケース別スコアから再計算できる。[評価履歴](../pahcer/summary.md)・[対照2000件](../pahcer/json/result_20261104_085055.json)・[最終版2000件](../pahcer/json/result_20261104_085056.json)

最終版を再評価するにはリポジトリ直下で次を実行する。個別の研究スクリプトには当時のローカルパスと保存済み設計を参照するものがある。その場合は対応するrun-idの出力と入力パスが必要になる。

```sh
python3 scripts/pahcer_run.py --compare solutions/as6-canon solutions/eject-single-window --seeds 0-2000 -c "最終版と開始時基準の再比較"
```
