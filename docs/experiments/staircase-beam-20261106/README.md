## 段階ごとの結果

### 第1段階: 全残余bitを順次被覆

各目標 `t` の未充足bit `R[t]` を保持し、候補紙の三値模様が「`R[t]`のうち今回塗る位置では目標色と一致する」なら寄与ありとする。少数bitしか埋めない目標は候補の評価から除外し、その最小寄与を後半にかけて高める。

ただし、少しずつ埋める構造では1目標の使用紙枚数と掘り出し／戻しが増えた。目標の完成自体は可能になっても、使用枚数平均8.43枚の設計では重かった。

| 初版の固定設定 | ケース数 | 平均手数/注文 | 誤り/不正操作 |
|---|---:|---:|---|
| 品質優先 | 100 | 16.01297 | 0 / 0 |
| 高速版 | 100 | 16.13713 | 0 / 0 |
| 紙列の外側ビーム幅2 | 20 | 15.96831 | 0 / 0 |

外側ビームの比較は**同じ20ケース**の単独ビーム16.02993→15.96831、改善約0.06162手。異なるケース数の行を直接比較しないこと。初版のソース・生CSVが今回存在しないため、数字の独立再検証はできない。

### 第2段階: 既存出力を観察して階段を再設計

**もっとも大きな発見は64段が過剰だったこと**。提供された既存解の実出力は6共用紙＋25段＋capで、64窓のうち38窓を共用層、25窓をアクセス階段、1窓をcapに割り当てていた。紙192枚のうち、6共用・1cap・71組共有紙・114単独主紙の計192枚。100ケースでの不透明bit平均は、共用紙12.67、2目標共有紙37.44、単独紙55.16。浅い段は紙が少なく、深い段ほど紙が多い（例: seed0で約3枚→約12枚）。

この観察に基づき、v2は**共用6枚の比較器を残しつつ**、共用37窓・階段26段・capに変更。DPで段ごとの主紙数を割り当て、共有可能性グラフから関連する12枚を集めて、上の段から主紙をビームで再構築した。単独／2目標共有の選択は固定せず、被覆bitではなく掘り出し・修復・共用層の並べ替え・補助紙の将来価値を代理評価とする。ビーム幅64、400回再構築＋短い既存配置探索。

| 同一 seed 0〜99（102,400注文/方式） | 総手数 | 平均手数/注文 | 表示誤り | 不正操作 |
|---|---:|---:|---:|---:|
| 提供された既存 `esw-clean.cpp` | 1,033,546 | **10.09322265625** | 0 | 0 |
| v2 | 1,036,371 | **10.120810546875** | 0 | 0 |

v2は45勝55敗、平均差+0.02758789手/注文（悪化）。CSVからケースごとに計算した差の標準誤差は約0.01318手、平均 log(新/旧) は+0.2713% ± 0.1301%（SE）。同じseed 20〜39のビーム有無は10.13550→10.10771で、ビーム単独の効果は改善0.02778手だった。既存の操作器・列最適化の寄与が大きい。

操作内訳では、掘り出し2.87534→2.79806、共用層変更1.23686→1.20939と改善した一方、アクセス窓のfix1.74274→1.80978、補助紙を戻す操作1.13006→1.14887などが増えた。**取り出し側の利益が修復・往復で失われた**。

単独15ケースの内部時間は平均約1.788秒・最大約1.894秒。2秒制限への余裕が少ない。

### 第3段階: 共用紙の白・黒・穴も自由なビームに

共用6枚の各共用窓に、少なくとも0と1を1枚ずつ含む三値列を割り当てる。候補は`3^6 - 2*2^6 + 2 = 602`種類。3枚以上に色が印刷される窓も許し、窓の物理位置と模様を同時に選ぶ。**既存の2枚比較器を初期解として使わない**。

各候補目標ペアの両側について、共用6枚の720順序から表示が成り立つ順序集合を別々に持つ。窓を一つずつ決めるビームと、4窓の削除・再ビーム構築（300回）を実装。共用紙の合法な移動は、実模様から求めた可視性と全720順序の遷移グラフで計画する。後半は完成候補の真の可視性を使った60回の追加ビーム評価を試した。

| 同一 seed 10〜29（20,480注文/方式） | 総手数 | 平均手数/注文 | 表示誤り | 不正操作 |
|---|---:|---:|---:|---:|
| 既存 `esw-clean.cpp` | 207,315 | **10.122802734375** | 0 | 0 |
| v2 | 207,587 | 10.136083984375 | 0 | 0 |
| 自由共用ビーム（追加評価前） | 210,092 | 10.258398437500 | 0 | 0 |
| 自由共用ビーム＋可視性評価 | 209,809 | **10.244580078125** | 0 | 0 |

追加評価後は既存解に6勝14敗、平均+0.12177734手悪化（差のSE約0.03274手、log(新/旧) +1.1909% ± 0.3201% SE）。v2に対して5勝15敗、平均+0.10849609手。追加評価だけなら10.25840→10.24458の0.01382手改善だった。

**自由化しても、多様性と可視性が自然には保たれない**。共用紙720順序で得られる異なる表示は、比較器の720個に対して自由三値の初期版で平均584.7個（最小186個）、可視紙数平均4.8333枚（比較器5枚）。追加評価後は異なる表示平均644.3個、可視紙数平均4.9117枚。3枚以上印刷の窓は追加評価後で1ケース平均4.35個。探索が実際に非比較型模様を採ったことは確認できるが、局所的な「表示できるペア数」が表現力や操作容易性を保証しない。

seed0の単独探索では、共用5枚/35窓10.24609、共用6枚/37窓10.10840、共用7枚/40窓10.46680、共用7枚/42窓は構築未成立。**単一ケースの結果で枚数の優劣を一般化しない**。

速度は致命的: 初期構築（追加評価前）だけでも20ケース4並列の平均約91.46秒、追加の可視性探索が約20.26秒（部分計測）、統合版のseed11の実対話実行は約99.84秒。**2秒の提出用解法ではない**。途中で保存した共用紙を読み込む部分実験の時間を、全工程の実行時間としていない。

## 技術的な結論と未解決課題

1. 「埋めたbit数」より「残る表示を何枚・何回の合法操作で完成させるか」が重要。対象が少ない紙ほど、将来の修復・戻しのコストも含めて評価する必要がある。
2. 64段を当然視せず、共用層の表示自由度とアクセス階段の段数・各段の収納数を共同で最適化すべき。単純な被覆優先の紙を繰り返すと使用枚数が増えすぎる。
3. 自由共用のスコアは、実現可能な目標ペア数だけでなく、**異なる表示の数、隠れていない可視紙の数、合法遷移距離**を含むべき。初期探索の「底以外の全紙は動かせる」緩和グラフでは費用を過小評価する。
4. 今回なお残した最大の制約は**主紙が1または2目標しか担当しない**ことと、共用層／階段層の役割分担。初期の「全192枚を上から設計する」自由構築ではなく、後段は構造制約付きの研究だった。
5. 目標性能10.0手以下、特に9.5手以下を実現した証拠はない。現時点では既存の提出解法を維持すべき。新たな仮説は、少数枚による多目標共有、修復費用の正確な先読み、設計と操作の交互最適化、強い下界での枝刈りなど。
