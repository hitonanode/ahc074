# chatgpt-local-macro

改良元: solutions/imp-combo

既存の紙の設計、穴埋め紙、汎用層の補助紙、前の専用紙の再利用を保ち、最後のハンドル修正だけを隣接3列の合法な操作列として再最適化する実験版。

1. 選ばれた計画の操作を再生し、最後の「汎用紙・専用紙・穴埋め紙を動かす操作、または別の列を跨ぐ操作」の直後を、最後のハンドル修正の開始点とする。それ以前の操作はそのまま使う。
2. 隣接3列を順に取り出し、その場で各ハンドルを逐次修正する操作を上界にする。
3. その3列が占める物理的な区間内で、見える紙の挿入を幅8・深さ3のビームで探索する。既存の穴埋め紙は動かさない。逐次修正と同手数以下の候補だけを調べる。
4. 3窓は目標と一致し、他の61窓は探索前の表示と同じになる候補に限る。重なりから列外の紙を再分類し、専用紙を除いた後に穴埋め紙をすべて合法に戻せることも確認する。
5. 終状態は既存と同じ `操作数 + 0.6 × 穴埋め紙枚数 + adaptive_next_cost` で比較する。最後に既存の操作列短縮を行う。

新たに列を跨いで残った紙は穴埋め紙として記録し、次の注文へ引き継ぐ。1手を計画に挿入して既存プランナを再実行する方式ではなく、部分目標への操作列と到達順序を直接選ぶ。

`CLOCK_SCALE` を継承する。追加探索は経過1.77秒以降には展開せず、その修正段の上界を使う。時計による打ち切り以外に別解法へ切り替える構成はない。

stderr の `macro_trials` は探索した3列段の数、`macro_selected` はその段で改善候補を得た数、`macro_saved` はその段の上界から減った操作数、`macro_nodes` は展開した合法候補数。これらは計画末尾全体の最終採否より前の集計なので、`macro_saved` を最終スコア改善量と同一視しないこと。

これは有限幅の探索であり、3列の全状態に対する厳密MDPではない。評価結果と採否は `trial_log.md` と検証レポートに記録する。
