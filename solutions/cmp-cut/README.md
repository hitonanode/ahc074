# cmp-cut

改良元: solutions/cmp-tune

汎用窓の割り当て（assign_windows）で目的に数える目標の対を、距離 28 以下から 26 以下にした（距離は常に偶数）。

- 対の数は約 7500 → 約 3500 組になり、同じ時間（0.52 秒まで）での反復が約 2.1 倍になる。距離 27〜28 の対は重みが小さい（exp(0.35 (center − h + 0.3 h_generic))）。
- 模擬（焼きなまし固定、割り当ては同じ時間に相当する回数、32 本）、cmp-tune 相当の設定に対して: 距離 26 以下（9300 回）で seed 24〜87 −0.164 ± 0.079%、seed 88〜151 −0.242 ± 0.074%。同じ回数（4200 回）だと +0.125 ± 0.085% で、効くのは反復が増えること。距離 24 以下（27000 回）は −0.219 / −0.097%、22 以下（10 万回）は +0.03%。
