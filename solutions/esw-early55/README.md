# 設計の締め切りを 0.55 倍に早める

改良元: solutions/esw-noprune。

設計の段の締め切り（窓の割り当て、焼きなまし、山登り、再割り当て、穴あけ、緊急設計への切り替え、補助紙の表の打ち切り、割り当てのやり直しの時間）をすべて 0.55 倍にする（定数 kDesignScale）。軽い計画への切り替え（kFastAfter = 1.80 秒）はそのまま。

- 理由: ジャッジでは注文処理が手元の見積りより約 1.4 倍遅く（約 0.47 秒）、esw-tidy・esw-noprune は多くのケースで 1.80 秒の軽い計画に入った（暫定 50 件の総和 531759・533784、最大 1810 ms。as6-canon は 529870）。設計を早く終えて注文処理に時間を回し、軽い計画に入らないようにする。
- 手元の評価（LOCAL_BENCH、軽い計画なし）では、設計の探索量が減る分だけ悪くなる。ジャッジでの効果は提出して確かめる。
- この版（0.55 倍）は、設計の探索がどこで飽和するかを測るためのもの（esw-early90 / 85 では手元の損がほぼなかった）。
