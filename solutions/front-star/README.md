# 複数の取り出し窓を共通の紙で覆う部品

改良元: solutions/reset-majority。研究用の操作模型は solutions/long-module と solutions/front-three のものを複製する。

先頭3列の商品紙から1〜3枚を、3窓すべてに印刷する共通紙とし、残りの紙は1窓だけに印刷する。共通紙の上下へ商品紙を差し込んで色を変える。列ごとに白黒の先頭を用意する構造と異なり、共通紙の移動で複数の窓を一緒に変える候補を探す。商品紙の印刷色は担当商品の色を保つ。

窓の割当と共通紙の選び方を無作為に作り、実要求の部分一致と指定紙の取り出しを含めたビーム探索で選別する。選別と検査で注文列を分け、検査ではビーム幅を広げる。有望な候補だけ、9枚以下の全順列による平均費用MDPで確かめる。

これは構造研究用で、部品内の指定紙の持ち上げ・即時返却は無料、外部の穴埋め紙は省く。公式スコアと区別する。main.cppは比較元のコピーで新構造は未統合。乱数は固定し、時計にCLOCK_SCALEを掛け、隠された注文列は読まない。
