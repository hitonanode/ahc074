# beam-staircase-v1: 26段・完成割当ビーム（研究用）

改良元：初期の `beam-topdown` という着想と、実行系の `solutions/esw-clean`。新規の主紙構築を、既存の6枚比較器・注文処理に接続するハイブリッド。

- 共有37窓・26ハンドル窓・キャップ1窓。比較器6枚・キャップ1枚・主紙185枚。
- 114単独紙と71共有ペアを割り当て、ペアの色違い窓を穴にして共通層の有向非巡回制約で完成可能性を確認。
- ビームは階段ハンドルを上から1段ずつ決め、各候補で残りの紙をハンガリアン法で完成割当する（既定幅2・候補5）。
- 評価関数は使用頻度付き掘り出し・残余補修・補助紙価値。被覆bit数のみではない。
- 参照解法の共通窓割当・比較器・ハンガリアン再割当・オンライン処理を再利用。既存主紙構築の焼きなましは既定経路で使わない。

原実験の構造・限界・結果は [研究報告](../../docs/beam-staircase-20261106/report.md) の第3節を参照。時間制限を保証する提出用の版ではない。
