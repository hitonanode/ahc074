# 取り出しの優先度に合わせた初期の重ね順

改良元: solutions/anchor-match。

紙の模様を変えず、最初に各列へ積む順序を、返却時に使う優先度に合わせる。優先度は担当商品の数と穴埋めへの追加需要から決まる。同じ色の最優先紙を1枚ずつ先頭へ置き、穴の要求が多い色を上にする。残りは色に関係なく優先度の降順に並べる。列の先頭2枚が両色である条件は保つ。

選んだ順序で紙を出力し、操作に出す紙番号も対応する番号へ変換する。他の制御、設計、時間配分は改良元と同じ。全時計はCLOCK_SCALE倍。

研究用probe.cppは保存設計と固定乱数の模擬注文で、色ごとに並べる条件・全体で並べる条件・先頭色も期待費用で選ぶ条件を比較する。隠された注文列は読まない。
