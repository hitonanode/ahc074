# 穴埋め候補を少し整えてから再始動を選ぶ

改良元: solutions/early-select。main.cppはtight-thirty-eightのコピーで研究用。

2本/4本へ分けた列共有探索の各候補に、穴埋め紙の交換を8000回だけ行ってから、通常の模型または先頭利益込みの模型で1候補を選ぶ。選んだ候補だけ残り57000回と一括再割当・穴追加を行う。先頭の印刷が未調整の状態で選ぶことによる誤差を減らすため。基準1本は元どおり65000回。

分割時には誤色確率も再計算されるため、全てが同じ探索順になるとは限らない。2本では8000回、4本では24000回の追加交換があるので、固定反復の差と時間増を分けて測る。入力1792〜1823・独立模擬8本。全表示と各条件1本の可視性・最終順序を検査。実注文は読まず全時計にCLOCK_SCALEを掛ける。
