# 汎用紙の印刷と商品対の共同探索

改良元: solutions/head-design。

6枚の比較器の窓の組・向きを変更した直後に、その変更で表示できなくなった共有商品を組み直す。表示できなくなった対の一方を、単独紙の商品と交換し、新しい対と単独紙を作る。列の白黒を残し、全商品の表示を保つ。紙の枚数と汎用紙6枚の全15比較組は変えない。

各候補を、列への割り当てを含む取り出し・穴・汎用操作の模型費用で評価する。交換する単独商品は全候補を比べる。印刷変更と修復を一つの候補として焼きなまし、最良の設計を残し、最後に先頭候補の利益による列交換を行う。

`probe.cpp` は保存設計からの研究用。固定乱数の模擬注文で比較し、実際の注文列は読まない。`main.cpp` は比較元のコピーで、提出用への組み込みは研究結果を見て決める。時計は `CLOCK_SCALE` 倍。

拡張した研究版では、比較器変更後の互換グラフで増大路と奇閉路の縮約を使って共有対を修復し、共有紙・単独紙をそれぞれ全列へ割り当て直す。割当は穴の費用の接平面を使い、列ごとの種類・白黒枚数を保つ。近い商品対の選別は距離28以下で、元の対は距離に関わらず残す。最大マッチングは小さい無作為グラフ2700件で全探索と照合した。

修復では、壊れた対のどちらも単独へ戻すことを許し、安い未使用商品対を先に選んでから増大路で不足を埋める。修復後の短い列・共有の焼きなましを加える条件も調べる。
