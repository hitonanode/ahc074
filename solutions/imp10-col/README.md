# imp10-col

改良元: solutions/imp-lean

solutions/gpt6pro-10-01-filler-chain（外部 agent が cmp-anneal から改良したもの）の、設計のモデルの列の費用だけを移植した（Design::colcost_of と、焼きなまし Design::Annealer が使う 40 倍の整数版 colcost40）。注文処理と時間配分は imp-lean のまま。

- imp-lean の列の費用: 巡回する列の掘りの手数 nt(n−1)/2 から、対の紙（2 目標分注文される）と両方の色を上に寄せたときの節約の 0.85 倍を引き、白黒の紙の数の偏り imb に 5 × imb² の罰則。
- 新しい列の費用: 0.15 × nt(n−1)/2 + 0.85 × W + 0.1 × imb²（n は列の紙の数、nt は目標の数）。W は「先頭 2 枚に両方の色がある」という条件の下で、対の紙を先頭に寄せたときの、目標の数で重みを付けた深さの和の最小値で、W = n(n−1)/2 + p(p−1)/2（p は対の数）。対のハンドルの色がすべて同じなら、逆の色の単独の紙を 2 番目に入れるために 2 枚目以降の対が 1 段ずつ下がるので p−1 を足す。列に片方の色しかないときの 1e5 の罰則は残す。
- 考え方（10 のもの）: 注文処理は列の紙を期待費用が最も小さい深さへ入れる（adaptive_insert）ので、白黒が交互に並ぶとは限らない。先頭 2 枚に両方の色があればハンドルの色の直しは浅く済むので、列全体の白黒をそろえる強い罰則はいらない。
- 整数版は 40 倍で厳密（0.15 / 2 × 40 = 3、0.85 / 2 × 40 = 17、0.1 × 40 = 4。kRankPriority = 0.85 を static_assert で固定）で、分岐を使わない。

パラメータと stderr は imp-lean と同じ。
