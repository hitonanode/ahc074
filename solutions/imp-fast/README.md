# imp-fast

改良元: solutions/imp-helper

注文処理を速くし、空いた時間を設計に戻した。

- **計画の後半の共有**（solutions/gpt6pro-06-02-regroup の考え方）: run_plan を、前の持ち上げた紙と古い穴埋め紙を処理する前半と、汎用紙の並べ替え・新しい穴埋め紙・D の持ち上げ・取っ手の掘りの後半（run_plan_tail）に分けた。後半は前半の後の状態（重なり順、持ち上げた紙、穴埋め紙の記録）と pre_cov・kept・use_filler だけで決まるので、process が計画の候補を試す間、注文ごとに後半の結果（追加の手と最後の状態）を覚えておき、同じ状態に来た候補では使い回す（ハッシュで絞って全項目を比較）。出力は imp-helper と同じ（回数を固定して seed 0〜15 で確認）。単独の実行で注文処理が 0.30 → 0.24 秒（seed 0）。
- 時間: 設計の焼きなましを 1.245 → 1.305 秒、穴埋めの山登りを 1.30 → 1.36 秒までに戻した（倍率込み）。

stderr: `tail_hits`（後半を使い回した回数）。
