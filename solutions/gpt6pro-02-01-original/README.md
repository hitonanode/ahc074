# gpt6pro-02-01-original

改良元: なし（外部 agent gpt6pro-02 の最初の版）

## 解法の全体

- 紙の構造（三角形）: 紙を窓ごとの 64 群に分ける。群 j の紙（アンカー j）は、窓 j を必ず塗り、窓 j+1〜63 はすべて穴、窓 0〜j-1 は学習した自由な模様。枚数はアンカー 0〜39 に 2 枚、40〜47 に 4 枚、48〜63 に 5 枚（計 192）。各群の先頭 2 枚はアンカー窓の色を逆にしておくので、その窓の色だけ直すなら 1 手。
- 待機時の並びは群 0, 1, …, 63 の順。各群の先頭の紙は自分のアンカー窓で見えている。
- 紙の模様の学習（256 商品から）: 商品 t ごとに「まだ担当の決まっていない窓」U_t を持ち、アンカーの大きい群から 1 枚ずつ模様を決める。共有させたい商品の集合 Q から、U_t の中で黒を要求する窓・白を要求する窓を OR で集め、両方要求される窓は穴、片方だけならその色にする（U_t の外は上の紙に隠れるので不一致でもよい）。Q を広げる候補を何通りも試し、利得 Σ_t max(0, |M∩U_t| − λ − 同じ群の既存の紙での利得)（λ=6）が最大の紙を採る。
- 注文ごと: 前の注文で前へ出した紙をアンカーの大きい順に元の群へ戻し、今回使う紙をアンカーの小さい順に取り出して、群 d の直前に差し込む（d < アンカーなので、窓 0〜d-1 は手前の群に隠れ、その紙は窓 d〜アンカーだけで効く）。この順序でどの操作も可視性が保証される。1 群から前へ出す紙は高々 1 枚。
- 計画の探索: 未処理の窓集合と使用済みアンカーの集合を状態にした幅 32 のビーム探索。1 枚使う手のほか、「1 枚目で 2 枚目の不一致部分を隠し、2 枚目で広く覆う」2 枚組の手も候補にする。費用は 2×(前へ出す枚数) + 群内で紙を露出させる手数 + 残った窓の 1 bit 修正の手数で、これを足すと総操作数に一致する（前へ出した紙を次の注文で戻す手数を前払いで数える）。覆えなかった窓は各群の先頭の色で直す。
- 時間: 学習は CPU 0.72 秒まで、全体で CPU 1.75 秒を超えたら以降の注文はビーム探索をやめて群の先頭だけで直す。

## パラメータ

- 群の配分（layout=4）、学習の試行（starts=64, probes=16, λ=6）、ビーム幅 32、CPU 上限 1.75 秒（学習 0.72 秒）。学習の乱数は入力の商品から作ったハッシュで初期化する（固定入力なら再現する）。
- stderr: `learn_cpu`（学習の CPU 秒）、`total_cpu`、`active_papers`（注文後に前へ出ている紙の平均枚数）、`truncated`（時間切れで探索を省いた回数）。
