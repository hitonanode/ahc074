# 一括割当の単独紙の利益を走査で求める

改良元: solutions/post-two。

一括割当で使う「単独商品を各列に置いたときの穴埋め利益」を、列ごとの再計算から窓の走査へ変更する。目標側は深い窓から浅い窓へ進み、最も深い誤色より先の寄与を固定する。供給側は浅い窓から深い窓へ進み、誤色が現れるたびに区間の確率をリセットする。0個・1個の不一致の確率と不一致数の期待値を保持し、元と同じ利益を求める。

今回の割当に移動できる商品だけを計算する。VERIFY_SINGLE_SCANを付けると、すべての商品・列の組について元の式と照合する。MATCH_SCAN_RESEARCHは研究用に元の計算との比較を有効にする指定で、main.cpp単独では担当商品側だけを走査し、供給側は元の計算を使う。紙の設計の評価式・反復数・時間配分・CLOCK_SCALEは改良元と同じ。
