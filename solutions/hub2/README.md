# hub2

改良元: solutions/hub

汎用層を窓ごとの白黒 2 枚から「小グループの MDP」に替えて紙を節約し、その分ハンドル窓（列）を増やした。列の大きさも深い列ほど大きくした。

## 変更点

- 汎用層: G を 4 窓ずつのグループに分け、各グループにグループ内だけで不透明な 6 枚の紙を置く。模様は事前にオフラインで探した `1110 ..0. ...1 0110 .0.. .100`（trial_log.md の「汎用構造の限界」）。1 窓あたり 1.5 枚（hub は 2 枚）で、平均 0.419 手/窓（hub は 0.5）。
- グループ内の操作は、一様な目標模様に対する平均費用最小の MDP 方策（状態 = 6 枚の順列 720 通り）に従う。方策は起動時に相対価値反復で計算する。専用紙のない注文で、各グループを目標の模様に合わせるときに使う。
- ハンドル窓の数 H を 16 → 32 にした（G が 4 の倍数になるように切り上げ）。
- 列の大きさ: 均等だったのを、列 l の大きさを (1 + slope × l) に比例させる（slope = 0.3。深い列ほど大きい）。各列は 2 枚以上の偶数（ハンドル窓の色の交互を巡回で保つため）。
- 専用紙のある注文の手順は hub と同じ。

## パラメータと指標

- 環境変数 `HUB_H`（既定 32）、`HUB_SLOPE`（既定 0.3）。
- stderr: `dedicated`（専用紙を持つ目標の数）を足し、`ded_requests` をやめた。ほかは hub と同じ。
