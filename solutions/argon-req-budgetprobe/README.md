R5の測定版。各注文を基準で解き、その同じ開始積層から3つの予算を独立に試す。0は中立候補の再編集を削除だけにする、1はそれに中立探索1周を組み合わせる、2は4周・追加計画8・追加計画の試行上限2・短い計画への限定なし・3削除・内部深さ4・最良計画の再編集1回。通常の出力と積層は必ず基準へ戻す。時計は測定だけに使い、未来注文は読まない。

#budgetは注文番号、予算番号、基準のraw計画長、通常eject後の長さ、製品紙のハンドル穴数・汎用穴数・列内深さ、旧フィラー数、初期候補数、上位2計画の値差、第1中立周回の利得、基準/別予算の最終手数、完成評価改善、基準/別予算の秒、内部検査の成否。時間配分の説明変数は全て重い探索前または基準の早い段階で得られる。別予算の結果は解析用の応答値で、選択の入力にはしない。

budget_base_secとbudget_<mode>_sec/gain/moves/invalidは基準・各予算の合計時間、完成評価改善、即時手数差、表示・到達性検査の失敗数。既存統計には仮試行分も含む。仮試行のheavy traceは出力経路と混ざらないよう破棄し、基準のtraceを保つ。全ログ・スイッチ・プロファイラ・CLOCK_SCALE・LOCAL_BENCH・DesignStore・目次・節を維持する。

固定設計の時間超過測定専用。通常評価で測定する場合のみ--no-recordを使う。
