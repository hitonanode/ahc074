# 窓交換後に列と商品対を探索し直す

改良元: solutions/eject-lean。窓交換と壊れた商品対の修復はsolutions/map-handle-repair。

汎用窓と取り出し窓を交換し、壊れた共有を単独商品の交換で修復する。変更直後の費用だけで採否を決めず、上位候補から列・商品対の焼きなましと先頭紙の再割当を行う。元の窓割当にも同じ再探索を行い、窓交換後の改善余地を比較する。

probe.cppは保存設計による研究用。固定乱数の独立模擬注文を使い、入力末尾の注文は読まない。全表示と各条件1本の全操作の可視性を検査する。main.cppは比較元のコピー。実行時間はCLOCK_SCALE倍で、時間内に使える構成への採否は検証後に判断する。
