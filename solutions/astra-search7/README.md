assign_windows の「汎用窓を別の紙2枚の組へ移す」近傍で、交換元の抽選を変える。
現在の状態でまだ候補が残る交換元を64bitの集合に持ち、その集合から一様に選ぶ。
移動元の組に窓が1個しかない、移動先がすべて不適合、または列挙した移動先を使い切った窓は集合から外す。
状態を受理したら集合を汎用窓全体に戻す。同じ状態で候補の尽きた交換元を繰り返し引く処理を減らす。

移動先の列挙・順位付け、全対評価とmatching_costの定義は基準と同じ。
窓交換などほかの近傍、G=38、71対、キャップ窓63、距離上限26、kMapEnd=0.50 / kGoptEnd=0.61を維持する。
停滞時の移動は256/512試行、逆手禁止は4受理分、温度は0.05→0.00125。
追加指標 source_empty は、交換元の候補集合が空で提案できなかった回数。

実験結果・採否は [REPORT.md](REPORT.md) を参照。
