# 同じ比較組の窓を一括で反転・交換する

改良元: solutions/post-repair。

汎用窓の割当で、同じ2枚の紙を比較する窓を全部まとめて白黒反転する候補と、2個の比較組に割り当てた窓の集合を交換する候補を追加する。1窓ずつ変える途中では共有が壊れる配置へ、一度の変更で移ることを狙う。各比較組の窓は最低1個を維持し、操作時の構造は同じ。

既定では1/64の提案を一括変更にし、選んでいる共有が6対以上壊れる候補は事前に捨てる。残る候補は全ての近い対とマッチングを計算して評価する。一括変更のキャッシュ識別子は通常の変更と分離し、交換後の窓の所属・組の枚数も更新する。group_trials/evals/acceptsは提案・全評価・受理の回数。

probe.cppは保存された比較器から同じ回数で再探索し、同じ列設計・穴埋め改善を行って模擬注文で比較する研究用。実際の注文列を読まず、固定乱数とCLOCK_SCALEを使う。
