# dp1

改良元: solutions/hub8

## 変更点

- 設計の焼きなまし（anneal_units）を打ち切る時刻を、プログラム開始から 1.2 秒 → 8 秒にした。焼きなましを長くするとどこまで良くなるかを測るための版で、制限時間（2 秒）を超えるので提出には使えない。
- 焼きなましの反復回数を stderr に出す。
- 紙の設計と注文ごとの操作は hub8 と同じ。

## パラメータと指標

- 環境変数 `HUB_TL`（既定 8.0）: 焼きなましを打ち切る時刻（プログラム開始からの秒）。そのほかの環境変数（ハンドル窓の数 `HUB_H` = 34 など）は hub8 と同じ。
- stderr の `anneal_iters`: 焼きなましの反復回数。
