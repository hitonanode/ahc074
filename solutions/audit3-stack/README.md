# audit3-stack

改良元: solutions/audit3-narrow

専用紙を持ち上げる前に穴埋め紙を選ぶ区間 DP（choose_fillers_prelift）に、「同じ段に 2 枚を重ねる」候補を足した。紙の設計は audit3-narrow と同じ。

## 変更点

- 浅い列 cU の紙 U を段 a に置き、続けて深い列 cL（cL > cU）の紙 L を同じ段 a に置くと、L は U のすぐ下に入る。すると次のように見える。
  - U は [a, cU] のハンドルのうち自分が不透明な窓に見える。
  - L は、U の穴（U が対の紙なら、対の 2 目標の違う窓）と、(cU, cL] のハンドルに見える。
- L は U が覆う窓では目標と色が違ってもよいので、L 1 枚のときの最も広い段より浅いところから使える。また L が U の穴を埋める。3 回目の監査（solutions/audit3-tools）で、最初の 1 手を総当たりしたときの差の大きい注文に、この形があった。
- 候補の組 (U, L) は、U の列を「L の色が合わない最も深いハンドル」から L の列の手前までに限って数え上げる（ハンドルの添字のビット列で計算）。各列の深さ 3 までの紙が対象。
- この候補の利得は「省ける掘り − 2 枚分の費用（1 枚 1 + 深さ）」で、2 以上のときだけ DP に入れる（1 枚ずつ置く穴埋め紙と同じく、1 枚あたり 2 + 深さ以上の掘りを省くとき）。
- 1024 注文の処理が合わせて約 0.05 秒増える。

## パラメータと指標

- 環境変数 `STACK`（既定 1）: 0 で重ねる候補を足さない（audit3-narrow と同じ）。
- stderr の指標は audit3-narrow と同じ。
