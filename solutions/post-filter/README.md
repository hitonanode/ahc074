# 後処理の誤表示候補を早く捨てる

改良元: solutions/eject-lean。

後処理の候補を最終順序に並べた時、上から初めて見えた色が要求と違えば、残りを走査せずに不成立とする。この段階で全表示を確認済みの候補は、可視性付き再生の後の同じ表示確認を省く。操作の候補や評価式は変えない。

研究ではこれに加え、元の連続区間の表示を2つの重なる表から合成して、一枚ずつの走査を省く条件も比較する。リンクが変更された位置だけで区間を区切る。全模擬注文の操作列・最終順序を元と完全一致するか調べ、各条件1本は可視性も独立に照合する。CLOCK_SCALEと時間配分は改良元のまま。main.cppの既定は誤色による早期打切りだけ。
