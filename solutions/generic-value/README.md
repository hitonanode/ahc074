# 終了状態に汎用紙の次注文費用を含める

改良元: solutions/stay-value（その注文処理の基準は solutions/post-repair）。

汎用紙の並べ替えでは次の要求に対する平均費用を同点判定に使っているが、計画全体の終了費用には含めていない。その値に汎用紙の変更が必要な商品の割合を掛け、ハンドル側と同じ終了費用へ加える。6枚の順序は階乗進数で番号にして既存の720状態の表を参照する。

係数0.5/1と、穴埋め紙の据え置き確率・無料被覆の補正との組合せを比較する。研究用の既定係数は0。保存設計と定数乱数の一様模擬注文を使い、実注文列は参照しない。可視性を独立再生で検査し、全時計をCLOCK_SCALE倍する。
