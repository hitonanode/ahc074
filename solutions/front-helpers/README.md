# 補助紙を浅い列へ移して新しい共有を作る

改良元: solutions/post-prune。必須補助紙の制御と共有候補の列挙は solutions/head-weave から。

既存の商品紙2枚を先頭列の紙と交換し、取り出しやすく、ハンドル窓を邪魔しにくい補助紙にする。その2枚を使えば表示できる、汎用比較器だけでは表示できない商品対を探す。共有1組と単独2枚を組み直すか、2枚の商品担当を交換し、紙の枚数と共有数は保つ。移動した4枚自身の担当は変更しない。

先頭列との単独交換を設計費用で順位付けし、上位24候補から重ならない2交換を試す。各交換先の色を保ち、列ごとの両色を維持する。移動で深くなる紙の取り出し費用とハンドル穴、補助紙の追加需要と配置返却、汎用紙の最小操作を数えて組を選ぶ。模型が正でも最良の非自明案を検証し、模型の誤差を観察する。

研究用。main.cpp単独では新しい設計を行わない。probe.cppが保存設計を読み、固定乱数の一様な模擬注文で通常案と比較する。隠された実注文は読まない。模擬の最初の1本は各移動紙の可視性と最終順序も独立に照合する。CLOCK_SCALEを適用する。
