# 操作2個をまとめて削除する後処理

改良元: solutions/post-two。

操作を1個ずつ削除する後処理に、2個を同時に削除する候補を追加する。一方が他方の可視性を作っている場合、どちらかだけを消すと不正でも、両方を消すと有効になる可能性を調べる。開始順から全操作を再生し、可視性・要求表示・汎用層とキャップの順序・穴埋め紙の到達可能性を検査した上で、従来と同じ終了評価が下がる変更だけ受理する。

研究用probeでは削除を差し込み先探索の前後に置く条件、すべての操作の差し込み先を見直す条件、後処理候補を1案に減らす条件を比較する。post_joint_mode のbit0/1は前/後の2操作削除、bit2はすべての操作の差し込み先探索。分類用のbit3/4は同じ紙/同じ列だけの削除、bit5/6は少なくとも一方/両方が前注文から残った紙である削除へ制限する。post_pair_trialsは2操作削除の試行数、post_pair_acceptsは受理数。設計と時計は改良元と同じ。
