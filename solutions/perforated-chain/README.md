# 同じ注文で更新される列の色をまとめて標本化する

改良元: solutions/perforated-eight。

補助穴を設計するときの8標本を、独立な色の抽選から、簡単な列状態の模擬へ変更する。1商品を選んでその穴の列を全て要求色へ変え、別に2商品を選んで担当列を穴要求の多数色へ戻す。返却頻度は元の設計模型と同じ2倍。これにより、同じ注文で更新された窓どうしの相関も標本に入る。

4096回を初期化に使い、その後8回おきに1状態を採り、全商品×8標本を作る。乱数seedは731000003で固定。区間DP、利益係数0.5、紙の先頭候補の固定、1穴ずつの変更、時刻1.49秒の打ち切りは改良元と同じ。

注文制御とその他の設計は改良元と同じ。追加のstderr指標も同じ。main.cpp単独で提出でき、全時計へCLOCK_SCALEを適用する。隠された注文列は使わない。
