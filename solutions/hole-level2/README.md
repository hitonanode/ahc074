# hole-level2

改良元: solutions/hole-level

前の注文で持ち上げた専用紙と、前の注文の穴埋め紙を、列へ戻す代わりに、新しい目標の段付き穴埋め紙として直接移せるようにした。

## 変更点

- 前の注文の専用紙 x は、どうせ一番上からどかす紙なので、列へ戻す 1 手の代わりに新しい目標の穴埋め紙の段へ移せば、列から紙を取ってくるより 1 手安い。浅い列の紙は対の浅いハンドルの穴を覆うのに向く。計画探索の「前の専用紙の戻し方」に、この選択肢（ret_mode 3）を足した。
  - 段は hole-level と同じく、x の色が目標と合わない最も深いハンドルの次。ただし x が新しい専用紙 D の列 l のハンドル h_l を覆うと D を掘り出せなくなるので、段は l + 1 以上にする。覆う穴がなければこの計画は捨てる。新しい目標の紙が x 自身なら使わない。
  - x を段へ移す前に、見えている前の穴埋め紙を先に片付ける（x が上に来るとそれらを隠すことがあるため）。
- 前の注文の穴埋め紙も、新しい目標の穴を覆えて、省ける掘りが 2 手以上なら、列へ戻さずに新しい段へ直接移す（fret_mode 3）。すでにその段にあるなら動かさない。使えないものは列の下端へ戻す。
- これらで先に覆ったハンドルは、新しく列から取る穴埋め紙の対象から外す。新しい穴埋め紙は、先に置いた深い段の穴埋め紙のハンドルに届くものを使わない（DP の候補にもこの条件を足した）。
- 計画の組み合わせ: 前の専用紙の戻し方は 下端 / 上端 / 穴埋め紙（新しい目標に専用紙があり、前の紙と違うときだけ）、前の穴埋め紙の戻し方は 下端 / 上端（上端へ戻せる紙があるとき）/ 新しい段へ（前の穴埋め紙があるとき）。
- 焼きなましの打ち切りを、プログラム開始から 1.2 → 1.15 秒にした（計画が増えて注文の処理が重くなった分）。

## パラメータと指標

- 環境変数（hole-level のものに加えて）: `PREV_FILLER`（既定 1。0 なら前の専用紙を穴埋め紙にしない）、`REFILL`（既定 1。0 なら前の穴埋め紙を新しい段へ移さない）、`HUB_TL`（既定 1.15）。
- stderr に足したもの: `prev_fillers_used`（前の専用紙を穴埋め紙にした計画が採られた注文の数）、`refill_plans_used`（前の穴埋め紙を新しい段へ移す計画が採られた注文の数）。
