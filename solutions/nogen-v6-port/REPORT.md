# v6移植と時間配分の中間結果

## 移植の整合性

nogen-map9kの時間ガード、DesignStore v2、ヘルパー共通後処理・候補拡張、radix sortをv6へ移植した。窓63は承認済みキャップ規約を別に監査し、異色所有者ペアの禁止を削除した。窓0–62の全所有色と非cap紙191枚の所有者を検査し、LOCAL_BENCHでは違反時assertする。

`20261106-103039_nogen-v6-port` の通常500件の紙192枚は、元v6 run `20261106-100659_ng-product-v6-fast` と500/500件一致。元v6要求処理を復元した `20261106-103524_nogen-v6-reference` は同設計上でstdout全体が元v6と500/500件一致した。したがって、cap規約変更とDesignStore移植自体による設計・要求の変化はなかった。
