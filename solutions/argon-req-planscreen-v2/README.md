既に生成済みの計画のうち、通常の編集対象から外れたものを、探索終了後に削除だけの安い編集で調べる。DP計画だけでなく、通常の返却方法・チェーン・ヘルパー計画にも同じ処理を適用する。既存の候補収集関数で同じ積層・同じ移動紙列の家族をまとめ、raw評価値の順に処理する。元の上位候補は押し出さない。

初期評価値が現在の勝者から1以内・別積層・通常編集キャッシュなしの候補だけを対象とし、削除編集後の完成評価値が勝者以下の場合だけ既存ejectで仕上げる。既存候補・予算・目的関数を変更せず、追加のDPや局所状態価値の仮実行は行わない。

raw_joint_trials/promisingは追加の削除編集数と競合できた数（名称をDP版と共通化）。仕上げの採用数・評価改善・手数差は既存のvalue_seed_*に含む。全ログ、実験スイッチ、プロファイラ、CLOCK_SCALE、LOCAL_BENCH、DesignStore、目次・節は保持する。
