# gen-bf

改良元: solutions/gen-cb2（系統は hub8 → gen-cb → gen-cb2 → gen-bf）

gen-cb と gen-cb2 には README がないので、hub8 からの変更をまとめて書く。gen-bf 自身の変更は最後の節。

## hub8 → gen-cb → gen-cb2 の変更（汎用層を相補ブロックに）

- 汎用層の MDP グループをやめ、G を連続した窓のブロック S_b（`CB_S` = 4 窓前後）に分ける。各ブロックは色の模様 Y_b を持つ（初期値はランダムで、焼きなましで変える）。ハンドル窓は hub8 と同じく最後の H 窓。gen-cb / gen-cb2 では、ブロックごとに Y_b の紙と白黒反転 ~Y_b の紙の 2 枚を置き、上にある方がブロックの表示を決める（1 手で反転）。
- 整合: 対 (u, v) の 2 目標が違う窓のうちブロック b に入るものを D とすると、D 上で A_u が Y_b か ~Y_b に一致していれば、ブロックの向きで u と v のどちらも表示できる（D 上で A_v はもう一方になる）。このとき、触れたブロック 1 つにつき注文あたり平均 0.5 手で済む（穴の数によらない）。
- 汎用層は任意の模様を出せないので、全目標に専用紙か対の紙を持たせる（対の数 = 256 − 専用紙の枚数）。初期の対は「整合しないブロックの数」、次に距離の小さい順に貪欲に選び、余った単独どうしも対にする。
- 焼きなましの見積り: hub8 の「G の穴 1 個 0.45 手」の代わりに、対が触れるブロック 1 つにつき 0.5 手、整合しないブロック 1 つにつき罰 30。近傍に Y_b の 1 ビットの反転（各反復で確率 5%）を足した。Y_b は焼きなましの後に確定し、汎用層の紙はその後で作る。
- gen-cb2: H を 34 → 36 にし、焼きなましの後に整合しない対が残っていたら、その対の片方を別の単位の目標と交換して直す（交換後の両方の単位が整合し、自分の列のハンドル窓で色が一致するもののうち、見積りが最小の交換）。ブロック間で窓を動かす近傍も実装したが既定では使わない。
- 注文: 専用紙の G の穴が触れるブロックごとに、D 上で A_u に近い向き（Y_b か ~Y_b）にしてから、hub8 と同じく専用紙を掘り出して持ち上げ、ハンドル窓の穴を掘りで合わせる。

## gen-cb2 → gen-bf の変更（土台 + 反転紙）

- 汎用層を、G 全体で色 Y（各ブロックの Y_b を並べたもの）の土台 F 1 枚と、ブロック b だけで ~Y_b の反転紙 F_b を各 1 枚にした（ブロック数 + 1 枚。gen-cb2 は 2 × ブロック数）。浮いた紙は専用紙に回す。
- F_b が F より上にあればブロック b は ~Y_b（オン）、下にあれば Y_b（オフ）。最初は F が一番上で、反転紙はすべてオフ。
- 向きの合わせ方（set_blocks）: F より下の反転紙は隠れていて動かせないので、オンにすべき反転紙のうち最も深いもののすぐ下へ F を動かす（1 手で複数をまとめてオン）。F より上でオフにすべき反転紙（F が通り過ぎたものを含む）は、1 枚ずつ F のすぐ下へ移す。
- 紙の内訳は H = 36、`CB_S` = 4 で、汎用 8 枚（7 ブロック）、専用 184 枚（72 対）。

## パラメータと指標

- 環境変数: `HUB_H`（既定 36）、`CB_S`（ブロックの窓数の目安、既定 4）、`CB_KB`（触れたブロック 1 つの見積り、既定 0.5）、`CB_KI`（整合しないブロックの罰、既定 30）、`CB_YFLIP`（Y_b の反転を試す確率、既定 0.05）、`CB_REPAIR`（整合しない対の修復、既定 1 = する）、`HUB_TL`（焼きなましの打ち切り、プログラム開始から 1.2 秒）。そのほかは hub8 と同じ。
- stderr: `blocks`（ブロック数）、`uncovered`（専用紙も対の紙もない目標の数。0 のはず）、`inconsistent_pairs`（整合しないまま残った対の数。残ると誤りになる）、`repaired_pairs`（修復した対の数）、`model_touched_blocks`（見積りの、1 注文あたりの触れたブロック数）、`flips_per_ded`（1 注文あたりの汎用層の手数）、`touched_blocks_per_ded`・`g_holes_per_ded`・`handle_holes_per_ded`（1 注文あたりの触れたブロック数・G の穴の数・ハンドル窓の穴の数）。hub8 の `gcare_*`・`model_g_holes`・`gen_moves_per_req` はなくなった。
