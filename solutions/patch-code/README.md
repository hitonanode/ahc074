# 比較器の途中に置く相補的な補修紙

改良元: solutions/as6-canon。

6枚の比較器に、同じ窓だけを覆い、白黒が反対の2枚を加える構造を調べる。補修紙の窓と色を商品集合に合わせて同時に選ぶ。従来の2窓の補修紙から広げ、異なる対が違う窓で補修紙を利用できるようにする。
補修紙を加える分、専用紙は183枚、共有する対は73組になる。古い構造への切り替えは行わない。

`probe.cpp` は保存された設計の汎用窓を使った構造の研究用。表示できない対を救う条件を比較グラフから判定する。補修窓を除いたグラフが閉路を持たず、入次数0の頂点を全て除いた残りの補修窓で色が合うことが条件になる。2商品の残りの和集合では、相補紙のいずれか一方の色と一致する必要がある。
探索時には新たな対の汎用表示費用を仮定して候補を絞る。最終的な候補は8枚の順序と可視性を使って価格を測り直す。この近似値を公式スコアとは扱わない。
`main.cpp` は比較元のコピーで、提出用の新構造はまだ組み込んでいない。時計は `CLOCK_SCALE` を掛ける。結果は trial_log.md に記す。

`exact.cpp` は8枚の全40320順序と合法な移動のグラフを作り、各商品対への多始点BFSで価格を計算する。全順序を一様にする模型に加えて、補修紙2枚が比較器より下にある1440順序から使う費用と、表示後に2枚を下へ戻す費用まで含む往復費用も調べる。下に置く模型では、従来の対には6枚の費用をそのまま使う。
