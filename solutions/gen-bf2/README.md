# gen-bf2

改良元: solutions/gen-bf

汎用層の向きを合わせるとき、土台 F を上へも動かせるようにした。設計と、それ以外の操作は gen-bf と同じ。

## 変更点

- gen-bf では F を下へ（オンにすべき最も深い反転紙のすぐ下へ）しか動かさず、F より上でオフにすべき反転紙は 1 枚ずつ F のすぐ下へ移していた。
- F を上へ動かすと、通り過ぎた反転紙は F の下になり、1 手でまとめてオフになる。そこで F の扱いを次の 2 つから選ぶ。
  - F を「オンにすべき反転紙のうち最も深いもののすぐ下」（オンにすべきものがなければ一番上）へ 1 手で動かす。今の F より上の位置なら上へ動くことになる。
  - F を動かさない。オンにすべき反転紙がすべてすでに F より上にあるときだけ選べる。
  - 「F を動かす 1 手 + その後も F より上に残る、オフにすべき反転紙の数」と「動かさないときに F より上にある、オフにすべき反転紙の数」を比べ、少ない方を採る（残った反転紙は gen-bf と同じく 1 枚ずつ F のすぐ下へ移す）。F が見えていない（全ブロックがオン）ときは F を上へは動かさない。
- オンにすべき反転紙が F より下にあるときは、gen-bf と同じく F を下へ動かす。
- この選び方で、汎用層だけの BFS の最小手（solutions/gen-cb/bf_opt.cpp）とほぼ同じ手数になる。

## パラメータと指標

- パラメータと stderr の指標は gen-bf と同じ。
