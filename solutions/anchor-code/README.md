# 汎用層だけで表示する商品を組み込む

改良元: solutions/as6-canon。`main.cpp` は比較元のコピー。

汎用6枚の順序で商品そのものを表示できるように窓の割り当てを設計し、その商品の専用紙を省く構造を調べる。最初は6商品を輪に並べ、6枚の循環順序を各商品に対応させる。6商品の色が円周上でちょうど2回変わる窓は、変わり目の2枚だけを逆の色で印刷すればよい。これは通常の比較器と同じ形だが、選んだ6商品は汎用窓を全て表示できる。

専用紙を省いた商品は、全てのハンドル窓を別に合わせる必要がある。省いた紙を他の共有対の分割に回す利益と、この費用の両方を評価する。選ぶ商品のID、循環順序、汎用窓の集合を固定乱数の探索で選ぶ。研究用模型では実際の注文列を使用しない。

キャップ窓は専用紙なしでも正しくなるよう、汎用層だけで表示する商品を全てキャップの色が黒の商品から選ぶ。`probe.cpp` は循環上の商品と汎用窓を同時に探索し、残り250商品の65対と列を再設計する。6商品は全ハンドルの要求数に加え、汎用層の全窓を合わせる費用も数える。

`general.cpp` は1〜6商品に対し、それぞれに異なる汎用紙の順序を割り当てる。各窓は、その商品群で指定色を出す比較器の組と向きから選ぶ。商品のID・対応する順序・比較器・汎用窓を同時に探索する。比較用に商品数0でも同じ探索を実行できる。保存済み配置から始める場合は、現在の汎用表示に近い商品と順序を選び、必要な比較器だけを変更してから最適化する。

`design.hpp` は `build.py` で比較元から作る研究用の設計器。専用紙を持つ商品数を変え、持たない商品も全ハンドルの色要求へ加える。`design_cost` は列・穴・汎用操作の模型費用、`optimistic_cost` は専用紙を持たない注文の持ち上げ・返却が各1手不要になると仮定した値。これらは実際の操作列の費用ではない。
