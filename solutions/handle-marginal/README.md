# 穴埋めを含む取り出し窓の限界費用

改良元: solutions/perforated-eight。

従来の紙の返却順と終了状態の費用は、各取り出し窓に穴のある商品の頻度をそのまま使う。本研究では、他列の紙による穴埋めを考慮し、列先頭の色を変えたときに残る修正費用の差を計算する。各商品と独立な列色16標本で、先頭白黒候補を使う区間DPを解く。

穴のある商品の色ごとに限界費用を集計する版と、穴のない商品への供給効果も含めて白黒の費用差だけを補正する版を比べる。前者は元との混合率0.25/0.5/1、後者は0.5/1。全需要を0.75倍する対照も置く。極端な負需要は0.001へ丸める。紙の模様・共有・列配置は共通。

設計の標本と独立した16本の模擬注文で比べる研究用。全表示と1本の全操作の可視性を確認する。実際の隠された注文列は読まない。全時計はCLOCK_SCALE倍。main.cppは比較元で、研究はprobe.cppから行う。
