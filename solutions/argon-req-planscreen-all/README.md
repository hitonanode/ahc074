既に生成済みの全種類の計画のうち、通常の編集対象に入らなかった候補を、探索終了後に安い削除編集で調べる。元の候補一覧を押し出さず、既存の同族判定で同じ積層・移動紙列をまとめる。削除前の足切りが、削除で大きく短くなる計画を捨てていないかを調べる。

raw値差上限は1e30、削除編集後の値差上限は0。後者を満たす候補を既存ejectで仕上げ、合法で完成評価値が改善する場合だけ採用する。追加DPは作らない。

raw_joint_trials/promisingは追加削除編集と追加eject対象の件数。採用数・改善値・手数差は既存value_seed_*へ加算する。全ログ、実験スイッチ、プロファイラ、CLOCK_SCALE、LOCAL_BENCH、DesignStore、目次・節は保持する。
