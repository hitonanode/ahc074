# ペース配分も軽い計画も使わない版（ジャッジでの時間の測定用）

改良元: solutions/esw-pace。

注文ごとの手間を常に最大（effort 0）にし、ペース配分と軽い計画を使わない。どれだけ遅くなっても全注文を通常の計画で処理する。それ以外は esw-pace と同じ。

- 目的: ジャッジに出して、高速化した注文処理（esw-fast）と 0.90 倍の設計の締め切りで、実際に何秒かかるかをケースごとの実行時間で見る（2 秒を超えれば TLE）。esw-nofb（高速化の前の版で同じ測定）と並べると、高速化がジャッジでどれだけ効くかも分かる。
- 手元の評価（LOCAL_BENCH）では、esw-pace も常に最大の手間なので、両者の動作は同じ。
