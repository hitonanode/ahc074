# 単独紙の利益を全列まとめて計算

改良元: solutions/tight-thirty-eight。

先頭紙の再割当で使う単独商品の利益表をまとめて計算する。単独商品の穴は列より深い窓の集合なので、補助紙の最後の不一致より浅い列では被覆利益が同じになる。また単独の補助紙を深い列へ伸ばすときは、不一致で有効区間をリセットしながら、誤色0個・1個の確率を更新できる。

既存の全候補個別計算と表の全要素を照合し、再割当後の全商品対・列・模型値を比較する。続いて独立模擬注文で表示・可視性・操作列の一致を検査する。入力末尾の注文は使わず、全時計はCLOCK_SCALE倍。研究用のfast_single_tablesは0が元、1が対象側、2が供給側、3が両方。
