# 先頭色による取り出し順の追加費用

改良元: solutions/post-two。

共有紙が片方の色にしかない列では、共有紙のない色を先頭にすると、先頭2枚の順が逆になる分だけ重み付きの取り出し深さが1増える。従来の取り出し模型は、共有紙を先頭にする最小値を使っていた。この差に、単独紙の色が先頭である確率を掛けて加える。先頭確率は返却を含むreset-headの式を使う。

確率は焼きなましの4区間の最初に更新し、区間内は物理窓ごとに固定する。費用は40倍の整数へ丸めて差分へ加える。列ごと移動する場合は窓も一緒なので費用が変わらず、ハンドルだけの交換では交換先の窓の確率を使う。

研究用のcolor_rank_strengthは0・0.5・1・2を比較する。main.cppの既定は対照の0。probe.cppは同じ2000万回の設計、65000回の穴埋め山登り、4回の再割当、独立した模擬注文で比較する。VERIFY_RESET_COSTで差分と全再計算を照合する。全時計はCLOCK_SCALE倍。
