窓の割り当ての目的を gobj − λB にする。B はハンドル窓ごとの (256目標中の黒の数 − 128)² の平均。色が偏った窓をハンドルに選ぶことで、reset強度6が穴の少数色を安く評価する効果を活かす。as6-gproxyのB項だけを移し、対の差のばらつきS項は加えない。

λの既定値は0.001。LOCAL_BENCHでは環境変数 D30A_GBIAS で指定でき、0で無効になる。0.001と0.002を比較する。Bは公開されたバーコードから8バイトの部分和表として前計算する。補正は貪欲マッチング全体の費用から引く。対の整数キー、失う対による枝刈り、キャッシュは変更しない。GCCとClangの両経路に同じ補正を入れる。反復回数と乱数は親のままで、新しい時計読み・時間打切りはない。

stderrのgobj_before / gobj_afterは、従来と比較できるよう補正前の費用を保つ。LOCAL_BENCHで gbias_lambda（λ）、gbias_before / gbias_after（割り当て山登り前後のB）、gobj_bias_before / gobj_bias_after（補正後の探索目的）、handle_minority_after（選んだハンドル窓の少数色割合の平均）を追加する。既存のCLOCK_SCALE、DesignStore、@paper/@ops、段の目印・目次、プロファイラと環境スイッチを保持する。

割り当て山登りは最良状態を復元して返すため、終了時の指標もその最良状態のmaskから計算する。探索の最後に受理した状態のhmは診断に使わない。
