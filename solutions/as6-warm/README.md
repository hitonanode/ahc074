# as6-warm: 初期の重なりを、架空の注文で慣らした状態にする

改良元: solutions/as6-cap38p0

## 変えたこと

- as6-cap38p0 の出力では、最初の注文がふだんより重い（seed 0〜399 の平均で、注文 0 が 14.1 手、注文 0〜11 が 11.7 手、注文 200 以降は 10.37 手）。最初の 25 注文で、1 ケースあたり約 18 手（スコアの約 0.17%）余分にかかる。
  - 設計した順の重なりから始めるので、穴埋め紙が列の外になく、各列の一番上の色と汎用紙の順も印刷の順のままになるため。
- 初期の重なり（上から紙 0, 1, …）は、印刷の順で自由に決められる。
  - そこで、設計と補助表が終わった後、出力の前に、架空の注文 kWarmRequests = 64 件を注文処理（Solver::process）で処理する。
  - 架空の注文は、入力の生成と同じ規則で作る（一様、直前と同じ目標は出ない、乱数の seed は定数）。
  - 処理後の重なりの上から順に、紙を出力する。紙の番号は、出力での番号への対応表（out_pos）で変換する。as6-cap38p0 のキャップを紙 0 にする変換は、この対応表に含まれる。
- 本物の注文は、この慣らした状態から始まる。終わりに出す指標（fast_requests、post_saved など）は、慣らしの分を 0 に戻してから数える。

## パラメータと指標

- kWarmRequests = 64（環境変数 WARM_REQ で変えられる。実験用。-1 で慣らさない）。慣らしにかかる時間は約 0.01 秒。
- stderr: `warm_requests`（慣らした注文の数）、`warm_end_sec`（慣らしが終わった時刻、倍率込み）。
