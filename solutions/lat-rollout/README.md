# lat-rollout

改良元: solutions/imp-lean

計測用（`-DSIM_HARNESS` の模擬でだけ使う）。注文ごとの計画の選び方の取りこぼし（方策の差）を見積もるため、費用の小さい計画の候補 RO_K 個をそれぞれ後処理し、その後に乱数の注文 RO_H 個をこの方策で続ける試行を RO_S 回（候補の間で同じ乱数）行って、「手数 + 続けた注文の手数の平均 + 最後の状態の見積り」が最小の候補を選ぶ。環境変数 RO_K / RO_S / RO_H が 0 なら imp-lean と同じ。stderr の `rollout_changed` は、費用の最小でない候補を選んだ注文の数（1 列あたり）。
