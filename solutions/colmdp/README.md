# 列の部分列 MDP（colmdp）

改良元: solutions/esw-fixiter

[ChatGPT] の研究報告（hitonanode/ahc074 PR 115 の 2 節「列の部分列MDP」。ソースはなく、説明だけ）の方法を、esw-fixiter の注文処理に移植した。設計は変えない（注文処理だけの変更なので、`--design-from` で比べられる）。

## 何をしたか

改良元は、掘りでどかした紙や列へ戻す紙の差し込み先を adaptive_insert で選び、計画どうしを plan_cost（手数 + 穴埋め紙の費用 + adaptive_next_cost）で比べる。adaptive_insert と adaptive_next_cost の列の評価は「次の 1 注文」の期待手数（1 手先の模型）で、重み付きの深さ / P と、取っ手の色ごとの「その色の最初の紙の深さ × その色の穴の割合」の和。

この解法では、列ごとに小さな平均費用 MDP を解いて「列の並びの長期の価値」を求め、この 2 か所に混ぜる。

### 列の MDP（main.cpp の「Column MDP: long-run values of the order of a column」）

- **状態。** 列の紙を 4 種類にまとめる: 種類 = 2 ×（2 目標を担当する紙か）+（列の取っ手での色）。状態は、列の紙の種類を上から並べた列。
  - 種類ごとの枚数を n0〜n3 とすると、全部の紙を並べた状態は n! / (n0! n1! n2! n3!) 通り。
  - 今の設計では、列の紙はほぼ 1 色にそろっている（逆の色は 1〜2 枚）。そのため、状態は最大でも数万で、ほぼ全部の列（25 列中平均 24.9 列）が対象になる。
- **事象（1 注文あたりの率）。** 1 手先の模型と同じ単位にする。
  - 位置 i の紙が注文される。率は、その種類の紙の adaptive_weights の平均 / P。
    - 掘りは i 手。上の紙はどかされ、注文された紙は持ち上げられて後で戻るので、どちらも列のどこへでも入れられる。
    - 下の紙は相対順が変わらない。そこで次の状態は「π[i+1:] を部分列として含む任意の並び」とする。
  - 取っ手に色 b が要る。率は adaptive_holes[c][b]。
    - 最初の色 b の紙（位置 d_b）まで掘る（d_b 手）。その紙は一番上に残り、どかした紙はその下へ入る。
- **F と H。**
  - F(s) は、s を部分列として含む並び π の V(π) の最小。
  - H(s) は、そのうち先頭が s[0] と同じ種類の並びでの最小。
  - 「1 枚消す」DAG に沿って、長い列から短い列へ最小値を伝える（F はどの紙を消してもよく、H は先頭以外）。
- **価値反復。** g + V(π) = { Σ_i p_i [i + F(π[i+1:])] + Σ_b λ_b [d_b + H(π[d_b:])] } / W を、V = 0 から相対価値反復（毎回最小値を引く）で 8 回解く。
  - W は事象の率の和。列に紙のない色の項は除く。
  - 1 回目の V は「次の事象」の期待手数で、1 手先の模型（重みを種類ごとの平均にしたもの）を W で割ったものと同じ。V は 8〜16 回でほぼ収束する。
  - V は事象ごとの式なので、単位は「長期に払う手数」。1 手先の模型（1 注文あたり）より大きく、浅い列ほど大きい（列の事象の率 W が小さいため）。
- **番号付け。** 長さによらず全部の部分列（種類の並び）に番号を付ける。番号は、種類ごとの枚数のベクトル（混合基数）と、そのベクトルの並びの中での辞書順の順位で決める。
  - 順位の各項は「その位置から後ろの枚数」だけで決まる。そのため、1 枚差し込んだ列の番号を全部の隙間について 1 回の走査で求められる（ColumnMdp::insertion_indices）。
- **上限。** 列の紙 14 枚以下、全部の紙の並び 40000 以下、全部の部分列 250000 以下の列だけを対象にする。ほかの列は改良元の評価のまま。
- 前計算は init_adaptive の中で、注文の前に 1 回行う。手元（24 並列、倍率込み）で平均約 9 ms、最大約 40 ms。

### 使う場所（main.cpp の「Solver: column MDP values in the future-cost model」）

- **adaptive_insert（差し込み先の選択）。** 隙間ごとの評価を 0.5 × 1 手先の模型 + 0.5 × MDP の値 にする。その注文で掘る分の手数（need の項）は、改良元と同じく足す。MDP の値は、差し込みの種類で次のように取る。
  - 列へ戻す（前の注文で持ち上げた紙、穴埋め紙）: 戻した後の列の F。紙が列の外に出ていても（穴埋め紙など）、列にある紙の部分列として評価する。この注文でこの列を要求の色まで掘るとき（need）は、その色まで掘った後の H（ColumnMdp::fix）。
  - 持ち上げ・穴埋め紙・補助紙を取り出すための掘り（目標の紙は列から出ていく）: 目標の紙より下の並びの F。上の紙はこの後どれも掘られるので評価に入れない。
  - 取っ手の色合わせの掘り（目標の紙は一番上に残る）: 目標の紙とその下の並びの H。
- **adaptive_next_cost（計画の比較と後処理の状態の評価）。** 改良元の値をそのまま残し、各列の「列にある紙の並び」の F の 0.5 倍を足す。
  - 持ち上げた紙と穴埋め紙は列の外なので、部分列として評価する。
  - 番号は、adaptive_next_cost がもともと行う積み重ねの走査の中で求める。列ごとに直前に読んだ F を覚えておく。
- MDP の値は W を掛けずに（事象ごとの値のまま）使う。

## 環境変数（研究用。既定値が提出の設定）

- COLMDP（既定 1）: 0 にすると MDP を一切使わず、esw-fixiter と同じ出力になる。
- COLMDP_UNIT（1）: 1 は MDP の値を事象ごとのまま使う。0 は列の事象の率 W を掛けて、1 手先の模型と同じ「1 注文あたり」の単位にする。
- COLMDP_MIX（0.5）・COLMDP_KEEP（既定 1 − COLMDP_MIX）: adaptive_insert での MDP の値の重みと、1 手先の模型を残す割合。
- COLMDP_NEXTMIX（0.5）・COLMDP_NEXTKEEP（1）: adaptive_next_cost での同じ 2 つ。
- COLMDP_INSERT / COLMDP_NEXT（1 / 1）: 0 で、adaptive_insert / adaptive_next_cost では使わない。
- COLMDP_ITERS（8）: 価値反復の回数。
- COLMDP_CASES（15）: adaptive_insert のどの差し込みで使うかの和。1 戻し、2 出ていく紙のための掘り、4 取っ手の色合わせの掘り、8 同じ列の目標の紙の下への戻し。
- COLMDP_NEEDFIX（1）: 0 なら、この注文で列を掘るときの戻しも F で評価する。
- COLMDP_CTRL（0）: 対照実験用。正なら、MDP の代わりに 1 手先の模型をその倍率にする。
- COLMDP_MAXLEN（14）・COLMDP_MAXFULL（40000）・COLMDP_MAXSUB（250000）: 対象にする列の上限。

## stderr の指標

- colmdp_columns: MDP を使う列の数（25 列のうち）。
- colmdp_full_states / colmdp_sequences: 対象の列の、全部の紙の並びの数と、全部の部分列の数の和。
- colmdp_sec: 前計算の時間（倍率込み）。
