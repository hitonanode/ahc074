# 窓割当の貪欲マッチングと厳密最適値の差を測る

改良元: solutions/perforated-eight。main.cppは比較元。

保存した汎用窓の印刷について、距離26以下で共有可能な全商品対の費用を、窓割当と同じ係数1800・5・144で計算する。最安の順に71対取る貪欲法と、厳密な最小費用71対マッチングを比較する。

厳密計算は研究環境のBoostを使う。256商品へ114個のダミー頂点を加え、各ダミーは全商品と結ぶ。完全マッチングでは114商品がダミーを受け持ち、残る142商品が必ず71対になる。各辺に総費用より大きい共通の利益を加えて完全性を優先する。全頂点の対応、71対、貪欲以下の費用を検査する。

これは窓割当の評価式にどの程度の近似誤差があるかを調べる研究用で、提出版への変更ではない。隠された注文は読まず、CLOCK_SCALEを適用する。
