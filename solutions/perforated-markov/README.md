# 列先頭の色の相関を穴の設計へ入れる

改良元: solutions/perforated-fixed。制御は solutions/stay-cover。

各窓の先頭色を別々に引く代わりに、1注文の穴をまとめて目標色へ変え、返却で自分の列を多数色へ戻す確率過程から標本を作る。元の返却頻度2倍の模型を保ち、同じ注文で更新された窓どうしの相関を含める。

別の条件では、実際の制御で独立した4352注文を模擬し、最初の256注文の後、16注文ごとに列先頭の色を採る。その256状態から穴設計の標本を引く。穴設計は先頭候補を固定した区間DP、利益係数0.5で8または32標本。比較元は通常の独立8標本。

研究用。検査は生成に使わない乱数で16本、以前とは異なるseed120〜151。表示一致と各1本の可視性を確認する。時間を要する実状態生成はまず研究模型で効果を測り、提出用には未統合。main.cppは制御の比較元。CLOCK_SCALEを適用し、隠された実注文は読まない。
