# 穴埋め利益に合わせた列と窓の順序

改良元: solutions/reset-head。

研究段階。商品紙の共有と担当する窓を保ち、列を担当窓ごと別の深さへ移す。列の取り出し費用は変えず、紙が印刷する接頭部分と、穴埋め紙を差し込める区間を変える。元の設計の列交換は穴と取り出しの費用だけを使うが、本候補では先頭紙の穴埋め利益も含める。

各候補で穴の要求数、返却後の先頭色の確率、先頭候補の利益を全て再計算する。隣接する列の交換を繰り返す条件と、離れた列も交換する条件を比較する。受理するのは同じ目的を改善する変更だけ。

probe.cpp は保存設計から同じ2000万回の設計、65000回の穴埋め山登り、4回の一括割当を済ませた後で分岐する。独立した固定乱数の模擬注文を使い、入力末尾の注文は読まない。main.cpp は比較元のまま。全時計はCLOCK_SCALE倍。
