# 先頭利益を使った焼きなましの再始動選択

改良元: solutions/reset-head。main.cppは基準のコピーで、研究用のprobe.cppが再始動を比較する。

比較器を固定し、列・共有・ハンドル順の焼きなましを同じ合計2000万候補で1本、2本、4本に分ける。各開始は同じ保存設計で、乱数だけ定数から変える。通常の模型費用で選ぶ条件と、各候補の穴埋め山登り・一括再割当を済ませて先頭利益を引いた費用で選ぶ条件を比べる。後者は候補数だけ末尾の設計計算が増える。

設計を固定した独立の模擬注文16本で検査する。入力末尾の隠された注文は使わない。操作・表示検査を行い、時計はCLOCK_SCALE倍。結果はtrial_log.mdに記録する。
