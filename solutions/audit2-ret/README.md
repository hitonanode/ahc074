# audit2-ret

改良元: solutions/audit-mix

古い穴埋め紙（前の注文の穴埋め紙）を列へ戻す先に、上端も選べるようにした。紙の設計は audit-mix と同じ。

## 変更点

- 古い穴埋め紙を使い直す・その場に残す計画（fret_mode 3, 4 と run_joint の 5。選ばれる計画の大半）では、使わずに列へ戻す古い穴埋め紙を、常に列の下端へ戻していた。2 回目の監査（solutions/audit2-probe）で、同じ計画の中でその列をハンドルの直しのために掘る注文が 1 ケース 60〜80 回あり、そのうち 12〜28 回は戻す紙の色が合っていて、上端へ戻せば掘りが要らなかった。
- そこで、これらの計画に「hub7 の規則で戻す」版を足した（PlanOpt::fret_ret = 0）。hub7 の規則は、その列のハンドルが新しい専用紙の穴で、今の上端の色が目標と違い、戻す紙の色が合っていれば上端へ、そうでなければ下端へ戻す（どちらでも列の巡回順は保たれる）。
- 足すのは、列の上端から取った穴埋め紙が列の外にあるときだけ（上端より下から取った紙は、どちらの規則でも巡回順の前の紙のすぐ下へ戻るので同じ計画になる）。下端へ戻す元の計画も残し、計画探索で費用の小さい方を採る。

## パラメータと指標

- 環境変数 `FRET_RULE`（既定 1）: 0 で hub7 の規則の計画を足さない（audit-mix と同じ）。
- stderr の `fret_rule_used`: hub7 の規則で戻す計画が選ばれた注文の数。
