# gpt6pro-07-01-postprocess

改良元: solutions/gpt6pro-06-01-comparator（外部 agent gpt6pro-07 に gpt6pro-06-01 のコードを渡して改良させた 1 版目。コードは書き直されている）

## gpt6pro-06-01-comparator との差分

比較符号の汎用紙 6 枚（G = 36）、対の専用紙、ハンドル H = 28、穴埋め紙の区間 DP という考え方は同じで、約 900 行に書き直されている。主な追加は、選んだ操作列の後処理。

- 操作列を「紙 x を紙 y の直後へ」という形（アンカー）に直し、1 手の削除、2 手の同時削除、旧専用紙・旧穴埋め紙を戻す位置の変更を試す。後ろの操作の深さは再生時に計算し直す。
- 全操作を可視性つきで再生し、表示が正しく、汎用紙が連続した塊に戻せるなら、最終の重なり順が元と違っても採用する。
- 時間の扱い: 設計は約 1.10 秒。残りの注文数と CPU 時間から重い後処理を止め、さらに足りなければ列単位の安全な処理（1 注文 350 手以下）に切り替える。

## パラメータ

- M = 6、G = 36、設計 1.10 s、後処理モード 5。コマンドライン引数で変えられるが、評価では使わない（既定値）。

stderr: `moves`、`mean`（手/注文）、`design`（設計秒）、`elapsed`、`cpu`、`fast`（安全な処理で答えた注文数）、`joint`、`post_saved`（後処理で減った手数）、`post_changed`、`quick`、`M`、`G`。安全な独立ビット設計に落ちたときは `fallback = 1`。

## 移植について

出所は main checkout の other_agents/gpt6pro-07-barcode_solution_and_tests.zip の barcode_v1.cpp（ログは gpt6pro-07.md）。`#include <bits/stdc++.h>` を個別の include に置き換え、stderr の統計を `名前 = 数値` の行に分けただけで、アルゴリズムは不変。

時計の倍率 CLOCK_SCALE は入れていない（時間で打ち切る部分は、手元ではジャッジより約 1.1 倍多く探索する）。
