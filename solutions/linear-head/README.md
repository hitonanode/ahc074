# 先頭利益を表にして共有と列を再探索する

改良元: solutions/post-two。main.cppは研究用の基準コピー。

最後の先頭利益つき設計をさらに変える研究。現在の先頭色確率と商品配置を固定して、全ての互換商品対・単独商品・所属列について、担当商品の穴埋め利益と、先頭へ置いた際の穴埋め供給利益を表にする。表を使う探索中は、商品の穴の利益を足し、各列・各色で直接頻度が最大の紙の中の最大供給利益を加える。両側を線形化するため、変わらない配置では利益の二重計上があるが、差分の一次効果を使う。

紙の列交換・1枚移動・互換共有相手の交換を焼きなましで調べる。ハンドル順は固定する。各探索区間の最良候補を、先頭色確率・返却頻度・全紙の利益を更新した本来の非線形目的で検査し、改善した区間だけ採用する。列の両色と全商品の担当を保つ。

固定回数の設計と独立な模擬注文で比較し、隠された注文列は使わない。CLOCK_SCALEを適用する。提出用への統合と採否は模型の結果から判断する。

probe_path.cppは、表の目的が最良になる途中状態ごとにも本来の目的を計算し、最後の状態以外の改善も保存する。CHECK_LINEAR_PATHで切り替える。
