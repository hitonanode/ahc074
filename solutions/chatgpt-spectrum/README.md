# ハンドルの差分の偏りを窓の割り当てで評価する

改良元: `solutions/imp-combo`。

窓の割り当ての評価関数に、後で行うハンドルの並べ替えによる得を近似する項を加える。
通常の評価は選んだ 70 対のハンドル差分の合計に比例するが、同じ合計でも、
差分が少数のハンドルに集中していれば、その窓を深く置くことで対の紙の穴を増やさずに済む。
対の列より深いハンドルは、差分がなくても三角形の構造により穴だからである。

選んだ 70 対について、各ハンドル j で異なる対の数を δ_j とする。
ハンドルを δ の昇順で置き、対の列の深さを一様と近似すると、
ハンドルの重みを平均 1/2 の直線にした場合の並べ替えの得は
`Σ_{i<j} |δ_i - δ_j| / (2 H)` となる。
既存のマッチング費用から、この値を対の数 70 で割り、係数 0.25 を掛けたものを引く。
列の大きさ・対の配置・ハンドルの色などの制約を無視した楽観的な近似なので、
係数を小さくして用いる。

変更点は `assign_windows` のマッチング選択後の評価だけ。
対そのものを選ぶ貪欲法、選別のしきい値、後段の設計、注文処理、時間制限は改良元と同じ。
差分数のヒストグラムを使い、ハンドルごとの値をソートせずに偏りの項を計算する。
完全な 70 対のマッチングが得られない候補では、この項は加えない。

主なパラメータ:

- `SPECTRUM_STRENGTH` 環境変数: 上記の係数。既定 0.25。0 にすると新しい項を無効にする。
- `CLOCK_SCALE`、時間の区切り、固定反復数の環境変数は改良元と同じ。

追加の stderr 指標:

- `spectrum_strength`: 使用した係数。
- `spectrum_raw_gobj`: 返した窓の割り当てでの、偏りの項を引く前のマッチング費用。
- `spectrum_sorting_gain`: 返した割り当ての `Σ_{i<j}|δ_i-δ_j| / (2 H × 70)`。対数 70 で正規化済みで、係数を掛ける前の値。

この項は、同じ合計差分数の割り当てを区別するための仮説である。
実際のスコアの改善や、ハンドルの並べ替えだけで近似値を達成できることは保証しない。

## 評価の区別

通常の対話比較と、共通注文列による `SIM_HARNESS` 比較は [評価環境の説明](../chatgpt-study/README.md) を参照。後者では設計は解法ごとに異なり、補助紙表の初期化期限と注文処理の時間による軽量化を外す。通常の 2 秒制約下の性能とは別の研究用比較として扱う。
