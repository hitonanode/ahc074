# 汎用紙にも最初の取り出し窓を印刷する

改良元: solutions/mixed-front。制御の基準は solutions/post-repair。

汎用6枚と最も浅い列の商品紙2枚を混ぜ、最初の取り出し窓について汎用6枚への白・黒・穴の全729印刷を調べる。汎用操作と同時にその窓の色も合わせられる一方、商品紙へのアクセスを妨げる費用を数える。商品紙の印刷は固定する。

全8!順序の平均費用MDPを用いる。既存の商品要求が表示できない印刷は除外。元の印刷の相対価値から反復し、下界が最良の上界以上なら打ち切る。内部商品の持ち上げと即時返却は無料で、外部の穴埋め紙を含まない模型なので公式スコアとは区別する。

研究用。実際の注文列は読まず、CLOCK_SCALEを適用する。main.cppは比較元のコピーで、新構造は未統合。
