# 片方の商品だけを上から覆う補修紙

改良元: solutions/head-demand。研究段階の `main.cpp` は比較元のコピー。

汎用窓の小さな集合Sに印刷した補修紙を1枚追加し、商品用の紙を184枚・共有72対にする。共有対A/Bでは、Sに商品Bの色を印刷する。Aが補修紙の色とS全体で一致するとき、Aの注文だけ補修紙を商品紙の上に置く。Bは商品紙を上へ出せばよい。残りの汎用窓の違いだけを6枚比較器で表示するため、従来は整合しなかった対も選べる。

補修紙はハンドル窓を1つ持ち、その窓でもAと色を合わせる。研究模型ではその取り出し・配置・返却の合計を定数の費用として与える。補修紙のマスクと色、ハンドルとその色を固定乱数で探索し、汎用操作は6枚の全720順序からの平均で厳密に価格付けする。補修紙の位置による可視性や将来状態はまだ含まないため、模型の値は公式スコアではない。時計は `CLOCK_SCALE` 倍する。

`probe.cpp` は保存設計の窓と比較器を読み、共有対を選ぶ模型。`pair_model.hpp` は `solutions/patch-code/probe.cpp` から複製した入力変換・比較器の部品で、末尾の旧研究用mainは無効にして使う。実際の注文列は読まない。

`design.cpp` は補修紙の印刷を固定した後に、商品用184枚・72対と25列を設計し直す。比較用の185枚と同じ反復回数で設計するが、補修紙そのものが列を占める負担は省いた、有利な模型である。
