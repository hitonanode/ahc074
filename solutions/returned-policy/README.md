# 仮に返却した後の深さと色を終了評価へ加える

改良元: solutions/deficit-policy。係数はsolutions/returned-valueの別計画1199組から推定。

列外にある紙を、元の重み付き深さと先頭色の費用が小さくなる場所へ順番に仮挿入する。前後の深さ・色合わせの差を終了費用へ追加する。列ごとの作業範囲を最初に決め、挿入位置は後続の重みと最初の色の位置から計算する。実際の紙順や操作は変えない。

研究用probeでは、元/新係数0.5混合/全量/従来のdeficit-policy0.5混合を同じ設計で比較する。入力1600〜1631と独立な模擬8本。各条件1本で可視性と最終順を再生し、仮挿入の差分を全挿入候補の再計算とも照合。主な係数はlearned.json。main.cpp単独は元の係数で、新しい係数は提出用にしていない。実注文を読まず全時計にCLOCK_SCALEを掛ける。
