# 上位2案を後処理してから選ぶ

改良元: solutions/reset-head。

通常の計画、複数の穴埋め紙を組み合わせる計画、汎用紙へ補助紙を挟む計画から、終了順序が異なる上位2案を残す。従来は最良の1案だけに適用していた操作の削除と差し込み先の変更を、残した2案にそれぞれ適用する。後処理後の操作数・残った穴埋め紙の費用・次の注文の期待費用を比べて最終案を選ぶ。

紙の設計、初期配置、計画の評価式と時間配分は改良元と同じ。既存の1.8秒以降の軽量処理も同じ。全時計はCLOCK_SCALE倍。

post_alternateは2案目を選んだ注文数、post_candidate_callsは後処理した候補数、post_secondary_savedは元の最良案を後処理した場合より減った当該注文の操作数の合計。post_savedには最終的に選ばれなかった候補の後処理も含む。build.pyが提出用の単一ファイルを作る。結果と採否はtrial_log.mdに記録する。
