# 穴埋めの利益を共有の探索の途中から使う

改良元: solutions/post-prune。線形な先頭利益の表は solutions/linear-head から。

先頭の紙が他の商品の穴を埋める利益を、最後の配置調整だけでなく、共有相手と列枚数を決める探索の途中へ入れる。最初の通常探索を1000万または2000万候補で区切り、互換な全商品対・単独商品と列に対する利益を表にする。表を使って共有相手の交換、列交換、1枚移動を焼きなます。区間ごとに実際の先頭候補を選び直した目的を確認し、改善した区間だけ採用する。

研究用。main.cppは基準のままで、この設計はprobe.cppで調べる。比較元は2000万候補の通常探索、全条件に65000候補の穴埋め山登りと4回の再割当を加える。追加探索は1〜4区間、5万〜20万候補、初期温度0.1〜1.0、利益係数0.5〜1.0。区間の途中の良い候補も本来の目的で保存する。

保存設計の比較器を読み、固定乱数の一様な模擬注文16本で測る。隠された実注文は使わない。最初の1本は可視性と最終順序を独立に検査する。CLOCK_SCALEを全時計に掛ける。
