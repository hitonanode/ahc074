# 1回の探索で保存した候補から先頭利益で選ぶ

改良元: solutions/head-archive（紙の設計と制御の元はsolutions/tight-thirty-eight）。

列共有探索の後半2区間で、区間内の最良解を4回ずつ保存し、最大8候補を残す。各候補の列の返却頻度を再計算し、従来の設計費用から先頭紙の穴埋め利益を引いた値が最小の候補を選ぶ。その候補だけへ穴埋め山登り・一括再割当・追加穴・補助表を計算する。再始動は行わず、探索の乱数列も変えない。

時間の区切りは改良元と同じで、選択に使った時間は後続の山登りに使える時間から引かれる。全時計はCLOCK_SCALE倍。archive_countは保存数、archive_chosenは選んだ時点、archive_secは選択の秒数。main.cppだけで提出できる。
