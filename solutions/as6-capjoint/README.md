# as6-capjoint: キャップの窓を探索で選び、対・列を修復する

改良元: solutions/as6-cap38（Astra の solutions/astra-cap2/main.cpp を写したもの。調査の全体は solutions/astra-cap2/REPORT.md）

- キャップを出力上の紙 0 にして、最初から一番上に置く（as6-cap38p0 と同じ。初期設置の 1 手が要らない）。内部の番号は元のまま（汎用紙 0〜5、キャップ 6）で、紙の模様と操作の出力時に番号を変換する。
- 比較器の窓の割り当てで、汎用窓とキャップの窓を交換する手を加える（ハンドルの集合は変えない）。
- 設計の焼きなましの区間の間で、キャップとハンドルの交換を試す。新しいハンドルで色が違う対は、紙全体の列の交換か、対の片側の商品の交換で直す（全商品を 1 回ずつ担当、比較器の整合、各列に白黒両方、を守る）。列・穴・汎用層の模型の費用が下がれば採用する。
- 時間の区切りは as6-cap38 と同じ。

stderr の指標: `cap_map_moves`（割り当て中のキャップ交換の受理数）、`cap_tried` / `cap_accepted`（ハンドルとの交換の候補数と採用数）、`cap_swapped_units`（修復で採用した交換数）、`cap_model_gain`（模型の改善量 / 256）、`cap_window`（最終的なキャップの物理窓）。
