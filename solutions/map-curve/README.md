# map-curve

改良元: solutions/imp-combo（計測用のコピー。提出用ではない）

窓の割り当ての段（焼きなましと山登り）の時間を `MAPT` / 100 倍、設計の焼きなましと穴埋めの山登りの時間を `ANNT` / 100 倍、穴埋めの山登りだけをさらに `CLMT` / 100 倍にする。穴埋めの山登りの proxy の重み kW は `KW` / 100（既定 0.3）。補助紙の表の打ち切り（kHelperGiveUp）と軽量処理への切り替えはなくしてある（時間を延ばしても補助紙が消えないように）。`-DSIM_HARNESS` でビルドし、`SIM_SEQS=8` で模擬の手数 `sim_moves` を出して、計算量の伸びしろを測る。
