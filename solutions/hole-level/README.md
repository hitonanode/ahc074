# hole-level

改良元: solutions/search-bf2

穴埋め紙を、汎用層のすぐ下だけでなく、もっと深い位置（段）にも差し込めるようにした（段付き穴埋め紙）。設計と、それ以外の操作は search-bf2 と同じ。

## 変更点

- search-bf2 の穴埋め紙 X（列 c の紙）は汎用層のすぐ下に置くので、持ち上げた専用紙 D の穴のうち h_0..h_c の全部で目標と色が合う必要があった。
- 段: X を列 c'（c' ≤ c）の一番上の紙のすぐ上に差し込むと、その上にある列 0..c'−1 の紙はハンドル h_{c'}.. で穴なので、X は h_{c'}..h_c だけで見え、浅いハンドル h_0..h_{c'−1} には影響しない。そこで、X の色が目標と合わない最も深いハンドルの次を段 c' にする（合わない窓がなければ段 0 = 従来の位置）。惜しく外れていた紙も穴埋めに使えるようになる。
- 採る条件は search-bf2 と同じ（覆う区間 h_{c'}..h_c で省ける掘りが「2 + 深さ」手より多い。深さは列の中での位置）。
- 1 注文で使う穴埋め紙の組は、覆うハンドルの区間 [c', c] が互いに交わらないものの中で、省ける手数の和が最大になるものを、区間スケジューリングの DP で選ぶ（区間が交わらなければ互いの列のハンドルを覆わないので、得が足し算になる）。DP を使わない貪欲（1 枚ずつ最良を選ぶ。深い段の穴埋め紙の上に、そのハンドルに届く紙は置かない）も残してある。
- 1 注文の穴埋め紙の上限を 4 → 8 枚にした。

## パラメータと指標

- 環境変数（search-bf2 のものに加えて）: `LEVELED`（既定 1。0 なら段を使わない）、`FILLER_DP`（既定 1。0 なら貪欲）、`MAX_FILLERS`（既定 8）。
- stderr に足したもの: `level_fillers_tried`（計画探索で試した全計画で、段 1 以上に置いた穴埋め紙の延べ数。採った計画だけの数ではない）。
