# 窓の役割交換と壊れた共有の修復

改良元: solutions/map-handle。

汎用窓と取り出し窓の交換で少数の共有対が使えなくなることを許し、その共有対の片方と単独商品を入れ替えて修復する。紙の所属列と、各列の単独・共有枚数を保ち、表示可能性と各列の両色を確認する。修復候補は実際の列・穴・汎用費用で比べる。

交換候補をすべて調べ、模型最良、または上位8案から先頭の穴埋め利益込みの最良を採る。壊せる対の上限は1〜3で比較する。共有を変えない交換だけでは動けない設計に、複合変更の余地があるかを見る。

研究用。main.cppは基準のコピーで、probe.cppが探索と独立模擬注文を行う。全表示・可視性・各商品の担当と共有の成立を検査し、実際の注文列は読まない。時計はCLOCK_SCALE倍。
