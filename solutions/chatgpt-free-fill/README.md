# chatgpt-free-fill

改良元: solutions/chatgpt-free-triples（紙の設計は solutions/imp-combo）。

隣接3列を自由な順序にする方策に、ブロックをまたぐ穴埋め紙を加えた実験版。
専用紙を取り出した後、その紙より深いブロックの見えている紙から、複数のハンドルをまとめて正しい色にできるものを選ぶ。
穴埋め紙はブロックの境界へ差し込み、その境界より浅いハンドルは元の紙で隠す。ブロック内部の自由な順序は維持する。

候補の価値は、同じ自由順序の修正手順で省ける操作数から、移動と次回返却の見積り1.7手を引いたもの。ブロック範囲が重ならない候補を最大3枚まで貪欲に選ぶ。前の注文の穴埋め紙は、次の注文の取り出しブロックを妨げず、実際に見える穴の色も正しい場合にその場へ残す。それ以外は元のブロックへ返す。要求された紙が穴埋めとして出ていれば、そこから直接持ち上げる。旧解法の計画器・フォールバックは呼ばない。

紙の設計、固定乱数seed、CLOCK_SCALE、ブロック内の探索は改良元と同じ。最初の上界が1手以下なら探索せず、後半は同じ自由順序の修正手順を使う。
追加指標 `free_fill_placed` は新たに使った穴埋め紙の数、`free_fill_returned` は返却枚数、`free_fill_windows` は新たに覆った専用紙の穴の数。`free_fill_kept` は据え置いた回数、`free_fill_direct` は穴埋め紙を直接要求紙として使った回数。
結果と採否は研究レポートおよび trial_log.md に記録する。
