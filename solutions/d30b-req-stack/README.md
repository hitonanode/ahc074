通常候補とexpanded候補の幅が同じ6のとき、同じ候補を2回収集・選別する処理を1回にまとめる。全計画の収集が終わった時点で、通常候補をexpanded候補へ1度コピーする。通常候補の後処理でタグや操作列が移動される前にコピーする。

expanded段のscreening・再探索・近接補正への候補追加は元のまま。候補の順番・同点処理・設計・反復数を変えない、出力同一の時間削減を狙う。幅が違う実験設定ではそれぞれの幅の収集を維持する。

LOCAL_BENCHのみ D30B_SHARE_COLLECTOR=0 で元の二重収集に戻せる（既定1）。新しい時計読み・時間打切り・stderr指標はない。既存のF3_*設定、ログ、profilerを保持する。
