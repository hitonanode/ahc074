# 3商品共有を目的に汎用紙の印刷を自由にする

改良元: solutions/reset-majority。研究の初期共有は solutions/triple-bound の理想化模型から読み込む。

汎用紙6〜8枚の各窓に、白と黒をどちらも含む全ての印刷を許す。2枚の比較という制約を外し、共有商品の表示順序、窓の印刷、共有相手、汎用窓とハンドル窓の選択を交互に変える。表示順序は全順列から不一致数に応じた分布で選び、印刷は選んだ順序への不一致を数えて決める。

単独・対・3商品共有の枚数を保ち、256商品を191−汎用紙数枚で覆う。途中は不一致を許すが、最後に表示可能な対と3商品を別に列挙する。印刷が任意でも、残った要求窓に誤った色を出さない紙を上から置く方法で可否を厳密に判定できる。全順列による判定とも照合する。

これは構造の研究用。実際の注文列は使わず、乱数seedは固定し、全時計にCLOCK_SCALEを掛ける。main.cppは比較元のコピーで、新構造は未統合。可視性を守る操作費用と列配置の再設計は、有望な印刷が見つかってから別途調べる。
