# astra-architecture

改良元: solutions/astra-structural-fast

任意の白黒穴ゲートを使う6枚の汎用層に対して、非線形窓の場所を移す2窓近傍を加える。紙の設計、可視性を保証する15比較窓、注文ごとの処理は改良元と同じ。

改良元は、最初に1窓を白黒それぞれ2枚以上のゲートへ変え、その後も少なくとも1窓の非線形ゲートを残す。このため、最初に選んだ窓が不適切でも、その窓を元の比較器に戻して別の窓に非線形ゲートを置く移動を、一窓ずつの改善だけでは実行できない。

この版では、現在の非線形窓を最後の2枚比較器へ戻し、別の窓で602種類のゲートを調べる。この途中の状態の良し悪しは判断せず、2窓の変更が終わった後の70対の費用で一括して採否を決める。候補が悪ければ両窓を元に戻す。最終設計には必ず非線形ゲートが残り、現解法との切り替えにはしない。

- 初回は改良元と同じく非線形ゲートを1窓に置く。
- 以後、3回の探索のうち2回を2窓の移動、1回を従来の一窓変更とする。
- 移動先は固定乱数で並べ替えた窓を順に調べ、同じ窓だけを繰り返さない。
- 汎用層の設計は経過0.75秒まで。時計は `CLOCK_SCALE` を掛ける。`DECODER_ITERS` を正にすると、診断用に探索回数を固定できる。
- 602候補の選別は改良元の近似順序を使い、上位4候補の費用は720状態の合法距離で厳密に計算する。移動の採否も同じ距離に基づく。

追加のstderr指標:

- `decoder_relocation_tried`: 2窓の移動を試した回数。
- `decoder_relocation_accepted`: 2窓の移動後の費用が改善して採用した回数。

設計の数学的な根拠は [任意ゲートの理論](../astra-structural/THEORY.md) を参照する。評価結果と採否は `trial_log.md` と今回の報告書に記載する。

## 可視性グラフの独立診断

`visibility_graph.cpp` は提出用解法ではなく、比較窓によって安全に動かせる紙を定めた720状態のグラフを全探索する診断用プログラムである。完全グラフ、1〜3本の独立辺を除いたグラフ、二部グラフ、閉路、星、最上位だけを動かす場合について、全点対の合法距離を調べる。

さらに固定乱数で作った4・8・16状態の目標集合について距離を集計する。この合成目標集合はバーコードの注文ではなく、列の取り出しや穴埋めの費用も含まないため、コンテストのスコアとして扱わない。出力を `visibility_graph.csv` に保存した。

```sh
g++ -std=c++23 -O2 solutions/astra-architecture/visibility_graph.cpp -o /tmp/visibility_graph
/tmp/visibility_graph
```
