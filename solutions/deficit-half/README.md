# 列へ戻る紙の負担を含む将来費用

改良元: solutions/tight-thirty-eight。係数の推定と独立入力の確認はsolutions/return-deficit、solutions/deficit-policy。

紙を列外へ出すと、その列の重み付き深さが一時的に小さくなる。列へ戻したときに復活する最小の深さを、計画の終了費用へ加える。単独紙a枚・共有紙b枚の最小重み付き深さはb(b−1)+ab+a(a−1)/2で計算し、全紙が戻った状態との差を256で割る。列内の紙順への係数は正の1を保つ。

24入力・1199組の別計画から推定した係数と元の係数を半々にしたものを使用する。穴費用1.666472、汎用層の下/上の穴埋め紙0.594776/0.691167、据え置き0.444391、無料被覆−0.100738、紙の組数0.010290、戻り深さ5.029860。正確な係数はweights.jsonと提出コードに保存。紙の設計と時間配分は改良元と同じ。全時計はCLOCK_SCALE倍。学習と選択に実際の隠された注文は使わない。
