既存の追加ejectを受ける価値付きDP計画について、eject後の積層が基準の完成積層と異なる場合に、共通のprocessから中立探索も最後まで行う。初期計画や編集・ejectは再実行せず、同じ開始状態と仕上げ途中の状態を渡す。途中の計画より完成値が悪化すれば途中結果を保持し、さらに基準の勝者の完成値を厳密に改善するときだけ採用する。計画ごとの既存の探索予算は変更しない。

F3_*、ログ・プロファイラ、CLOCK_SCALE、LOCAL_BENCH、DesignStore、@paper/@ops、目次・節名を保持。仮の完成経路を最終経路としてheavy traceへ出さず、外側の要求で選ばれた経路を出す。新しい環境変数はない。

seed_finish_trials/valid/better/gainは追加の中立探索数、有効数、eject済み途中計画を改善した数、その完成評価値改善合計。既存value_seed_*はejectと中立探索の後の候補を基準勝者と比較した結果になる。追加統計は静的なプロセス単位で、Solver内の配置を変えない。
