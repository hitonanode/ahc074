# 浅い2列を自由に重ねる厳密模型

改良元: solutions/head-excess。研究のMDP部品は solutions/module-lab から複製。`main.cpp` はまだ比較元のコピー。

保存設計の最初の2列、計6枚の紙を一つの部品にする。各紙の担当商品の色が共通する窓には自由に印刷し、最低1つの取り出し窓を残す。全ての不透明マスクを列挙し、全720順序で最適な平均費用を求める。三角形の配置も全候補の中で最適化し、単に列への割り当てを変える効果と区別する。

イベントは実際の256商品の要求頻度を使う。部品外の商品では、その商品紙が穴にする窓だけを合わせる。部品内の商品では、指定紙を可視にして持ち上げ、その紙の穴も直す。持ち上げと直後の任意位置への返却は無料という模型。部品外から持ってくる穴埋め紙は含めない。模型のイベントは商品一覧から作り、実際の注文列は読まない。

相対価値反復の上下界幅を出力する。全ての窓が少なくとも1枚で覆われる設計だけを使い、部品外の紙の色には依存しない。`exact.cpp` の引数は `profile.py SEED 0 2` で作った入力。時計には `CLOCK_SCALE` を掛ける。
