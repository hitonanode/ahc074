# Task 4: deval-ordered8

未使用seed 500–999の新規注文列1–7で、seven-wide比 **-0.0587 ± 0.0058%**。通常2000件の同時比較のjudgeモデル平均は旧SOTA比 **1.0768倍**、p99は **1.8657秒**（nofb **1.8697秒**）。時間条件は満たした。

## 最終解法

改良元は`solutions/deval-seven-wide`。窓割当て・焼きなましの探索回数と注文探索の幅を保ち、次の変更を行った。

1. 窓割当ての4組の閉包計算で、関係行列の展開を整数表からAVX2 gatherで行う。浮動小数点演算と選ぶ手は同じ。
2. 4つの焼きなまし分岐の後、通常の再仕上げと穴を保存する再仕上げを交互に2回ずつ行い、V16で全8候補から選ぶ。各回は現在の最良完成配置から始める。通常の追加仕上げはclimb25k＋再割当て1回＋穴あけ＋最終再割当て。穴保存ではclimbと前半の再割当てを省き、既存の穴から穴あけと最終再割当てを行う。自然な紙の模様を復元元として保持し、穴の復元も物理紙へ正しく反映する。
3. 最終設計の各列内で、同じ色の紙を既存のfiller需要込みの重み順にし、2色の混ぜ方を小さいDPで選ぶ。目的は `Σ w_k × depth_k / 256 + h_0 × first_0 + h_1 × first_1`。紙の番号とdedを対応して更新する。模様、担当注文、所属列は変わらない。注文列は使わない。

初期順序の簡易DPは約0.48 ms。列MDPで初期状態を選ぶ案と品質差がなく、後者には約9.60 msかかった。通常500件では改善のほぼ全てが最初の256注文にあり、その後768注文の差は−0.014 ± 0.141手だった。紙を印刷する時点なら列内の並べ替えに操作を払わずに済むため、望ましい順番へ近づくまでの手数を減らせる。

穴保存の2候補は学習用500件の59%で選ばれた。8候補版の仕上げ時間は約0.205秒で、seven-wideの7候補とほぼ同じ。追加のVと初期順序の計算を、窓割当ての高速化で賄う。

全て固定seed・固定回数。時間不足による軽量モード、設計時間上限、時刻による候補数変更はない。DesignStoreは初期順序を整えた最終設計を保存する。@paper/@opsと段の目印・目次を維持した。
