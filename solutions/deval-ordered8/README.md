窓割当て・焼きなましの探索回数は同じ。窓割当ての4組の閉包計算で、関係行列を既存の整数表からAVX2 gatherで展開する。整数計算だけの置換で、選ぶ手は同じ。

最初の4つの焼きなまし分岐を完成した後、現在の最良完成配置から「通常の再仕上げ、穴を保存する再仕上げ」を2組行い、V16で全8候補から選ぶ。通常の追加仕上げはclimb25k、再割当て1回、穴あけ8サンプル、最後の再割当て。穴保存ではclimbと前半の再割当てを省き、旧穴を初期状態として穴あけと最後の再割当てを行う。復元用の自然な紙模様を保持し、穴を復元する判断も物理紙へ反映する。

最後に、各列の同色の紙をfiller需要込みの重み順に並べ、2色の混ぜ方を小さいDPで決める。目的は、紙を取り出す期待深さと、各色の最初の紙までの修復深さの和。紙の模様・所属列・担当注文を保ち、紙番号とdedを対応して更新する。注文列を使わず、初期配置だけを改善する。

注文処理の探索設定は改良元と同じ。

探索量は固定。時間不足による軽量モード、設計時間上限、時刻による候補数変更はない。固定seedで動き、時計はCLOCK_SCALE倍。DesignStoreは初期順序を整えた選択済み設計を保存する。C++23の単一ファイルで、GCC/Clangを使える。

`dv_candidates`は完成候補数（8）、`dv_chosen`は採用候補の0起算番号。0–3は焼きなまし分岐、4/6は通常の再仕上げ、5/7は穴保存。`dv_*_sec`は焼きなまし・仕上げ・Vの累積時間。`initial_order_changed`は初期順序を変えた位置数、`initial_order_model_gain`はDP模型上の費用減、`initial_order_sec`は追加計算時間。@paper/@opsと段の目印・目次は保持する。
