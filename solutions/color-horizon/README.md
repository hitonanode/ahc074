# 色が更新されるまでの価値を終了費用へ入れる

改良元: solutions/tight-thirty-eight。

穴の色は次にその窓が要求されるまで残る。白黒2状態で要求確率をq0,q1、列の取り出しによる色更新率をrとすると、色の差による長期の費用差は、次注文の費用差をq0+q1+rで割った量になる。この近似を終了費用と列への返却位置へ入れる。式が直接表すのは先頭色の差で、色を直す深さ全体にも同じ倍率を使う部分は追加の近似。無料被覆の利益も同じ倍率にする。紙の設計と実際の直しに必要な手数は変更しない。

研究用の6条件は基準、全列1.5倍、全列2倍、rを担当商品率の2倍/1倍とする正規化、2倍の正規化と基準の半々。紙設計は全条件で同じで、独立な模擬16本を比較する。入力末尾の実注文は読まず、全時計はCLOCK_SCALE倍。main.cpp単独は基準の係数。
