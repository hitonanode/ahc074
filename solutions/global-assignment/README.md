# 列と取り出し窓を一括で割り当て直す

改良元: solutions/head-excess。研究段階の `main.cpp` は比較元のコピー。

局所的な2枚交換に加え、割当問題を解いて多数の紙や窓を同時に入れ替える。

- 共有関係とハンドル順を固定し、各列の単独・共有と白黒の枚数を保ったまま、全紙の列を割り当て直す。穴の費用は現在の要求数で接平面に置き換える。この費用は凹関数なので、接平面での改善は実際の模型費用も悪化させない。
- 各紙の列を固定すると、ある窓をある列のハンドルにしたときの穴の費用と取り出し費用は、その列と窓だけで決まる。25窓の割当問題を厳密に解く。
- この二つを交互に行い、最後に穴埋め紙の山登りを行う。

割当問題にはハンガリアン法を使う。商品対・汎用紙の印刷は固定する。`probe.cpp` は保存設計から模型を復元し、同じ初期順の作り方で紙を組み立て直して、固定乱数の注文で制御を比較する。実際の注文列は読まない。時計は `CLOCK_SCALE` 倍する。

研究用の緩和版では、色ごとの枚数を固定する代わりに、各列に最低1枚ずつ白黒を残す。元から共有紙に両色があれば、その条件も残す。他の枠は色を自由にして割り当て、取り出し費用が増えない範囲を広げる。

枚数も変える版は最小費用流を使う。取り出し費用の二次式を現在値で一致する凸な上界に置き換え、全枚数と共有枚数の費用を分離する。上界との差は0.0375×（全枚数の変化−共有枚数の変化）の二乗。色の条件は最低1単位を流す枝で保ち、穴の費用と合わせて全紙の所属列を決める。毎回、元の目的関数が悪化しないことを検査する。
