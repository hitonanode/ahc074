# 少ない汎用窓で3商品を共有する

改良元: solutions/triple-bound。比較の制御は solutions/post-repair。

汎用紙は6枚のまま、汎用窓を18〜38個へ減らし、残りを取り出し用の列にする。3商品の共通色だけを印刷した紙が、3商品の全てで比較制約を満たす場合に限って共有を許す。各商品の汎用操作費用は、6枚の全720順序からの合法な距離の平均を使う。

窓割当は通常の2商品共有の目的で25万候補・貪欲5万候補を探索。その後、単独・2商品・3商品と列・ハンドル順を一般化した探索で選ぶ。各列の両色・全256商品の担当・計192枚を守る。取り出しと穴の費用は元の近似模型で測るため、全体の値は正式スコアではない。全比較辺が残ることも検査する。

研究用。main.cpp単独は基準のコピーで、probe.cppが模型を検査する。実際の注文列は読まない。全時計にCLOCK_SCALEを適用する。
