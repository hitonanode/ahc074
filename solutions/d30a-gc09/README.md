設計が見積もる汎用層の操作費用を 0.9 倍する。初期化・焼きなまし・再割り当てに揃えて適用する。窓割り当てでは整数キーを保つため、汎用項は 5 のまま、ハンドル差の係数を 1800→2000、全窓差を 144→160、未対応対の罰を 10/9 倍にする。Clang と GCC の両経路を同じ式にする。V の GenericTable は変更しない。

LOCAL_BENCH の D30A_GC で実現率を指定でき、1 で元に戻る。範囲は整数キーの安全性のため 0.5〜1.5。窓の係数は整数に四捨五入する。

固定反復・決定的な乱数列を保ち、時間による打切りや新しい時計読みは加えない。CLOCK_SCALE、DesignStore、@paper/@ops、既存の指標・プロファイラ・切替・段目次を引き継ぐ。新しい stderr 指標はない。評価と採否は solutions/impla-notes/PROGRESS.md に記録する。
