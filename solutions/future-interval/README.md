# 注文後の状態を次の穴埋め区間で評価する

改良元: solutions/reset-head。

研究段階。元の方法で得た上位2個の異なる終了状態を、それぞれ操作列の後処理まで行ってから比べる。元の終了費用に加え、次の全256商品について現在の列先頭から穴をまとめて直す区間DPを解き、その期待利益を評価する。

各列の白黒の最初の紙と取り出す深さを使い、目的商品の穴だけを正しく覆う区間を列挙する。元の穴修正の見積りから、区間の配置・返却1.6手と取り出し深さを引いた正の利益を求める。区間が重なる利益を二重に数えない。元の線形な穴埋め需要の終了費用も、補正の強さに応じて除く。列への返却方法は元のまま。

補正係数0/0.1/0.25/0.5/1を保存設計と固定乱数の模擬注文で比較する。実際の次の注文は使わない。main.cpp の既定係数は0で、提出用には未統合。全時計はCLOCK_SCALE倍。

追加の比較では、DPを使わず上位2案を後処理するだけの条件も分ける。また、元の費用差が0.1/0.01/ほぼ0のときだけ再評価する条件を比較し、計算量を減らす。probe.cppは各ケースの最初の模擬系列で操作列を独立に再生し、可視性と終了順序を検査する。
