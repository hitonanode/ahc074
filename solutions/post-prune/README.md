# 返却操作を含む2操作をまとめて削除する

改良元: solutions/post-two。削除候補の選別は solutions/post-joint の研究から。

後処理の1操作削除の直後に、2操作を同時に消す候補を試す。少なくとも一方が、注文開始時に持ち上げられていた商品紙か、穴埋め中だった紙を動かす操作である場合に絞る。一方を戻す操作が他方の可視性を作っているだけなら、片方ずつは消せなくても、両方を消せることがある。

従来の後処理と同じ再生検査と終了費用で判定する。紙の設計・上位2案の保持・時間配分は改良元と同じ。全時計はCLOCK_SCALE倍。post_pair_trialsは同時削除の試行数、post_pair_acceptsは受理数で、最終的に選ばれなかった候補の後処理も含む。
