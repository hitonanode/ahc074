# 設計と注文処理の重複計算を削減する

改良元: solutions/tight-thirty-eight。計算短縮はsolutions/post-fixed、solutions/move-span、solutions/head-singles。

後処理の操作編集列・一時的な紙順を固定長配列にし、使用中の要素だけコピーする。紙の移動では両端の間だけを更新し、紙番号から位置への表を維持する。単独商品の先頭紙利益では、同じ穴の接尾区間の計算を共有する。浮動小数点の加算順と候補選択は改良元と同じ。

提出時は固定長配列・位置表・対象側の利益共有を使用する。FUSED_RESEARCHは独立模擬による一致検査だけの切替。紙の設計方針、候補数、時間配分、穴係数0.38は改良元と同じ。全時計はCLOCK_SCALE倍。
