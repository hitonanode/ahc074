# 汎用の比較窓を取り出し口にする追加列

改良元: solutions/reset-majority。

単独の商品紙を数枚、汎用6枚の直下に集める。これらの商品紙は汎用の全窓と最終窓だけを印刷し、通常の取り出し窓25個は全て穴にする。

取り出す際は、ある比較窓を覆う汎用紙2枚を目的の商品紙の直下へ順に移す。比較窓から追加列の先頭が見えるので、目的の紙より上の商品紙を列の末尾へ移してから、目的紙を最上部へ持ち上げる。残る汎用6枚は再び連続する。2枚の選び方と順序は汎用状態の将来費用で決める。

追加列に移す商品は、通常列で節約できる取り出し費用と、新しく増える穴の費用から選ぶ。追加列の深さと、入口を開く2手も費用に含める。通常列には両色を残す。

`screen.cpp` は保存済み設計で追加列の枚数1〜8を比べる模型。`probe.cpp` は選んだ紙を追加列へ移し、1枚・2枚の場合を独立した模擬注文で比較する。操作は可視性を検査して再生し、各注文後の表示と列の配置条件も確認する。

操作制御は `main.cpp` に実装している。追加列の注文では古い紙と穴埋め紙を戻してから取り出し、通常の穴埋めを行う。追加列の紙は通常列の穴埋め紙にはしない。操作列の短縮後も、追加列は汎用層の下・通常列の上に保つ。提出用の設計部分から追加列を有効にする処理はまだ接続していない。将来の実注文は参照しない。
