# lean-a

改良元: solutions/imp-lean

リファクタリングで削れるかを見る切り分け。注文ごとの計画の候補のうち、外しても最良の費用がほとんど変わらないもの（seed 0〜3 で 1 ケースあたり 0〜4）を除き、関係するコードを消した。

- keep（持ち上げた紙が要求の紙なら上に置いたまま）: 外したときの増分 0
- fret_mode 2（古い穴埋め紙を一番上の罰なしで全部戻す）と 3（害がなくても残さない）: 0.5〜3 と 0。fret_mode 4 は「害がなければ残す」を常に行う
- fret_ret 0（戻すときに一番上の罰なし）: 2〜4
- merge_double_moves（同じ紙を 2 回動かす手の合成）: 後処理が同じ手を見つけるので 0
