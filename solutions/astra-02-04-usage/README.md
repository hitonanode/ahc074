## 改良元との差分

- 紙の使用頻度の学習: 設計の候補ごとの内部シミュレーションの注文列を「乱数 64 注文 + 256 商品の順列 2 周」に変え、1 周目で実際に上層へ出した紙の回数 u_k を数えて重み w_k = 0.1 + u_k とする（グループ内で紙を戻す位置を、Σ w_k · 深さ が小さくなるように選ぶ重み。03 までは設計時の見積りから作っていた）。2 周目の手数で候補を比べる。
- 商品を独立に乱数で選ぶ代わりに全商品を一巡させるので、評価が特定の商品に偏らない。
- それ以外（構造、ビームサーチ、構成の候補、幅）は 03 と同じ。
