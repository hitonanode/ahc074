# 操作の削除と差し込み先の変更を同時に行う

改良元: solutions/post-prune。

通常の後処理の後、前注文の商品紙や穴埋め紙を動かす操作について、差し込み先の変更と別の操作1個の削除を同時に試す。片方ずつでは表示が崩れるが、残す紙に削除した操作の役割を受け持たせる候補を探す。可視性、表示、次注文に必要な配置条件を全て再生検査し、従来と同じ終了費用が減った案だけを採用する。

研究条件は、削除した操作の差し込み先へ移すだけ、元の後処理と同じ全差し込み先、動かす紙が同じ列の場合だけの3通り。main.cppの既定は1番目。保存設計と固定乱数の模擬注文を使い、実注文列は読まない。模擬の最初の1本は可視性と最終順序も独立に照合する。

rewrite_trialsは試した組合せ、rewrite_acceptsは受理数。rewrite_same_columnとrewrite_same_paperは受理した組合せが同じ列・同じ紙だった数。未選択の計画も含む。CLOCK_SCALEを全時計に掛ける。

追加研究では、候補の最終表示だけを双方向リストで先に計算する。途中の可視性はこの段階では調べず、表示が合う候補のみ元の完全再生へ渡す。採否を変えずに、表示が崩れる組合せの検査を短縮する。
