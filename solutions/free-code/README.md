# 印刷を自由にした6枚の汎用層

改良元: solutions/as6-canon。

研究用の `search.cpp` は、汎用窓を2枚の比較に限定せず、6枚への白・黒・穴の印刷602通りから選ぶ。比較用の窓は保護せず、ランダムな印刷からの探索も行う。
中間の設計では表示できない商品対も許し、最も近い表示との不一致数に罰則を付ける。商品対の選択と印刷を同時に更新し、表示できる対だけを使った目的も別に保持する。完成した印刷は、実際に見える紙だけを動かす720状態の移動グラフで調べ直す。

入力はテストケースと保存出力のパス。保存出力から汎用窓の位置と初期印刷だけを読む。将来の注文は読まない。`start=base/random/balanced`、`iters`、`seconds`、`seed` で探索条件を指定する。時計には `CLOCK_SCALE` を掛ける。
探索中の手数は表示可能な順序の数からの近似で、最後に全状態からの合法な最短手数を計算する。これは構造の研究用であり、公式スコアの評価ではない。`main.cpp` は比較元のコピーで、提出用の新構造はまだ組み込んでいない。
