# legal-speed-dups（legal-tie-fast の注文処理で同じ仕事を繰り返す回数を数える版）

改良元: `solutions/legal-tie-fast`。出力は改良元と同じ（数えるだけ）。提出用ではない。時間は数える分だけ遅い。

## 改良元からの差分

1 回の注文の中で同じ仕事を繰り返す回数を数える（集合は注文ごとに空にする）。

- `dup_trial_calls` / `dup_trial_repeats`: 後処理の試行（evaluate）の数と、その注文で前に試したのと同じ編集の列の数。
- `dup_filter_pass` / `dup_filter_pass_repeats`: 表示の検査を通った試行の数と、そのうち前にも通った列の数。
- `dup_value_misses` / `dup_value_repeats`: 終状態の値の計算（memo に当たらなかったもの）の数と、その注文で前に同じ終状態（並びと元の補助紙の列）を計算した数。
- `dup_next_misses` / `dup_next_repeats` / `dup_next_repeats_all`: 次の注文の費用の計算（cache に当たらなかったもの）の数と、同じ鍵をその注文で前に計算した数、実行全体で前に計算した数。
- 後処理（post_optimize）の時間と成果を、呼んだ段と操作ごとに足す（F3_PROFILE を有効にし、1 回ごとの記録の代わりに合計を出す）。`f3_s<段>_o<操作>_<項目>`。段は 0 最良の計画、1 次点の計画、2 最良の取り出し、3 追加の候補と重みつきの計画、4 中立の書き換えの候補集め、5〜8 中立の書き換えの候補（順位 1〜4）。操作は 0 削除、1 差し込み先の付け替え、2 削除と付け替えの組、3 取り出し（2 削除 + 1 直し）、4 2 対 2、5 1 対 1、6 3 対 2、7 呼び出し全体。項目は trials（試行）、legal（合法）、accepts（採用）、gain（値の改善）、saved（減った手）、ms。
