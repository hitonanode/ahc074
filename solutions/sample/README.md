# sample

改良元: なし

公式の Python サンプル解法を C++ に移したもの。動作確認用のベースラインで、工夫はない。

## 紙の設計

- 紙 k（k = 0..K−1 = 191）に、バーコード A_k をそのまま印刷する（穴はない）。紙は上から 0, 1, ..., 191 の順に並ぶので、最初は紙 0 が見えている。
- バーコードは P = 256 種あるので、A_192..A_255 の紙はない。

## 注文ごとの操作

- 注文 a が a < K なら、一番上の紙を一番下（深さ K−1）へ送る操作を、紙 a が一番上に来るまで繰り返す。紙の並びは巡回するだけなので、手数は (a − 今の一番上の紙の番号) mod K。
- a ≥ K（紙がないバーコード）なら何もしない（その注文は誤りになる）。
- 時間で打ち切る探索はない。

## stderr の指標

- `moves`: 操作の総数 T。
- `skipped`: 紙がないため何もしなかった注文の数（≒ 誤りの数 E）。
