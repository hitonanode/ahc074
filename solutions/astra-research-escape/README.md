# 七枚比較器の停滞脱出

改良元: `solutions/astra-research-look`。

窓割り当て探索の停滞回数を、全費用評価で却下された近傍数から、**提案した近傍の総数**へ変更する。既定は焼きなまし1024提案、山登り2048提案で、観測済み最良近傍へ移る。

初版は近傍の重複メモで同じ手を再評価しないため、局所点の近傍を調べ尽くすと、棄却数が増えず脱出条件にも達しないことがあった。本版はメモで省略した提案も停滞に数え、利用できる設計時間を再び探索へ使う。印刷構造、厳密な七要素半順序費用、オンライン処理、時計区切りは同じ。七枚の距離圧縮と先読みも改良元から引き継ぐ。

追加stderr指標 `map_escapes` は最良既知近傍へ移った回数。評価結果はルートの `trial_log.md` とPR報告に記載する。
