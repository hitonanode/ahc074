# 一般印刷規則の焼きなまし検証

## 差分更新と合法操作の検証

`check.cpp` は固定乱数 seed 1701 で 256 目標を生成し、1000 候補の探索を行う。
`RULE_VALIDATE=1` を指定すると、最初の 64 受理と、その後 127 受理ごと、および
最良状態の復元後に、現在の全規則から全候補対の許容順列集合を再計算する。
差分更新した集合・費用・全体目的値と一致することを assertion で検査する。

探索後と、非 witness 窓に 4 枚 2:2 規則を強制した後の二つの構成について、
全 720 順列の物理的な表示合成、互換性、許容終点集合、全始点からの最短距離和、
逆向き距離球の公式、復元経路の長さ・可視性・終点表示を独立に検査する。

```sh
g++ -std=c++23 -O2 -DCLOCK_SCALE=1.1 solutions/astra-rule-anneal/check.cpp -o solutions/astra-rule-anneal/check-report
RULE_VALIDATE=1 solutions/astra-rule-anneal/check-report
RULE_VALIDATE=1 RULE_FULL=1 solutions/astra-rule-anneal/check-report
```

双方とも終了コード 0、assertion failure なし。出力全文は `verification.json` と
`verification-full.json` に保存した。

|検査項目|balanced 140 規則|full 602 規則|
|---|---:|---:|
|評価候補数|1000|1000|
|受理数|33|17|
|最良値の更新|31|16|
|2 窓候補数|264|258|
|2 窓候補の受理|1|0|
|全状態からの再計算照合|34|18|
|目標対の検査|6818|6818|
|合法最短経路の検査|462|292|

これらは無調整の乱数初期配置を使う正しさの検査であり、基準解法との得点比較ではない。

## 調整済み基準解法からの探索

run `20261101-200746_astra-rule-anneal`、生成ケース 0〜31、基準解法と同じ固定探索量
`800000,200000,20000000,66000`、`RULE_STEPS=10000`、balanced 140 規則での比較。
各ケースで必ず 10000 候補を評価した。平均受理数 51.34、2 窓受理数 1.656 で、
悪化する遷移を許して探索しても、32 ケースすべてで最良値の更新がなかった。
最良状態の復元により、最終規則も実スコアも基準解法と全件一致した。

したがって、今回の 1 窓・2 窓近傍、温度、候補予算では、調整済み設計から改善できる
証拠は得られなかった。無調整配置における大きな代理値改善を、本番に近い初期状態での
成長余地と混同しない。10 倍以上の探索や別目的への変更は別実験として扱う必要がある。
