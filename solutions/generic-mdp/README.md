# 汎用紙の順序を平均費用で選ぶ模型

改良元: solutions/as6-canon。`main.cpp` は比較元のコピーで、提出用の変更はまだない。

保存済みの紙から、6枚または8枚の汎用紙だけの全順序と合法な移動グラフを作る。各商品の専用紙の穴を満たす順序を目標集合とし、一様な商品要求が続くときの平均手数を価値反復で求める。目標集合までの最短距離だけでなく、到着後の状態価値も数える。

`probe.cpp INPUT OUTPUT M` が研究用の実行形式。最短距離を用いた1注文先の見積り、最短手数の同点をその見積りで決める方策、平均費用の最適方策を比較する。移動グラフは実際の窓の可視性から作る。紙の取り出し・ハンドルの修正・汎用層へ挟む補助紙は含まないので、公式スコアではない。

乱数は使わず、時計には `CLOCK_SCALE` を掛ける。結果には価値反復の下界・上界と、汎用紙を動かす要求の割合を出す。
