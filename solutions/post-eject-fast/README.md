# 途中修復の可視性検査を必要な候補だけに行う

改良元: solutions/post-middle。

2操作を削除した後の最終順序を双方向リストで作り、1枚で表示を修復できる候補がある場合だけ途中状態の可視性を計算する。前半の合法性を省略して受理することはなく、候補生成後の全再生は同じ。mid_fast=falseを比較用に残し、手数・受理数が元と一致することを検査する。

研究用probe.cppは対照・変更前の途中修復・変更後の途中修復を比較する。main.cppは1ファイルで完結し、mid_fast=true、mid_eject_mode=2。時計倍率・操作の条件・設計は改良元と同じ。

profile.cppは改善した変更を、削除した2枚と修復に使う1枚の種類で分類する。種類は汎用紙・今回の商品紙・前の商品紙・前の穴埋め紙・通常列の紙。分類ごとの採用回数と評価費用の減少を記録する。
