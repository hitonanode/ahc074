# 汎用6枚の比較組を全て印刷する制約を外す

改良元: solutions/perforated-eight。列の研究補助は solutions/map-groups。

汎用窓の割当で、15組の比較が最低1窓ずつある制約を外す。比較を自由に消す条件、1組を使わない14組の条件、互いに重ならない3組を使わない12組の条件を比べる。どの紙も最低1組には参加し、全面穴の汎用紙は作らない。

割当中は元の完全比較器の価格を使うが、完成後は全720順序で実際の可視性を調べ、合法な移動だけの最短距離を再計算する。この厳密価格で共有・列を2000万候補、穴埋め配置と再割当を元と同じ量だけ最適化する。完全グラフでは元の価格表との一致も検査する。

まず設計模型と先頭利益を比べる研究用。main.cpp単独の注文制御にはまだ不完全グラフを組み込んでいないため提出用ではない。隠された注文は使わず、CLOCK_SCALEを適用する。
