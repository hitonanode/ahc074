# 汎用紙を増やし、3商品以上を共有する構造

改良元: solutions/as6-canon。`main.cpp` は比較元のコピー。

6枚の比較器と2商品ずつの共有を離れ、10〜16枚程度の汎用紙で3商品以上を1枚の紙にまとめる構造を調べる。共有紙には全商品の共通色だけを印刷し、どれかが違う窓は穴にする。各商品の比較制約が全て非巡回なら、その共有は表示できる。

汎用紙の枚数を増やすと1回の並べ替えは高くなる一方、単独のまま残せる商品が増え、共有紙の要求頻度も集中する。可否と両方の費用を同じ模型で調べる。比較の組を全て使わない配置では最下段以外にも不可視な紙があり、可視性を無視した並べ替え費用は下限として扱う。

`probe.cpp` はまず2商品・3商品の可否を数える研究用。実際の注文列は読まない。乱数は固定し、時計には `CLOCK_SCALE` を掛ける。

`design.cpp` は単独・2商品・3商品を一緒に選び、列の配置・ハンドルの順序も探索する。汎用操作は、8個の固定開始順からの可視性を無視した最小移動数を使う。逆転した先行制約の半順序の最大マッチングで計算し、6枚の1000半順序×8開始順を部分集合全列挙と照合した。これは汎用層に有利な選別模型で、窓の割り当て自体の最適化や最終スコアの評価ではない。
