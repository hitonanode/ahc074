# hub7

改良元: solutions/hub6

注文の最初に前の専用紙 d を列へ戻すとき、列の一番下だけでなく一番上（列の今の一番上の紙のすぐ上）にも戻せるようにした。設計は hub6 と同じ。

## 変更点

- 列の上端と下端のどちらに戻しても列の巡回順（色の交互）は保たれる。次の目標はもう分かっているので、次の注文が楽になる方を選ぶ。
  - 次の目標の紙が同じ列にあり、d とは別の紙なら下端へ（上端に置くと、その紙を掘り出すのに 1 手余計にかかる）。
  - 次の目標の紙が d 自身（同じ目標か対の相方が続いた）なら上端へ（掘らずに持ち上げられる）。
  - それ以外で、次の目標の紙がこの列のハンドル窓で穴（または専用紙がない）なら、今の列の一番上の色が次の目標の色と違い、d の色が合うときだけ上端へ（掘りを 1 手省ける）。
- 環境変数 `HUB_DUMP_H` を置くと、汎用グループの MDP の相対価値を stderr に出す（hub8 で埋め込むための道具）。

## パラメータと指標

- パラメータと stderr の指標は hub6 と同じ。
