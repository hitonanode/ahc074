# 共有紙の穴を非対称なハンドル補修へ置き換える

改良元: solutions/reset-head。

研究用の選別模型。ハンドル窓の集合Sを印刷した補修紙を想定する。共有商品A/Bの紙にはSでBを印刷し、Aの注文だけ補修紙を上へ出す。補修紙の色がAとS全体で合う場合、従来の両商品の穴を減らせる。補修紙は別の深いハンドルhを持ち、商品紙の列はSより深くhより浅いこと、Aがhでも補修紙の色に合うことを要求する。

probe.cpp は保存された共有と列配置のまま、各共有対の違いからSと色を列挙する。補修紙の配置・返却を1/1.6/2手と仮定し、要求数を減らした穴費用を計算し直す。補修紙の取り出し、列への負担、紙1枚を空ける費用は省いているため、実際より有利な模型である。注文列は読まない。

main.cpp は比較元のコピーで、新しい構造の制御はまだ実装していない。時計はCLOCK_SCALE倍。結果と採否はtrial_log.mdに記録する。

model.cpp は選んだ補修模様に対し、商品紙を184枚に減らして共有72対と列配置を各1000万候補で再設計する。普通の共有と補修を使う共有を切り替えられる。補修する窓に担当窓が含まれる場合は、2商品の担当窓の色が異なっても許す。補修紙が見えるよう、担当窓は補修紙の窓より浅い位置に限定する。基準の185枚も同じ設計器で探索する。補修紙の取り出しと列への負担はこの段階でも省いている。
