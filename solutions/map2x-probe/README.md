# 窓の割り当ての反復を 2 倍にしたときの設計の質の計測（map2x-probe）

改良元: solutions/climb4-fast（計測用の版。提出用ではない。時間は 2 秒を超える）

## 改良元からの差分

- 窓の割り当ての焼きなましの回数 kMapIters を 450000 → 900000、その山登り kGoptSteps を 133000 → 266000 にした。ほかの段（設計の焼きなまし、filler climb など）と注文処理は改良元と同じ。
- 目的: 割り当ての段の探索量を増やすと設計がどれだけ良くなるかを測り、割り当ての段を出力を変えずに速くする価値（同じ時間で回数を増やせたときの得）を見積もる。
