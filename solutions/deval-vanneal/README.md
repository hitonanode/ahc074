# deval-vanneal

改良元: `solutions/deval-vbranch-nofb`。研究用。

焼きなましの毎反復で、V の代わりの指標（V の取っ手のモデルを、取っ手の深さごとのフィラーの吸収率で一次近似したもの）を使う。

- 各段の始めに、穴あけ前の自然な紙の設計で V の被覆 DP（色分布の 2 回の更新の後）を計算する。取っ手の深さ j ごとに、多数側・少数側の色の要求のうちフィラーで覆われる割合（吸収率）と、吸収された不一致 1 回あたりのフィラーの手数 κ（フィラー 1.348 手と、その掘り出し 1.054 手を、覆った不一致の数で割る）を求める。
- 焼きなましの取っ手の費用を、深さごとに `N0 W0 P1 + N1 W1 P0` に置き換える。
  - N0 / N1 は色 0 / 1 の穴の数。
  - W は不一致 1 回の手数（吸収されなければ色直し 0.871 手、吸収されれば κ。どちらも列の費用の係数 0.940 で割る）。
  - P1 = (N1 K1 + R [N1 > N0]) / (N0 K0 + N1 K1 + R) は、吸収されなかった要求だけが列の先頭の色を変えるとした長期の確率（K = 1 − 吸収率、R はリセットの強さ）。
  - 吸収率を固定した V3 の取っ手のモデルにあたる。毎反復の計算量は、静的な取っ手の費用と同程度。
- `DEVAL_VANNEAL=1` で有効。
  - `DEVAL_VANNEAL_FROM`: 使い始める段（既定 0 = 全段、2 = 分岐した後の 2 段だけ）。
  - `DEVAL_VANNEAL_MIX`: 静的な取っ手の費用との混合率（既定 1）。0 なら出力は改良元と同じ。
  - `DEVAL_VANNEAL_SAMPLES`: V の積分点の数（既定 8）。
- 焼きなまし以外（フィラーの climb、再割り当て、穴あけ）は改良元のまま。

stderr の `vb_refreshes` は吸収率を計算し直した回数、`vb_kappa` / `vb_alpha` は最後に計算した κ と吸収率の平均、`vb_sec` はその計算時間の合計。
