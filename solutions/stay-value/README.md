# 残した穴埋め紙が次の注文でも使える確率で評価する

改良元: solutions/post-repair。

注文後の穴埋め紙を1枚0.6手で評価する代わりに、全256商品についてその位置のまま残せる割合を前計算する。次の商品紙の取り出し窓を隠す場合、または商品の穴に違う色を出す場合は残せないとする。定数0.4との差で0.6手を補正し、全体の料金水準を大きく変えずに紙と位置の違いを比較する。

別の補正では、そのまま残せる場合に次の商品の穴を無料で覆う確率を各窓について保持する。元の終了費用が数える、その窓の色合わせの深さから対応する期待値を引く。複数の穴埋め紙の重複は最大値だけを使う。汎用紙の上や間に挟まった補助紙はこの補正から除く。

研究用。補正の係数を変え、保存した設計と固定乱数の一様模擬注文で比較する。実際の注文列を読まない。最初の模擬系列は可視性と最終順序を独立再生で照合する。main.cppの既定係数は0で、研究結果が出るまで提出用へ組み込まない。CLOCK_SCALEを適用する。
