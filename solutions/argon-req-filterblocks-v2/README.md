後処理の表示チェックだけを高速化します。

- 移動紙の集合を初期積層の位置で表します。区間の境界は、移動紙、その直前、アンカーです。「直前」は192ビットの集合の右シフトで一括計算し、各編集で設定する処理を省きます。境界から始まる区間は必ず1枚なので、区間表の問い合わせをせず、その紙を直接読みます。
- 区間の被覆と表示色を隣り合う2語の `Block` にまとめます。同時に読む値の局所性を上げ、1枚の区間も同じ表から読みます。保存するビット列と合成の式は従来と同じです。

候補・順序・計算結果・浮動小数点演算は不変です。Solver の総サイズと他のメンバの位置は変えません。設計や予算、キャッシュの参照回数も変えません。

F3_*、COLMDP_*、設計の反復回数、ITER_SCALE、SIM_HARNESS、全プロファイラと trace スイッチ、CLOCK_SCALE、LOCAL_BENCH、DesignStore、既存の全stderr行と `@paper` / `@ops` を保持します。新規スイッチ・指標はありません。`cfprof_eval_filter_*` がこの表示チェックの時間・回数、`cfprof_post_setup_*` が要求ごとの区間表の準備を測ります。
