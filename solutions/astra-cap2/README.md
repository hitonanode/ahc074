# astra-cap2: キャップ窓の共同探索と修復

改良元: `solutions/as6-cap38`。

汎用紙 6 枚・汎用窓 38・1 窓キャップ・25 ハンドル・185 専用紙（71 対）を維持し、キャップの物理窓を入力に合わせて選ぶ。

- 比較器の窓割り当てで、汎用窓とキャップ窓の交換を追加する。交換ではハンドル集合を変えず、キャップとなった窓の比較制約と距離費用を取り除いて、71 対のマッチングを評価する。
- 設計の焼きなましの区間間で、キャップとハンドルの交換も調べる。新しいハンドルで不一致となる対は、紙全体の列交換、または対の片側の商品交換で修復する。全商品の担当、比較器の整合、各列の白黒両色を守り、列・穴・汎用層の合計模型が下がる交換を採用する。
- キャップは注文中は固定する。キャップを外部の紙番号 0 として最初から一番上へ配置し、初期設置の手は 0 とする。内部番号から外部番号への変換は印刷順と全操作で揃える。注文ごとの持ち上げ・補助紙・後処理は基準の方式を使う。

時刻はすべて `CLOCK_SCALE` 倍。割り当て 0.50 秒＋山登り 0.61 秒まで、設計 1.305 秒まで、穴埋め改善 1.36 秒まで。補助表は 1.48 秒で打ち切り、1.68 秒から簡易注文処理に切り替える。

`cap_map_moves` は汎用窓・キャップ交換の受理数、`cap_tried` はハンドルとの交換候補数、`cap_accepted` は採用数、`cap_swapped_units` は採用した修復操作数、`cap_model_gain` はその時点の模型改善量の合計 / 256。`cap_window` は最終的な物理窓。模型の各内訳と `end_sec` も stderr に出す。

評価と研究結果は [REPORT.md](REPORT.md)。`cand2` は列交換による修復だけを使う候補。その他の `.cpp` は研究・棄却実験の再現用であり、提出候補ではない。
