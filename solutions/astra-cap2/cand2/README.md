# キャップ窓交換と列の修復

改良元: `solutions/as6-cap38`。

汎用紙 6 枚・汎用窓 38・1 窓キャップ・25 ハンドルを維持する。設計焼きなましの 4 区間の間で、キャップと各ハンドルを交換する候補を調べる。新ハンドルで異色となる共有紙は別列の紙と交換して修復し、各列の白黒両色と比較器の整合を守る。列・穴・汎用層の合計模型が下がる候補を採用する。

PR 78 の cap-joint が事前に棄却していた、不適合な共有紙のある窓も調べる。キャップ窓の最初の配置は基準どおりで、比較器割り当て中のキャップ交換や商品の組み替えによる修復は行わない。

キャップを紙番号 0 として初期の一番上に配置し、初期設置の手を省く。印刷順と全操作の紙番号を同じ対応で変換する。設計の時間配分は基準どおり。補助表 1.48 秒、簡易処理への切り替え 1.68 秒（CLOCK_SCALE 込み）。`cap_accepted` は窓交換採用数、`cap_swapped_units` は修復で採用した紙交換数、`cap_model_gain` は模型改善量 / 256。結果は [../REPORT.md](../REPORT.md)。
