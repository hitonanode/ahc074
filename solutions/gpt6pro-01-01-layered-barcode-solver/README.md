# gpt6pro-01-01-layered-barcode-solver

改良元: なし（gpt6pro-01 のコードが残っている唯一の版）

## 解法の全体

- 紙の構造（上三角）: 紙ごとに「アンカー窓 h」を決め、その紙は窓 h より前（j < h）を全部穴にし、窓 h には 0 か 1 を塗る。h より後ろは自由（色か穴）。アンカー 0〜15 に 6 枚ずつ（96 枚）、16〜62 に 2 枚ずつ（94 枚）、窓 63 に 0 と 1 の単独紙 2 枚（計 192 枚）。同じアンカーの紙（群）はアンカー窓の色を 0,1,0,1,… と交互にする。
- 初期の重ね順は 単独紙 → アンカーの大きい群 → … → アンカー 0 の群。予備の位置では、群の先頭の紙は必ず自分のアンカー窓で見える（上の群はその窓を塗れない）。群の中で r 番目の紙は、上の r 枚を群の末尾へ回す r 手で取り出せる。
- 紙の模様の学習（256 商品から、2 段階）: まずアンカー 0〜15 の 96 枚、次にアンカー 16〜62 の 94 枚。各群・各アンカー色について、その色を要求する商品の「まだ前の段で覆われていない窓」の要求を集め、近い商品を 2〜6 個まとめて、0 と 1 の要求が衝突する窓を穴にした候補を作る。候補の利得（その紙 1 枚で正しく覆える窓の数 − 取り出し費用の目安）の和を、商品ごとの最大値で数えて貪欲に選び、1 枚ずつ入れ替える改善を 2 回。2 段目では、1 段目で覆える窓は「どちらの色でもよい」として扱う。
- 注文ごと: まず前の注文で上に出した紙を自分の群へ戻す。次に、上に積む紙の列（各紙はアンカーがまだ覆われておらず、まだ覆われていない窓では目標と一致すること）を選ぶ。候補の計画は (1) 紙を使わず各群の先頭を正しい色にする確実な計画、(2) 紙 1 枚 + 残りの修正、(3) 貪欲に紙を足す計画、(4) 覆った窓の集合を状態とする幅 64・深さ 8 のビーム探索。費用は取り出しの手数 + 覆えなかった窓の修正の手数 + 使った紙 1 枚あたり 0.5（次の注文で戻す手数の見込み）。選んだ紙を群から取り出して上から順に積み、覆えなかったアンカー窓は群の正しい色の紙を先頭へ、窓 63 は単独紙で直す。
- 時間の管理はない（前計算 + 1024 注文の計画探索のみ）。

## パラメータ

- アンカー群の枚数配分（allocation=2: アンカー 0〜15 に 2 枚ずつ追加）、学習の段の分け方（learning=7: アンカー 16 未満 / 以上）、ビーム幅 64・深さ 8、使った紙 1 枚の追加費用 futureweight = 0.5。
- stderr: `design_cpu_seconds`（紙の設計にかかった CPU 時間）。

## 移植について

外部の agent（gpt6pro-01。この repo の文脈を共有しない）の成果。元のソースと報告は main checkout の other_agents/gpt6pro-01.md, gpt6pro-01-layered_barcode_solver.zip（solver.cpp）。元から reactive で、引数なしで採用設定が動く。未来の注文は読まない。変更は次だけ:

- `#include <bits/stdc++.h>` を個別の include に置き換えた（Clang でもビルドできるように）。
- 元は `--stats` を付けたときだけ設計の CPU 時間を JSON で stderr に出していた。これを常に `design_cpu_seconds = 数値` の形で出す。アルゴリズムは不変。内部の検査（動かす紙が見えていること、表示が目標と一致すること）は元のまま abort する。
- 報告された成績（独自の Python 生成器、調整に使わなかった 100 件、公式 seed とは対応しない）: 平均 15.624 手/注文、誤り 0、1 注文の最大 36 手、CPU 平均 0.35 秒・最大 0.44 秒/ケース。

対象外にしたもの: `baseline.cpp`（単独紙 128 枚の比較用の基準）、`tester.py`（独自テスター）。チャットの最初に言及された layered_barcode_experiments.zip（静的な被覆辞書の実験）は手元に無い。gpt6pro-01-sparse_barcode_structures.zip は GQ(3,5) などの疎な支持集合の生成・検査（build_masks.py, verify.py）と、ファイル入出力で色を学習する研究用プログラム（learn_colors.cpp, learn_cascade.cpp）で、対話する解法は含まれない。
