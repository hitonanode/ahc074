# hub8

改良元: solutions/hub7

起動時の計算を減らし、焼きなましを反復回数ではなく時間で打ち切るようにした。紙の設計の仕方と注文ごとの操作は hub7 と同じ。

## 変更点

- 汎用グループの MDP（6 窓 7 枚、5 窓 6 枚、4 窓 6 枚）の相対価値 h を、hub7 の `HUB_DUMP_H` で出した値の表としてソースに埋め込み（1e-4 単位の整数）、起動時の価値反復をなくした。表のない形のグループだけ、従来どおり起動時に解く。方策（各状態からの次の手）は同じなので結果は変わらず、起動が速くなる（その分を焼きなましに回す）。
- 焼きなまし（anneal_units）を、プログラム開始から 1.2 秒まで回す。温度は 3.0 から 0.05 へ、経過時間の割合で指数的に下げる。`HUB_ANNEAL` に正の値を与えると、従来どおり反復回数で打ち切る。
- 見積りのハンドル窓の穴・G の穴の重み（0.51・0.45）を環境変数で変えられるようにした。

## パラメータと指標

- 環境変数（hub7 のものに加えて）: `HUB_TL`（焼きなましを打ち切る時刻。プログラム開始からの秒、既定 1.2）、`HUB_ANNEAL`（既定 0 = 時間で打ち切る）、`HUB_KH`（ハンドル窓の穴 1 個の見積り、既定 0.51）、`HUB_KG`（G の穴 1 個の見積り、既定 0.45）。そのほか `HUB_H` = 34、`HUB_SLOPE` = 1.0、`HUB_DMAX` = 22 など。
- stderr に足したもの: `anneal_end_sec`（焼きなましが終わった時刻。プログラム開始からの秒）。
