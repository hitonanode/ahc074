# astrasearch-perforated

改良元: `solutions/astrasearch-relaxed`（元は `solutions/imp-gla`）。

非整合な商品対を既存の専用紙で救済する際、補助紙のハンドルの誤色に加え、汎用窓の誤色にも穴を開ける。
穴の下には汎用紙の正しい色を見せ、補助紙の正しい色は残す。
補助紙の元の1〜2商品の表示可能性も同時に守ることで、追加の紙なしに表示の選択肢を広げる。
現在の実装は、最良の1交換を検証する研究用の初版。

## 汎用窓の検査

補助紙より上にある汎用紙の集合は64通り。
その集合が覆う窓は補助紙の影響を受けないため、誤色を消すべき窓は集合だけで決まる。
「集合内の紙が集合外の紙より上」と「補助紙が覆わない要求窓の色」を有向辺として足し、閉路がなければその置き方が存在する。
720順序×挿入位置の列挙を、この64個の半順序の検査へ縮めた。

補助紙に穴を開けた後、元の担当商品のそれぞれについて、元の汎用穴と追加穴の和集合から作る半順序が閉路を持たないことを確認する。
追加穴では対の2商品が同色の場合があるため、片側の向きの反転で代用せず、両商品を独立に検査・評価する。
既存の `PosetSums::one` を使い、一様な開始順序720通りからの合法な平均最短手数の増分を設計費用へ加える。

1つの補助紙を異なる2つの加工で使う衝突を避けるため、新対の両方向では異なる補助紙を選ぶ。
新対・解消する旧対・補助紙は互いに異なる紙とし、紙192枚と全商品の担当を保つ。
補助紙自身の持ち手は絶対に穴にしない。

## 実装と評価の扱い

列設計・探索時間・最大1交換・補助紙必須の注文処理は改良元と同じ。
新対の候補順は 0.8×ハンドル差 + 0.12×汎用窓差。
補助紙の列内の深さ・回収費用・覆うハンドルの価値は近似、半順序の表示可能性と補助紙自身の一様開始時の汎用費用増分は厳密に扱う。新対の費用は、選んだprefix集合に制限した終状態への厳密距離であり、全prefixの終状態の和集合への距離の上界になる。
最終的に印刷する実際の紙の模様からすべての必須補助紙の終状態を再計算する。
実行時の可視性・表示一致・次回の回収可能性の検査も残す。

- `RELAX_FORCE=1`: 最良の有効な1交換を強制し、探索時間の打ち切り・注文処理の軽量化を外す研究モード。2秒制限を超え得る。
- `RELAX_PAIRS=n`: 調べる新対の数（既定40）。
- `RELAX_MIN_DEPTH=n`: 補助紙より上に置く汎用紙の最小枚数（既定0）。
- 既存の `MAP_ITERS/GOPT_STEPS/ANNEAL_ITERS/CLIMB_ITERS` で初期設計を固定し、`imp-gla` と同じ設計からの純効果を比較できる。

`relax_punched_generic/handles` は追加穴の数、`relax_selected` は置換数。
`relax_predicted_delta/actual_model_delta` は全256商品について足した設計モデルの差で、1注文の実測差とは区別する。
`mandatory_targets/requests/failures` は補助紙が必須の商品の数・注文数・有効な手順が見つからなかった数。
通常モードでも必須の終状態の検査と処理を省略しないため、制限時間を満たすかは別途実測で確認する必要がある。
