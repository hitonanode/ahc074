改良元: `solutions/deval-ordered8`。

次の独立した変更を併用する。

- `deval-free-late`: 全8候補の穴あけ後の再割当てで、単独紙の元の色を固定しない。巡回は従来の仕上げ目的の改善で受理し、完成設計をVで選ぶ。片色が消える提案は不採用。探索回数・候補数は同じで、時間不足の切り替えなし。
- `deval-mdp-cluster`: 列MDPの紙の4種類を、担当目標数×色から、filler需要を含む紙の重みの2群×色へ替える。同色ごとに重み順の全分割を比較し、群内二乗誤差が最小の2群にする。群ごとの平均需要で従来と同じMDPを解く。1注文先の費用は紙ごとの値を保つ。設計・探索回数は同じ、時計による切り替えなし。
- `deval-genone50`: 設計と探索幅は同じ。汎用紙6枚の順序の将来価値を既存の1注文先の最小移動数の平均とする。現在の汎用紙計画の同手数の選択に使う。計画全体の末端費用には、この価値×0.5を加える。計画を再検査するmemoにも同じ項を加える。注文列は未知のまま、固定予算で動く。
- `deval-prefix8`: 窓マッチングのradix整列を出力同一で軽くする。histogramの排他的累積和をAVX2整数8項ずつで行う。キー・同値順・貪欲選択・目的値・乱数列は同じ。全予算固定、時計による切り替えなし。
- `deval-vdraw`: Vの出力を保つ高速化。固定積分点からの色マスク生成をAVX2の整数比較で8窓ずつ行う。代表紙と積分点、浮動小数点の集計順、探索予算を保つ。時計による切り替えなし。

元の8候補と全ての探索予算は固定。時間不足の切り替えなし。選ばれた最終設計をDesignStoreに保存する。
