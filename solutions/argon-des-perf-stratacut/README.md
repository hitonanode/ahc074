穿孔の色標本を32個の層別標本にし、owner側のDPを1窓の変更として差分評価する。
1つの穴またはその窓のhead色が変わったとき、区間の利益が変わるのはその窓をまたぐ区間だけ。
互いに重ならない区間の集合には、そのような区間は高々1つしかない。
変更窓より前のforward値と後ろのbackward値は同じなので、その区間の辺だけを再計算して挟む。
窓をまたぐ区間がない場合も、窓の前後のキャッシュの和で評価する。

ownerの穴追加・復元と色反転に使う。初回と受理後のDPキャッシュ構築は従来通り。
係数0.7、owner条件付け、利益上限、候補順は維持する。値だけの連続配列は加えない。
新しい環境変数や指標はない。全ログ・@paper/@ops・profiler・予算スイッチ、CLOCK_SCALE、
LOCAL_BENCH、DesignStore、段の目印と目次を保持する。変更はHandle perforationだけ。
