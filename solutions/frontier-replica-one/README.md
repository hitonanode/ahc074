# frontier-replica-one

改良元: solutions/frontier-replica。

**費用モデルを反証するための診断版であり、本解法としての推薦ではない。**

元の版は、単独紙 a を商品 b との共有紙にする各候補について、
「b に選択肢が増える得 − a の修復費が増える損」を模型で評価し、
純便益が -0.10 手以上の場合だけ採用する。
この版はその候補生成・評価・注文処理を維持したまま、候補が存在する場合に
**模型上で最良の候補を必ず 1 個だけ昇格**する。
候補が存在しなければ昇格は 0 個。

変更点:

- 昇格数の上限を 1 に固定する。
- 採用する純便益の下限を -1e100 に固定する。
- `REPLICA_LIMIT` と `REPLICA_MIN_GAIN_CENT` は、この診断版では使用しない。
- 最良候補について、`replica_best_loss`（a の費用増加）と
  `replica_best_benefit`（b の選択利益）も stderr に出す。

これにより、紙の共有化の損と、オンラインの表現選択の得を実際に発生させ、
模型が候補を正しく棄却しているか、それとも得を見落としているかを調べる。
模型が悪化を予測する候補を意図的に採用するので、スコア悪化自体は不具合ではない。
誤表示・不正操作・制限時間超過は別途確認する。

そのほかの構造、CLOCK_SCALE、設計時間、軽量処理、Interleave の無効化、
`replica_*` の利用率指標は改良元と同じ。
評価結果と採否は trial_log.md に記録する。
