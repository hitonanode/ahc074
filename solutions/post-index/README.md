# 後処理候補の可視性を短く再生する

改良元: solutions/eject-quick。

表示が正しい候補の可視性付き再生を短くする研究。条件1は紙の位置を配列で保持して探索を省き、移動した区間だけ位置を更新する。条件2は元の連続区間の不透明集合を前計算し、双方向リストで変更された場所の間をまとめて読む。元の区間内にある操作紙・差し込み先の位置を算出し、操作紙より上の不透明集合で可視性を判定する。

操作の候補と評価式は変えない。全模擬注文の操作列・最終順序を元の再生と完全一致するか検査し、各条件1本は全可視性を独立に照合する。設計・時間配分・CLOCK_SCALEは改良元と同じ。main.cppの既定は位置配列の条件1。
