# frontier-clique10

改良元: solutions/frontier-clique

汎用紙を 10 枚、汎用窓を 45 個にする。
K10 の 45 辺を各汎用窓に一度ずつ対応させるため、辺重複による 2-cycle が存在しないという条件は維持する。
ハンドルは 19 窓、専用紙は 182 枚（74 対と 108 単独）になる。
この変更で、汎用紙を増やすとともにハンドルの穴を減らす効果を調べる。
列の深さが増える損と、汎用層の要求が増える損もあるため、紙数だけの変更とは別に評価する。

窓の割り当て、固定 8 通りの現在順からの厳密な集合全探索による費用見積り、設計・注文処理の時間配分は frontier-clique と同じ。
環境変数 `CLIQUE_M=9` または `10` でこの二つの構造を切り替えられる（未設定時はこの版では 10）。
時計には CLOCK_SCALE を掛ける。
その他のパラメータと stderr の指標は frontier-clique と共通。
