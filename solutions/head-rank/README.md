# 取り出し深さで減る穴埋めの利益

改良元: solutions/head-design。

返却する紙の穴埋め需要を深さに比例する罰で表す代わりに、取り出しに必要な手数を引いた正の利益で扱う。全商品に対し、不一致窓の数の確率分布を求め、「直す窓数−1.6−取り出し深さ」の正の部分を深さ0〜7について前計算する。列内でのこの利益の和を、紙を返す位置と注文後の状態の費用から引く。

直接の商品頻度は元の1・2を使う。追加需要を線形な重みにする補正は使わない。利益の係数を研究で比較する。既存の設計と時計倍率を保つ。`probe.cpp` は同じ保存設計・独立した固定乱数の模擬注文で比較する研究用。係数0は対照を得るための研究設定。
