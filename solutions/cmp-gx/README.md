# cmp-gx

改良元: solutions/cmp-base

設計（対の組み方と焼きなまし）で使う汎用層の手数の見積り gcost を、乱数の 8 通りの順序での計画の長さの平均から、720 通りすべての順序からの正確な平均手数にした。

- Comparator::mean_moves: 2 つの順序の間の最少手数は M − 最長共通部分列（1 手で 1 枚を任意の位置へ動かせるため）。720 × 720 の表（dist）を一度だけ作り、対の汎用窓の違いが求める関係を満たす順序の集合への最短距離を、全順序で平均する。約 20 ms（対の候補約 800 組分を含む）。
- 動機: 8 通りの見本では見積りの sd が約 0.35 手あり、焼きなましの対の選択に雑音が入っていた。模擬（回数固定、32 本の乱数注文列）で seed 24〜87 で −0.129 ± 0.066%、seed 88〜151 で −0.166 ± 0.062%。汎用層の費用の重みを 0.7 / 1.3 倍にしても ±0.05% 以内で変わらない。
- 汎用層の計画（注文処理）は変えていない。終わりの順序を次の注文の期待手数で選ぶ先読みも試したが、汎用層の手数は 1.471 → 1.468 手/注文でほぼ変わらなかった（要求を満たす順序の集合が小さく選ぶ余地がない）。
