# 汎用層と商品の紙を混ぜる構造の研究

改良元: solutions/as6-canon

商品の共有紙の穴を6枚の比較器だけで埋める制約を外し、別商品の紙を比較器の間に挟んで埋める構造を調べる。
既存の補助紙は整合する商品対の手数短縮に使われるが、本研究では補助紙があることで初めて表示できる商品対も対象にする。

現時点の `main.cpp` は比較用にコピーした改良元と同じ。`probe.cpp` は保存された設計に対する構造の分析用で、提出用ではない。
分析は保存された設計と公開された商品一覧だけを使い、近い商品対に対して補助紙を含む表示の存在と候補数を調べる。将来の注文は解法の設計に使わない。

表示の可否は、比較関係のグラフから入次数0の頂点を取り除いて判定する。残った比較窓について、補助紙の不透明な部分が目標と一致し、補助紙の穴に残る比較関係が閉路を持たなければ表示できる。共有紙を置く列を仮定し、その穴で補助紙のハンドルの色が食い違う場合は候補から外す。使用する2商品の現行の紙と、共有紙を置く列の紙は補助紙から除く。
複数商品を1枚で共有する可能性も、比較器の可解性を使って別に数える。
実行時間を測るコードには `CLOCK_SCALE` を適用し、乱数を使う場合は定数seedとする。

`run_probe.py RUN START-END` は、保存済みの run の設計を分析して `probe-START-END.json` に集計する。`mean_proxy` は候補が各列内のランダムな位置にあるとした粗い取り出し費用で、実測スコアではない。

評価結果と採否は trial_log.md に記す。
