# ia-ret-skip

改良元: `solutions/dcomp-combo-dual30`。

`kTopPenalty == 0` のとき、返却モード 2 は、それより前の返却モード 1 と同じ計画になる。親は計画の模擬だけを共有していたが、表示・合法性・費用・二重移動の結合・候補登録を繰り返していた。この試作はモード 2 の選択肢を処理する前に省く。

候補の選択はすべて厳密な改善時だけ更新し、同じ計画の再登録は採用結果を変えない。候補が途中で上限から外れた場合も、上限の費用は悪くならないので再登録されない。設計・探索の非重複候補・出力ラベルはそのまま。計画の再実行で増えていた `merge_trials` などの診断回数は減る。親の再利用コードは差分を小さくするため残す。
