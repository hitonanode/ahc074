# 商品を担当しない穴埋め専用紙

改良元: solutions/reset-majority。

商品紙を184枚・共有72対へ変え、空いた1枚をハンドル窓の穴埋め専用にする。専用紙の色と穴は商品と一致する必要がなく、列の担当窓だけは不透明にする。汎用窓とキャップ窓は全て穴にする。通常の列先頭からの穴埋め・返却の操作で扱う。

研究模型では、比較器を固定して商品共有と列を再設計する。穴の需要と先頭色の分布から、1回の穴埋めで省ける操作の正の部分を近似し、専用紙の列・色・穴を探索する。選んだ複数の候補を固定乱数の訓練用注文で比較し、別の注文列で最終候補を検査する。商品紙185枚の対照も同じ再設計回数で作る。

専用紙を列先頭にどの程度優先して戻すかは、列内順位の計算で使う仮の注文頻度で指定する。実際には専用紙の商品注文はない。紙数を減らした損と、先頭に専用紙を置く損の両方を模擬操作で数える。

これは研究段階。main.cppの対話用の設計は比較元のままで、新構造は未統合。将来の注文は読まず、全時計にCLOCK_SCALEを掛ける。
