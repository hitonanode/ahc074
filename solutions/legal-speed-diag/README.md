# legal-speed-diag（legal-speed-fast の試行がどこで落ちるかを数える版）

改良元: `solutions/legal-speed-fast`。出力は改良元と同じ（数えるだけ）。提出用ではない。

- 後処理の試行（evaluate）を、呼んだ場所（0 削除、1 差し込み先の付け替え、2 削除と付け替えの組、3 取り出し、4 2 対 2、5 1 対 1）ごとに、結果で数える。`diag_s<場所>_r<結果>`: r0 呼んだ数、r1 差し込み先が自分、r2 表示の検査の前の蓋の検査、r3 表示、r4 memo で届かない補助紙、r5 再生での見えない紙の手、r6 再生の後の蓋の検査、r7 届かない補助紙、r8 値が良くない、r9 採用。
