# 穴埋めの重複を考慮した一括割当

改良元: solutions/anchor-match。

研究段階。main.cpp は比較元のまま。probe.cpp で保存設計から別の割当目的を調べる。

各列の先頭候補は、直接取り出す頻度と単体の穴埋め利益で選ぶ。各商品の注文について、列の先頭色を固定乱数で複数回抽出し、複数の先頭紙を穴埋めに使う区間DPを解く。区間が重なる利益を二重に加えず、反対色の先頭を取り出す場合には1手を加える。

一括割当の行列では、担当商品の穴が変わる効果と、現在の先頭候補の模様が変わる効果を別々に計算する。先頭候補の差し替えは、その候補を使わない最適値と、差し替えた候補を1回使う最適値の大きい方で評価する。得られた置換を巡回ごとに適用し、全体のDPを再計算して改善するものだけ受理する。

主な研究パラメータは先頭色の抽出数、DP利益の係数、割当反復数。模擬注文は入力末尾の注文を読まずに固定乱数で作る。全時計は CLOCK_SCALE 倍。表示の正しさと模型の差分は研究コード内で検査する。評価結果と採否は trial_log.md に記録する。
