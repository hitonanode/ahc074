# cmp-fast

改良元: solutions/cmp-cut

焼きなましを速くした（同じ回数なら出力は同じ）。

- Design::anneal の mutate: 却下した変更を、4 つの update を逆に当てて戻すのではなく、変更前に保存した数（4 つの単位の列の nc / nt / n1 / pairOne と、それらの穴のあるハンドルの hn）を書き戻して戻す（cur は従来どおり変更前の値に戻す）。却下が大半なので、焼きなまし 400 万回が 0.48 → 0.33 秒（手元、空いた状態）。
- 出力の一致: cmp-base/eqcheck.py（割り当て 3000 回・焼きなまし 200 万回・山登り 3 万回、seed 0〜47）で cmp-cut と全件一致。時間制では同じ時間で焼きなましの反復が約 1.45 倍になる。
- colcost / hcost の値をキャッシュして参照を減らす版も試したが、速さは変わらなかった（入れていない）。
