# 穴埋めにも使われる需要を紙の返却順序へ入れる

改良元: solutions/as6-canon。

各紙が自身の商品以外の穴埋めに使われる可能性を設計から計算し、列内の差し込み位置の将来費用へ加える。紙と全商品の組について、最後の不一致より深い窓で正しい色を覆う範囲を求める。現在の需要比から、その範囲のうち少なくとも2窓が間違っていて、紙の移動で直せる確率を計算する。穴埋め紙自身の取り出し窓は、列先頭ですでに正しいため利益から除く。

需要の補正は列内の平均を引く。列全体の取り出し費用と穴の修正費用の相対比を大きく変えず、同じ列の中で補修に使いやすい紙を優先する。実験時の係数はコンパイル定数 `FILL_DEMAND_WEIGHT` で選び、既定値は0.25。`filler_demand_spread` は紙の追加重みの標準偏差。時計・設計時間・その他の操作探索は比較元と同じ。
