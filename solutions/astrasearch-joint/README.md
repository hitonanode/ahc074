# astrasearch-joint

改良元: `solutions/imp-gla`。

汎用窓の選択と、商品を対にする選択・列への配置を一体として改善する実験。
従来は汎用窓を貪欲マッチングの近似費用で先に決め、その後は汎用窓を動かせなかった。
この版は列の設計後に汎用窓とハンドル窓を交換し、交換で使えなくなった対を単独紙へ戻す。
増えた単独紙の集合から同数の新しい対を作り、紙の枚数を保つ。
対の整合性・ハンドル色を検査したうえで短い焼きなましを行い、実際の列と穴の費用で採否を決める。

- 注文処理は改良元と同じ。未来の注文は参照しない。
- 通常の列設計は 1.10 秒まで、その後の窓交換は 1.305 秒まで。穴埋めの山登りは 1.36 秒まで。
- `JOINT_STEPS` を正にすると窓交換を固定回数で行う。`JOINT_ANNEAL_ITERS` は各交換の後の焼きなまし回数（既定 30000）。既存の固定回数の環境変数も利用できる。
- `joint_trials` は交換の試行数、`joint_repaired` は紙の枚数を保って再構成できた数、`joint_accepted` は設計の費用が改善した数。
- `joint_before` / `joint_after` は専用紙設計のモデル費用を 256 で割った値。実測の手数とは区別する。

交換の前後で従来のモデルを使うため、模型の改善が実測の改善になるかは別途検証する必要がある。
