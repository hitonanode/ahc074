# cmp-gobjr

改良元: solutions/cmp-gobj

割り当ての後の山登りの指標 gobj で、対の鍵を「ハンドル窓での違いの数」から「ハンドル窓での違いの数 + 0.5 ×（閉包の関係の数 − 6）」にした。

- 閉包の関係の数（汎用紙 6 枚の上下関係のうち、対の違いが決めるもの）が多い対ほど、それを満たす紙の順序が少なく、汎用層の手数が多い。gobj は鍵の小さい順の貪欲マッチングで 70 組の鍵の平均（鍵は 1/4 単位で数え上げソート）。関係の数は閉包を計算するときに対ごとに持つ（Pair::rel）。
- 模擬（回数固定、seed 88〜215 の 128 件、cmp-gobj 比）で、関係 1 つあたりの重み 0.25 / 0.5 / 0.75 / 1.0 / 1.5 は −0.101 ± 0.047 / −0.153 ± 0.051 / −0.144 ± 0.050 / −0.125 ± 0.050 / +0.042%。
- 山登りの回数を 3000 → 6000 にすると（焼きなまし固定で）さらに −0.15% だが、時間の分だけ焼きなましを減らすとほぼ 0。割り当ての目的の低下の許容 5% → 10% / 20% は変わらない。
