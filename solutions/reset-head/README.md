# 紙の返却による先頭色の偏りを穴埋め設計へ反映

改良元: solutions/anchor-match。

商品紙を取り出した後の返却で、列の先頭を穴の要求が多い色へ戻せる効果を、穴埋めの利益にも入れる。列の穴の白要求をx、黒要求をy、担当商品数の2倍をtとし、黒の先頭確率を `(y + t×黒要求が白要求より多い)/(x+y+t)` とする。白黒が同数なら白側を使う。

穴埋め山登りでは開始時のこの確率を固定する。最後の一括再割当では、割当変更のたびに穴の要求数から確率と先頭候補を計算し直す。線形化には、商品の穴・供給する紙の模様の変化に加え、要求数が先頭色の確率を変える効果も入れる。誤色が0個・1個になる確率から微分を計算し、先頭候補の色の確率が変わる効果も含める。

割当は最大4反復、係数1.0、終了目安1.445秒。前回の所要時間から次の反復が収まらないと見積もれば終了する。その他の設計、初期順、注文時の制御、時間配分は改良元と同じ。全時計にCLOCK_SCALEを掛ける。stderr の match_* 指標の意味は改良元と同じ。build.py が提出用の単一ファイルを生成する。
