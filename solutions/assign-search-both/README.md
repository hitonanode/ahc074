窓交換の候補を、現在採用中の71組の費用変化で順位付けする。窓aを外した各組について、比較器の弧を順方向・逆方向に足したときの費用を1回ずつ計算し、全交換先で共有する。組が無効になる場合は、現在の採用組の最大費用で補充すると見積もる。新しく有効になる組の推定利益も足す。順位だけに用い、目的関数・全組の厳密評価・受理判定は維持する。

AS_RANK=4が既定。0は元の選択、1は新しく有効になる組の推定利益、2は1にハンドル差を加算、3は現在採用組の費用変化、4は1と3の合計。AS_WORK=1（既定）は窓割り当ての反復数倍率で、同じmap時間に合わせるために使う。AS_PROFILE（コンパイル時、既定0）は1で演算子別の時間・改善量を計測する。

追加指標rank_rows / rank_pairs / rank_choices / rank_positiveは順位表数、新規有効組の延べ数、順位選択数、正の推定利益があった数。as_rank / as_workは使用設定。既存の全指標・ログ・プロファイラ・設定・CLOCK_SCALE・LOCAL_BENCH・DesignStore・@paper/@opsを維持する。
