# 返却による先頭色の偏りを操作側の優先度へ入れる

改良元: solutions/post-prune。

列内への返却順を決める穴埋め紙の追加需要に、返却で先頭色が多数色へ寄る確率を使う。設計側と同じく、穴の白黒需要をx/y、列の商品要求数をnとして、先頭黒の確率を (y + 2n・[y>x]) / (x+y+2n) とする。需要と要求数はどちらも全商品の数で割って揃える。

この確率を使って紙ごとの穴埋め利益を計算し、元と同じ列内の平均に対する比で取り出し頻度へ加算する。追加需要の既定係数は0.25。研究用probeでは先頭更新の強さ0/1/2/4と追加係数0.25/0.5/1を比較する。紙の設計、その他の操作とCLOCK_SCALEは改良元と同じ。
