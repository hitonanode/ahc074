# 商品紙の余分な穴で穴埋め性能を上げる

改良元: solutions/post-prune。

担当商品が一致する位置でも、ハンドル窓の印刷をあえて穴へ変える。補助紙として置いたときに邪魔になる色を取り除き、より長い範囲の穴をまとめて埋められる紙を作る。担当する取り出し窓は必ず印刷したままにし、汎用窓・キャップ窓は変更しない。商品を表示するために増える穴の費用も数える。

列の先頭に残りやすい紙の期待利益を使い、1窓の穴の追加・復元を繰り返す。自身の担当商品と、他の商品への穴埋めの両方を差分で更新する。列先頭の色の確率は巡回の開始時に更新し、巡回中は固定する。研究条件は利益係数0.25/0.5/1.0、1〜2巡回、直接需要が最大の紙だけを変更する条件。

研究用。main.cppは基準のまま、新しい印刷はprobe.cppで作る。保存設計と固定乱数の模擬注文を用い、実注文列は読まない。最初の模擬1本は可視性と最終順序を独立に照合する。CLOCK_SCALEを全時計へ適用する。
