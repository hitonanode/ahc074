# deval-vtarget2

改良元: `solutions/deval-vsingle`。研究用。

焼きなましの V の代わりの指標に、対象ごとの吸収率を使う版（`DEVAL_VANNEAL=2`）を足した。

- 各段の始めに、穴あけ前の自然な紙の設計で V の被覆 DP を計算する。対象 t・深さ j ごとに、そこに穴があれば、不一致がフィラーで覆われる確率を吸収率とする。穴がなければ、その深さの多数側・少数側の色の平均を使う。
- 焼きなましは深さごとの穴の数 N0 / N1 に加えて、穴ごとに (1 − その対象の吸収率) を足した重み付きの数 X0 / X1 を保つ。
- 取っ手の費用は、深さごとに次の式にする。
  - (W_fix X0 + W_abs (N0 − X0)) P1 + (W_fix X1 + W_abs (N1 − X1)) P0。
  - P1 = (X1 + R [N1 > N0]) / (X0 + X1 + R)。
  - W_fix、W_abs は色直し・吸収された不一致 1 回の手数。
  - 対象の吸収率をすべて深さごとの平均にすると、`DEVAL_VANNEAL=1` の式と同じになる。
- 列の移動・対象の交換・複数の紙の置き換えは、対象ごとの重みで X の差分を正確に足す。
- 取っ手の交換と列の入れ替えは、評価のときだけ深さごとの平均の重みで近似する。採ったら、その深さの X を数え直す。
- `DEVAL_VANNEAL_CHECK=1`: 各段の終わりに X を一から数え直し、差分で保った値とのずれの最大を `vb_check_err` に出す（確認用）。

他の設定は改良元（deval-vsingle、deval-vanneal）と同じ。

修正（2026-11-07、独立のコード確認の指摘）:
- 取っ手の交換の評価で、交換後の費用は 2 色に共通の平均の重みで近似していたのに、交換前の費用は色ごとの正確な値を使っていた。そのため、何も変わらない交換にも一定のずれが足され、交換を採るかどうかがずれで決まっていた。交換前の費用も同じ近似で数えるように直した。採った後は、数え直した正確な変化を `cur` に入れる。
- 列の入れ替えの近似で、穴の数 0 のときの割り算の保護を 1e-6 から 1 にした。
- 合わない要求が見込まれない深さと色（V の DP で不一致の期待値がほぼ 0）は、吸収率 0（情報なし）として扱う。前は 0.95（ほぼ全部覆われる）だった。
