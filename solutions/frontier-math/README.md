# 循環列における二重表現の数理模型

改良元: なし（解法ではなく解析用の模型）。

`replica_model.py` は、同じ商品の紙を 2 枚用意したときの掘り手数を調べる。
紙の列は固定された循環順序を保ち、開始位置は一様と仮定する。
実際の解法では紙の戻し方と穴埋めによって順序が変わるため、これは実測値ではない。

- 長さ `n` の循環列にある旧表現と新表現の距離を `g` とする。
- 新表現の穴埋めなどの追加費用を旧表現に対して `delta` とする。
- 旧表現しか使わない場合からの得は
  `g/n * max(0,n-g-delta) + (n-g)/n * max(0,-g-delta)`。
- `delta >= 0` では、最適間隔は `(n-delta)/2` に近い整数。
  `delta = 0` かつ `n` が偶数なら平均 `n/4` 手を削減する。
- 単独紙 a を共有紙 `(a,b)` に変える場合、a の増分費用を `delta_a` として、
  b の得が `delta_a` を上回る必要がある。他注文への穴埋め用紙としての影響も別途生じる。

Python 3 の標準ライブラリだけで動作する。
`python solutions/frontier-math/replica_model.py` で閉形式と総当たりの一致、
各列長・追加費用における最適間隔と得、および昇格の損益分岐を出す。

最後に合成した小さな Markov 模型も出力する。列の前半の紙は 2 商品、後半は
1 商品を表し、後半の紙 1 枚を、半周前の共有紙の商品も表すように昇格する。
共有紙の追加費用は一律 2.6 手と仮定する。紙の色は交互で、商品要求以外に
白黒の色合わせを行う事象を混ぜる。色合わせは回転として実行され、循環順序は
保たれる。定常分布を求めて、循環開始位置の一様性が厳密でない場合も調べる。
これは生成したコンテスト入力への評価ではなく、明示した仮定の下の合成模型である。
