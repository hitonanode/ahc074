# 列の先頭に残る紙を考えた設計

改良元: solutions/head-excess。期待利益の計算は研究版 solutions/design-demand を利用する。

各紙の穴埋め利益を全商品で合計し、列内で単純に平均する代わりに、実際に先頭へ残りやすい紙の利益を使う。列の色の確率は要求色の比率で近似する。その色の紙の中で直接使われる頻度が最も高い種類（共有紙があれば共有紙）に限り、合計利益が最大の紙を先頭候補にする。

模型費用から、先頭候補と列内平均を混ぜた穴埋め利益を引き、紙2枚の所属列を交換する。研究版は混合率0.5/1.0、係数0.3/0.6/1.0。利益は修正窓数−1.6手の正の部分の期待値で、共有による浅い穴も含む。比較元は元の山登りを使う。

`probe.cpp` は保存設計・固定乱数の模擬注文で比較する。実際の注文列は読まない。時計は `CLOCK_SCALE` 倍。提出用への時間配分は模型の結果を見て決める。
