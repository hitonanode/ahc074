# astra-rule-full

改良元: solutions/astra-rule-flex。

汎用6紙の非定数な三値印刷を全て候補にする。各紙で穴・白・黒の3通りからなる729通りのうち、白または黒がない印刷を除いた602通り。白黒の枚数が非対称な1対2、1対3、2対3なども扱う。

商品対は穴で互いに補色だが、許容順序集合と合法距離は両商品を独立に厳密計算しているため、白黒の枚数を一致させる必要はない。非対称な窓が別の窓との制約を緩める可能性を調べる。各15比較組を最低1窓残す可視性保証は維持する。

探索回数・時間制限は改良元と同じ。`rule_three`/`rule_five` は3枚/5枚の窓数、`rule_unbalanced` は白黒の枚数が等しくない窓数。評価結果は astra-lab/REPORT.md に記録する。
