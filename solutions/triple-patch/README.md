# 6枚比較器に少数の補助紙を足して3商品を共有する

改良元: solutions/reset-majority。

保存された6枚の比較器を保ち、汎用窓にだけ印刷する補助紙1〜2枚を加える。元の6枚を補助紙より上に置けば従来の表示ができるため、既存の共有対の表示可能性を保てる。補助紙の白・黒・穴を変え、近い3商品を1枚で共有できる組を増やす。

研究用の選別では、表示可能な対の元の費用と、3商品に仮定した固定復号費用を使う。違う窓の和集合38以下の3商品を調べ、紙総数191−汎用紙数を守る貪欲な共有選択の目的を最小にする。任意の印刷の可否は、残った要求に誤りを出さない紙を上から置く方法で厳密に判定する。最初の6枚で先に解消できる要求を除いて計算を短縮する。

選別目的は実際のスコアではない。得られた印刷は、合法移動の費用と列配置を別途測る。入力は公開バーコードと保存設計だけで、将来の注文は使わない。CLOCK_SCALEを全時計に適用。main.cppは比較元のコピーで、新構造は未統合。
