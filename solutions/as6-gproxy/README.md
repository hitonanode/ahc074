# as6-gproxy: 窓の割り当ての目的に、色の偏りと対の違いの集中を足す

改良元: solutions/as6-imb0gb（Astra の solutions/astra-gproxy/main.cpp をそのまま写したもの）

## 変えたこと

- 窓の割り当て（assign_windows）の目的を gobj − 0.001·B − 0.07·S にした。対の貪欲な選択のキーは元のまま。
  - B: ハンドルの窓の色の偏りの二乗平均（窓 j の 256 目標の黒の数 n_j について、25 ハンドルの (n_j − 128)² の平均）。
  - S: 選んだ 71 対のうち、ハンドル j で違う対の数 D_j の、25 ハンドルの間の標準偏差。
- 理由: 同じ入力で割り当ての乱数だけを変えた 768 設計で、最終の設計の模型の費用との入力内の相関が、gobj だけの 0.575 から、B と S を足すと 0.756 に上がった。
  - B: 色の偏った窓をハンドルにすると、穴の要求を偏らせやすい。
  - S: 対の違いが一部のハンドルに集まれば、違いの少ないハンドルを浅く置ける。
- 時間の配分、後段の設計、注文処理は元のまま。stderr の gproxy_before / gproxy_after は、割り当ての山登りの前後の補正済みの目的。研究の詳細は solutions/astra-gproxy/REPORT.md。
