# 取り出し深さを引いた穴埋め利益で返却する

改良元: solutions/head-design。研究版 solutions/head-rank の係数0.1を提出用にまとめた。

穴埋め需要を深さに比例する重みへ加える方法を、深さごとの正の利益に置き換える。全商品に対して不一致窓数の分布を計算し、「直す窓数−1.6−取り出し深さ」の正の部分を深さ0〜7で前計算する。各列で、この利益の合計の0.1倍を、返却位置と注文後の状態の費用から引く。深さ8以降の追加利益は0とする。

直接の商品頻度は共有紙2、単独紙1のまま。線形の追加需要は使わない。紙の設計・時間配分・時計倍率は改良元と同じ。

`rank_utility_mean` は各紙を深さ0で取り出すときの期待利益の紙あたり平均。経過時間は `CLOCK_SCALE` 倍。
