# 七枚比較器の距離表圧縮と先読み

改良元: `solutions/astra-research`。

七枚の汎用紙と38汎用窓の構造・設計はそのままに、汎用層の最短操作数が同じ終了順序の中で、次の注文の期待操作数が最小のものを選ぶ。六枚版 `astra-search4` にあった先読みを七枚でも使うための版。

七枚の全点対最短路は5040²要素になるが、紙の番号を同時に置き換えても合法操作グラフは変わらない。この対称性を使うと、開始順序を恒等順序にした**一始点5040状態の距離**だけで、任意の二順序間距離が正確に求まる。可視でない最下の紙を直接動かす操作は、距離表を作るBFSから除く。

商品ごとの目標順序集合への距離は、その集合を始点にする逆BFSで全5040順序について計算する。全商品の距離の平均を終了状態の価値とする。現在の注文の手数は増やさず、最短の目標の中でこの価値が小さいものを選ぶ。

設計の時計区切り、`CLOCK_SCALE`、固定乱数は改良元と同じ。七枚専用の補助紙の挿入探索は追加しない。前計算の時間は `helper_end_sec` に含まれるため、オンラインの余裕が減る影響も比較で調べる。
