# 商品の取り出しによる列の先頭色の更新を設計費用に入れる

改良元: solutions/head-design。列単独の厳密模型 solutions/queue-lab から得た費用を使う研究版。

穴の色だけを合わせる列では、白黒の要求頻度x,yに対する費用は2xy/(x+y)。商品を取り出した後の返却で、多い要求色を先頭へ戻せるなら、その頻度tを入れた費用は(2xy+t min(x,y))/(x+y+t)になる。この式を、既存の穴の係数0.8と組み合わせる。列内に両色の共有紙があり、取り出し後すぐ返せる単独列模型では、多くの実プロフィールで厳密値と一致する。

全体の制御では返却が次の注文になるため、tに係数を掛けて比較する。tは各焼きなまし区間の開始時の担当商品数で固定し、区間ごとに更新する。最後の列交換でも最初に更新する。これにより窓ごとの費用をAVX2で差分計算できる。

紙の枚数・汎用印刷・操作制御・時計倍率は改良元と同じ。`probe.cpp` は保存設計から同じ反復数で再設計し、独立した模擬注文で比べる。係数0は研究の対照。`VERIFY_RESET_COST` は差分費用と全計算の照合。

`PRIORITY_NUM` は直接取り出し費用の最小配置への寄せ方（既定17/20=0.85）。完全な寄せ方20/20との組み合わせも研究する。
