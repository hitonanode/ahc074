# 区間DPの除外費用を横切る区間から計算

改良元: solutions/perforated-screen。注文処理は solutions/post-repair。

穴追加の評価で、ある列の補助紙を使わない最良費用を列ごとにDPし直す代わりに、その列を0手で通過する経路と、後ろまで横切る区間の最大値から一括で求める。前向き・後ろ向きDPを使い、二次時間で全列の除外費用を計算する。

さらに、変更前後で有効な被覆位置と最浅の差し込み位置が同じ商品では、全ての先頭色標本の利益が同じなので前の値を再利用する。VERIFY_CROSSINGで全列の再DP、VERIFY_FAST_PERFORATIONで各候補の全DPと照合する。

研究用。候補や目的は元の全1穴変更・16標本・利益係数0.5と同じ。固定乱数の模擬注文を使い、隠された注文列は読まない。CLOCK_SCALEを適用する。
