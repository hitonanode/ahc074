# 商品を複数の共有紙で表す

改良元: solutions/as6-canon。

各商品に対応する紙を1枚に限定せず、同じ商品を別の共有紙にも印刷する構造を調べる。単独商品bの紙を、既に別の紙を持つ商品aとの共有紙に置き換えると、枚数を変えずにaの選択肢を増やせる。ただしbの穴と汎用紙の移動は増える。この差を取り出し費用の分布も含めて比較する。

- 各候補の紙で通常の計画を作り、操作数・穴埋め紙・次の注文の費用の合計が最小の計画を選ぶ。
- 汎用紙の目標順序と補助紙は、候補ごとに計算する。列への返却は、もう一方の紙が安ければその紙を使うという最小値を計算する。紙ごとの固定費は汎用操作の平均とハンドルの穴数×0.4。穴の色要求の頻度は候補を等確率で使う近似とする。
- 紙を共有する2商品は、汎用層で両方を表示でき、その紙の取り出し窓で同じ色のものに限る。キャップ窓は従来どおり差し込み位置で決める。

`probe.cpp` は保存済み設計から候補を調べ、固定乱数の注文列で構造を比較する研究用。入力末尾の実際の注文列は設計に使わない。`main.cpp` の対話形式への設計変更は研究結果を見て追加する。時計には `CLOCK_SCALE` を掛ける。

`copy.cpp` は共有を72対にして専用紙を1枚確保し、既存商品の紙を別の列へ複製する模型。窓の比較器は保存設計のものを使い、対と列を2000万回の焼きなましで作り直す。複製する商品と列を模型で絞り、24候補を4本の注文列で比較して選び、別の16本で検査する。比較元も同じ比較器・同じ反復数で185枚を再設計する。列への戻し方では、複製先が安い場合に元の紙の優先度を下げる。
