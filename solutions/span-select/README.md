# 汎用窓数を入力ごとに選ぶ余地の測定

改良元: solutions/perforated-eight。研究用の復元処理は solutions/map-groups。

固定の38窓と、37・39窓を同じ計算量で最初から設計する。窓割当25万回・山登り5万回、共有と列の探索2000万回、先頭利益の山登り65000回、一括再割当4回、補助穴8標本を共通とする。全体の計算時間は提出制限を超えるため、そのまま提出する方式ではない。

各候補を独立した16本の模擬注文で測り、設計模型や窓割当の指標で窓数を選べるか調べる。模擬の前半で選び後半で測る比較も行い、候補ごとの偶然を選択利益として数えない。まず、入力ごとに窓数を変えること自体の改善余地を測定する。

全表示と各模擬1本の可視性を確認する。入力末尾の隠された注文は使わない。全時計へCLOCK_SCALEを適用する。main.cppは比較元で、研究はprobe.cppから行う。
