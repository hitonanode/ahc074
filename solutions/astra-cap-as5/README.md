# astra-cap-as5

改良元: `solutions/as5-g38`。固定1窓capの仕組みは `solutions/astra-cap` から移植。

汎用窓38・比較器6枚を保ち、物理窓63をハンドルから外して、その窓だけ黒い固定cap紙を1枚置く。ハンドルは25窓、専用紙は185枚（共有71対と単独114目標）になる。窓63は窓割り当ての候補列挙 `window_options` とハンドル集合 `hm` の両方から除く。as5-g38の候補の非重複列挙、停滞閾値、時間配分は保つ。

専用紙のcap窓は不透明とする。単独または共有2目標の色が同じならその色を、共有目標の色が異なるなら白を印刷する。印刷色で目標を表示できるときは通常どおり最上部へ持ち上げる。白い専用紙で黒を要求されたときはcap直下へ持ち上げる。いずれも持ち上げ1手で済み、cap窓の修復を省ける。

capはID6、比較器はID0..5。最初の注文でだけcapを最上部へ運ぶ1手を追加し、以後動かさない。汎用層の操作・補助紙の配置はcapの下で行い、操作列の後処理でも比較器がcapを越える変更を禁止する。座標選択・座標の共同最適化は加えていない。

`cap_window=63`、`model_cost`、`model_col`、`model_hole`、`model_gc` を診断用に出す。モデル費用には最初のcap移動1手や通常の持ち上げ・返却の定数分を含めない。

## 汎用窓数の比較

`g37.cpp` は同じ仕組みでGを37にする。H=26となり、cap追加後もas5-g38と同じ列数を保つ構成である。専用185枚・共有71対は同じ。G38/H25の直接移植と、列数を保つG37/H26の得失を対比較するための版で、実行中に旧解法へ切り替えるものではない。

共有対が71対になることに対応し、窓割り当ての作業配列 `empty` と `saved` の容量を70から128へ拡張した（探索アルゴリズムと評価式は変更しない）。
