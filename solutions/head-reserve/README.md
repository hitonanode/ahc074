# 穴埋め紙の次候補を設計へ入れる

改良元: solutions/tight-thirty-eight。

列ごと・色ごとに、直接使われる頻度が最大の紙を対象として、穴埋め利益が最大の紙と2番目の紙を選ぶ。最大の紙が列外で使われている間に次候補が役立つよう、設計時の先頭利益を2枚の加重平均にする。列交換の山登りと、全商品の一括再割当の両方へ適用し、先頭色確率の微分も同じ式に合わせる。

研究用のprobe.cppは次候補の重み0/0.1/0.25/0.5を比較。同じ窓割当・列共有2000万提案の後から、山登り65000提案・再割当4回を実行し、独立な模擬16本で検査する。実際の隠された注文は読まず、全時計はCLOCK_SCALE倍。提出用の定数は結果を見て決める。
