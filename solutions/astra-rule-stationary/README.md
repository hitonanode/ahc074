# astra-rule-stationary

改良元: `solutions/astra-rule-post`。

最終的に印刷する70商品対を固定し、汎用6紙の各窓に602通りの三値印刷を試す。各15比較組の可視性を保証する窓を最低1つ残し、両targetの表示可能性を保つ。この部分と前半の探索は改良元と同じ。

違いは一般印刷の評価に使う開始順序の分布である。720順序の一様分布から、現ルール・現商品対・既存one-step generic policyが作るMarkov連鎖の定常分布へ置き換える。巡回の開始時に満足順序集合、1段先費用、距離最小かつ将来費用最小の遷移先を計算し、定常分布を更新する。その巡回中は分布を固定し、8状態単位の重み付きpopcount表で逆到達集合の質量を計算する。分布更新時は距離費用cacheを捨て、全70対の現在費用も計算し直す。

モデルは専用紙を単独で表示するときの汎用層だけを扱う。helperや部分的な穴の被覆で汎用層を並べ替える効果は含まない。同じtargetを続けて要求しない制約は、この単純化モデルの定常分布を変えない。理由と評価結果は `REPORT.md` に記録する。

`RULE_SWEEPS` の既定値2、通常モードの終了時刻1.44秒、固定回数モードで完走する条件は改良元と同じ。π更新中は現ルールを変更しない。均等重みの目的値と定常重みの目的値は別の尺度なので、初期・最終モデルの数値を別途stderrに出す。πの最大確率、有効状態数、収束誤差、反復数も診断する。
