# chatgpt-permutation-code

改良元: なし（研究用の符号合成器。提出用解法ではない）。

`code_probe.cpp` は、q 個の商品を m 枚の紙の異なる順列として表し、窓ごとに
`0` / `1` / `.` の印刷を選んで全商品の色を実現できるか調べる。
従来の「商品ごとの専用紙」を、商品群ごとの少数枚の順列符号に置き換えられるかを
検証するための小さな実験である。可視性を満たす群の取り出し手順はまだ扱わない。

すべての m! 順列と 3^m 種の印刷の出力を前計算し、各商品に割り当てる順列を
焼きなましで変更する。目的は64窓の色ベクトルのうち実現できないものの数。
入力なしでは固定seedの一様な重み32の64bit商品を作り、指定ファイルがあれば
公式入力の先頭のバーコードだけを読む。隠された注文列を最適化には使わない。

コンパイル例: `g++ -std=c++23 -O2 code_probe.cpp -o code_probe`

実行例: `./code_probe 6 8 100000 16`（m、q、反復数、群数）。
出力はモデルの成立性の検査であり、コンテストスコアではない。

`elimination_probe.cpp` は同じ1窓の実現性を全印刷の列挙なしで正確に判定する。
先頭となる商品に白黒の両方が混じる紙を穴として除き、これを反復する。
停止した時点で先頭商品の色を各紙に印刷できるなら成功、全紙が消えれば失敗。

`quadruple_bound.cpp` は4商品を3枚で表すために使える列パターンの族を全列挙し、
引数に公式入力ファイルを与えると256商品の全4要素集合も検査する。
検討結果とその適用範囲は `REPORT.md` にまとめる。
