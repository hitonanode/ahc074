# 先頭候補の利益と共有・列枚数を同時に最適化

改良元: solutions/head-excess。研究版 solutions/design-head の先頭候補の穴埋め利益を使う。

紙2枚の列交換で種類・色の枚数を固定する制約を外し、列への1枚の移動、商品対の相手の交換も試す。各列の白黒を最低1枚ずつ残し、共有した商品の汎用部分が比較器で表示できる条件は保つ。紙の取り出し・穴・汎用部分の模型費用から、先頭候補の期待穴埋め利益を引く。各色の先頭候補は、直接使う頻度が最大の紙の中で利益が最大のもの。

研究条件は、元の制約つき交換、自由な列交換と1枚移動、それに商品対の組み替えを加えたもの。係数0.6/1.0、固定65000候補で比較する。差分更新は全計算と照合する。保存設計と模擬注文だけを使い、実際の注文列を読まない。時計は `CLOCK_SCALE` 倍。提出用への統合は模型の結果を見て判断する。
