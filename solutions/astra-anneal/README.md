# astra-anneal

改良元: solutions/astra-assign

固定反復数で乱数列、浮動小数点の結果、受理判定、出力を維持し、設計の焼きなましと窓の割り当てを高速化する。注文処理・モデルの費用・時間配分は改良元と同じ。

- 焼きなましの列移動では、2単位の除去・追加の汎用ループを、交換・1単位移動・2単位移動に共通する整数の差分式に置き換える。動かない2番目の単位の穴差分を省く。
- 固定長の AVX2 ループと、目標交換・対の組み替えの短いループを展開する。穴費用の除算と加算順は維持する。
- 列移動・目標交換・ハンドル交換の列費用を、2列まとめて整数SIMDで計算する。元の `colcost40` と同じ整数式を各レーンに適用する。
- ハンドル交換を受理したとき、全商品の2ビットの交換を分岐なしで行う。
- 窓割り当ての関係と費用を32 bitにし、8対ずつAVX2で処理する。互換な対・再計算する対の列挙順は維持する。
- 閉包キャッシュの参照をインライン化し、8件先のキーの場所を先読みする。キャッシュの容量・キー・完全一致の検査は元版と同じ。

時間配分、閉包キャッシュの262144エントリ、固定回数の指定 `MAP_ITERS`・`GOPT_STEPS`・`ANNEAL_ITERS`・`CLIMB_ITERS`、stderr の指標は改良元と同じ。時計は `CLOCK_SCALE` 倍する。提出用は `main.cpp` の1ファイル。計測方法と結果は `REPORT.md` に記録する。
