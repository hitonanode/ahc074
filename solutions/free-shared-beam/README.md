# free-shared-beam — 自由三値の共用層をビームで構築（研究版）

改良元: `solutions/staircase-beam-v2`（このPRで追加）。**2秒の提出制限は満たさない**。既存最良より平均手数も悪い。目的は比較器の制約を外す実験であり、提出への採用を推奨しない。

## 元から変えたところ

- 共用6枚×37窓を従来の「各窓が2枚の逆色比較」には固定しない。各窓の6枚に `0` / `1` / `.` を割り当てる602通りの非定数模様から選ぶ。共用窓をどの物理窓に割り当てるかも選ぶ。**従来の比較器を初期解として使わない**。
- 窓単位で6枚を同時に決めるビーム。共有する2目標は独立した順序実現集合（6!=720順序）を持ち、候補ごとに71組のマッチングを構成する。
- 完成後4窓を取り除いて再構築する近傍探索。最後に候補固有の可視紙・合法遷移で距離を評価する追加探索を行う。
- オンラインでも共用紙6枚の実際の模様から合法な最短移動グラフを作り、目標を表示する順序まで移動する。主紙の1〜2目標担当、26段の階段は残している。

標準設定: `FB_G=37`, `FB_WIDTH=8`, `FB_SHORTLIST=32`, `FB_ROUNDS=300`, `FB_REMOVE=4`, `FB_GEOMETRY_ROUNDS=60`。後者0で追加探索前。基本構築中は可視性を緩和した代理費用を用い、追加探索とオンライン処理では実際の合法性を使う。設計段階で注文列は読まない。

## ビルド

```sh
g++ -std=c++23 -O2 -march=native main.cpp -o solver
```

`FREE_LOAD` で保存済み共用層を読み込むと初期構築時間を省略する。**このオプションを使った測定は提出時間の評価には使用しないこと**。公式Rustテスタ・統一 `pahcer_run.py` の結果はまだない。

実測・失敗分析は `docs/experiments/staircase-beam-20261106/`、結果の採否は `trial_log.md` を参照。
