# deval-best8

改良元: solutions/deval-headcache（高速化したdeval-vbranch-nofb）。

4分岐の焼きなまし・climb50k・再割当て2回を元と同じに行い、穴あけ8サンプル・穴あけ後再割当てまで全候補を完成させる。完成後のVが良い上位2分岐の焼きなまし直後へ戻り、追加で計4回、固定saltを変えて仕上げる。追加分はclimb25k・再割当て1回・穴あけ8サンプル・穴あけ後再割当て1回。既存の4完成候補を残し、全部で8完成候補の最小Vを選ぶ。

追加分の枝を、仕上げ前のVではなく完成した設計のVで選ぶ。窓割当て・焼きなましの総反復数・注文探索予算は元のまま。時間による打切りはない。DesignStoreは採用候補を保存し、@paper/@ops・目次・段の目印を保つ。
