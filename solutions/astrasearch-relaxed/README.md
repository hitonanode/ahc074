# astrasearch-relaxed

改良元: `solutions/imp-gla`。

従来は、1枚を共有する2商品の違う汎用窓を、6枚の汎用紙だけで表示できることを必須にしていた。
この版は、既存の専用紙を汎用紙の間に挿すことで初めて表示できる対も許す。
その補助紙がハンドル窓で誤色を出す場合、自身の持ち手以外の誤色セルに穴を追加する。
補助紙自身の商品の注文では、追加された穴を通常のハンドル修正で表示する。
追加の紙は使用しない。

## 紙の設計

列設計の焼きなましを1.04秒まで、穴埋めの山登りを1.09秒まで行う。
次に「既存の対1組と単独2商品」を「新しい非整合の対1組と単独2商品」に置き換える候補を調べる。
初版では最良の置き換えを最大1回行う。
新対の候補は 0.8×ハンドル差 + 0.08×汎用窓の差が小さい順に既定40組、探索は1.35秒まで。

各方向について、汎用紙720順序と補助紙の挿入位置を列挙し、目的の汎用窓を表示できる終状態を求める。
補助紙の評価は、汎用紙の平均最短移動、列から掘り出す深さの近似、挿入1手と回収0.8手、覆うハンドルの利得で行う。
追加の穴の費用は補助紙の担当商品数（単独1、対2）を含む既存の穴の費用表で計上する。
列の両色、紙数192、各商品の所属、補助紙自身のハンドルの保持を維持する。

## 注文の処理

非整合の新対の注文は、通常の汎用紙だけの処理へ入らない。
前の専用紙と補助紙を回収し、6枚の汎用紙を整列してから、検証済み補助紙を挿し、要求の専用紙を持ち上げ、残りのハンドル穴を直す。
実際に出力する紙の模様から補助紙の終状態をもう一度列挙し、両商品に合法な表示が存在することを検査する。
手順は模擬時に可視性・表示一致・次回の回収可能性を検査する。
将来の注文は使用しない。

## 研究用の指定

- `RELAX_FORCE=1`: モデルの改善がなくても最良の有効な置き換えを1つ採用する。候補数上限は保つが探索の時間打ち切りと注文処理の軽量化は外すため、2秒を超える研究専用モード。
- `RELAX_PAIRS=n`: 調べる非整合の新対の候補数。
- `RELAX_MIN_DEPTH=n`: 補助紙の上に最低n枚の汎用紙を残す（0〜4、既定0）。3なら底2〜3枚の間での置換だけになる。

`relax_selected` は置換数、`relax_predicted_delta` は置換前の予測差、`relax_actual_model_delta` は追加穴を反映した設計モデルの差。
`relax_punched_handles` は補助紙に追加したハンドル穴の数。
`mandatory_targets/requests/failures` は補助紙必須の商品数・実際の注文数・有効な計画が作れなかった数。
モデルの列内の深さや回収費用は近似であり、性能は実測比較で確認する。
