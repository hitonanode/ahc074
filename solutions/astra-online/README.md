# astra-online

改良元: `solutions/astra-search4`。

列の中に戻す紙の位置は、現解法では「重み付きの深さと各色の最初の紙の深さ」という一段先の費用で決めている。
ここでは、その後にも残る紙順の価値を平均費用 Markov 決定過程として調べる。

研究用 `column_mdp.cpp` は、紙を単独/共有と白/黒の4種類にまとめ、1本の列の全ての型順序を列挙する。
要求された紙より上の紙は、要求紙より下の任意の位置へ差し込める。要求紙の深さを1ずつ減らすDPにより、各要求を達成した後の相対価値を最小化する。
要求は紙ごとの取り出し（単独1、共有2の重み）と、指定色を先頭へ出す要求からなる近似モデルである。
これは全体のコンテストスコアではなく、列の一段評価にどれだけ改善余地があるかを調べる道具である。

提出用 `main.cpp` は、列の挿入位置の一段費用が同点の場合だけ、列全体の同色連続区間の `長さ×(長さ−1)/2` の合計を最小にする。従来は最も深い挿入位置を選んでいた。第2段以降の色の偏りを避け、後の注文がそこへ到達した際の掘りを減らす狙い。一次費用を変えない微小係数 `1e-6` で同点を選び、最後の同点だけは従来と同じく深い位置を優先する。紙の設計・計画候補・その他の時間配分は改良元と同じ。

`generic-mdp.cpp` は別の独立候補。比較器6枚の720状態について、実際に設計した共有紙の要求を用いる平均費用MDPの相対価値反復を最大30回行う。到達可能な表示の中から「今回の最短距離＋終端相対価値」を最小にする。元の一段先読みの再検証であり、列の同色run変更は入れない。`generic_mdp_iterations`、`generic_mdp_residual`、`generic_mdp_span` は反復数・Bellman差分の範囲・終端価値の範囲。

`column_mdp.cpp` の引数は `単独白 単独黒 共有白 共有黒 白色要求重み 黒色要求重み`。
状態数、最適モデル費用、一段評価方策の費用を標準出力へ出す。
