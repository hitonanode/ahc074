# 割当の変更に合わせて先頭色の確率を更新する

改良元: solutions/anchor-match。

研究用。元の割当目的では、先頭色の確率を最初の穴の要求比率で固定する。本候補では、割当後の要求数で確率を更新する。また、商品紙の返却によって多い要求色へ戻る効果を加え、黒の確率を `(黒の要求数 + 更新強度×列の商品数×多数色が黒)/(全要求数 + 更新強度×列の商品数)` とする条件を調べる。

割当の線形化には、先頭紙の直接の利益と穴の変化に加えて、要求数が先頭色の確率を変える効果を入れる。覆う穴のうち誤色が0個・1個になる確率を使い、各窓の確率に対する利益の微分を計算する。供給する先頭候補の色の確率が変わる効果も含める。巡回の受理では、確率と先頭候補を全て計算し直す。

probe.cpp は更新強度0/1/2、確率の固定・更新、微分の有無を比較する。保存設計と固定乱数の模擬注文のみを使い、実際の注文列は読まない。main.cpp は比較元のまま。CLOCK_SCALEを全時計へ掛ける。

pipeline.cpp は先頭色の近似を、最後の一括割当だけでなく、その前の穴埋め山登りと注文時の追加需要にも適用する条件を比較する。各ケースは同じ2000万回の設計結果から分岐し、65000回の山登りと4回の割当を行う。observe.cpp は独立した8192注文で列先頭の色と候補の選択率を数え、設計時の確率と比べる。

probe_tie.cpp は白黒の要求数が同じときの偏りを0.5とする条件と、先頭候補の直接使用頻度の差も加えて返却時に望ましい色を決める条件を調べる。
