# 汎用6枚と浅い商品紙2枚を混ぜた復号部品

改良元: solutions/reset-majority。

汎用紙6枚の直下にある商品紙2枚を含め、8枚全体の順序を自由にする構造を研究する。商品紙を補助として汎用層へ持ち上げる代わりに、汎用紙を商品紙の下へ差し込み、その印刷で穴を埋める。商品紙を別途配置・返却する手を省けるか調べる。2枚は最初のハンドルで逆の色を持ち、元から持つ商品を担当するので、補助専用の紙は増やさない。

`model.cpp` は保存設計から2枚を選び、汎用窓と先頭ハンドルについて全8!順序の平均費用MDPを解く。外の商品の部分一致と、内部の商品紙を取り出した後の穴修正を含める。後者は上の商品紙に隠されていない窓だけで紙を動かせる。持ち上げと即時返却は無料の模型で、実際より有利。

対照は同じ印刷・同じ商品紙で、汎用6枚を常に商品紙より上に保つ模型。これで操作を混ぜること自体の余地を比較する。その他の列との干渉、穴埋め紙、時間制限はこの模型の外なので、公式スコアとは分ける。実際の注文列は使わず、CLOCK_SCALEを掛ける。`main.cpp` は比較元のコピーで、まだ統合していない。

`templates.cpp` は、2商品で色が違う汎用窓だけを印刷した相補的な商品紙を選ぶ。先頭ハンドルも逆の色にし、元の商品を表示する際に残る穴が汎用6枚で直せることを要求する。新しく共有できる近い対の数と、元の商品自身の穴修正費用を比べる。

`model.cpp` の追加引数でこの2商品と不透明窓を指定できる。価値反復後の定常分布から、各共有対を「操作数＋次状態の価値−今の価値」で値付けする。`design.cpp` はその価格で残りの商品紙の共有と列配置を再設計する。2枚を先頭列へ固定し、先頭窓の穴費用は復号価格に含めて重複を避ける。`design.hpp` はその研究用設計器、`build_design.py` は生成手順。
