# 不完全な比較グラフ

改良元: `solutions/astra-search4`

汎用紙 6 枚の 15 組のすべてに窓を割り当てる制約を外す。
窓を別の組へ移すとき、元の組に窓が残らない変更も許し、
完全グラフに限らない比較器の設計を探索する。紙の枚数や時間配分は変えない。

比較する窓がない紙の組があると、底以外の紙も隠れる場合がある。
720 通りの順序ごとに不透明な窓の和を上から求め、実際に見える紙だけを
動かせる遷移を作り、その有向グラフの BFS で注文処理の距離と経路を求める。
比較グラフが不完全な場合も汎用層の先読みと補助紙の探索を使う。

設計段階の `PosetSums` は完全グラフの合法距離の表を引き続き使用するため、
不完全グラフでは汎用紙の手数を小さめに見積もる代理目的関数である。
注文処理は実際の可視性に従う正確な距離を使う。互換性判定の DAG 条件は変わらない。

追加の stderr 指標:

- `generic_edges`: 窓を少なくとも一つ持つ比較組の数。15 なら完全グラフ。
- `generic_extra_hidden`: 全 720 状態における、通常の底紙以外に隠れている紙の延べ数。

評価条件と結果は同ディレクトリの報告書および `trial_log.md` に記録する。
