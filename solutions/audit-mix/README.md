# audit-mix

改良元: solutions/mix-pt

最良解の監査（solutions/audit-tools）で見つかった注文処理の無駄 2 つを直した。紙の設計は mix-pt と同じ。

## 変更点

- 同じ紙の 2 回の移動をまとめる覗き穴（merge_double_moves）: 計画が同じ紙を 2 回動かすことがある（古い穴埋め紙を列へ戻した直後にその列を掘る、戻した紙をまた穴埋め紙に置く、列の外の注文の紙を戻してから持ち上げる、など）。1 回目で 2 回目の行き先（2 回目の後と同じ深さ、または 2 回目が下に入れる紙のすぐ下）へ直接動かすか、1 回目を省いて、全部の手を再生し直し、すべての手が合法で最後の重なりが同じなら置き換える。全ての計画にこれをかけてから費用を比べる。
- 紙を今と同じ場所へ動かす手（例: 穴埋め紙を自分の段へ置き直す）は出力しない。
- 前の専用紙を残す計画（run_plan の ret_mode 4）: 古い穴埋め紙には「害がなければその場に残す」計画があったが、前の注文で持ち上げた専用紙にはなかった。新しい専用紙をその上に持ち上げ、前の専用紙はそのまま段 0（ハンドル h_0 から自分の列のハンドルまで）の穴埋め紙として列の外に残す。前の専用紙は新しい紙の穴に自分の色を見せるので、そこで目標の色と合う必要がある。汎用層より上にあるので、新しい紙に汎用窓の穴がある場所で不透明なら使えない。費用は穴埋め紙と同じ 1 枚 0.8。後の注文で戻すか、穴埋め紙として使い直す。
- 列の外から直接持ち上げた紙（pool-value）を前の専用紙として残したときも、巡回順の前の紙を覚えておく。

## パラメータと指標

- 環境変数 `MERGE_DOUBLE`（既定 1）: 0 で覗き穴をかけない。`PREV_STAY`（既定 1）: 0 で前の専用紙を残す計画を試さない。
- stderr の `prev_stay_used`: 前の専用紙を残す計画が選ばれた注文の数。
