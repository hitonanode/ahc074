# 操作結果から終了状態の費用を測る

改良元: solutions/tight-thirty-eight。

現在の操作方策で独立の一様模擬注文を処理し、終了状態の各費用と、その後の実際の手数を記録する。特徴は直接注文による列内の深さ、穴埋め需要による追加深さ、穴の色合わせ費用、汎用層の下/上の穴埋め紙数、据え置き確率、無料被覆の利益、穴埋め紙の組数。平均費用を引いた1/4/16/64注文先のTD方程式を集計し、状態価値の係数を推定する。

設計には保存窓割当から列共有2000万提案・山登り65000提案・再割当4回・補助穴設計を使う。収集時の方策は改良元そのまま。最初の64注文を除き、別の乱数で作る模擬注文16本を使う。入力末尾の隠された注文は読まない。収集と、係数を変えた方策の検査は別入力で行う。時計はCLOCK_SCALE倍。
