# as6-canon: 穴埋め紙の水準を、空の列を越えて上げる

改良元: solutions/as6-imb0gb

## 変えたこと

- 注文処理は、列の外にある紙（穴埋め紙）を「水準」で記録する（canonicalize）。水準 L の紙は、その紙より下にある列の中の紙のうち一番浅い列の番号で、ハンドル h_L から自分の列までに見える、という前提で使う。
- ところが、列 L−1, L−2, … に列の中の紙が 1 枚もないと、その紙はそれらのハンドルにも見える。浅い列は 2 枚ほどしかなく、1 枚が持ち上げられたり穴埋め紙に出たりすると空になる。注文の始めに空の列は 1 注文あたり 1.3 列ある（as6-imb0gb、seed 0〜9）。
- 水準を、すぐ上の空の列を越えて上げるようにした。穴埋め紙がどのハンドルに見えるかの記録が、実際の表示と合うようになる。
- 根拠: 設計を固定した模擬（solutions/steady-probe/knobs.cpp の CANON_FIX、seed 24〜87、注文列 4 本）で −0.012 ± 0.004%（43/3/18）。
