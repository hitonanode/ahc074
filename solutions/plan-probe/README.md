# plan-probe

改良元: solutions/as5-g38（計測用のコピー。提出用ではない）

注文処理の定数を環境変数（百分率）で変えられるようにした版。いずれも未指定なら元の値。補助紙の表の打ち切りはなくしてある（設計の回数を固定した模擬で、補助紙が消えないように）。

- `FC`: kFillerCharge（列の外に残す紙 1 枚の費用。元は 0.6）。
- `EW`: kEndWeight（終わりの状態の期待費用の重み。元は 1.0）。
- `TP`: kTopPenalty（列の一番上へ戻す罰。元は 0.35）。
- `RL`: kRelevel（元は 0.5）。
- `ST`: kStay（元は 0.8）。

`-DSIM_HARNESS` でビルドし、設計の回数を固定して（MAP_ITERS など）、同じ設計の上で注文処理の違いだけを比べる。
