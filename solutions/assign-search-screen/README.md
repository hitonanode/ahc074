反転・汎用窓同士の交換で生じる両向きの弧を、既存の採用組の色ビット集合から数える。両向きの弧だけで3組以上が無効なら、閉包計算をせず従来と同じ理由で棄却する。残る候補は従来の閉路判定と全組評価を受ける。各汎用窓を除いた辺の色は同一状態内で保存する。候補・乱数・目的関数は変えない。

AS_SCREEN=1（既定）は有効、0は無効。AS_WORK=1（既定）は窓割り当ての反復倍率。コンパイル時AS_PROFILE=0（既定）は演算子別の計測を無効にする。direct_checks / direct_rejectsは追加の簡易判定回数と、そこで証明できた棄却の回数。既存のログと実験・解析施設はすべて保持する。screen_checksは閉包を使う従来判定に到達した組数なので減る。
