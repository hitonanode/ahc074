# 同じ最終状態の後処理評価を再利用する

改良元: solutions/eject-single-window。

後処理の候補ごとに得られる最終の紙順を、64枠のキャッシュに保存する。ハッシュが一致した後もリンク配列の全要素を比較し、同じ状態と確認できた場合だけ将来費用を再利用する。候補の操作数は無操作を除いて数え、その費用が現在の最良以上なら、途中の可視性を再生する前に捨てる。改善する可能性があれば従来どおり全再生する。

候補列・採否・紙の設計を変えず計算を短縮する研究。probe.cppはキャッシュ有無で全操作列・最終順序のハッシュと全表示を照合し、各条件1系列で可視性も検査する。全時計はCLOCK_SCALE倍。提出用の採用は正式比較後に判断する。
