# 表示順序と汎用紙の印刷を交互に設計する

改良元: solutions/head-demand。研究用の入力・価格計算は solutions/free-code から複製。

6枚の汎用紙への印刷を、2枚の比較に限らず602種類の白黒穴から選ぶ。商品対の選択だけでなく、各商品を表示する汎用紙の順序を潜在変数として持つ。現在の印刷で表示に近い順序を選ぶ段階と、その順序で商品に合う印刷を全窓について選ぶ段階を交互に行う。中間の不一致は温度を付けて許し、1窓ずつの変更では抜けにくい制約をまとめて変える。

共有対は近い商品から71対を選ぶ。探索中は表示できる順序の数を汎用操作の近似価格に使い、最後は720状態の実際の可視性と合法な移動で価格を計算する。探索で使うのはバーコードと保存設計だけで、注文列は読まない。`main.cpp` はまだ比較元のコピーで、提出用には組み込んでいない。

`search.cpp` の引数は入力、保存出力、反復回数、初期温度、乱数seed。時計には `CLOCK_SCALE` を掛ける。`base.hpp` は free-code の研究用ソースの複製で、そのmainは無効にして使用する。
