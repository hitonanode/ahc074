# filler climb を同じ結果のまま速くし、4 倍の回数を回す（esw-climb4）

改良元: solutions/esw-colmdp（fallback を外した版）

## 改良元からの差分

- 設計の filler climb（両方の取っ手で色を保つ同じ種類の 2 単位の列の入れ替えを `cur − 0.5 × proxy` で受理する山登り）を、探索の経路を変えずに安くした（Astra の solutions/head-steer の差分を移植）。
  - 棄却した入れ替え（同じ状態のまま）を、受理の回数を世代番号にして記録し、次の受理まで同じ組を引いたら評価を省く。引く乱数は同じなので、経路はキャッシュなしと同じ。
  - 入れ替えは両方の列の種類と色の数を保つので、各列の各色で最も重い単位（先頭の資格）は変わらない。資格のない紙の効用は proxy に効かないので保持しない（動いた紙は移動先で計算し直す）。
- そのぶん filler climb の回数を 38500 → 154000（4 倍）にした（`kClimbIters`）。
- 根拠: solutions/head-steer（dsel-probe λ 0.5 比、1000 件 × 注文列 4 本で −0.023 ± 0.007%。climb の時間は −40%、設計の後半全体で −3%）。4 倍の回数の利得は trial_log 2026-11-05 の filler climb の節（λ 0.5 で 1 倍 −0.072%、4 倍 −0.095%）。
- 注文処理は改良元と同じ。
