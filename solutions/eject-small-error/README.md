# 小さい表示差でも2操作削除後の修復を調べる

改良元: solutions/tight-thirty-eight。

2操作を消して1操作で修復する探索では、削除後の表示の不一致が2窓未満だと候補を捨てていた。この閾値を1窓、0窓へ下げる。0窓でも、修復候補の紙を取り去った状態で不一致が生じ、再挿入で表示を直せる場合だけ調べる。表示の変化が小さくても、途中で紙を見えるようにする操作を短縮できる可能性を調べる。

紙の設計と時間配分は変更しない。min_eject_errorsの既定値2は従来どおりで、probe.cppが0/1/2を比較する研究用。公開バーコードと保存設計だけを読み、独立な固定乱数の注文を使う。全表示と各条件1系列の可視性・最終順序を検査する。全時計はCLOCK_SCALE倍。
