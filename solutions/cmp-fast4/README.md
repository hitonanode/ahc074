# cmp-fast4

改良元: solutions/cmp-hswap2

速さだけを変えた（割り当て・山登り・焼きなましを同じ回数にすれば出力は cmp-hswap2 と同じ。cmp-base/eqcheck.py に `GOPT_STEPS=1500` を付けて seed 0〜31 で一致）。

- 焼きなまし: 列だけが変わる手では、却下に備えて保存するハンドルの数を、4 単位の穴の和集合から、穴になるかが変わるハンドルだけにした（約 3% 速）。
- 割り当て（assign_windows）: 対の関係が変わらず重みだけが変わる対（窓の交換）は閉包を計算し直さず、両立と関係の数をそのまま使う。目標ごとの (degree + 0.2)^0.7 をキャッシュし、手ごとの pow を半分にした（割り当て 8000 回 + 山登り 2000 回が 0.44 → 0.40 秒）。
