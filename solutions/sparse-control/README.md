# 比較を省いた汎用6枚を合法移動で制御する

改良元: solutions/sparse-map。

不完全な比較グラフでは、汎用紙の全720順序から作った合法移動の距離表で通常計画も実行する。完全グラフ専用の部分列による復号を使う条件を分け、補助紙との組合せにも実際の距離を使う。紙の印刷と配置は、sparse-mapで保存した全比較必須・比較を自由に消す・1組を禁止する3候補をそのまま読み込む。

共有・列を再探索せず、補助穴を元の8標本で追加した後、独立した16本の模擬注文を実行する。全表示一致と各1本の可視性を検査する。汎用操作数、計画失敗、最終検査で退けられた計画も数える。

研究用のprobe.cppで動作する。main.cpp単独は割当の研究設定を選ばないため提出候補ではない。隠された実注文は読まず、CLOCK_SCALEを適用する。
