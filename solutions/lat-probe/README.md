# lat-probe（分析スクリプトのみ）

改良元: なし（解法ではない）

imp-all（run 20261101-183237_imp-all）の出力を scripts/replay.py で再生して、構造の見直しのための数を出すスクリプト。どれも `python3 <script> SEED...`（run は common.py の RUN）。列は「不透明なハンドルの数」から決める（bold-probe と同じ）。

- common.py: 入力・出力・列の読み込み。
- overhead.py: 注文の手を役割（持ち上げ・前の紙・掘り・汎用紙・それ以外の直し）に分け、対/単独 × 列の深さごとに平均。前の紙が動いた割合（前の紙が浅い/深い）。
- digstat.py: D より上にある同じ列の紙の数（うち対）と列の大きさ。
- pairholes.py: 対の |Δ_G|、不透明な範囲のハンドルでの違い（対の穴）と三角形の穴、それぞれの開始時の不一致。
- genmis.py: 対の注文で、開始時に色が違う Δ_G の窓の数と汎用紙の手数（不一致 1 窓あたりの手数）。
- pairfix.py: 不一致の穴を自分の列の紙（回転）で直したか、別の列の紙（穴埋め紙）で覆ったか（対の穴と三角形の穴で別）。
