# 先頭の商品紙を必須の補助紙にする共有

改良元: solutions/post-two。研究用で、main.cppだけでは新しい共有設計は行わない。

比較器だけでは表示できない商品対でも、別の商品紙を比較器の間へ挟めば表示できる場合を使う。既存の共有1組と単独2枚を、別の共有1組と単独2枚へ置き換え、または2枚の商品担当を1個ずつ交換し、商品紙185枚を保つ。補助紙は変更する3枚以外から選び、共有紙のハンドルの穴と色が一致することを確認する。

模型は補助紙の配置・返却1.6手、汎用紙の全720開始順からの最小手数、補助紙の追加需要による取り出し費用、補助紙が埋めるハンドルの穴の減少を数える。選んだ2商品の補助紙を固定する。

注文処理では、これらの商品を通常の比較器だけで復号せず、指定した補助紙を必ず使う。深さ制限を外し、同じ共有紙のもう片方の商品が続く場合にも補助紙の計画を作る。返却優先度には必須補助紙の利用頻度を加え、必ず埋まる穴の要求を除く。設計・注文の検査は保存設計と固定乱数の模擬注文で行い、隠された実注文は読まない。CLOCK_SCALEを適用する。
