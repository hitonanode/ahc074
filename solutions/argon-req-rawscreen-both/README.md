既に生成済みの状態価値付き共同DP計画のうち、通常の編集対象に入らなかった計画へ削除だけの安い編集を行う。元の最終計画からの値差1以内で別積層のものに限り、編集後の評価値が元の最終値以下なら既存のeject処理で仕上げる。既存候補を押し出さず、元の探索を終えた後で改善した計画だけを採る。新たなDP解や区間の状態価値を計算し直さない。

対象は抽出直後とハンドル修正後の2種類のDP。raw_joint_trials/promisingは安い編集の試行数、編集後に最終値以下となった数。追加ejectの結果は既存のvalue_seed_*にも含む。全ログ、実験スイッチ、プロファイラ、CLOCK_SCALE、LOCAL_BENCH、DesignStore、節と目次を保持する。
