R2の採用済み状態価値付き共同DP計画を保存し、通常の探索が完成した後、その計画だけでも後処理・中立探索を行う。元の初期評価値が完成した最良値から0.5手以内で、同じ操作列ではない時だけ試す。初期計画は保存したものを使うので、DPをもう一度解かない。完成値が厳密に改善した時だけ使い、同値では元の結果を保つ。目的関数・設計・各探索の予算を変更せず、将来の注文も読まない。

既存のログ・予算スイッチ・プロファイラを維持し、常に0のvalue_filler_zero/value_filler_zero_usefulは削除する。process_coreが共通の探索を担当し、processは条件付きの追加探索を行う。追加段のsection markerと目次を追加した。

late_seed_trials/valid/better/gain/savedは追加処理した数、有効な完成計画数、採用数、完成評価値改善の合計、その時点の即時手数節約。新規環境変数はない。

既存のplan_cacheに対応する結果があれば、削除・挿入位置変更済み、またはeject済みの計画を引き継ぐ。既に済んだ段は繰り返さない。値の条件はこの途中結果に適用し、現在の完成結果と全紙の順序が同じ候補は追加処理しない。

late_seed_cachedは途中結果を引き継げた注文数、late_seed_order_skipsは同じ積層のため追加処理を省いた注文数。

追加処理は通常の候補編集が既に済んでいるがeject・中立探索が未完了の計画だけに限定する。未編集の候補を一から処理すること、および既に通常の勝者としてeject・中立探索を受けた計画の再探索を省く。初期積層が通常計画と同じ候補も対象とする。完成値との差の上限は0.5。
