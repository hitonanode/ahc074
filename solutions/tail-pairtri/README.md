# tail-pairtri

改良元: solutions/audit4-flip-clk

焼きなましの費用で、対（2 目標で 1 枚の紙）の単位の「三角形の穴」（列 l より深いハンドル h_m, m > l の穴）の重みを
`PAIR_TRI` 倍にする（hole_w。対の違いの穴と単独の目標の穴は今までどおり）。

- 根拠: solutions/tail-probe/fitpair.py の回帰（brk-probe、seed 0〜95、焼きなまし固定）で、穴に関わる手数は
  単独の目標 0.765 + 0.380 × 三角形の穴、対の目標 2.134 + 0.345 × 三角形の穴 + 0.343 × 対の穴。対の三角形の穴は
  単独より 1 個あたり約 9% 安いが、焼きなましは同じ重み（HUB_KH = 0.51 × 持続モデルの重み）で値付けしている。
- `PAIR_TRI`（環境変数、既定 1.0 = 改良元と同じ）。山登り（filler_climb）の費用は変えていない。
