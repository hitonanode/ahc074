- breakdown2.py RUN [SEED_FROM SEED_TO]: run の出力を scripts/replay.py で再生し、注文 1 回あたりの手を役割ごとに数える。紙の役割は出力だけから決める。
  - 汎用紙: 最初に上にある 6 枚。
  - ハンドル窓: 汎用紙がすべて穴の窓。
  - 専用紙の列: その紙が不透明な最も深いハンドル（下記）。
- 数える役割（列は「その紙が不透明な最も深いハンドル」。ハンドルの順は最初の重なりから復元する。対の紙は浅いハンドルにも穴を持つので、不透明なハンドルの数では決まらない）:
  - 汎用紙の移動（generic）。
  - 注文の紙 D を一番上へ（to_top）、汎用層のすぐ下へ（below_generic）。
  - 深い位置への移動（deep:*）。内訳は、前の注文で一番上だった紙を戻す（prev_top_back）、D より前に D と同じ列を掘る（dig_D_column）、それ以外を D の前（other_before_D）と後（after_D）に分けたもの。
- あわせて、D のハンドル窓の穴の数（D_handle_holes。うち三角の穴 D_triangle_holes）と、D の列の紙の数（D_column_size_x）の平均も出す。
- holes.py RUN [SEED_FROM SEED_TO]: 注文の前の状態で D を一番上に置いたと仮定し、D のハンドル窓の穴のうち、見える紙の色が要求と違うものを数える（wrong_holes_before）。
- breakdown2.py はキャップ付きの解法（solutions/as6-cap38）にも対応する。
  - 不透明な窓が 2 個以下の紙（キャップ）は、汎用紙と同じ扱いにする。
  - すべての専用紙が不透明な窓（キャップの窓）は、ハンドル窓に数えない。
  - D は、注文の後に一番上にある専用紙とする（キャップの直下に置かれる場合を含む）。
