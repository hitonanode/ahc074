新しく有効になる組の利益を見積もり、窓交換を順位付けする。ただし対象組の両端が別々の採用組に使われている場合は、順位の利益に数えない。1組を挿入すると2組を追い出す費用を無視した過大評価を防ぐ。両端が空いていれば採用組の最大費用、一端だけ採用中ならその組の費用との差で順位を付ける。全候補の評価と目的関数は変えない。

AS_RANK=0は元の提案、1（既定）は順位付け、2はハンドル差も加算。AS_WORK=1（既定）は反復数倍率。AS_PROFILE（コンパイル時、既定0）は1で演算子別の時間・改善量を計測する。追加指標rank_rows / rank_pairs / rank_choices / rank_positiveは順位表数、除去で有効になる組の延べ数、順位選択数、正の推定利益を持つ選択数。既存の全ログ・設定・CLOCK_SCALE・LOCAL_BENCH・DesignStore・@paper/@opsは維持する。
