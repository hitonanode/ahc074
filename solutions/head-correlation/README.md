# 列の先頭色の相関を穴埋め利益へ加える

改良元: solutions/reset-head。

研究段階。各窓の先頭色が独立という近似を見直す。一つの注文が複数の穴を同時に更新する過程と、商品紙の返却が担当窓を多数色へ戻す過程を用い、任意の2窓の定常共分散を計算する。

穴埋めの利益 `max(0, 不一致数−1.6)` に、共分散による2次の補正を加える。他の窓の不一致が0個・1個である確率を使い、各2窓の共分散に `0.4×0個の確率 + 0.6×1個の確率` を掛ける。覆う窓が2個ならこの補正はその相関過程に対して厳密で、3個以上では高次の相関を省いた近似になる。

穴埋め山登りでは開始時の共分散を固定し、一括割当では巡回の受理時に更新する。割当の微分は元の独立近似のままで、受理では補正を含む目的を計算し直す。probe.cpp は補正係数0/0.5/1/2を、同じ2000万回の設計から65000回の山登り・4回の割当で比較する。固定乱数の模擬注文を使い、実際の注文は読まない。

main.cpp の補正係数は0で、提出用の変更は未確定。全時計はCLOCK_SCALE倍。結果はtrial_log.mdに記録する。
