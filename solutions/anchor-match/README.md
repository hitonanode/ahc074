# 共有相手を一括で入れ替える割当問題

改良元: solutions/reset-majority。

共有対ごとに片方の商品を固定し、残りの商品と単独商品を、全ての紙へ一括で割り当て直す。固定した商品がない紙は単独用、ある紙はその商品との共有用になる。各紙の列・単独か共有か・取り出し窓の色を保つ制約を付けるため、列の取り出し費用と両色がある条件は変わらない。

穴の色要求の費用を現在の要求数で微分し、汎用紙の操作費用と先頭紙の穴埋め利益を合わせて185行の割当問題をハンガリアン法で解く。得られた商品の置換を巡回ごとに適用し、全紙の先頭候補を再選択した元の非線形費用が改善するものだけ採る。穴埋めの利益では、商品の穴の変化と供給する紙の模様の変化の両方を一次近似し、色の分布は反復中固定する。

main.cpp は改良元の穴埋め山登りの後に、係数1.0の一括割当を最大4回行う。1.445秒を目安とし、前の反復時間から次の反復が間に合わないと見積もる場合は開始しない。他の時間配分・紙の枚数・注文時の操作方法は改良元と同じ。全時計にCLOCK_SCALEを掛ける。

stderr の match_iterations は実施回数、match_cycles は受理した巡回数、match_changed は交換した紙数の累計、match_decrease は模型費用の変化を商品数で割った値、match_sec / match_end_sec は所要時間と終了時刻。

研究用の probe.cpp は穴埋め利益を含めない条件、probe_head.cpp は係数、probe_rounds.cpp は反復数を比較する。保存設計と固定乱数の模擬注文を使い、隠された注文列は読まない。build_submit.py が単一ファイルの提出用を作る。結果と採否はtrial_log.mdに記録する。
