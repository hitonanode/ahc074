# 汎用層の定常分布で共有対を値付けする

改良元: solutions/reset-majority。

従来は各商品対の汎用操作を、6枚の全720順序を同じ重みとして独立に値付けする。本研究では、選ばれた71対から来る注文を使い、実際に訪れやすい順序とその将来費用を平均費用MDPで求める。他の共有候補も、その定常分布と将来費用から価格を付け直して、商品の共有と列配置を再探索する。これにより、単独では安い対だけでなく、一緒に使ったときに汎用層の移動が少ない対の集合を探す。

全順序間の距離は可視性を満たす合法移動の距離。状態価値には任意の余分な移動も含める。価格は「今回の操作＋終了状態の価値−開始状態の価値」の定常期待値。元の一様分布価格との混合率を比較し、焼きなましの4区間の前に更新する。

`price.hpp` と `probe.cpp` は保存設計・独立した模擬注文を使う研究用。`main.cpp` は価格更新のフックを追加した段階で、通常実行ではまだ基準と同じ。実際の注文列は設計に使わない。時計はCLOCK_SCALE倍。
