# 表示用の窓と取り出し用の窓を兼ねる部品

改良元: solutions/as6-canon。研究模型は solutions/module-lab の全順列MDPを拡張する。

現行の構造は、汎用表示の窓と列から紙を取り出す窓を分けている。この分離を外した局所構造を調べる。2枚の表示用紙、複数の商品用紙、汎用窓1個、取り出し窓2〜3個を一緒に扱う。

- 比較基準は表示用紙が汎用窓だけを白黒にし、商品用紙が汎用窓と階段状の取り出し窓を覆う印刷。列への割り当ても探索する。
- 新構造では、表示用紙を取り出し窓にも印刷し、商品用紙にも自由に穴を追加・削除できる。紙の順序と移動は全て実際の可視性で検査する。
- 外の商品から来る要求は取り出し窓の色合わせで、割合 `gprob` では汎用窓の色も指定する。割合 `q` の要求は指定の商品用紙の取り出しと、その紙に残る穴の色合わせ。
- 指定紙の持ち上げと、その直後の任意の位置への返却を無償とした模型。実際より有利なので、全体のスコアとは扱わない。

`build.py` が `module.cpp` を生成する。`H`、`K`、`q`、`gprob`、`seed`、`triangle`、探索回数と時間を引数で指定する。固定seedと `CLOCK_SCALE` を使う。`main.cpp` は基準のコピーで、まだ提出用の新構造は含まない。

`build_general.py` / `general.cpp` は、3枚の比較器・3個の汎用窓・2個の取り出し窓・4枚の商品紙へ広げた模型。比較器の汎用窓の印刷は固定し、取り出し窓への印刷と商品紙の穴を探索する。`lock_body` は商品紙の汎用窓を不透明のままにする指定。

`guard=2` では、模型の外の汎用窓への干渉を表す窓を3個追加する。比較器の各組が白、全商品紙が黒を印刷し、外からの色合わせでは白を要求する。これにより商品紙を比較器の上へ出すだけで取り出し窓を直す手順を制限する。取り出し要求では指定紙の黒も目標に含める。追加した窓の印刷は探索で変更しない。

実験の入力と結果は `results/`、`general-results/`、`guard-results/` に分ける。全順列での価値反復の上下界を記録するが、印刷の探索自体は局所探索であり、大きな構造の最適性を保証しない。
