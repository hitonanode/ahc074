# left-fast

改良元: solutions/audit2-blk

焼きなましを速くしただけで、近傍・費用・注文処理は audit2-blk と同じ。同じ時間で反復が約 1.85 倍（24 並列の評価で約 9.2M → 18.5M 回）になる。

## 変更点

- ハンドルの入れ替え（2 列のハンドルの窓を交換する近傍、試行の約 1 割）は、毎回すべての単位を走査していて、焼きなましの時間の約 4 割を占めていた（試行の 88% は対の一致が崩れて不可）。列ごとの単位の表を持ち、まず入れ替える 2 列 a, b の単位だけで可否と色を判定し、可能なときだけ列 a..b−1 の単位で費用の差を計算する。
- 温度の計算を 256 反復ごとにした。
- 受理の判定 u < exp(−Δ/T)（u は一様乱数）を Δ < T × (−log u) と読み替え、−log u は 65536 分位の表から引く（棄却のたびの exp を省く）。
- 焼きなましの乱数を std::mt19937_64 から xoshiro256**（splitmix64 で初期化）に替え、範囲の乱数は 64 ビットの剰余でなく乗算とシフトで作る。

## パラメータと指標

- 環境変数・stderr の指標は audit2-blk と同じ。焼きなましの反復数は従来どおり `anneal_iters` に出る。
