# 最後の注文だけ残り状態の費用を外す

改良元: solutions/tight-thirty-eight。

最後の注文には次の取り出しや返却がない。同じ計画器で将来の列費用と穴埋め紙の返却費用を0にした候補も探索し、通常計画より操作数が厳密に少ない場合だけ使う。最後の1注文だけ追加探索する。最初の1023注文は同じ動作をする。

研究用probe.cppは独立模擬注文で、最初の1023注文の操作列・最終順序の一致と、最後の操作数が増えないことを確認する。全表示・全操作の可視性も検査する。入力末尾の注文は使わず、全時計はCLOCK_SCALE倍。研究用ではlast_requestをprobe.cppから設定する。
