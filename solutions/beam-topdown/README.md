# beam-topdown: 64段の残余bit二重ビーム（研究用）

改良元：なし。提供された `esw-clean.cpp` の設計・比較器・注文処理を使用せずに構築した独立実験。

- bit c をハンドルとする64段。各段の紙はbit cを必ず白または黒とし、より後方のbitを穴とする。
- 上から1枚ずつ、外側のビームが256目標の未被覆マスクを保持し、内側のビームが白黒の矛盾を避けた紙の候補を生成。
- 寄与下限 `tau(c)=round(5+15*c/63)`、採用1回につき罰則6、外側ビーム幅2・内側幅12、最大18段。
- 残余は注文時の列先頭の色切替で修復。目標を完成できるように0/1双方を各列に確保する。
- 研究用の条件や環境変数は [実験ノート](../../docs/beam-staircase-20261106/notes_topdown.md)。

このソースの原本は `#include <bits/stdc++.h>` を用いており、Clang対応のための書換えは行っていない。提出用とする場合は移植性・時間を再検証する。
