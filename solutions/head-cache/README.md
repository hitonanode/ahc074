# 先頭候補の穴埋め利益を再利用する

改良元: solutions/head-design。

配置探索で同じ紙の組の穴埋め利益を何度も計算するため、その値を保存して再利用する。共有相手・窓順・誤色確率はこの探索中に固定される。

- 穴埋め紙が商品紙より浅い場合は、商品紙の列番号に利益が依存しない。
- 商品紙より深い位置で色が違う場合は、その窓より前が隠れるため、やはり商品紙の列番号に依存しない。
- この2種類を直接表に保存し、残りだけ大きさを固定したハッシュ表に保存する。

値はdoubleのまま保存し、目的・候補・乱数列を変えない。固定反復で結果の一致を検査する。追加メモリは約21MB。時計倍率と制限時間は改良元のまま。`probe.cpp` は保存設計から固定反復で速度と一致を調べる研究用。
