# 汎用層の上に残した紙の費用を実測に合わせる（fcharge-above）

改良元: solutions/climb4-fast

## 改良元からの差分

- 状態の価値（plan_cost の filler_charge）で、列の外に出ている紙（補助紙）の費用を、汎用層の上（または汎用層の中）にあるか下にあるかで分けた。
  - 改良元: どちらも 1 枚 0.7 手（kFillerCharge）。汎用層の下の紙だけ、残って役に立つ確率（stay_table）で ±の調整がある。
  - この版: 汎用層の上にある紙は 1 枚 0.95 手（kFillerChargeAbove）。下の紙は改良元のまま。
- 理由（solutions/delprobe の計測。設計固定 300 件、後処理で操作を 1 手減らす試行 24293 個からのロールアウト）:
  - 汎用層の上に紙が 1 枚増える試行（前に持ち上げた紙を列に戻さない `-ret` など）では、状態の悪化が見積り +0.534 手に対して実際 +0.792 手だった。紙 1 枚の実際の費用に直すと約 0.96 手。
  - 汎用層の上の紙は汎用窓に自分の色を見せるので、後の注文がほぼ必ず動かす。0.7 手（再利用される分を引いた値）では安すぎる。
  - 汎用層の下に増える試行は、見積り +0.382 手に対して実際 +0.465 手で、ずれは小さい（費用に直すと 0.74 手に対して見積り 0.66 手）。中立探索の方向（valprobe）では、この項の当たりは 0.94 だった。
- 時間は改良元と同じ。
