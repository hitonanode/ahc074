# astra-rule-post

改良元: solutions/astra-rule-full（基盤の解法は solutions/astra-search4）。

一般印刷ルールの学習を、列と商品の組合せを決める焼きなましの後に移す。実際に印刷する70商品対を固定し、その両側に対する汎用層の平均合法手数の総和を減らす。汎用窓・ハンドル窓の区分、商品対、列への配置、専用紙の模様は改良元と同じ探索結果を用いる。

候補は汎用6紙の非定数三値印刷602通り。各15比較組が最低1窓残ることを守り、720状態の合法移動表を維持する。使う70対のどちらかが表示不能になる変更は採らない。制約を満たす順序集合までの距離和は、逆到達集合のORによって厳密に評価する。

前半の代理マッチングではなく、最終的に使用する商品対を直接改善するための実験。前半のルール探索は行わない。既定2巡回、`RULE_SWEEPS`で変更できる。通常モードではプログラム開始から1.44秒まで、固定回数モードでは完走する。

`rule_before/after` の差は、固定した実70対に対する汎用手数の改善だけを含む（ハンドル・ハミング距離項は一定）。採否と評価結果は astra-lab/REPORT.md に記録する。
