# astra-sparse-exact

改良元: solutions/astra-novel（その改良元は solutions/astra-search4）。

完全比較グラフを外した後、設計の焼きなましに渡す汎用層の費用を、実際の不透明マスクに基づく720状態の合法最短距離で評価する。完全グラフ用PosetSumsによる楽観的な評価を置き換える。対の両商品について別々に平均距離を求め、その平均を使う。

窓割当中の代理目的は astra-novel と同じ。紙数、時間区切り、操作候補、固定乱数は維持する。最短距離表の前計算と費用キャッシュの作成時間が増えるため、固定回数の手数比較と時間制の比較を区別する。評価結果は astra-lab/REPORT.md に記録する。
