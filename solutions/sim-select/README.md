# 独立した模擬操作で複数の設計候補から選ぶ

改良元: solutions/post-repair。複数開始の設計生成は solutions/head-restart から。

列・共有の焼きなましを同じ合計2000万候補で1本、2本、4本に分け、各候補に同じ穴埋め山登り・再割当を行う。通常の模型で選ぶほか、軽い操作計画で模擬注文を処理し、実際に必要だった操作数で候補を選ぶ。注文は公開された商品から定数乱数で作り、商品数をそろえた無作為順と、独立な一様抽選を比較する。終了状態と初期状態の費用差も計測し、短い模擬の過渡状態を補正する。

軽い計画は、前の紙を返す案と穴埋めへ移す案の4案、または通常の全基本案から選ぶ。連鎖・汎用補助紙・後処理は省く。検査には通常の制御と別の乱数の模擬注文16本を使い、選択用の注文と混ぜない。全候補の検査値も保存し、選択の上限と誤差を調べる。

研究用。main.cpp単独は比較元の設計を行い、probe.cppが複数設計を生成して選択の情報を保存する。隠された実注文は読まない。時計にはCLOCK_SCALEを掛け、各検査の最初の1本で可視性を独立照合する。

軽量4案が全て無効になる場合は、同じ紙構造の全基本案を調べる。全基本案でも無効なら元の完全制御へ進める。
