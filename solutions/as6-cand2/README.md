# as6-cand2

solutions/astra-search6/cand2 の写し（評価の run 名を区別するため）。

改良元: solutions/as5-g38

assign_windows に、汎用窓aを外し、別の比較器の組へハンドル窓bを入れる複合手を加える。
単独の窓交換と組移動では通れない割り当てへ、一手で進めることを狙う。
窓交換の1/16をこの手にする。元の組に窓が2個以上あり、70対を選べている場合に提案する。

窓aを外した70対の閉包を計算し、26ハンドル×28方向（別の14組×2色）について、不適合になる対の数をビット並列で数える。
3対以上を失う候補を除く。失う商品対の数が0/1/2対の候補に、それぞれ4/2/1倍の選択確率を与える。候補を完全には除かず、同じ状態で重複して選ばない。
状態を受理したら候補表を無効にする。受理と最良状態の保存には、従来どおり全商品対の更新とmatching_costを使う。

G=38、距離上限26、目的関数の係数1800/5/144、kMapEnd=0.50、kGoptEnd=0.61、温度と停滞判定、ほかの段は変えない。
CLOCK_SCALEも維持する。変更はassign_windowsの中だけ。

追加のstderr指標:
- cross_rows: 複合手の候補表を作った窓の延べ数。
- cross_samples: 候補表から選んで全対評価へ進んだ複合手の数。
- cross_accepts: 受理された複合手の数。
