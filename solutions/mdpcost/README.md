# 列 MDP の長期の平均費用で設計の質を測る計測用の版（mdpcost）

改良元: solutions/esw-climb4

列 MDP は列ごとに、紙の種類の並びの長期の平均費用（1 事象あたりの手数、相対価値反復の最小値）を解いている。その「平均費用 × 事象の率」の列の和（1 注文あたりの掘り + 取っ手の色合わせの長期の手数）を `mdp_cost` として stderr に出す。設計の模型（列の費用と穴の費用）より設計ごとの実際の手数をよく予測するかを、dsel-probe の設計で調べるための版。`MDPCOST_ONLY=1` なら値を出してすぐ終わる（テスターは誤りを出すが、stderr だけを使う）。
