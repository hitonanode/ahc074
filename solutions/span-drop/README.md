# 汎用窓を列の取り出し窓へ転換

改良元: solutions/perforated-eight。研究用復元と設計模型は solutions/span-select。

完成した38汎用窓の設計を引き継ぎ、1窓を新しい列の取り出し窓にする。残り37窓に全15比較を保ち、商品どうしの共有を保つ。新しい列を全ての深さへ挿入し、他列の白黒を失わないよう紙を移す。まず各色1枚を選び、続いて模型が改善する紙を追加する。全窓・全深さを調べ、模型の小さい候補と先頭利益を加味した候補を比較する。

選択後は元と候補の両方へ同じ少量の追加探索・穴埋め山登り・再割当を行う。最終的な8標本の補助穴と操作制御は共通。独立した16本の模擬注文で操作数を比較し、全表示と1本の全操作の可視性を検査する。隠された実際の注文は使わない。

この段階は固定計算量の研究であり、時間制限内への組込みは別途判断する。全時計へCLOCK_SCALEを適用する。main.cppは改良元の複製で、研究はprobe.cppから行う。
