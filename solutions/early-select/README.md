# 最後の設計計算をする前に再始動を選ぶ

改良元: solutions/tight-thirty-eight。研究用でmain.cppは改良元のコピー。

固定された窓割当から、新しく初期の共有・列配置を作る。列共有探索を合計2000万回の1本/2本/4本へ分け、各候補の通常の模型、または先頭の穴埋め利益を引いた模型で1本を選ぶ。穴埋め山登り・一括再割当・穴追加・補助表は選んだ1本だけに行う。全候補へ末尾の計算を行うhead-restart/sim-selectと異なり、設計時間を候補数倍にはしない。

未使用入力1760〜1791と独立模擬8本で検査。基準も同じ新しい初期共有から探索する。実注文は読まず固定乱数を使い、全時計はCLOCK_SCALE倍。各条件1本で可視性と最終順序を再生し、全注文の表示と計画失敗を確認する。
