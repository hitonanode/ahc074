# imp10-chain

改良元: solutions/imp10-hidden（imp-lean に、穴埋め紙どうしが隠し合うことを許したもの）

solutions/gpt6pro-10-01-filler-chain の、最大 4 枚の穴埋め紙を重ねる探索（Solver::append_wide_chains）を足した。

- 使う紙: D の列以外の各列の上から 3 枚まで（kChainDepth = 2: 深さ 0〜2）。ハンドルが既存の穴埋め紙で覆われた列は除く。
- 重ね方: 異なる列の紙を最大 4 枚（kChainLength）、上から順に並べる（最終の上下の順は列の順と無関係）。下へ紙を足すたびに、上の紙の不透明なハンドルの集合 O と、D の穴で A_u と違う色が見えるハンドルの集合 B（上の紙に隠れていないもの）を更新する。重ねる位置（レベル）は B の最も深いハンドルの次で、組の紙の列の最小値以下でなければならない。利得 = レベル以降で覆う D の穴の掘りの手数 − 紙ごとに（1 + 深さ）。長さごとに利得の大きい 24 本（kBeamWidth）を残すビームで、手数がレベル以降の掘りの手数の合計（節約の上界）以上になる枝は刈る。
- 組は区間 [レベル, 最も深い列] の候補として、既存の区間 DP（単独の紙と 2 枚重ね）に加える。取り出す順は列の昇順（D より浅い列は D を持ち上げる前、深い列は後。深い列のハンドルを D が覆うなら、その組は使わない）。各紙は、同じ組ですでに置いた紙のうち、自分より下の最も近い紙の直上に（なければ上の最も近い紙の直下に、なければレベルの位置に）入れる（place_picked_filler）。
- 試すのは、通常の計画の候補（joint 以外）で費用が最も小さかった選択肢 1 つだけで、その選択肢で計画をもう一度作る。組を 1 つも選ばなければ打ち切る（元の計画と同じになるため）。費用は process と同じ式で、ほかの候補・補助紙の計画と比べる。

stderr: `chain_trials`（組を選んだ計画を作った注文の数）、`chain_selected`（その計画が採用された注文の数）、`chain_papers`（採用された計画の組の紙の数の合計）。
