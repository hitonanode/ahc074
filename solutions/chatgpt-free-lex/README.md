# chatgpt-free-lex

改良元: solutions/chatgpt-free-triples

自由3列版の終状態選択を、手数を第1優先、将来費用を同手数の中の第2優先とする辞書式評価へ変更した版。初期上界の紙の挿入位置は将来費用で選び直す改良を保つ。

ビームに残す途中状態の評価は改良元と同じ。到達した操作列だけを辞書式に比べるため、将来価値のために現在の操作を1手多く払うことはない。初期上界より短い操作列が見つかれば探索の深さの上限もその長さに下げる。

6枚の厳密MDP模型で、最短手数の中の終状態選択だけで最適方策と同じ定常費用になったことを、実際の長い列で検証するための対照実験である。本番でも成立することを仮定したものではない。

他の定数・指標は改良元のREADMEを参照。コードは `main.cpp` の1ファイルで完結する。
