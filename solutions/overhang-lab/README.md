# 離れた深い窓へ印刷を伸ばす2列模型

改良元: solutions/long-module。main.cppは現基準 solutions/stay-cover のコピー。

浅い列と離れた深い列を取り出し、浅い紙のうち1枚に深い列の窓の共通色を追加する。自分の商品に残る穴を減らし、返却のときに深い窓も同時に変える利益と、深い列を隠して取り出しを妨げる損失を比べる。2列内の順序は自由に動かす。

保存設計の紙枚数・商品色・全256商品の部分要求を使う。全1枚の追加印刷を独立した訓練注文で選び、別の注文列で比較する。操作は可視紙だけとし、内部の商品紙を持ち上げた後は、その紙の穴から見える紙だけを動かす。持ち上げ・即時返却は無料。間にある列や外部の穴埋め紙の影響は模型の外なので、公式スコアではない。

研究用。隠された注文列は使わず、CLOCK_SCALEを適用する。模型の制御は幅32のビーム探索で、候補の長い検査では幅64も比較する。
