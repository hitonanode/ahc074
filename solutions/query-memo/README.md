目標ごとに、過去の最終状態で汎用層に挿入されていた1〜2枚の補助紙、挿入位置、汎用紙の順序を記憶する。再注文では現在の列からの掘り出しとハンドル修正を計算し直し、その配置を通常の計画候補に加える。前回補助紙を使わなくても、最後に使った配置は残す。過去の絶対深さや掘り出し列は再利用しない。通常の補助紙候補に開始状態・全引数が同じ計画がある場合は、重複再生を省く。既存の設計・目的関数・探索回数は変更しない。

QM_MODE=3が既定（配置の再利用）。0は無効、1は前回操作列を紙の直後への挿入として再生、2はさらに不可視操作を省く再生も追加。各候補は現在状態で合法性・表示・次注文でのフィラーの取り出し可能性を検査する。

qm_template_duplicateは通常候補との完全一致で省いた数。qm_template_saved / qm_template_trials / qm_template_legalは記憶した配置数・再構築試行数・有効候補数。qm_requests / qm_seen / qm_exact_state / qm_local_stateは注文数・再注文数・開始状態全体の一致数・汎用順と対象列順だけの一致数。ほかのqm_*は操作列再生用。既存の全ログ・スイッチ・プロファイラ、DesignStore、CLOCK_SCALE、LOCAL_BENCH、@paper/@ops、段の目印を保持する。

QM_MODE=1/2用のqm_trials / qm_legal / qm_candidates / qm_selected / qm_skippedは、再生試行数・合法かつ表示一致の候補数・フィラー到達可能性も満たす候補数・生計画の最良へ選ばれた注文数・省いた不可視移動数。qm_selectedは後処理後の最終採用数ではない。
