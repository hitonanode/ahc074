# astra-structural-fast

改良元: solutions/astra-structural

非線形優先順位辞書の構造・候補・目的関数・時間配分は同じ。
合法目標集合までの平均距離を、距離球のビット集合で厳密に計算する。

六枚の合法順序グラフの最大距離は 5 である。目標集合を F とすると、
各開始順序 s に対する最小距離の和は、d=0..4 について
「F のどれへも d 手以内に届かない開始順序の個数」を足したものに等しい。
各目標 g の **g へ向かう** 距離球を前計算し、F の全目標について OR と popcount を使う。
これにより、720×目標数の最小値計算を、おおよそ 48×目標数の 64 bit OR に置き換える。
値は近似せず、方向を逆にした無向距離も使わない。

時間打切りでは高速化した分だけ辞書候補が増える。
`DECODER_ITERS` で辞書の仕事量と入力状態を固定したときは、辞書内部で計算する値と選択は改良元と同じである。
提出プログラム全体の出力一致には、他の設計探索・補助表の打切り・注文処理の軽量化も揃える必要がある。
全時計の `CLOCK_SCALE` は維持する。

追加の診断として、学習前後の距離 26 以下の互換対数と、増えた対・失った対の数を出す。
`decoder_final_selected_gained` は、最終の列設計に採用された 70 対のうち、
学習開始時の二枚比較器では表示できなかった対の数。
`decoder_proxy_selected_gained` は辞書探索の近似マッチングに対する同じ数であり、最終採用数とは区別する。

`verify_distance.cpp` は固定乱数の 1200 目標集合について、距離球の式と
全 720 開始順序からの明示的な最小値計算が完全一致することを検査する。
