改良元: `solutions/esw-fixiter`

PR 114 の「2→2 中立リライト＋再短縮」を注文処理へ移植した。設計・通常の計画生成・評価関数・ペース配分は改良元を引き継ぐ。

手間 `effort=0` の注文で、通常の後処理の後に追加の eject パスを行う。2 操作を削除して残りを合法に再生できた場合、末尾の 2 操作で正しい表示に戻す。候補紙は窓の第 1・第 2 不透明紙（キャップ以外）、挿入位置は共同修復の区間の浅い端・深い端を試す。追加操作は既存の `repair` ラベルを使う。

合法性・表示・キャップの不変条件・補助紙の回収可能性を満たす候補のうち、手数が増えず、評価値が最良値の許容幅内で、終了積層が元と異なるものを保存する。前面 2 層に関わる紙の列のハッシュで重複をまとめ、評価値の良い候補を残す。各候補へ既存の編集・2→1 修復を再適用し、評価値が改善した場合だけ、その状態・操作列・ラベルをまとめて採用する。

環境変数は初回だけ読む。

| 変数 | 既定値 | 意味 |
|---|---:|---|
| `NEUTRAL` | 1 | 0 で追加探索を無効化する。標準出力は改良元と同じになる |
| `NEUTRAL_WIDTH` | 4 | 保存候補数の上限。1 未満を指定すると 1 |
| `NEUTRAL_DEPTH` | 2 | 0: 保存候補の再短縮なし、1: eject から開始、2 以上: 編集パスから開始。eject→成功時の編集は最大 2 周 |
| `NEUTRAL_SLACK` | 0.75 | 保存候補の評価値に許す、生成時の最良値からの増加幅 |
| `NEUTRAL_TRACE` | 0 | `LOCAL_BENCH` で 1 のとき、候補経由で短縮した注文を `#neutral r u before witness after` と出す。各列は出力紙番号の `paper:depth,...`（空列は空文字） |

追加の stderr 指標（全注文の累計）:

- `triple_trials`: 2 操作削除後の残りの手順を合法に再生できた組数。
- `triple_repairs`: 2 枚の末尾修復を完全評価へ渡した数。同じ端点でも PR と同じく重複して数える。
- `triple_accepts`: 追加の列挙中に最良評価値を更新した数。2 操作削除だけで表示が一致した候補も含む。
- `neutral_total`: 追加パス後に残った保存候補の延べ数。
- `neutral_accepted`: 保存候補からの再短縮で最終選択を更新した注文数（手数が同じでも数える）。
- `neutral_direct_saved`: 追加の収集パス自体による手数減少の合計。
- `neutral_escape_saved`: 保存候補の再短縮による手数減少の合計。

`@paper` と `@ops`、設計の保存・読み込み、`CLOCK_SCALE`、`LOCAL_BENCH` の手間固定は改良元のまま。追加探索には専用の時間打ち切りを入れていない。
