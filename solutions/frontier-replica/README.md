# frontier-replica

改良元: solutions/imp-lean。

同じ商品を複数の紙で表し、現在の重なりから取りやすい表現を選ぶ実験的な解法。
紙の枚数は変えない。元の設計で単独商品 a を表す紙を、一部だけ共有紙 (a,b) に
変える。b は元から共有紙で表される商品に限定し、元の表現も残す。
各紙は最大 2 商品、各商品は最大 2 枚の紙で表す。

昇格候補は、同じハンドル色を持ち、汎用層が両方の商品を表示できる組から作る。
紙の模様は a と b が違う窓を穴にする。現在の各列の枚数から一様な深さを仮定し、
b に選択肢が増える得と、a の汎用操作・ハンドルの穴が増える損を比較する。
同じ列では、初期の循環順序における 2 枚の間隔を使う。別の列では独立な深さを使う。
最大 16 枚を昇格する。初版では模型の増分が 0.10 手まで悪い候補も許す。
これは有望性を調べるための設定であり、模型の得は実測の得を意味しない。

注文処理では表現ごとに同じ開始状態から元の計画処理を実行し、操作数と残った状態の
期待費用で最良を選ぶ。未来の取り出し費用も、紙ごとの頻度の和から
「商品ごとの、表現の中で最小の深さ + 固定修復費」に変える。
列への挿入では、その列の紙が表す商品だけを再評価して計算量を抑える。
ハンドルの穴の頻度は、深さ模型で得た表現の選択率で重み付けする。

元の補助紙表 Interleave は専用紙が一意であることを前提としているため、この版では
構築しない。設計の焼きなまし終了を 1.205 秒、穴埋めの山登り終了を 1.26 秒にする。
CLOCK_SCALE と 1.80 秒以後の軽量処理は引き継ぐ。軽量処理では表現を静的な費用で
一つ選び、列への挿入には選択率を反映した紙の重みを使う。

追加の実験用環境変数:

- `REPLICA_LIMIT`: 昇格数の上限。未指定または 0 は 16。
- `REPLICA_MIN_GAIN_CENT`: 採用する模型の純便益の下限を 0.01 手単位で指定。
  未指定または 0 は -10、すなわち -0.10 手。

追加 stderr:

- `replica_candidates`: 条件を満たした昇格候補数。
- `replica_promotions`: 実際に昇格した紙の数。
- `replica_predicted_gain`: 採用した模型の純便益の和を 256 で割った値。
- `replica_best_gain`: 最良候補の模型上の純便益。
- `replica_requests`: 複数表現を持つ商品が要求された回数。
- `replica_trials`: 複数表現の商品について実行した計画処理の回数。
- `replica_selected`: 主表現以外を採用した注文数。
- `replica_selection_rate`: 上記を replica_requests で割った割合。
- `replica_failures`: 表現候補の計画がすべて検査を通らなかった回数。

評価結果と採否は trial_log.md に記録する。
