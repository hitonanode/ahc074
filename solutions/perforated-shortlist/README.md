# 穴の追加候補を先に順位付けする

改良元: solutions/perforated-screen。注文処理は solutions/post-repair に更新。

全ての1窓の穴追加・復元を、穴埋め利益を独立に足す安い式で先に評価する。この段階では変更を採用しない。候補を安い順に並べ、上位16/32/64/128個だけを、16標本の先頭色と区間DPで詳しく調べる。区間DPの利益係数0.5、独立式の選別係数1を使う。採用後に候補の順位は更新しない近似。

狙いは、利益が小さい多くの候補について区間DPを呼ぶ時間を減らすこと。研究用のprobe.cppは保存した設計と固定乱数の模擬注文を使い、実際の注文列は読まない。可視性・表示・差分計算の照合を行い、CLOCK_SCALEを適用する。main.cpp単独は新しい穴を設計せず、研究結果が出てから提出用への組込みを判断する。
