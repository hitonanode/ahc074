保存設計から、キャップ窓の色を背景6商品の最上位の実色で作る構造のモデルを測る。背景窓の配置と6商品の所有者は固定し、キャップ窓で異色の商品ペアも、両商品の表示を満たす背景順列が存在する場合だけ許す。背景の遷移費用は720状態から許可順列への最短距離の平均を厳密に計算する。

構造案では元キャップ紙を全穴とし、異色ペアもキャップ窓を穴にする。各背景紙の色は所有商品のまま。これは測定用モデルだけであり、実際の印刷と注文処理は保存設計のまま。
`study_controlled_gain` は現設計からのモデル改善、`study_same_edges/mixed_edges` は同色・異色の互換辺数、`study_mixed_pairs` は採用された異色ペア数。`study_saved/controlled_col/hole/gc/merit` は列・ハンドル・背景・総費用。測定時間を追加するため `--no-record` で実行する。
