# chatgpt-fixed-columns

改良元: solutions/chatgpt-free-triples

`FREE_BLOCK_WIDTH=1` とした対照実験用の解法。紙の設計、要求ごとの前の専用紙の戻し、掘り出し、修正手順、将来費用は改良元と同一で、隣接する列の順序を混ぜる機能だけを除く。

旧 `imp-combo` の穴埋め方策・補助紙などは加えていない。この版と幅3の版を同じ設計探索の反復数で比較することで、自由順序に由来する増減を分離できる。

提出コードはこのディレクトリの `main.cpp` だけで完結する。その他の定数と stderr の指標は改良元の README を参照。
