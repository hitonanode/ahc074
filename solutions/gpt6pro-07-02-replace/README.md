# gpt6pro-07-02-replace

改良元: solutions/gpt6pro-06-01-comparator（外部 agent gpt6pro-07 の 2 版目。07-01 の書き直しではなく、gpt6pro-06-01 のコードに直接手を入れ、07-01 の後処理の考え方を足したもの）

## gpt6pro-06-01-comparator との差分

- **設計: 対の組み替え**: 対 (a, b) + 単独 c, d → 対 (c, d) + 単独 a, b の近傍を加えた（端点の交換では、互換性グラフの連結成分ごとの対の数が変えられないため）。新しい対が元の列に置けなければ、3 枚の列も入れ替える。
- **設計: 対の汎用層の費用を両側で見積もる**: 対 (a, b) の汎用紙の並べ替え費用を「a を出す費用の 2 倍」としていたのを、同じ 8 つの初期順序で a と b の両方を評価した和に変えた（最下段の紙は動かせないので、a と b で費用が対称にならない）。
- **操作列の後処理**（07-01 と同じ考え方）: アンカー表現に直して 1 手の削除・旧紙を戻す位置の変更を試し、さらに「2 手を消して、別の見えている紙 1 枚の移動で直す」近傍を加えた。直す 1 手の差し込み深さは、各窓の一番上の不透明な紙の位置から区間として直接求める。最終の重なり順は元と違ってよい。
- **注文の終わりに汎用紙 6 枚が連続していなくてよい**: 間に専用紙が残っても、表示が正しく、次の注文で紙を分類し直して回収できれば許す。次の注文の片付けで連続した塊に戻す。
- **計算の省略**: 異なるモードの候補で差し込み位置が全部一致したときだけ後続の候補を省く。列の先頭・修正費用・穴埋め紙の可視性の走査を共有する。省略だけを入れた版は 06-01 と出力が一致する。

## パラメータ

- 設計 200 万回または 1.0 秒まで、軽量処理への切り替えは CPU 1.55 秒（06-01 と同じ）。
- 機能の切り替えマクロ（BARCODE_RELAX_GENERIC、BARCODE_SYMMETRIC_ESTIMATE、BARCODE_PAIR_REPLACE_RATE など）は既定値のまま。

stderr は 06-01 と同じ。

## 移植について

出所は main checkout の other_agents/gpt6pro-07-barcode_solution_and_tests.zip の barcode_solution.cpp（ログは gpt6pro-07.md の後半）。`#include <bits/stdc++.h>` を個別の include に置き換えただけで、アルゴリズムは不変（stderr はもともと `名前 = 数値` の形）。

時計の倍率 CLOCK_SCALE は入れていない（時間で打ち切る部分は、手元ではジャッジより約 1.1 倍多く探索する）。

agent の報告（独自生成 40 件、同じ入力）は 10.987 手/注文で、gpt6pro-06-01 の 11.081 手比 −0.85%、29 勝 1 分 10 敗。
