# noise-probe（計測用）

改良元: solutions/imp-all

main.cpp は imp-all と同一（変更なし）。評価の雑音（同じ解法・同じケースでのスコアのぶれ）と、必要なケース数を調べるためのディレクトリ。

- 回数固定の評価: imp-all の環境変数 `MAP_ITERS` / `GOPT_STEPS` / `ANNEAL_ITERS` / `CLIMB_ITERS` で設計の各段の反復回数を固定すると、設計はマシンの速さによらなくなる。1 つの段の回数だけをずらした run どうしを比べると、「その段から先の軌道が変わる変更」の雑音を測れる。焼きなましの進み具合は 256 回ごとに見るので、回数を +1 しても軌道は変わらない（1% ずらす）。回数を時間制の平均（24 並列で割り当て約 2.9 万・焼きなまし約 1490 万回）に近づけると、遅いケースで注文処理が 1.80 秒後の軽量処理に落ちてスコアが約 10% 悪くなるので、9 割より少なくする。
- noise_stats.py（`python3 solutions/noise-probe/noise_stats.py`、標準ライブラリだけ）: runs/ の全 500 ケースの run を読み、(1) 同じソースを別々に評価した run どうしの、ケースごとの log スコア比の標準偏差（A/A）、(2) 同時比較（`--compare`）の別解法どうしの標準偏差（A/B）、(3) 同じ 2 解法の独立な反復どうしで、ケースごとの差の相関（どのケースで効くかの再現性）、(4) 標準偏差から、効果の大きさごとの検出力を出す。
- `--split RUN RUN ...`（同じソースの run を 2 つ以上）: 1 回の実行のぶれを、注文列によるぶれ（各 run の注文の前半と後半の手数の比から）と、設計の良し悪しのぶれに分ける。
