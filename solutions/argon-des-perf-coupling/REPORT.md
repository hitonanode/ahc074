# D2：穿孔と再割当の交互実行・モデル誤差

基準PR146 argon-des-perf-latew105。共有judge平均予算15 ms。
外部助言01-1「穿孔処理とフィラー評価の対象拡大」の残件を検証する。
D1終了。D2の残件が終わったらD3–D5へ進み、採用版が出たらその時点で止める。

## 追加穿孔を許した交互最適化

`design_papers: perforation-aware reassignment` の後に現在の目標・紙・穴から
Perforationを再構築する。headは現在のutilityで選び直す。
元のペアの自然な穴は復元せず、現在の所有目標が同じ色を要求する窓だけを復元できる。
現在のheadには新しい穴を許し、旧headなどの既存穴も復元候補に含める。
係数0.7、32層化標本、1回。cap、列ハンドル、汎用窓は固定。

初期500件の同時比較（全てsave-design、記録あり）：

| 候補 | log比±SE (%) | 勝/分/敗 | judge平均差±SE (ms) | 追加段 (ms) |
|---|---:|---:|---:|---:|
| alternate：全head | −0.015679±0.005373 | 204/146/150 | +17.540±3.067 | 17.984 |
| altfocus：変更紙・新headのみ | −0.002154±0.003682 | 131/239/130 | +8.749±3.022 | 8.592 |
| alternate2：全head→再割当ももう1回 | −0.015705±0.007845 | 220/119/161 | +16.675±3.040 | 24.290 |

基準run `20261106-064830_argon-des-perf-latew105`、候補runは
`20261106-064854_argon-des-perf-{alternate,altfocus,alternate2}`。
平均judgeは順に1.572875 / 1.590415 / 1.581624 / 1.589550 s、
p99は1.722790 / 1.759263 / 1.725609 / 1.758964 s。WA・2秒超えなし。
外部負荷平均0.13・最大0.41コア。全て同じ500件で比較。

全headでは1件当たり0.896穴を追加、0.802穴を復元（6.100→6.194穴）。
穴費用差+0.000669、所有者の条件付き価値差+0.000245、他目標への価値差+0.002247手/注文。
変更紙だけだと追加0.094・復元0.798穴であり、改善の大半を失う。
旧headの穴あけによって別の紙のhead適性も変わるため、再割当で直接動いた紙だけでは足りない。
追加のHungarianは7.472単位を変更、予測改善0.000440手/注文だが、実測は追加穿孔だけとほぼ同じ。

`altcache`では同じ層化乱数の再生成を省く。固定seedとHで決まる一様乱数を保存し、
更新後のhead確率と再比較する。候補順と数値は維持し、出力一致を確認する。

## whole-unit：重なるフィラーと列費用の診断

旧500件の設計を読み、通常の注文処理は変えずに128層化標本で4種類の価値を測った。
計測run `20261106-065002_argon-des-perf-modelprobe`（旧基準の設計）と
`20261106-065003_argon-des-perf-modelprobe`（wholeの設計）。
元runは `20261106-062233_argon-des-perf-rematch-v2` と
`20261106-062412_argon-des-perf-whole`。元runと計測runのスコアは各500/500件一致。

| 手/注文 | 基準 | whole | 差 |
|---|---:|---:|---:|
| 穴費用 | 3.941916 | 3.949447 | +0.007532 |
| 解析式のhead価値の和 | 0.656176 | 0.667840 | +0.011665 |
| 標本内の列ごとの最良区間を全て足す | 1.029435 | 1.048481 | +0.019046 |
| 重ならない区間の最良和（DP） | 0.685795 | 0.694337 | +0.008541 |
| 最良区間1個のみ | 0.615229 | 0.622543 | +0.007314 |
| 重なりによる損失（無制約和−DP） | 0.343639 | 0.354144 | +0.010505 |

穴費用−価値（係数1）の予測差は、解析式の和−0.004133、DP−0.001010、
最良1個+0.000217。実測は+0.003723±0.001350手/注文。
実測差とのseed相関は順に−0.106 / +0.097 / +0.175。
重なりの過大評価は確かにあり、DPにすると予測改善の約76%が消えるが、
これだけでは残る悪化を説明できない。

保存済み`@ops`の500件集計では、dig +0.001189、fdig +0.000645、fill +0.000648、
fret +0.001043、repair +0.001113、fix −0.001043手/注文。
「fixをフィラーでまとめる」方向には動くが、取り出し・戻し・修復の増加が上回る。
列の種類・色別枚数を保つのでDesignの列費用は同じでも、
Solverのadaptive_weightsとadaptive_holesは変わりうる。
既存column MDPの正規化量（最後の8回目の相対価値反復、列事象頻度を掛けたもの）を
追加計測し、この違いの方向を確認する。これは実処理の列外状態やフィラーを省いた近似であり、
実際の長期費用の正解とは扱わない。

詳細数値は `alternate500.json`、`whole-diagnosis.json`。

列モデルの追加計測runは `20261106-065835_argon-des-perf-modelcolumn` / 
`20261106-065837_argon-des-perf-modelcolumn`。各500件、元の注文結果と500/500一致。
MDPの平均費用近似は8.119133→8.126510、差+0.007378±0.000668手/注文。
列事象率は+0.005672、穴需要は+0.005703、紙の適応重みの総和は両方1.0。
列ごとの状態数・被覆列数は全件一致した。
この費用差はDesignの穴費用差+0.007532とほぼ等しく、
「同じ頻度・色の列交換に伴う未計上の列費用」が残りの悪化を生んだという証拠は得られなかった。
MDP費用差と実測差の相関は0.256だが、穴費用に加算すると二重計上になる。

保存済み設計をDPや最良1区間の予測で選別する対照も行った（`gate-diagnosis.json`）。
区間DP係数0.5の選別では116/500件を採用し、差−0.008525±0.004684%。
45設定中で最も良いものを選んだ値であり、有意な改善とは言えない。
128標本の再構築・測定は1設計43 ms、実装するなら最低でも候補生成に加え前後のDPが必要で、
この方向をそのままオンラインで採用する根拠は弱い。
重なりの診断は有効だったが、全ての損失を説明する軽い費用モデルは未確定のままとする。

## 2000件への延長と時間対策

`20261106-064830` / `064854` の3群を2000件に延長し、設計を全件保存。
全headは−0.013795±0.002851%（780/603/617）、追加再割当ありは−0.010716±0.004045%
（810/493/697）。追加再割当の効果は増えず、全headの再穿孔だけを主候補とした。
judge平均は基準1.594132→全head1.611478（+17.346±1.669 ms）、
p99差+19.577 ms。追加再割当ありは平均+14.920 msだがp99差+37.303 ms。
この時点では両方とも時間条件を満たさない。

`altcache`は乱数生成だけを再利用する対照。500件で出力と非時刻stderrが全件一致。
run `20261106-065730_argon-des-perf-latew105` /
`20261106-070010_argon-des-perf-alternate` /
`20261106-070021_argon-des-perf-altcache`。
追加段は19.620→18.122 ms、初回穿孔は21.671→22.128 ms。
全体judge差は基準比+22.381±4.640 msであり、これだけでは時間条件を満たさない。

`altwarm`では初回穿孔の区間DP表を保持し、再割当後も有効区間と必要な標本の色が
一致する行を再利用する。色や穴が違うだけで無条件に再利用することはない。
再利用行についてforward/backward/avoid/valueの全てを再計算と完全一致で照合する診断を実施する。

照合runは `20261106-070723_argon-des-perf-{latew105,altcache,altwarm}`、通常200件、
設計保存・記録あり。平均6926.755/8192行（84.56%）、合計1,385,351行を再利用し、
全てのforward/backward/avoid/valueが独立再計算と一致した。altcacheとaltwarmのスコアは全件同じ。
照合用再計算を含むため、このrunから照合なしの速度を主張しない。

順序の対照 `altbefore` は再穿孔をlate Hungarianの前に行う。
run `20261106-070053_argon-des-perf-latew105` / `20261106-070134_argon-des-perf-altbefore`、
通常500件で−0.010950±0.008849%、191/156/153、judge差+18.722±4.626 ms。
「再割当後に行う方がよい」という差を断定できず、両方とも0.03%へ届く根拠はなかった。

## D2の結論（2026-11-06 07:00の新方針を適用）

BASE.mdの07:00/07:05新方針では採用閾値が0.03%へ変更された。
有意な小改善は同じ系列で積み重ねてよいが、確かな改善が続かない段階で止める。
全headの追加穿孔は通常2000件で−0.013795±0.002851%と改善したが、
その後にもう一度再割当する拡張は−0.010716±0.004045%で、改善を積み増せなかった。
対象を絞る案と段の順序を変える案も改善を増やす根拠は得られなかった。
従って **追加穿孔は改善あり・未採用** とし、新しいマージ対象はない。
段ごとの時刻とjudge mean/p99/max/2秒超え件数は[MEASUREMENTS.md](MEASUREMENTS.md)にまとめた。
新閾値を知る前に着手したaltwarmの照合は完了したが、照合なしの最終時間比較は実施しない。

filler climbについては、同じ種類・色別枚数を保ったwhole-unit交換がその移動を包含する
代表的な近傍である。穿孔後の穴を見た和proxyは改善を予測したが、
重なりを除くと残る予測差は−0.001010手/注文（スコア約−0.010%）に縮み、
実測は悪化した。列MDPへの置換でも未計上の平均列費用を示せなかった。
従って、穴を見越した費用を前段のclimbへ入れることに0.03%以上の改善を期待する根拠は得られず、
新しい前段climbは実装しない。これは全ての設計目的関数への数学的な否定ではない。
非加算のフィラー価値と実際の取り出し・戻し費用の誤差は未解決事項として残す。

D2の追加調査はここで終了する。これまでの採用済みPR138/139/141/145/146は維持。
D3–D5は新方針（失敗案は原因を特定した改訂1回まで、上限0.03%未満は省略）で進める。
