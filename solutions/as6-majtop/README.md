# as6-majtop: 列の一番上を、ハンドルで要求の多い色にして印刷する

改良元: solutions/as6-cap38p0

## 変えたこと

- 設計は、ハンドル h_c で要求の少ない色（少数派）の目標を列 c に集める。そのため、列 c の紙は h_c で少数派の色が多い。
- as6-cap38p0 の印刷の順は、列の中で「自分の紙に多い方の色を先（上）」にしていた。
  - その結果、設計した初期状態では、各列の一番上が要求の少数派の色を見せていた。
  - 多数派の色を見せる列の割合は、初期状態で 18%、慣れた状態で 65%（seed 0〜39）。
- 各列の一番上を「その列より上の列の目標が h_c で要求する色の多数派」に、2 番目をもう一方の色にした。3 番目以降は元の規則のまま。
  - 設計の模型が仮定する「上の 2 枚に両方の色がある」状態にもなる。
- solutions/as6-warm（架空の注文で慣らす）と比べて、初期の重さのうち、この色の向きで説明できる分を切り分けるための版でもある。
