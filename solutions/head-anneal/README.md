# 先頭紙の利益を含む配置を焼きなます

改良元: solutions/reset-head。

研究段階。穴埋め山登りの列交換で、途中の少し悪い配置も温度に応じて許す。列の単独・共有と白黒枚数を保つ交換を使い、穴の費用から先頭紙の穴埋め利益を引いた目的を最小にする。開始時の先頭色の確率は固定し、最後には探索中で最も良かった配置へ戻す。

probe.cpp では初期温度0/0.05/0.2/0.8、65000/260000提案を比較する。温度は提案数に対して指数的に下げ、最終温度は初期の0.01倍。どの条件も同じ2000万回の設計結果から始め、最後に元と同じ4回の一括割当を行う。固定乱数の模擬注文を使い、入力末尾の注文は読まない。

main.cpp の温度の既定値は0で、提出用の変更は未確定。全時計はCLOCK_SCALE倍。climb_acceptedは悪化を許した交換も含む受理数。結果と採否はtrial_log.mdに記録する。
