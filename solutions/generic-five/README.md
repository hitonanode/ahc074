# 5枚の比較器と186枚の商品紙

改良元: solutions/tight-thirty-eight。

汎用紙を6枚から5枚へ減らし、商品紙を186枚（共有70対・単独116枚）へ増やす。汎用窓34・取り出し窓29・キャップ1窓。汎用5枚の全10比較組を残し、全120順序の実際に合法な移動距離で共有を値付けする。窓割当、補助紙の配置表、操作計画も5枚に対応させる。追加穴の計算で商品紙の開始番号を固定していた箇所も5枚へ合わせた。

5要素の半順序4231個・同型63種類について全状態の最短距離を独立なPythonで計算し、料金表を提出コードに埋め込む。料金の尺度を従来にそろえるため、120順序の費用和を6倍して保持する。generate.pyが再生成、verify.cppがC++の移動グラフと料金・計画を照合する。

時間配分・先頭利益の一括再割当・追加穴・後処理は改良元と同じ。以前の5枚構成と、現在の紙設計・制御との組合せを確認するための候補。全時計はCLOCK_SCALE倍。提出ファイルはmain.cppだけで完結する。

窓割当の移動先スクリーニングも10比較組へ変更。6枚用の15組の固定ビット抽出を使わず、5枚の行列から正逆の10ビットを作る。
