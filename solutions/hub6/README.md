# hub6

改良元: solutions/hub5

焼きなまし（anneal_units）の近傍を 2 種類足した。見積りや手順はそのまま。

## 変更点

- 2 列のハンドル窓の入れ替え: 各反復で確率 5% で、ランダムな 2 列のハンドル窓を入れ替える（列の深さの順を変えるのと同じ）。各単位のハンドル窓での色・対の一致・浅いハンドルの集合が変わるので、全単位の見積りを計算し直す。入れ替えた 2 列のどちらかに、新しいハンドル窓で色が一致しない対があれば採らない。
- 色の違う 2 単位をまとめて別の列へ移す: 列 l1 にある、ハンドル窓の色が逆の 2 単位を、移した先の列でも色が逆になるなら列 l2 へ移す（列の大きさが 2 ずつ変わるので偶数のまま、色の交互も保てる）。元の列には 3 単位以上が要る。
- 既定の近傍は「列の入れ替え + 組み替え + この 2 単位の移動」（`HUB_MOVES` = 14）。

## パラメータと指標

- 環境変数（hub5 のものに加えて）: `HUB_HSWAP`（ハンドル窓の入れ替えを試す確率、既定 0.05）。`HUB_MOVES` のビット 8 が 2 単位の移動。
- stderr の指標は hub5 と同じ。
