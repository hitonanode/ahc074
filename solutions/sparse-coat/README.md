# 少数窓だけを覆う汎用紙で商品を上書きする

改良元: solutions/head-design。研究模型は solutions/overcoat-code の上書き共有を拡張。

汎用紙6枚のうち1枚だけを2〜5窓に印刷し、残る5枚の全10比較組を使う。少数窓の色が合う商品では、その汎用紙を商品紙の上へ残す。相方の商品では商品紙を一番上へ出す。上書きされる窓は共通色でなくても穴を開けずに印刷でき、上書き前後の並べ替え費用を変えられる。比較器の1枚による上書きでは、相方から見たその紙への比較制約が全て同じ向きになるため、表示可能な商品対そのものは増えない。

汎用窓の集合を固定し、少数窓の位置・比較相手・色と、他の窓の比較組・色を同時に探索する。探索中は完全比較器の移動費用を下限として使い、完成後に6枚の全720順序で実際の可視性に従う移動グラフを作り直す。正確な費用で商品対・列・ハンドル順を再設計して判断する。

`main.cpp` は比較元のコピー。研究は公開された商品だけを読み、隠された注文列は使わない。固定乱数と `CLOCK_SCALE` を使う。
