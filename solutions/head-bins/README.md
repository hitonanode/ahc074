# 誤色確率をまとめた配置探索

改良元: solutions/head-design。

穴埋め利益の計算で、各窓の誤色確率を少数の値へ丸め、同じ確率の窓数をビット演算で数える。全窓を0.5とする版、0.25/0.5/0.75の3段階、0/0.25/0.5/0.75/1の5段階を調べる。紙の選び方・返却方針などは同じ。

独立な誤色数の期待値と0個・1個の確率を、窓数とべき乗の表から計算し、元と同じ1.6手を引いた正の利益を近似する。目的は変わるため、同じ反復数の近似の影響と、反復数を倍にした影響を分けて調べる。`probe.cpp` は保存設計と固定乱数の模擬注文を使い、実際の注文列は読まない。時計は `CLOCK_SCALE` 倍。
