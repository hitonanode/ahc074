# 状態の価値の見積りの当たり方を測る計測用の版（valprobe）

改良元: solutions/esw-colmdp（fallback を外した版）

注文処理の中立探索は、同じ手数で終わりの状態の価値（plan_cost の状態の項）が良い操作列に置き換える。その価値の見積りの差が、その後の実際の手数の差にどれだけ当たるかを測るための版。提出用ではない。

- 環境変数 `VALPROBE=n`（LOCAL_BENCH のみ。0 か未設定なら esw-colmdp と同じ出力）: 中立探索が操作列を変えた注文の n 回に 1 回、変える前（通常の後処理の結果）と後の 2 つの終わりの状態から、同じ乱数の注文列（`VALPROBE_SEQS` 本、各 `VALPROBE_LEN` 注文。既定 2 本・48 注文）をソルバーの複製で処理し、手数と最後の状態の価値を比べる。
- stderr の最後に `#vprobe r u 変える前の手数 変えた後の手数 前の価値の項 4 つ 後の価値の項 4 つ (前の手数 後の手数 前の最後の価値 後の最後の価値) × 本数` を出す。価値の項は 1 手先の掘り・1 手先の取っ手の色合わせ・列 MDP の項・列の外の紙の費用（filler_charge）。
