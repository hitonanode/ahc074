# 途中で見える可能性のある紙だけを修復候補にする

改良元: solutions/post-eject-fast。

元の操作列で動かない紙どうしの相対順序は、操作を2個消しても変わらない。動かす紙を全て取り除いた状態でも上の動かない紙に隠れる紙は、どの途中状態でも見えない。この必要条件から、修復に使う紙の候補を全192枚から減らす。

候補の表示条件・途中の可視性・最終状態の全再生は同じ。mid_possible=falseで全枚数を調べる版と、各注文の手数・採用数が一致することを確認する。probe.cppは基準、短縮前、短縮後を同じ模擬注文で比べる。CLOCK_SCALEを全時計に掛ける。
