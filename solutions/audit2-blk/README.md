# audit2-blk

改良元: solutions/audit2-ret

汎用層（土台の紙 1 枚 + ブロックごとの反転紙）の向きを合わせる手順 set_blocks を、最短路の表と 1 段先読みの方策に替えた。紙の設計と、それ以外の注文処理は audit2-ret と同じ。

## 変更点

- 汎用層の状態は、土台と反転紙（ブロック 5 個なら 6 枚）の上下の順で、720 通り。見えている紙を動かす合法な手だけで状態間を結び、焼きなましの後に全状態間の最短手数と最初の 1 手の表を BFS で作る（約 0.02 秒）。
- 注文では、今の状態から、注文が求める向き（触れたブロックごとにオン / オフ、触れないブロックは問わない）を満たす状態のうち最短で行けるものへ、表に従って動かす。
- 最短の行き先が複数あれば、その状態からの「次の対の目標の期待手数」が最も小さいものを選ぶ（1 段先読み）。期待手数は、設計のすべての対の目標について、その目標の向きを満たす状態までの最短手数を平均したもの。元の手順は、手数は注文ごとの最小にほぼ近かったが、終わりの状態を気にしていなかった。
- 専用紙が汎用層の上にあるとき（前の専用紙をその場に残す計画など）や、ブロックを分割して 6 個以上になったときは、元の手順を使う。

## パラメータと指標

- 環境変数 `BLK_POLICY`（既定 1）: 0 で元の手順を使う。
- stderr の `blk_states`: 汎用層の状態の数（ブロック 5 個で 720）。`blk_build_sec`: 表を作り終えた時刻。`blk_policy` / `blk_fallback`: set_blocks の呼び出し（計画探索で試した計画を含む）のうち、表の方策を使った回数 / 元の手順を使った回数。
