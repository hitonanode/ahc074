# C++ による評価関数の仕様

`value.hpp` の `deval::DesignValue` が最終評価関数である。初期化を1回行い、候補ごとに `value.from_design(state)` を呼ぶ。返り値は小さいほどよい平均操作数／注文。係数は `models/<採用名>.final.json` と `value.hpp` に固定する。

```cpp
#include "value.hpp"
deval::DesignValue value;  // 汎用紙の設計非依存の表を一度作る
double v = value.from_design(design_state);
```

入力は `DesignState` の `M,G,H,A,edge,polarity,papers,columns,ded,handle`。時刻、設計時の stderr、実測スコア、注文列は使わない。対象は現在の6枚の汎用紙を持つ解法で、Sobol 表は H=25,31,35 を備える。緊急設計や別の M は学習対象外。

## 1. 列と要求の集計

列 c について、紙数を N_c、担当する対象数を T_c、取っ手色1の紙数を B_c、2対象を担当する紙数を Q_c=T_c−N_c、そのうち色1の紙数を Q1_c とする。対象 t の担当紙に穴がある取っ手 c への色0、1の要求数を x_c,y_c とする。すべて、最後の穴あけ・再割り当てを反映した物理的な紙から数える。

列の取り出しコストは次の和を256で割る。

```
N_c (N_c−1)/2 + Q_c (Q_c−1)/2
  + max(0,Q_c−1) * [Q1_c=0 または Q1_c=Q_c]
```

先頭色1の初期確率は、リセット強度 r に対して次式を使う。

```
p_c(r) = (y_c + r T_c [y_c>x_c]) / max(1,x_c+y_c+r T_c)
E_c(r) = (x_c p_c(r) + y_c (1−p_c(r))) / 256
b_c    = min(x_c,y_c)/(x_c+y_c)  // 分母0なら0
d_c    = c/(H−1)
```

従来の取っ手コストは r=2 の E の和の0.76倍に一致する。実装は再構成した列・取っ手・汎用紙の合計と `d2_model_final` の一致を確認している。

## 2. 汎用紙

各対象の担当紙の汎用窓の穴から、6枚の汎用紙に要求する半順序を作り、推移閉包を取る。その要求を満たすまでの操作数を、一様な720通りの出発順序について平均した値を g_t とする。最下部の汎用紙を動かせない規則を含む。

`poset_data.hpp` の318個の無ラベル半順序をラベル付けし、130023個の閉包の表にする。数値は元解法の `kPosetClasses` と同じで、注文計画器を呼ばない。表の生成は設計候補に依存せず、全候補で共有できる。

## 3. donor の代表と区間

以降、取っ手は列番号 c のビットで表す。対象 t の要求色を a_t、担当紙の穴を h_t とする。donor k の取っ手の不透明マスクを o_k、黒マスクを z_k、所属列を c_k とする。

担当紙と同じ列の donor は除く。donor が対象の穴で誤色を出す最深の位置の次を l とする。誤色がなければ l=0。

```
l = bit_width((z_k XOR a_t) AND o_k AND h_t)
cover(t,k,l) = o_k AND h_t AND NOT low_bits(l)
```

l>c_k なら候補にならない。l以上の開始位置に短くして使うことも認める。

列ごと・取っ手色ごとに代表紙を1枚選ぶ。担当対象数の多い紙を優先し、同数なら次の filler 価値 U_k が最大の紙を選ぶ。完全な同点では紙番号が小さいものを選ぶ。

取っ手の色を独立と近似し、代表の価値は、上の区間から donor 自身の取っ手を除いて、誤色の数 Z について

```
U_k = Σ_t { E[Z] − Pr(Z≥1) − 0.6 Pr(Z≥2) }_+
```

とする。Pr(Z=0), Pr(Z=1) は、各ビットの誤色確率を順に掛けて求められる。この代表選択では p_c(2) を使い、後の色分布更新中も代表を固定する。先頭 filler 価値の特徴は、各代表の U をその色が先頭に来る確率で重み付けした和／256。

## 4. 注文別の被覆DP

32点の固定 Sobol 点列を、各列の p_c を閾値として先頭色のビット列に変換する。点列は設計にも実測にも依存せず、`quadrature.hpp` に数値を格納する。Pythonでの生成は SciPy `Sobol(d=H,scramble=True,seed=19790427)` の先頭32点。

対象 t について、現在の誤色マスクを w_t=(先頭色 XOR a_t) AND h_t とする。代表紙 k を開始位置 l、終端 c_k の filler として使う利益は

```
popcount(w_t AND cover(t,k,l)) − 1.6 − [代表の色 ≠ 列の先頭色]
```

である。1.6は設置1回と将来の返却の代理費用0.6。最後の項は逆色の代表を掘り出す費用1回。正の利益だけを用い、重ならない区間の利益の合計を最大にするDPを列順に解く。

各点・各対象で、元の誤色数、最良利益を差し引いた費用、残る色直し数、filler 数、掘り出し数、覆った取っ手数、区間長の和、残る色直し数の2乗を記録する。対象ごとに32点を平均し、さらに全256対象を平均した8項を特徴にする。初期分布では、対象ごとの費用の2次・3次モーメントも使う。

## 5. 先頭色の更新

被覆後に残る色直しを使って、列ごとの2状態の遷移率を更新する。F_c,b は、色 b への色直し回数を32点で平均し、全256対象について足した値。

```
q01 = F_c,1 / max(0.0001,1−p_c)
q10 = F_c,0 / max(0.0001,p_c)
p*  = (q01 + 2 T_c [y_c>x_c]) / max(1,q01+q10+2 T_c)
p_c ← 0.5 p_c + 0.5 p*
```

「残った要求の色比」だけにすると、filler が現在の先頭色を見て選ばれることを無視する。条件付きの遷移率にするのがこの更新の要点である。更新を2回行い、それぞれもう一度被覆DPの8項を計算する。各回の最深列・末尾5列の残る色直し数も特徴にする。合計は初期分布を含む3回の積分。

## 6. 最終的な線形評価

`V = intercept + Σ_i coefficient_i × feature_i`。線形係数は、seedごとに中心化した予測誤差を最小にする ridge 回帰で学習する。特徴の標準化も訓練 seed 内のケース内変動から計算する。切片は訓練データの平均操作数に合うように置く。テストデータで切片・傾きを補正しない。

上記の列、汎用紙、被覆、遷移の特徴に加え、以下の集計を使う。名前・係数の完全な一覧は生成した `value.hpp` にある。

| 名前 | 定義 |
|---|---|
| `hR_dq` | Σ_c E_c(R) d_c^q、R=0,0.5,1,2,4,8、q=0..3 |
| `hR_lastL` | 最深側L列の E_c(R) の和、L=1,2,3,5 |
| `hR_balance`, `balance2` | Σ E_c(R)b_c、Σ E_c(R)b_c² |
| `dem_pq`, `minor_pq` | (x+y)/256、min(x,y)/256 の列ごとのq乗の和 |
| `balance_pq` | b_c のq乗の和 |
| `unit_minor_pq`, `pair_minor_pq` | 少数色の紙数、少数色の2対象紙数のq乗の和 |
| `nc_pq`, `np_pq` | N_c、Q_c のq乗の和 |
| `t_generic_pq` | g_t のq次モーメント |
| `t_gen_holes_pq`, `t_gen_relations_pq` | 汎用窓の穴数、閉包の辺数のq次モーメント |
| `t_holes_pq`, `t_early_holes_pq` | 取っ手の穴数、担当列より浅い側の穴数のq次モーメント |
| `t_minor_requests_pq` | 穴のうち要求色がその取っ手の少数色である数のq次モーメント |
| `t_hole_bal_pq`, `t_hole_bal2_pq` | 対象の穴での Σ b_c、Σ b_c² のq次モーメント |
| `f_s2_p1.6_*` | 初期先頭色分布での被覆DP集計 |
| `m_s2_itJ_*` | J回目の色分布更新後の集計、J=1,2 |

上表の q は、特記のない限り1,2,3。`col`, `gc`, `G`, `H`, `holes`, `extra_holes` も含む。同値・共線性のある特徴も残しているので、個々の係数を独立した実操作単価とは解釈しない。関数全体を使う。

## 増分更新

- 列の取り出し項、汎用紙の項・モーメント、x,y,T と列の深さだけで決まる項は、変更を受けた列・ペアだけ再計算できる。現在の hcost と同程度の更新範囲である。
- `t_holes` など、変更した担当紙だけで決まる対象のモーメントも、その紙の1–2対象の寄与を入れ替えればよい。
- `t_hole_bal` の2次・3次モーメントは、1列の b_c の変化が多数の対象に伝わる。上記の列ごとの項と同じ安さでは更新できない。
- donor の代表選択、対象間で共有する filler 価値、被覆DP、色分布の更新は全体を結び付ける。現状の完全な V を1100万回の焼きなましの各近傍に入れることは推奨しない。候補選択用として使う。

## 代理評価の限界

各列の先頭色の独立性、逆色の代表までの深さ1、返却費用0.6は近似である。既存 filler の位置、汎用紙 helper の具体的配置、複数 filler の連鎖、後処理の書き換えは再現しない。これらの平均的な影響は設計レベルの教師と校正に含まれる。最終設計の分布で検証した関数なので、これを新しい焼きなましの目的関数にして極端な設計を探索した場合の外挿性能は未検証である。
