# 3商品を共有できる復号器に必要な性能

改良元: solutions/reset-majority。一般化した単独・対・3商品選択は solutions/group-lab の研究用設計器を参照する。

3商品が1枚を共有できると仮定し、その汎用操作を商品ごとに2.5・3・3.5・4手と固定して、紙の共有と列の配置を再設計する。実際の6枚比較器で表示できない3商品も許すため、提出できない有利な模型である。対については実際の可解性と正確な均一開始価格を使う。

3商品の共通色だけを印刷し、色が違うハンドルは全て穴にする。元の紙数185枚と全256商品を守り、列には白黒の両方を残す。3商品の違う窓の和集合が40以下の候補を列挙し、単独・対・3商品の交換、列・ハンドル順の変更を探索する。直接取り出しは最小順位費用、穴は reset-majority の更新式を用いる。更新率は4区間ごとに固定する。

保存設計から始め、3商品共有を使わない同じ設計器と比較する。これで改善に必要な復号費用の尺度を調べ、実装する構造とは区別する。将来の実注文は使わない。全時計はCLOCK_SCALE倍。main.cpp は改良元のコピーで、3商品共有は提出版に統合していない。
