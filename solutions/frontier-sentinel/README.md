# frontier-sentinel

改良元: なし（提出解法ではなく汎用層の厳密な組合せ模型）。

6枚比較紙・36窓に、36窓全体が不透明で模様が相補な2枚 `Y`, `~Y` を追加した8枚構造を調べる。比較器の15辺は36窓へほぼ均等に繰り返す。窓の比較紙の白黒極性は固定乱数で決める。

穴がちょうど `h` 個の部分目標 `X` とその補色の両方が、紙の順番で表示できる割合を測る。判定は、未確定の窓で誤色を出さない紙を上から選ぶ貪欲法。任意の安全な紙は任意の正しい順序の先頭へ移しても表示を壊さないので、この判定は必要十分である。

`Y` は全白、窓ごとの乱数、辺ごとの乱数向き（同じ辺の窓では比較関係が一貫）、元比較器の実現可能な完全表示、の4通り。最後のものは対照群であり、表示集合を増やさないことが理論的に分かる。global紙以下を、その模様を実現する元比較紙の順番に置き換えられるため。

手数模型は全8!=40320順序を列挙。各順序で36窓のいずれかに見える紙だけを取り出して任意位置へ挿入する有向グラフを作り、目標を満たす順序集合を始点とする**逆辺**のmulti-source BFSで、各開始順序からの正確な最短距離を求める。一様開始順序、補色2目標を同確率とした平均であり、オンライン解法の実測値ではない。

ビルド・実行例:

```bash
g++ -std=c++23 -O2 solutions/frontier-sentinel/model.cpp -o solutions/frontier-sentinel/model
solutions/frontier-sentinel/model --samples 200000 --distance-pairs 100 > solutions/frontier-sentinel/model-results.jsonl
```

モデル結果の行ごとにJSONを保存する。乱数seedはソース内の定数。ハンドル、専用紙の減少、窓割り当て最適化、CPU制限、オンラインの状態分布は含まない。

## 判定と対照群の正当性

未確定の窓で誤色を出さない紙を安全な紙と呼ぶ。完成できる順序が1つでもあり、安全な紙 `k` があれば、その順序の中の `k` を先頭へ移せる。変わるのは `k` が不透明な未確定窓だけで、そこは目標色と一致する。従って安全な紙を任意に選んで剥く操作は可解性を保つ。安全な紙が1枚もなければ、どの紙を先頭にしても誤色を出すので不可能。この繰り返しは必要十分な判定になる。

`Y` が元の6枚のある順序 `q` で出せる場合、`~Y` は `q` の逆順で出せる（各窓は2枚が正反対の色）。8枚の任意の順序について、最初の全面紙より上にある比較紙の列を `p` とする。全面紙の模様が `Y` なら、6枚を `p` の後に `q` から `p` の紙を除いた列を続けて並べる。`p` が覆う窓は元通り、覆わない窓では2枚の比較紙がともに後半にあり、`q` の相対順序から `Y` が出る。`~Y` でも逆順を使えば同じ。よって元の6枚で実現可能な `Y` の全面紙を追加しても、表示集合は増えない。

## 今回の模型の結論

`h=12`、200,000組で、窓ごとランダムな `Y` の追加による両側整合率の増加は4.7870%から4.8500%（新たに救われる126組）。片側だけ可になる組は3,398組で、相補の両方を要求すると大半の増加が消える。100組の厳密最短距離計算でも一様順序からの費用は増えたため、固定・未最適化の全面sentinel案は実装対象から外す。詳細な数字と条件は `RESULTS.md` と `model-results.jsonl` に残す。

一様な8枚順序には全面紙が他の紙を隠す状態が多い。従ってこの距離増分は、オンライン方策が全面紙を下に保つ場合の実測差ではない。今回棄却するのは上記の固定模型であり、最適化した異なる構造への不可能性証明ではない。
