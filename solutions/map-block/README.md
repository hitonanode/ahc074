# 同じ比較器の2窓をまとめて入れ替える

改良元: solutions/post-two。

汎用窓割当の1/256の提案で、同じ2枚を比較する窓を2個外し、ハンドル窓を2個入れる。元の2窓を除いた共有対の制約を計算し、全ハンドル窓の組合せと白黒方向を調べる。失う共有が最も少なく、2対以下で済む候補から1個を選ぶ。片方だけの入れ替えでは通れない構成を探す。

変更後の全互換対と共有の費用を、従来の焼きなましで判定する。除外用のビット集合の計算は、全対計算で得た不適合数と照合する。同時変更のキャッシュは物理窓4個と色の完全な識別子も持ち、ハッシュ衝突で値を取り違えない。

block_trialsは提案回数、block_viableは失う共有が2対以下の候補があった回数、block_evalsは全対評価回数、block_acceptedは受理数。MAP_BLOCK_RATEは提案頻度の逆数で既定256。紙の構造・後続の設計・時間配分・CLOCK_SCALEは改良元と同じ。
