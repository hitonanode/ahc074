# 最短の取り出し手順で列の順を最適化する模型

改良元: solutions/as6-canon。`main.cpp` は比較元のコピー。

研究用 `queue.cpp` は、列の紙を色0/1と商品数1/2の4種類にまとめ、指定紙の取り出しと、指定色を先頭に出す要求が独立に来る模型を解く。指定紙の持ち上げと即時の返却だけは無料とし、比較する双方で同じ条件にする。

位置dの指定紙は、その前のd枚を後ろへ動かして取り出す手順に限る。余分に巡回してから取り出す手順は含まない。残る元の末尾の順序は保たれるため、操作後の候補はその末尾を部分列として含む順序に一致する。この性質を使い、全ての部分列へ価値の最小値を配ることで、この手順の範囲で最適な平均費用と価値関数を計算する。
比較側は現在の `adaptive_insert` と同じ、重み付きの深さと各色が最初に現れる位置を最小化して一枚ずつ戻す方策。
状態を色と商品数だけに縮約するのは、この模型の中で同種の紙の注文頻度が等しいため。実際の紙は他の窓の模様も異なるので、この値は解法のスコアではない。

`counts=2,2,1,1` は単独0、単独1、共有0、共有1の枚数。`r0`、`r1` は各色の要求頻度で、単独紙1枚の注文頻度を1とした値。`CLOCK_SCALE` を時計に掛ける。
