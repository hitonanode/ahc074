# imp-seg

改良元: solutions/imp-s2hd

設計の焼きなまし（Design::anneal）を時間で 4 区間に分け、区間ごとに新しい Annealer を、それまでの最良の状態から始める（Annealer::run は最良の状態を残して終わる）。温度は全体の予定（2.0 → 0.015）のうち、その区間の部分を使う。焼きなましの途中で悪い状態のまま進み続けるのを、区間の境目で最良の状態に戻して防ぐ。ほかは imp-s2hd と同じ。模擬（solutions/night-probe5 由来の計測用コピー、192 件）で 4 区間 −0.072 ± 0.035%、16 区間 −0.069 ± 0.038%。
