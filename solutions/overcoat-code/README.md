# 汎用紙を商品紙の上に置く共有

改良元: solutions/as6-canon。研究の初期段階では `main.cpp` は比較元のコピー。

汎用紙iに印刷された汎用窓の色が商品Bと全て合う場合、その紙を一番上に置き、共有の商品紙Dを直下へ差し込む。Dには商品Aの色を印刷し、AとBが違う窓でも、汎用紙iが覆う場所は穴にしなくてよい。商品AではDを通常どおり上へ出す。商品Bでは汎用紙iを上に残し、他の5枚で残った穴を埋める。

Bは固定キャップの下へ入るため、キャップ窓が黒の商品に限定する。ハンドルの共有条件は従来と同じ。表示できる対と、Aの部分制約・Bの「iが先頭」という制約を含む平均汎用操作を計測する。比較器の表示全体を商品Bに合わせる必要はなく、汎用紙1枚の不透明な窓だけを合わせればよい。

`search.cpp` は保存された汎用窓の集合を保ち、比較器の組と向きを再設計する。全15組は残し、上から覆う共有の価格を含めた71対の貪欲・長さ3の増大道による選択を目的にする。同じ回数で通常の共有だけを使う対照も実行する。
