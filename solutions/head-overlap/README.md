# 穴埋めの重複を除いた配置の目的

改良元: solutions/head-design。

各列・各色の先頭候補を従来の単独利益で選び、その候補を複数同時に使う利益を区間DPで計算する研究版。全商品について、列の色を穴の要求分布から固定乱数で標本化する。先頭の候補は取り出し0手、逆色の候補は1手として、覆う不一致窓数から配置・返却の1.6手と取り出しを引く。窓の区間が重なる利益を重複計上しない。

現採用版の列交換後から、紙の種類と列の白黒枚数を保つ交換を追加する。目的は模型費用からDPの平均利益を引く式。標本と誤色確率は探索の間固定する。研究の注文列は設計用の標本とは別の固定乱数で、公開された商品情報だけを使う。

`main.cpp` は比較元のコピー。研究用は `probe.cpp`。時計は `CLOCK_SCALE` 倍。提出用の時間配分は、模型での効果を確かめてから決める。
