# 浅い3列の実要求での構造探索

改良元: solutions/head-excess。研究用MDPは solutions/front-module の全順列模型を3窓・最大9枚へ広げる。

先頭3列の実際の紙を使い、共有商品の共通色を保って各紙の3窓の穴を変更する。外部商品の要求は必要な窓だけを合わせる。部品内の商品は、指定紙の持ち上げを無料とし、持ち上げ後の穴も直してから、任意位置への即時返却を無料とする。外部の穴埋め紙は省く。

全順列で合法な移動を列挙した平均費用MDPを価値反復で解く。紙1枚の穴の全変更を比較する山登りを行い、元の設計、自由な設計、窓の順序を選べば階段型になる設計を分けて記録する。階段型の判定では、共有商品の色が違うために必ず開く穴を除外する。入力末尾の実際の注文列は読まない。時間には `CLOCK_SCALE` を掛ける。`main.cpp` は比較元のままで、提出用への統合は行っていない。

`pruned.cpp` は各設計の価値反復の下界が現最良値を上回った時点で評価を止める。紙1枚・2枚の不透明位置を同時に変える全近傍を調べ、商品要求が同じ紙の入れ替えで同一になる設計は重複除去する。勝つ候補の収束精度は保つ。

既に走り始めた `pruned-*.json` の初期の記録には、共有の穴を考慮しない旧分類が残る。その `chain` やログの `nested` は最終的な構造の判定に使わず、入力の `allowed` と保存された `opaque` から分類し直す。最良設計を選ぶ費用・探索自体には影響しない。
