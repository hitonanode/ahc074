# chatgpt-free-context

改良元: solutions/chatgpt-free-triples

自由3列版のビーム探索で、将来費用の係数だけを一律4からブロックごとの `1 / f` に替えた実験版。紙の設計と他の操作方策は同じ。

`f` は1注文でそのブロックを使う確率。新しい目標の専用紙がブロック内にある場合、専用紙の穴をブロックで直す場合、または前の専用紙をブロックへ戻す場合に使用すると数える。連続注文が異なるという生成規則も含め、256目標の列と穴を数えて計算する。

全注文で平均した次回費用は使用頻度 `f` に比例して小さくなる。一方、未使用注文を自己遷移として取り除いても平均費用MDPの相対価値は変わらない。このずれを直すために係数 `1 / f` を使う。これは相対価値そのものを厳密に解いたものではなく、1注文先の費用を条件付き費用へ直す近似である。

浅いブロックの頻度は小さく、深いブロックの頻度は1に近い。共通の係数の調整だけでは表現できない深さごとの違いを検証する。他のパラメータと指標は改良元のREADMEを参照。
