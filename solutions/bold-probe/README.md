# bold-probe（分析スクリプトのみ）

改良元: なし（解法ではない）

cmp-* 系の run の出力を scripts/replay.py で再生して、構造の見直しのための数を出すスクリプト。どれも `python3 <script> RUN SEED...`。

- colstat.py: 設計の列の大きさ（不透明なハンドルの数ごとの紙の数と、汎用窓の不透明の数の平均）。
- holecost2.py: 注文の初めに前の専用紙を除いて D を一番上に置いたとき、D のハンドルの穴で目標と色が違う窓の数（ハンドルの深さごと）。
- holecost.py: 注文の間に穴の窓で見える紙が変わった数（前の専用紙が覆っていた窓も数えるので参考値）。
- fixstat.py: 不一致の穴を、その列の紙を動かして直したか、別の列の紙（穴埋め紙）で覆ったか。
- reqcost.py: D の列の深さ・対か単独かごとの注文あたりの手数。
