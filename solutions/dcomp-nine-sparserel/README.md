dcomp-nine-livepairsの互換ペア一覧の差分更新に加え、窓探索のrelation費用配列を疎に更新する。配列の非ゼロ要素は互換ペアだけなので、作業用配列の直前の非ゼロ要素だけ消し、元の互換ペアのうち不変な費用と新たに計算した費用だけ書く。受理時は状態と作業用の配列を交換するのに合わせて、それぞれの非ゼロ一覧も交換する。残りの要素は厳密にゼロのまま。
