# 補助紙を取り出す窓とキャップ窓を兼ねる

改良元: solutions/as6-canon。研究用の移動グラフは solutions/patch-code を拡張する。

6枚の比較器に、独立した窓と色を持つ2枚の補助紙を足す。従来の固定キャップを外し、その窓で補助紙2枚を白と黒にする。比較器の下にある補助紙も、この窓から取り出せる。専用紙は184枚、共有72対。共有紙のキャップ窓は、2商品で色が違えば穴にし、補助紙の順で表示を決める。

`cap.cpp` は保存設計上での模型。汎用8枚の全40320順序と実際に合法な移動を列挙し、対の可否と手数を求める。通常の全順序平均に加え、補助紙2枚を比較器の下に置く1440順序からの平均、その状態群へ戻す費用を含めた平均を使い、紙の組と列を再設計する。補助紙を持ち上げる前後の費用を無料にはしない。

キャップの色も目標に含める。手数にはハンドルの修正・専用紙の持ち上げと返却の全ては入っていないので、公式スコアではない。`main.cpp` は比較元のコピー。時計には `CLOCK_SCALE` を掛ける。

`search.cpp` は2枚の不透明位置と色を固定乱数の焼きなましで選ぶ。可否は現在残る穴に間違った色を出さない紙を上から置く手順で厳密に判定し、全40320順序との照合を行う。`independent.cpp` はそれを正確な操作費用で再設計する。最後に `generic-mdp` で完成設計の全状態の平均費用を価値反復し、開始順を一様とする仮定も外す。保存する193枚のファイルは分析用の空の先頭紙を含み、提出用ではない。
