# 共有を保った紙の一括移動

改良元: solutions/anchor-match。

研究段階。商品の共有相手を固定し、紙全体の所属列をハンガリアン法で一括変更する。各列の単独・共有と取り出し窓の色を保つ条件を使う。元の穴埋め山登りの2枚交換より長い巡回交換を許す。

目的は穴の要求色の費用と先頭紙の穴埋め利益。担当商品側の穴と、現在の先頭候補が供給する印刷の変化を線形化し、得られた巡回を実際の非線形目的で再検査する。先頭候補も毎回選び直し、悪化する巡回は受け入れない。

probe.cpp は保存設計から1/2/4/8反復を行い、同じ固定乱数の模擬注文で比較する。隠された注文列は読まない。main.cpp はまだ比較元のまま。時計はCLOCK_SCALE倍、評価結果はtrial_log.mdに記録する。
