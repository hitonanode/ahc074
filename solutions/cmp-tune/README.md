# cmp-tune

改良元: solutions/cmp-gx

係数と時間の配分だけを変えた。

- 設計のハンドルの穴の重み kHoleWeight 0.50 → 0.40。模擬（回数固定、32 本、seed 24〜151 の 128 件、cmp-gx 比）で 0.30 / 0.35 / 0.40 / 0.45 / 0.60 は +0.45 / +0.10 / −0.12 ± 0.045 / −0.06 / +0.41%。
- 注文処理の、列の外に残す紙の費用 kFillerCharge 0.8 → 0.6、終わりの状態の重み kEndWeight 0.6 → 1.0。設計が同じ模擬で −0.070 ± 0.005%（seed 24〜87、穴の重み 0.40 の上）。片方だけでも同程度で、両方を大きく動かすと打ち消し合う（trial_log の cmp-）。
- 時間: 割り当て 0.45 → 0.52 秒、焼きなまし 1.10 → 1.28 秒、山登り 1.15 → 1.33 秒まで（倍率の掛かった時計）。注文処理は約 0.23 秒なので、終わりは平均 1.56 秒・最大 1.65 秒程度の見込み（CLAUDE.md の目安 1.8 秒以内）。軽量処理への切り替えは 1.70 → 1.80 秒。
