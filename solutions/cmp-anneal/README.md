# cmp-anneal

改良元: solutions/cmp-speed

設計の焼きなまし（Design::anneal）の実装だけを速くした。手の種類と選び方、モデルの費用、受理の規則、乱数の引き方（同じ乱数列を同じ順に引く）は cmp-speed と同じで、違うのは丸めだけ。時間の区切り（焼きなましは倍率込み 1.425 秒まで）は cmp-speed のまま延ばしていないので、同じ時間でより多く回る。

## 速くしたところ

焼きなましの状態を Design::Annealer<NR> に持ち直した（NR = ハンドルを覆う 8 レーンのレジスタの数。H ≤ 32 なら 4、H = 36 なら 5）。

- 手の評価と適用を分けた。手は状態を変えずに費用の差だけを求め、受理したときだけ適用する。却下（評価した手の約 9 割）では何も戻さない。
- ハンドルの穴の費用: ハンドル j の色 0 / 1 の穴の数 n0, n1 と q = n0 n1 / max(n0 + n1, 1) を float のレーンに持つ（hcost = 4 kHoleWeight q）。手による穴の数の変化を、ハンドルのビットマスクからレーンへ展開し（1 バイト分の 8 レーンの表 kBitLanes）、全ハンドルの新しい q とその差の和を AVX2 で一度に計算する（分岐なし）。元は変わるハンドルごとに double の表を引いて費用 cur へ依存した加減算をしていた。
- 列の費用 colcost を、40 倍した整数で分岐なしに計算する（colcost40。kRankPriority = 17/20 なので厳密に整数）。元は手 1 回で 2 列分、分岐の多い浮動小数点の計算をしていた（分岐の予測失敗が多かった）。Design::colcost_of も分岐なしの形にした（値は元と同一）。
- ハンドルの交換 a ↔ b: 列ごと・ハンドルごとに「色 1 の目標の数・単位の数・対の数」と「そこで異なる対の数」を持ち（受理した手で更新）、列 a..b−1 の和で新しい穴の数を求める。元は列 a..b−1 の単位を全部たどっていた。
- 2 単位の移動の相手探し（同じ列の逆の色の単位を乱数で最大 16 回引く）を、単位ごとの key = 列 × 2 + その列のハンドルの色 の比較 1 回にした（引く乱数は同じ）。
- 手が対の違いの位置に列を置くかの判定（valid）を分岐 1 つにした。
- AVX2 は Annealer のメンバ関数だけで `__attribute__((target("avx2,fma,bmi,bmi2,popcnt")))` を付けて使う（手元の評価は -march=native なしでコンパイルするため）。この中から SSE の浮動小数点のコードを（インライン化されずに）呼ぶと、上位レジスタが汚れたままの SSE 命令になって全体が約 3 倍遅くなったので、焼きなましの中で呼ぶ関数（colcost_of, colcost40）は always_inline にした。

## 丸めの違い

- 穴の費用を float で計算する（相対誤差 1e−7 程度）。列の費用は整数で厳密。
- 回数を固定しても出力は cmp-speed と一致しない。受理の判定 `d <= 0 || d < temp × logs[乱数]` で、厳密には差 0 の手が、元は丸めで正（乱数を 1 つ引く）、新しい方は 0（引かない）になることがあり、以後の乱数列がずれるため。
- 正しさは `-DANNEAL_CHECK`（下記）で確かめた（H = 28, 32, 36）。

## 速さ

- 焼きなまし 600 万回（回数固定、空いたマシンの逐次、手元と同じ -O2）: 約 0.29 秒 → 0.17 秒（約 1.7 倍）。
- 時間制（CLOCK_SCALE=1.1、逐次）で焼きなましの回数は約 1450 万回 → 2520 万回（実時間で毎秒約 2030 万回 → 3520 万回）。
- 主な内訳（自作の標本抽出による行ごとの時間）: 列の手の評価（マスクの展開・q の計算・列の費用）が約 4 割、乱数と手の生成・有効性の判定が約 3 割、2 単位の移動の相手探し約 4%、ハンドルの交換約 3%。残りは分岐の予測失敗と乱数の依存の連鎖が中心で、同じ乱数列を保つ限りこれ以上大きくは縮まない見込み。

時間の区切り（kMapEnd など）と stderr の指標は cmp-speed と同じ（anneal_iters など）。

実験用: `-DANNEAL_CHECK` で 4096 回ごとに、差分で持つ状態（穴の数と q、列の数と費用、列ごと・ハンドルごとの数、key、owner）を数え直しと照合し、違えば stderr に `CHECK` を出す。
