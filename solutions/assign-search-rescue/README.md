停滞時に、通常の3組損失による事前除外で捨てる窓交換を構造に基づいて1つ救済する。
1窓の除去で有効になりそうな無効組が多い窓を選び、全交換先の極性ごとに、残る採用組の正確な費用と新たに有効になる組の費用を共有計算する。新規有効組の数が失う組数以上であり、安い順に補充した楽観的な合計費用が改善する場合だけ、従来の全組評価・matching_costへ進む。新規組同士の端点競合はこの見積りでは無視し、最終的な採否は元の厳密評価で確認する。通常の除外閾値・温度・停滞回数・近傍比率は維持する。

AS_RESCUE=1（既定）で有効、0で無効。AS_WORK=0.96（既定）は窓割り当ての反復数倍率。AS_RANK=0（既定）は通常の一様提案、1/2は別実験の新規有効組による順位。AS_PROFILE（コンパイル時、既定0）は1で演算子別の時間・改善量を計測する。
追加指標rescue_attempts / rescue_candidates / rescue_acceptsは試行状態数、全評価に進んだ候補数、受理数。rescue_lost / rescue_newは候補が失う採用組と新規有効組の延べ数。既存の全ログ・実験設定・プロファイラ・CLOCK_SCALE・LOCAL_BENCH・DesignStore・@paper/@opsを保持する。
