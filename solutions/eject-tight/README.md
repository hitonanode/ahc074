# 同じ紙列の候補をまとめ、後処理を短縮

改良元: solutions/eject-quick。計算短縮はsolutions/post-packed-links、候補選別はsolutions/post-diverse。

後処理のリンクを1バイトの紙番号にし、可視性付き再生で各紙の位置を配列に持つ。最終表示と全操作の可視性は従来どおり検査する。後処理へ渡す2候補は、動かす紙番号の列が同じなら費用の小さい一方だけを残す。

紙の設計、時間配分、修復成功後の通常後処理と修復再試行はeject-quickと同じ。全時計はCLOCK_SCALE倍。研究用の切替値は定数とし、提出用は単一の処理を使う。
