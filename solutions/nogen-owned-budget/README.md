改良元: solutions/nogen-budget12

背景の6枚は実商品の模様から作る。窓63も含め全64窓で所有色を照合し、
ペア商品は窓63が同じ色のものだけとする。キャップ以外に所有者のない紙を作らない。

背景窓を36から35へ減らし、窓割り当ての候補ペアを距離26以下から28以下へ広げる。
所有色の制約により減った互換ペアを補い、設計のマッチングを成立させやすくする。
窓割り当ては6,000反復、商品・列の焼きなましは4,000,000反復。
背景層への補助紙は、1枚案・2枚案とも実行と後処理を2案まで。2枚の組の予選は6組。
背景紙を主紙にする追加探索は既定で無効。通常の商品紙は全商品に存在する。

DesignStoreを版2にし、背景列数と背景紙の所有商品も保存する。M=0と仮想ハンドルを
含む設計を読み込めるよう検査を修正した。版1の保存ファイルは受け付けない。

時計はすべてCLOCK_SCALE込み。窓割り当ては有効な組が揃った後、経過1.00秒で打ち切る。
商品・列の焼きなましは経過1.15秒まで。ジャッジでは経過1.70秒以降、同じ計画器の
最初の有効な計画を使い、追加の候補探索と後処理を省く。LOCAL_BENCHでは注文の短縮を止める。

追加指標 `light_requests` は短縮した注文数。`control_initialize_failed` は実マッチング失敗。
`audit_owner_violations` / `audit_unowned_papers` は64窓の色違反数・無所有紙数で、LOCAL_BENCHでは違反時assert。
`ng_base_sec` / `ng_helper_sec` / `ng_alternate_sec` は通常計画・補助紙探索・別主紙探索の時間。
`helper_end_sec` / `req_sec` / `end_sec` と既存の `audit_*`、紙属性と操作ラベルは維持する。

主な調査用スイッチは NG_CONTROL_MAP=6000、PC_DIST=28、V4_JOINT_LIMIT=6、V5_ALTERNATE=0。
その他のNG_*・V4_*・V5_*・PC_*は改良元を引き継ぐ。通常評価では環境変数を上書きしない。
