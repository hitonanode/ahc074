# 後処理へ残す計画の違いを広げる

改良元: solutions/eject-quick。

上位2案を残す時、終了順序だけでなく動かす紙の並びが同じ計画をまとめる。通常の後処理が差し込み先を変えられるため、差し込み先だけが違う似た計画に2枠を使わず、別の紙を使う計画を残す。

研究条件は従来の終了順序だけ、動かす紙の順列が同じ場合も統合、動かす紙の多重集合が同じ場合も統合。統合する時は元の評価値が最小の計画を残す。候補数は2のまま。実際の後処理・修復・表示確認は改良元と同じ。全表示と各条件1本の可視性・最終順序を検査する。CLOCK_SCALEを適用し、隠された注文列は使わない。

wide.cppは候補数4案でも順列・多重集合による統合を比較する。各条件の候補数と統合方法以外は同じ。
