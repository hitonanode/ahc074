# compat-price

改良元: solutions/imp-combo（計測用のコピー。提出用ではない）

比較器で両側を出せない対（整合しない対）も使えるとしたときに、設計のモデルの費用がどれだけ下がるか（整合の値段）を測る。

- `COMPAT_FREE=d`: 距離 d 以下の整合しない対も対の候補にする（Design::initialize と焼きなましの組み替えの相方）。
- `COMPAT_GX=x`: 整合しない対の汎用層の費用を、目標 1 つあたり x / 100 手とする（整合する対は従来どおり厳密な平均手数）。
- 焼きなましと穴埋めの山登りの後に、モデルの費用とその内訳を stderr に出す。値はすべて 1 注文あたり（256 目標の和 / 256）。
  - `model_cost`: 合計。
  - `model_col`: 列の掘り。
  - `model_hole`: ハンドルの穴。
  - `model_gc`: 対の汎用層。
  - `pairs_incompat`: 選ばれた整合しない対の数。
  - `pair_gc_mean`: 対の汎用層の平均。
  - `pair_shallow_hd`: 対が自分の列以浅のハンドルで違う数の平均。
- `MODEL_ONLY=1`: 内訳を出したら注文処理をせずに終わる。整合しない対は実際には表示できないので、この版はモデルの計測専用。
- `CAPWIN=1`: 汎用窓 1 つ x を比較器から外したとみなす。x での対の違いは関係も汎用層の手もいらない。
  - 想定する仕組みは「キャップ紙」: x だけで黒い紙を一番上に固定して動かさず、D をその上に置くか下に置くかで x の色を決める。
  - x は、近い対のうち整合するものが最も多くなる窓を選ぶ。
- `CAPPAPER=1`: キャップ紙に専用紙を 1 枚使う（71 対）。
