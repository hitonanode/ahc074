# 既存キャップに補修窓を持たせる模型

改良元: solutions/post-two。研究用main.cppは基準のコピー。模型はsolutions/overpatch-codeの共有対選択を使用。

既存の黒い1窓キャップへ、汎用窓の小集合Sを追加印刷する。商品Aのキャップ窓が黒でSも一致すれば、共有紙に商品BのSを印刷し、Aではキャップを上、Bでは下へ置く。紙は増やさず185枚・71対を保つ。キャップ窓の色が異なる普通の共有対では、黒側の商品がS全体でキャップと一致しない限り表示できないため、その制約も入れる。

キャップを汎用層の上・下へ移す追加操作は、まず無償として有利な模型を比較する。共有の汎用費用は残った違いの半順序から正確な全開始順平均を使う。共有相手選択は貪欲と長さ3の増大路で、全体設計・注文処理を含む公式スコアではない。入力末尾の注文を使わず、CLOCK_SCALEを適用する。
