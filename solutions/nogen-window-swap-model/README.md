LOCAL_BENCH専用の設計模型。商品ペア・所有者・列番号を固定し、比較窓1個と取っ手窓1個を同時に交換する。比較窓を担当する背景2枚は、その窓で実際の所有色が反対になる組から選ぶ。全背景対の比較窓、通常列の両色、全256商品の補完可能性を保つ。印刷は所有者の共通色だけから作り、追加穴は保持する。

実際の列費用・取っ手穴費用と、720状態の正確な背景距離平均で最大3回の貪欲交換を行う。その後、独立した固定乱数の軽量4096注文・通常2048注文で再生する。実注文の将来は読まず、模型の紙は実出力へ使わない。study_swap_*は候補数・受理数・模型と実再生の改善手数・所有色監査・補完証明・時間。
