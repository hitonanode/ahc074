# gopt-h33

改良元: solutions/gopt

ハンドル窓の数 H を 34 → 33 にした（汎用窓は 30 → 31 窓で、ブロックは 7, 6, 6, 6, 6 窓）。ほかは gopt と同じ。

- 動機: gopt で汎用窓を「整合する良い相方を作れるか」で選ぶようになった後、H を模擬（焼きなまし固定、32 本の乱数注文列）で振り直すと、H34 比で H32 −0.02 ± 0.12%、H33 −0.11 ± 0.08%（seed 24〜87）、H35 +0.28%、H36 +0.68% で、H33 は seed 88〜215 でも −0.19 ± 0.05%。clean-base 以前の調整（retune-）では H33 は +0.20% だった。
- H はコンパイル時の定数 `HUB_H`（-DHUB_H=n で変えられる）。
