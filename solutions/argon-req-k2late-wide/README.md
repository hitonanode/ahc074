抽出直後の状態価値付き共同DPから、紙集合が異なる第2解を保存する。元の後処理候補を押し出さず、通常探索の後に評価する。既にeject済み・同じ最終積層の候補は省き、評価値差2以内の候補だけを削除だけの安い編集で整える。編集後の差が0.5以内ならejectを行い、完成評価値が改善した場合だけ採用する。既存の編集済みキャッシュを再利用し、中立探索全体の繰り返しは行わない。

joint_extra_plans/better/gainは第2解の有効数、初期最良値を上回る数と改善量。joint_late_trials/ejects/accepts/gain/savedは追加編集、追加eject、最終採用の件数、完成評価値の改善合計、即時手数差。既存の全ログ、実験スイッチ、プロファイラ、CLOCK_SCALE、LOCAL_BENCH、DesignStore、目次・節は保持。NEUTRAL=0では追加候補を通常候補として扱う。

第2解の区間DPは各位置に2状態だけを保持し、候補ごとの選択列コピーとstable_sortを、固定長2要素と前駆ノードによる復元へ置き換えた。同じ紙集合の統合、浮動小数点加算順、同点で先の候補を保つ順序は元の第2解版と一致する。追加のスイッチ・指標はない。
