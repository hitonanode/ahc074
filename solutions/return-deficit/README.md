# 列外の紙が戻ると復活する深さの費用

改良元: solutions/counterfactual-value、収集時の方策はsolutions/tight-thirty-eight。

現在の深さ費用は、列外の紙を除いた列だけで計算している。多くの紙は次の注文で列へ戻るため、紙を外に置いて列が短くなる利益を過大に見積もる可能性がある。列の単独紙数a・共有紙数bに対し、頻度順に置いた最小の重み付き深さはb(b−1)+ab+a(a−1)/2。この値の全紙と列内紙の差を、新しい特徴として加える。

同じ24入力・1199組の別計画を、8系列・16注文先へ進めて測り直す。特徴は9項、深さの2係数は1を維持して残る7項を推定する。元の方策は変更しない。隠された注文は読まず、全時計はCLOCK_SCALE倍。取得した差は将来費用の代理であり、方策の手数への効果は別の入力で検査する。
