改良元: solutions/climb4-fast

窓の割り当てより後の設計処理を、乱数列・評価値・採否・出力を変えずに高速化する。
窓の割り当てと注文探索、各段の反復回数は変更しない。

穴コストの SIMD 関数をインライン展開し、一時配列を介した呼び出しを避ける。
演算の順序と浮動小数点命令は変えない。
末尾の SIMD レジスタに変化がないときだけ、その再計算を省く。
個数は小さい整数で分子も丸めなく計算されるため、保存済みの商と厳密に一致する。
列コストが 10000 より増える候補は、穴コストの全変動の上界 8192 と
採用閾値の上界 22 を使って棄却を確定する。従来の採否判定と同じ乱数を1回消費する。
列間移動を採用した際の行集計は、両列の差分を一度作って両側に加減算する。
行の値も中間結果も小さい整数であり、float の丸めがないので結果は同じになる。

再割り当てで棄却したサイクルの補助紙価値表は、次のマッチングが読む直前に復元する。
次のサイクル試行は全表を設計から上書きするため、棄却直後の復元は不要である。
各サイクルの評価値、順序、採否は従来どおりである。
重みの大小で列の先頭候補から必ず外れる紙の価値計算を省く。
先頭紙の走査は重みがゼロでない紙を元の番号順に並べ、加算順序を保つ。
覆う穴が空の補助紙価値は、元の漸化式が厳密に返す正のゼロを即座に返す。

穴あけでは、先頭選択の後は固定された先頭紙だけの価値を更新する。
生成直後に同じ設計をもう一度初期化する処理も省く。先頭の選択規則と評価の加算順は同じ。
穴あけの区間 DP は実在する遷移だけを元の順番で走査する。
存在しない遷移の -1e9 は非負の DP 値を改善できず、取り除いても結果は同じである。
Hungarian 法の訪問フラグはバイト配列とし、作業配列を再利用する。
補助表はターゲットのハンドル色を一度だけ変換し、紙の挿入位置は単調な被覆集合を
二分探索して求める。元の列挙と同じ最も深い位置を同じ状態順に記録する。

`AF_PROFILE`（通常 0）で段別・演算子別の時間計測を有効にできる。
細かい関数は呼び出しの一部だけを計測し、`af_*_calls`（全呼び出し数）、
`af_*_samples`（計測数）、`af_*_sec`（標本平均から推定した秒数）を出す。
これらは包含時間で、呼び出し元と呼び出し先は重複する。時計は CLOCK_SCALE を使う。
計測処理は探索用乱数と設計の状態を変更しない。最終的な速度比較では無効にする。

CLOCK_SCALE、LOCAL_BENCH、DesignStore、`@paper` / `@ops` の構造出力を引き継ぐ。

焼きなましの反復設定 14,900,000（256回ごとの終了判定）、filler climb 154,000 回、再割り当て4回などの
反復回数、目的関数、乱数 seed、注文探索の候補数は改良元のまま。
