穿孔の色標本を32個の層別標本にする。目標・列ごとに一様分布を32等分して1標本ずつ抽出し、
独立に並べ替える。受理係数0.7、owner条件付け、利益上限、差分キャッシュは基準と同じ。

標本数が増えたときの費用を抑えるため、各DPのvalueだけを連続した配列にも保存する。
変更がない目標はこの配列から読み、1標本約1.5 KBのDPレコードへの飛び飛びの参照を省く。
DPを作り直す時だけ同時に値を更新する。全目標・標本の加算順と受理判定は従来通り。

新しい環境変数や指標はない。全ログ・@paper/@ops・プロファイラ・予算スイッチ、CLOCK_SCALE、
LOCAL_BENCH、DesignStore、段の目印と目次を保持する。変更はHandle perforationだけ。
