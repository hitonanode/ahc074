# 同時修正の利益を返却順序へ入れる

改良元: solutions/head-demand。

穴埋めに使われる需要の式を比較する研究。元の「2窓以上が誤色である確率」に加え、1窓以上、3窓以上、修正窓数から移動と後の返却に相当する1.6手を引いた正の利益を試す。規格化は比較元と同じで、列内平均を引く。非常に小さな重みも調べ、改善が主に同点の差し込み位置の選択によるものかを分ける。

`DEMAND_MODE` の既定値は3（3窓以上）、2は元の式、1は1窓以上、4は正の利益。`FILL_DEMAND_WEIGHT` は既定0.25。紙の設計・操作の候補・時計は比較元と同じ。`probe.cpp` は保存設計と固定乱数で生成する注文だけを使い、隠された注文列は読まない。
