# audit3-narrow

改良元: solutions/left-ap

穴埋め紙を選ぶ 2 つの区間 DP（run_joint と、専用紙を持ち上げる前に選ぶ choose_fillers_prelift）で、候補の紙を、より狭い段でも候補に入れるようにした。紙の設計は left-ap と同じ。

## 変更点

- 列 c の紙を段 lvl に置くと、ハンドル h_lvl..h_c に見えるので、そこにある専用紙の穴すべてで目標の色と合う必要がある。これまでは各候補を、合う範囲で最も広い段（色が合わない最も深いハンドルの次）でしか候補にしていなかった。このため、最も広い区間が重なる 2 枚の紙を組み合わせられなかった。
- 同じ紙をより深い段 lv に置けば、h_lv..h_c だけを覆い、h_lvl..h_{lv−1} はほかの紙に任せられる。そこで、h_lv がその紙の覆う穴であるすべての lv（同じ覆い方になる段のうち最も深いもの。ほかの区間との重なりが最も少ない）も候補に足した。
  - run_joint: 新しい穴埋め紙、古い穴埋め紙の置き直し、前の専用紙を穴埋め紙として使う場合。
  - choose_fillers_prelift: 新しい穴埋め紙。
- 3 回目の監査（solutions/audit3-tools）で、計画の前に合法な最初の 1 手をすべて試すと、良い計画が見つかる注文の多くが「紙をより狭い段に置く」形だったことから入れた。

## パラメータと指標

- 環境変数 `NARROW_J` / `NARROW_P`（既定 1 / 1）: 0 で run_joint / choose_fillers_prelift の狭い段の候補を足さない。
- stderr の指標は left-ap と同じ。
