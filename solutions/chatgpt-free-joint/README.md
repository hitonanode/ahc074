# chatgpt-free-joint

改良元: solutions/chatgpt-free-lex

自由3列のビーム探索で、正しい表示に到達した操作列を比較するときだけ、
将来の修正費用を「窓ごとの色合わせの和」から「3窓を同時に合わせる最少手数の期待値」に置き換える。
操作数を第1優先とし、同じ手数の候補の終状態選択にだけ使う。
途中のビーム評価、初期上界のgreedy、専用紙の戻し位置は改良元のままである。

終状態の3列から、各元列のハンドルが白・黒になる最も手前の紙を1枚ずつ選ぶ。
この6代表の実際の印刷と相対順序を使い、各部分要求について、
要求される窓に見える紙だけを動かせる720状態のグラフでBFSを行う。
目標色の最初の到達距離を、256商品の専用紙の穴から得た要求分布で重み付けする。
必要マスクごとの目標色は高々8通りで、すべて見つかればBFSを打ち切る。

評価値は「実際の全紙の平均掘り費用＋6代表の同時修正費用」。
既存の独立窓修正費用をさらに加えることはしない。
6代表に落としたため、同じ色の紙が何枚も続く深さや、掘り・持ち上げ・返却との結合は
修正費用の模型では失われる。掘り費用の項は実際の全紙について計算する。
最後の1〜2列だけの群、および持ち上げ中の紙のため白黒の代表が揃わない群では、
同じ自由順序解法の従来の費用近似を使う。旧解法へ切り替えるものではない。

印刷型は729通り、相対順序は720通り。群・型・順序ごとに計算済みの期待費用を保存する。
既定では新しいBFS計算の累計を時計倍率込み0.10秒、開始時刻を1.72秒までに制限する。
既存キャッシュの参照は継続し、予算外の新規状態では従来の費用近似を使う。
`FREE_JOINT_MISSES` に正数を指定すると、この時間条件の代わりにその回数まで新規BFSを行う。
探索回数を固定した検証用であり、提出の既定値は時間制である。

`joint_goal_calls` は新評価を要求した回数、`joint_cache_hits` はキャッシュ参照回数、
`joint_misses` は新規BFS評価の回数、`joint_bfs_states` はBFSで調べた状態数の合計、
`joint_missing_representatives` と `joint_budget_skips` は費用近似を使った回数、
`joint_build_sec` は新規計算の累計時間（CLOCK_SCALE込み）。

この変更の根拠となった6枚の厳密MDP模型は `solutions/chatgpt-block-mdp/` にある。
小模型の改善が長い列・掘り・返却込みでも成り立つことを仮定した実装ではなく、
本番の操作で検証するための実験版である。

`check_joint.cpp` は、提出側の前向きBFSを研究模型の独立した逆向きDijkstraと照合する検査器。
9模型の全6480状態と、同じ値のキャッシュ再参照を検査する。

```sh
g++ -std=c++23 -O2 solutions/chatgpt-free-joint/check_joint.cpp -o check_joint
./check_joint solutions/chatgpt-block-mdp/models-seed100000.txt
```
