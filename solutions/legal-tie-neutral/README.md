# legal-tie-neutral（中立探索の採否にも同点の補正を使う）

改良元: `solutions/legal-tie-fix`。設計は変えない。

## 改良元との差分

- 中立探索（2 対 2 の書き換えなど）の候補を短縮したあとの採否で、その候補と今の最良の plan_cost の差が kTieGap（0.3）未満なら、「plan_cost + 同点の補正」（tie_choice と同じ一次式をその終状態で計算した値）で比べる。差が大きいときは今までどおり plan_cost で比べる。
- なぜ: 最後の選び直し（tie_choice）は記録した候補の中からしか選べない。中立探索の途中の選択も補正で行えば、その後の短縮（refine）が補正の好む状態から進む。補正を plan_cost 全体に入れると悪化したので、ほぼ同点の採否だけに使う。
- 時間不足の打ち切りなどはない。
