後処理の初期積層の区間表に、黒色ではなく現在の要求に対する誤色マスクを保存します。区間内で最初に不透明になる紙の色が要求と違う窓を、要求ごとに一度だけ計算します。移動した紙にも同じ表の長さ1の項を使います。

上の紙で隠れていない誤色があれば、その候補は下の紙では修復できません。この判定により、候補ごとに表示全体を組み立てる計算を省きます。最後に未被覆の窓を白背景として確認するので、全窓を覆わない積層も従来と同じ判定になります。区間表は `process` ごとに無効化され、異なる要求には持ち越しません。

探索候補・順序・浮動小数点演算を変えない要求処理の高速化です。Solver のメンバの型・大きさ・配置、設計、探索予算、キャッシュのキーと参照回数を変えません。

既存の F3_*、COLMDP_*、設計反復回数の環境変数、ITER_SCALE、SIM_HARNESS、全プロファイラと trace スイッチを保持します。CLOCK_SCALE、LOCAL_BENCH、DesignStore、`@paper` / `@ops`、既存の stderr 指標も保持し、新しいスイッチや指標は追加しません。`cfprof_eval_filter_*` は候補の最終表示チェック、`cfprof_post_setup_*` は要求ごとの区間表の準備を測ります。
