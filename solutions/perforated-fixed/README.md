# 穴追加の評価で供給紙を固定する

改良元: solutions/perforated-crossing。

各列の白黒の先頭候補を、追加穴を開ける前の頻度と穴埋め利益で1枚ずつ選び、その集合を固定して穴を設計する。候補となる紙が途中で入れ替わると、多数の列の区間DPを計算し直す必要があるため、その計算を省く。固定は設計の近似模型だけに用い、実際の注文での紙の順序や選択は制限しない。

穴追加を選ばれた紙だけに限る条件と、全紙を試す条件を比較。先頭色の標本は4/8/16個、利益係数0.5。差分計算を全再計算で照合し、独立した模擬注文で品質を見る。

研究用。隠された注文列は読まず、CLOCK_SCALEを適用する。main.cppは制御の基準post-repairのコピーで、新しい設計はprobe.cppで調べる。
