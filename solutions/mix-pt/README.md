# mix-pt

改良元: solutions/pool-climb と solutions/tiny-bias（合流。どちらも hole-relax からの改良）

2 つの改良を合わせた版。pool-climb からは注文処理の run_joint（pool-value）と、焼きなまし後の山登り filler_climb を、tiny-bias からはハンドルの穴の色の持続を入れた焼きなましの費用と、計画の費用の tops_penalty を取った。そのまま合わせると両者がぶつかるので、filler_climb を持続モデルに合わせて直した。

## 両者の衝突

- tiny-bias の焼きなましは、浅い列の目標の色を深いハンドル h_m で多数派の色に寄せる。各窓の色は全目標でほぼ半々なので、残る深い列の紙（穴埋め紙の供給元）は逆の色に寄り、pool-climb の proxy（穴埋めの機会）が下がる。
- 逆に、一様な穴の費用のままの filler_climb は、tiny-bias が作った色の偏りを壊してしまう。

## filler_climb の変更点

- モデルの費用のハンドルの穴の部分を、持続モデルの正確な値にした（ハンドルごとの穴の数 n_m と色 1 の数から p_m を求め、n_m × 4 p_m (1 − p_m) × 0.51。焼きなましの限界費用の近似ではなく数え直した値）。
- proxy で覆う穴 1 個を、1 でなく 2 (1 − p_m(A_u[m])) と数える。p_m(c) は h_m が穴の目標のうち色 c の割合で、この値は持続モデルで省ける直しの期待値。多数派の色の穴は列の上端がたいてい合っているので、少数派の色の穴を覆える深い紙を高く評価する。
- proxy の重みを 0.7 → 0.3 にした。
- 山登りの後に、注文の計画（tops_penalty）が使う各ハンドルの多数派の色とその利得 2 p_m − 1 を数え直す（入れ替えで変わるため）。

## パラメータと指標

- 環境変数 `CLIMB_W` の既定が 0.3 になった。`CLIMB_BIAS`（既定 1）: 0 で filler_climb の穴の費用を pool-climb の一様な費用に戻す。`CLIMB_PQ`（既定 1）: 0 で proxy の持続の重み付けをやめる。そのほかの環境変数（`BIAS_*`、`CLIMB_*`、`JOINT*`）は改良元と同じ。
- stderr の `climb_hole_fixes`: 山登り後の、持続モデルでの 1 注文あたりの直しの期待値（tiny-bias の `model_hole_fixes` の山登り後の値に当たる）。ほかの指標は改良元の 2 つと同じ。
