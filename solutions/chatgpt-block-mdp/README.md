# chatgpt-block-mdp

改良元: なし（既存解法が出力した紙の設計を読む研究用プログラム）。

`probe.cpp` は隣接3列から各列のハンドルが白・黒になる紙を1枚ずつ選び、
6枚の全720順列を状態にした有限状態の平均費用MDPを解く。
注文時の3窓の部分目標27種の分布は、入力の256商品と実際の専用紙の穴から計算する。
必要ない窓は上の専用紙が隠しているものとし、必要な窓に見える紙だけを動かせる。
部分目標はその経験分布から独立に来る模型であり、公式の「直前と同じ商品を除く」
条件は含めていない。状態遷移を全列挙する対象は、この明示した小模型に限る。
平均費用と相対価値は有限回の価値反復で近似する。

各部分目標の逆向き合法グラフで、正しい表示の状態を始点とする多始点Dijkstraを行う。
終状態の相対価値を始点の費用に使って相対価値反復を行い、Bellman残差の最小・最大値で
最適平均費用の数値的な上下界を求める。区間演算による浮動小数点誤差の保証は行わない。
比較対象は同じ6枚を元の3列に分けた独立操作方策。

この模型には残りの紙、専用紙の掘り出しと戻し、汎用層、ほかのブロックの影響は含まれない。
長い実際の列に対する改善率やコンテストスコアへの外挿は行わない。

```sh
g++ -std=c++23 -O2 solutions/chatgpt-block-mdp/probe.cpp -o block_mdp
./block_mdp tools/in/100000.txt runs/<run-id>/out/100000.txt
./block_mdp --self-test
./block_mdp --models solutions/chatgpt-block-mdp/models-seed100000.txt
MDP_REGRESSION=1 ./block_mdp --models solutions/chatgpt-block-mdp/models-seed100000.txt
./block_mdp --cross-models solutions/chatgpt-block-mdp/models-seed100000.txt
```

任意の第3引数は反復上限（既定400）。時計で探索を打ち切る提出用解法ではない。

`--models` と `--cross-models` は同梱の6枚の印刷・27要求の度数だけを使うので、
元の `runs/` や公式入力がなくても模型の検証を再現できる。
`MDP_REGRESSION=1` は価値反復で求めた近似hを26種の部分要求への距離から回帰し、
各群144/720状態を学習から外して誤差と方策費用を計測する。
`--cross-models` は要求分布で平均した8特徴を使い、9群のうち1群全体を外した回帰を計測する。
どちらも提出用解法の設計にケース100000の学習係数を埋め込むための処理ではない。

模型内の正の結果、長い列に移す際の未検証点、全数値の出所は `REPORT.md` にまとめる。
