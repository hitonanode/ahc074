# ch5-access（整合しない近い対の修復の紙と、その取り出しの費用の計測）

改良元: なし（研究用の分析。解法ではない）。助言 gpt6pro-advice-1107-01 の 5 章の実現性の調査の手順 1・2。

保存した run の出力（stdout の紙の模様と操作、stderr の `@paper`・`@ops` の注記）だけを読み、scripts/replay.py で再生する。解法もテスターも実行しない。既定の run は SOTA の通常の比較 `20261108-063038_legal-tie-fix`（注文処理は legal-tie-fast と同じ）。

`analyze.py` が seed ごとに求めるもの:

- 比較器: 役割 generic の 6 枚、その不透明な窓 G、720 の順序。
- 近い対（64 窓のハミング距離 26 以下）の各側 x について、err_x = 6 枚のどの順序でも x の色にならない相違汎用窓の数の最小。両側 0 が整合する対。`--emax` までの対を調べる。
- 修復の候補（側ごと）: 紙 R（蓋・汎用紙・その対の 2 商品の紙は除く）を、汎用紙のある順序のある深さ p に差し込むと相違汎用窓がすべて x の色になり、R が相違する汎用窓以外の窓（共有紙の穴）でも x の色であるもの。共有紙のより深い取っ手の穴は覆われているとみなす（候補に有利）。両側とも候補がある対を「救える対」と数える。
- 再生（可視性の検査つき）: 注文ごとの操作のラベル別の数、動いた紙、注文の始めに見えている紙の数、前の注文の紙の扱い。救える対の、修復が要る側の商品の各注文について、候補ごとの取り出し方を、その注文の始めの重なりで判定する: SOTA の計画ですでに動く（ラベルつき）、見えている、または露出の費用（候補の窓のうち上に重なる紙が一番少ない窓の、その枚数）。
- 1 回の使用の費用: 楽観（`opt`）は、すでに動く候補 0 手、見えている候補 1 手（差し込み）、それ以外は露出 + 1 手。片付けは無料とみなす。現実（`real`）は、汎用層の上に紙を 1 枚残す実際の費用 0.96 手（trial_log 11-05 fcharge-above の測定）を片付けとして足す。候補のうち一番安いものを使う。
- 露出の手の合法性: 一部の注文で、覆う紙を上から順に一番下へ動かし、候補を一番上へ動かす操作を、可視性を検査して再生する（`validate`）。
- 商品ごとに、その商品のすべての注文で動く紙があるか（`reliable`: 一番多く動く紙の割合、ラベル、同じ列か）。

実行（重い計算なので評価のロックの下で）:

```sh
flock -x /home/sato/ahc074/runs/.lock nice -n 10 /home/sato/ahc074/.venv/bin/python analyze.py --seeds 0-50 --emax 3 --out results.json
```

集計は `summarize.py`。数値は保存した出力の再生と、上の費用の模型による。修復した設計を作って解いた結果ではない。
