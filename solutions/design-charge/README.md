# 設計で見込む穴埋め紙の返却費用

改良元: solutions/tight-thirty-eight。

紙の設計が穴埋めの利益を見積もる際の返却費用0.6を、0.4/0.8/1.0と比較する。列交換の山登り、先頭の一括再割当、その先頭色に関する微分、追加する穴の区間DPを同じ係数に揃える。注文処理の費用は変更しない。

同じ窓割当・列共有2000万提案の後から、山登り65000提案・再割当4回・補助穴設計を実行する研究用。未使用の32入力・独立模擬16本で、印刷の変更そのものの効果を比べる。実際の隠された注文は読まず、全時計はCLOCK_SCALE倍。main.cpp単独の係数は元の0.6。
