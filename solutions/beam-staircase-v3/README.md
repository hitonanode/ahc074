# beam-staircase-v3: 穴あけと操作列の再探索（研究用）

改良元：`solutions/beam-staircase-v2`。初期完成割当・連動構築はv2のまま、印刷パターンの穴あけと注文処理を改良。

- 既存の `Perforation` を復活し、ハンドルを維持したまま主紙の一部を穴にして他商品への補助価値を増やす。
- 異なる完成手順候補を深く探索し、合法な操作列の削除・挿入先変更・中立書換えを繰り返す。
- 既存の2削除→1修復を3削除→1修復へ拡張し、全操作列の可視性と完成表示を再生検証して採用する。
- デフォルトは品質優先版。`BEAM_FAST=1` のv3設定は、今回の本検証では対象外。

**2秒制限に達していない研究専用ソース。** 時間打ち切りがないため、現状のままAtCoderに提出しない。説明と不採用案は [v3ノート](../../docs/beam-staircase-20261106/notes_v3.md)。
