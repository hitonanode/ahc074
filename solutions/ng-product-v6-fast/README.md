# ng-product-v6-fast

改良元: solutions/ng-product-v5-overlap-fast（外部の研究版 v6 の軽量版）。ユーザーから渡された misc/ng_product_v6_fast.cpp を、そのまま main.cpp に置いたもの。コードは変えていない。

作者の説明は同じディレクトリの report_ja.md（misc/ahc074_product_only_v6_report_ja.md の写し）。

## v5 からの変更（report_ja.md から）

- **背景紙 6 枚の持ち主を、先に固定しない。**
  - 各背景紙が印刷した窓で、最も近い実在の商品との不一致の数を d_i とする。
  - 窓の設計の目的関数を F + 0.1 × Σ d_i にし、比較窓と持ち主を一緒に探索する。
  - Σ d_i = 0 になれば、各背景紙はどれかの商品とすべての印刷窓で一致する。全 15 比較を保つので、6 枚の持ち主は互いに別の商品になる。
- 探索に成功した後の、持ち主を固定した窓の探索（NG_CONTROL_MAP）は 0 回にした。
- 背景の持ち主に、背景用ハンドルの両色を要求していた不要な条件を外した。
- 軽量版（fast）は、通常の列の焼きなましと climb の予算だけを減らしている。NG_CONTROL_ANNEAL 2,000,000、PC_CLIMB 30,000。
- 紙の構成は v5 と同じ（キャップ 1、背景 6、単独 114、ペア 71）。注文処理も v5 のまま。

## 主なスイッチ（環境変数）

V6_MAP（300,000）、V6_CLIMB（60,000）、V6_OWN_PEN（0.1）。そのほかは v5 と同じ（NG_*、PC_* など）。

## 注意

- ファイルの冒頭のコメントのとおり、2 秒の制限は保証しない。
- **窓 63（キャップ窓）:** 窓 63 で色の違う 2 商品のペア紙は、窓 63 を白で印刷する（esw-clean 以来のキャップの慣習）。この窓は片方の持ち主の色と一致しない。
