# cmp-fast2

改良元: solutions/cmp-gobjr2

焼きなましで列だけが変わる手（2 単位の列の交換、1 単位・2 単位の列の移動。全体の約 57%）を、4 回の update（全部の穴を外して入れ直す）ではなく、穴になるかどうかが変わるハンドル（2 つの列の間）だけを数え直す move_col で評価する。

- 焼きなまし 600 万回が 0.50 → 0.39 秒（手元、空いた状態）。足し算の順が変わるので出力は同じにならないが、焼きなましの後の cur は数え直した値と 1e-9 以内で一致し、数も一致する（確認用の版で seed 1〜3）。回数を同じにした模擬で cmp-gobjr2 比 −0.036 ± 0.063%（同等、seed 24〜87）。
- 動機: 模擬（回数固定）で焼きなましを 2 倍 / 4 倍にすると −0.22 / −0.42% で、焼きなましの量にまだ余地がある。
- 対の組み替え（相手の交換）も含めて、変わるハンドルの数だけを足し引きする一般の版も書いたが、分岐が増えて 600 万回 0.68 秒と遅くなったので、列だけが変わる手に限った。
