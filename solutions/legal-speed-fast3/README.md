# legal-speed-fast3（legal-speed-fast + 試行の canonicalize を途中から）

改良元: `solutions/legal-speed-fast`（legal-speed-fast2 の cache の拡大は入れない）。出力は改良元と同じになるはず（設計固定の 2000 seed × 4 本で確かめる）。

## 改良元からの差分

- 後処理の試行の値を計算するとき（evaluate の memo に当たらなかったとき）の canonicalize は、紙の並びを下から 192 枚たどって補助紙と持ち上げた紙を作り直す。試行の手は上の方の紙しか動かさないので、試行の再生で手が触れた一番深い位置より下は、注文の始めの並び（st0）と同じ。
- 注文ごとに 1 回、st0 の並びを下からたどったときの途中の状態（各位置まで見たときの cur、汎用紙を見たか、紙のある列、見つけた補助紙）を記録しておき、試行ではその位置から上だけをたどる（位置 0・1 は持ち上げた紙の判定があるので、必ずたどり直す）。結果の補助紙の列と順番は、全部たどったときと同じ。
- 再生の途中の状態を使い回す仕組み（replay_prefix）に、手が触れた一番深い位置も記録する。
- 結果が同じことは solutions/legal-speed-fast3chk（両方を計算して比べる版）で確かめる。
