# 2操作を削除し、途中の1操作で修復する

改良元: solutions/perforated-eight。

後処理済みの操作列から2操作を除き、表示の不一致を別の1操作で修復する。従来の試作では最後に見えている紙を最後に動かす形だけだった。本研究では途中で見えている紙も候補にし、操作列の任意の位置に挿入する。途中で紙が見えなくなる場合にも、見えていた時点で移しておけるか調べる。

削除後の最終順序で各窓の先頭と2枚目を数え、1枚の移動で表示を直せる紙・挿入位置だけを残す。その候補を最初から再生し、全操作の可視性・最終表示・次の注文に必要な配置条件を検査する。以前と同じ終了費用が下がる案だけ受理する。

研究用のmid_eject_modeは0が対照、1が末尾への修復、2が途中を含む修復。各候補の1本は独立にも可視性を再生する。設計と模擬注文は別の固定乱数で、実際の隠された注文は読まない。時計は全てCLOCK_SCALE倍。重い研究用のため、提出制限内への組込みは結果を見て判断する。
