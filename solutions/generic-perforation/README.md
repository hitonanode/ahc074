# 商品紙の汎用窓を穴にして補助紙として使いやすくする

改良元: solutions/eject-lean。main.cppは基準のコピーで、変更するのは研究用probe.cpp。

各列・色の先頭候補にある商品紙の汎用窓へ穴を追加する。担当商品を表示する汎用順序が両方とも残ることを必須にする。他の商品への補助利用がしやすくなる利益と、自分の商品で増える汎用操作を比べる。新しい共有を作る過去のpatch設計とは異なり、現在の担当と列を保つ。

模型では全720汎用順序を等確率とし、補助紙なしと先頭候補1枚の挿入を比較する。取り出しは先頭色の確率から0〜1手、配置・返却は1.6手、覆った取り出し窓は不一致確率の和で価格付けする。補助紙どうしは最小費用を取るため重複計上しないが、他の穴埋め計画との競合は省略した模型である。補助利益の係数0.25/0.5/1を比較する。

実行可能性を確認した印刷だけ採用し、別乱数の模擬16本で実際の制御・全表示を検査する。各条件1本は全可視性と最終順序も照合する。隠された注文は読まず、CLOCK_SCALEを全時計へ適用する。
