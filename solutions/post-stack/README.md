# 前の穴埋め紙2枚を重ねて列の修正を省く

改良元: solutions/stay-cover。

後処理で、前の商品紙・穴埋め紙のうち2枚の返却操作を変更し、同じ深さへ上下に重ねる。下の紙の誤色を上の紙が隠す組合せなら、単独では使えない位置でも複数の窓を正しく覆える。既存の操作列から、その被覆で不要になる列の色合わせを2操作以上まとめて消す。

候補は下から見える色が全て正しい位置だけとし、削除は対象窓で誤色を持つ通常の列紙の操作だけに限る。全候補の最終表示、全操作の可視性、最後の紙の分類と費用を元の後処理と同じ方法で検査する。削除可能な全操作だけを消す版と、2操作ずつの組合せも試す版を比較する。

研究用。main.cppのpost_stack_mode=0は基準。probe.cppが変更を有効にし、保存設計・固定乱数の独立模擬注文で比較する。隠された注文を使わず、CLOCK_SCALEを適用する。
