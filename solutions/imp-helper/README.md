# imp-helper

改良元: solutions/imp-post（後処理は軽量版: `POST_PAIRS 0`。solutions/imp-post-lite と同じ）

solutions/gpt6pro-08-01-colswap の「汎用紙の間に専用紙を挟む」計画（補助紙）を移植して、注文ごとの計画の候補に足した。

## 補助紙

- 要求の紙 D の汎用の穴で、汎用紙 6 枚の並べ替えの代わりに、ほかの列の専用紙 x を汎用紙の間に挟む。x は上の汎用紙が穴の窓で自分の色を見せ、下の汎用紙を隠す。D の取っ手の穴でも x の不透明な窓は x の色が見える（そこが A_u と同じ色の紙だけを使う）。
- 前計算（Interleave）: 汎用紙 6 枚の 720 通りの順序の間の最少手数と最初の手（最下段の紙は見えないので動かさない）を BFS で求める。目標 u ごとに、使える紙 x と、順序 s で上から t 枚の下に x を挟むと D の汎用の穴に A_u が出る (s, t) の一覧（s ごとに最も深い t）を作る。倍率込み 1.55 秒を過ぎたら作るのをやめる（補助紙なし）。
- 注文ごと（try_helpers）: 前の持ち上げた紙と古い穴埋め紙を全部列に戻した状態から、補助紙 1 枚の候補（列で 5 枚目まで、汎用紙の手数が補助紙なしより減るもの。距離 + 深さ + 1.8 + 覆わない取っ手の穴の掘りの見積もりの小さい 4 つ）と、補助紙 2 枚の候補（3 枚目まで。見積もりの小さい 12 組から、汎用の手数を足して 4 組）を実際に動かす。汎用紙を目標の順序に動かし、補助紙を列から掘り出して挟み（D より浅い列なら D を持ち上げる前、深い列なら後）、D を持ち上げ、残りの取っ手の穴は run_plan と同じく区間 DP の穴埋め紙と掘りで直す。費用は process と同じ式で、ほかの計画と比べる。
- 補助紙は穴埋め紙（レベル 0）として記録され、次の注文で列に戻る（汎用紙が連続していないので、それを残す計画は set_generic で無効になる）。汎用紙が分かれているときは後処理をしない（全部の編集が棄却されるため）。

## 時間

補助紙の前計算に約 0.03 秒、注文ごとの候補に約 0.04 秒かかるので、設計の焼きなましを 1.305 → 1.245 秒、穴埋めの山登りを 1.36 → 1.30 秒までにした（倍率込み。cmp-anneal は 1.425 / 1.48）。

## stderr

- `helper_end_sec`: 前計算が終わった時刻、`helper_papers`: 全目標の補助紙の候補の数の合計
- `interleave_trials`: 動かして試した補助紙の計画の数、`interleave_selected`: 補助紙の計画を選んだ注文の数
