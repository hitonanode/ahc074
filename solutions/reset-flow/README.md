# 列への返却を含む先頭色の流れ

改良元: solutions/reset-majority。

列の穴修正費用を、先頭色0・先頭色1・取り出した紙の返却でどちらも選べる状態、の3状態模型で調べる。色cの紙を取り出して返す際、残った列の先頭が逆色なら、返却位置によって次の色を選べる。穴要求がない注文では、多く要求される色を選ぶと近似する。

色別の担当商品数と先頭紙の頻度（共有なら2、単独なら1）から、自由に色を選べる状態へ移る率を見積もる。これらの数は焼きなましの4区間の開始時に固定する。先頭色の定常分布から穴の費用を計算し、既存の係数0.8を掛ける。

対照として元の更新式の強さ2・4・8・16も調べる。`probe.cpp` は固定反復の設計と独立した模擬注文で比べる研究用。将来の実注文は使わない。提出版の既定は元と同じ強さ2で、候補の選別後に固定する。全時計はCLOCK_SCALE倍。
