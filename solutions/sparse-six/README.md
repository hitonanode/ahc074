# 汎用6枚の比較組を自由に減らす

改良元: solutions/perforated-eight。割当と制御は研究版 solutions/sparse-map / sparse-control から移植。

汎用窓の割当で、全15組の比較を最低1窓ずつ残す条件を外す。紙が全面穴になる変更は許さない。比較を省くことも含めて同じ割当探索で模様を決める。窓数38・汎用紙6枚・商品紙185枚は同じ。

比較を省いた場合は、汎用6枚の全720順序で実際に見える紙だけの移動グラフを作る。その距離で共有候補を値付けし、通常計画・補助紙を使う計画・次の要求の期待値を計算する。全比較がある場合の価格と制御は従来の等価な高速計算を使う。

その他の設計・穴追加・操作の後処理・打ち切り時刻は改良元と同じ。追加の距離と価格計算も設計時間に含め、その分だけ後続の探索量が減る。generic_edgesは印刷した異なる比較組数。全時計へCLOCK_SCALEを適用し、main.cppだけで完結する。
