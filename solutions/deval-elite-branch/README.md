窓割当てelite poolのうち同じ汎用窓集合を持つ別割当てを、4本目の枝に使う。共有前半の状態を引き継ぎ、不整合のペアは単独紙との1ターゲット交換で修復する。各スロットの色を保ち、元の仕上げ目的で修復先を選ぶ。窓目的が最小の別割当てを使う。代替がない・修復不能の場合も4枝の探索回数は同じ。完成設計をVで選び、再仕上げには選ばれた窓割当てを引き継ぐ。時間による打切り・予算変更はない。

elite_used / elite_broken / elite_prepare_secは別割当ての採用可否・修復ペア数・準備時間。
