# AHC074 商品紙兼務比較器 v6（研究実装）

- **ベース**: ユーザー提供 `esw-clean.cpp` の設計・列内操作エンジン。研究シリーズは [`docs/research/product-only-series-2026-11/`](../../docs/research/product-only-series-2026-11/README.md) に記録。
- **目的**: 担当のない汎用紙を0枚とし、実際の商品紙6枚を比較器の背景として兼務する。完全に汎用機能が消えたわけではない。
- **紙**: キャップ1枚＋比較器を兼務する専用紙6枚＋普通の専用紙114枚＋2商品共有紙71枚＝192枚。通常商品紙185枚だけで256目標を網羅し、比較器6商品の担当は重複。
- **窓**: 比較器の各窓は対応する2紙に反対色、他の比較紙に穴。各2紙の前後関係で表示を切り替え、6!＝720背景を用いる。階段状の列で主紙・修復紙を取り出す。
- **v6変更**: 背景を印刷しながら、各紙に最も近い実際の商品模様との不一致数 `D` に罰則をかける。探索の最終状態で担当商品に完全一致させることで、背景と担当商品の同時設計を実現する。
- **注文**: 共有紙・専用紙の取り出しに加え、別の商品紙1枚または2枚を比較器の間に挿入し、背景の並べ替え・ハンドル修復・回収を総費用で評価する。未来の注文列は読まない。
- **研究測定**: 公式ツール由来の100ケース×1024注文で10.177646手/注文、表示誤り・不正操作0（保存済み測定、公式Rust tester実行の主張ではない）。直前のv5 overlapは10.286123、元の6汎用紙版は10.093223。**元の方が良い**。
- **実行時間**: v6強化版のローカル直列4ケース平均約2.634秒。**公式2秒制限に未対応、提出にそのまま使わない。**
- **再評価**: リポジトリの `scripts/pahcer_run.py` を用いて、基準と同時に seed 0～99 を比較。詳細な測定条件は[研究レポート](../../docs/research/product-only-series-2026-11/reports/ahc074_product_only_v6_report_ja.md) を参照。

単独C++23ファイルで、`g++ -std=c++23 -O2 -march=native main.cpp -o solver` を想定する（今回GitHub上での2000ケース評価は未実施）。研究用の実験環境変数は必要なとき以外指定しない。
