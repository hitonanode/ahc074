# cmp-hswap2

改良元: solutions/cmp-hswap

焼きなましのハンドルの交換を約 3 倍安くし、率を 8% → 15% にした。

- 位置 a < b の交換で、列 < a と列 ≥ b の単位にとっては h_a と h_b の穴がそのまま入れ替わる（深いハンドルの穴も、対の違いの穴も）。新しい穴の数は「もう一方のハンドルの古い数 − 列 a..b−1 の単位の古い分 + 新しい分」で、列 a..b−1 の単位だけを見ればよい。列 a, b の単位について、対が新しいハンドルで一致するか（できなければ却下）と、ハンドルの色の数を数え直す。古い色から評価し、hb（目標のハンドルの色）は受理したときだけ入れ替える。
- そのために列ごとの単位の表（cu、cpos）を焼きなましの間持つ（受理した手で付け替え、rebuild で作り直す）。焼きなましの後の数と cur は全体の数え直しと一致する（確認用の版、seed 1〜3）。
- 600 万回の焼きなましで、交換なし 0.32 秒に対し率 8% は cmp-hswap 0.41 秒 → 0.35 秒、15% は 0.36 秒。模擬（回数固定）で率 20% は 8% より約 −0.05〜−0.07%（cmp-hswap の README の数字）。
