# 穴設計の色標本を層化して偏りを抑える

改良元: solutions/perforated-fixed。制御は solutions/stay-cover。

各商品の各窓について先頭色を独立に8回引くと、少ない標本で色の割合が大きく偏る。各窓で確率区間を8分割し、それぞれから1標本ずつ取って独立に並べ替える層化抽出と、乱数vと1−vを組にする反対変数法を調べる。先頭候補の固定と区間DPの目的は同じ。

層化8標本の利益係数0.4/0.5/0.6、16標本の係数0.5も比較する。選別用の乱数と検査用の模擬注文は独立。以前の選別とは異なるseed56〜87を使う。

研究用。main.cpp単独は制御の基準。隠された注文は使わず、CLOCK_SCALEを適用する。
