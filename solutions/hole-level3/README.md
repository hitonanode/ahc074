# hole-level3

改良元: solutions/hole-level2

穴埋め紙を、専用紙 D を持ち上げる前に選んで置けるようにし、計画の費用と選択肢を調整した。設計は hole-level2 と同じ。

## 変更点

- 持ち上げる前の穴埋め紙（choose_fillers_prelift）: D を持ち上げる前は、すべての列の一番上が見えている。D の列 l より浅い列 c の紙は、D がハンドル h_c を覆う（D がそこで不透明）場合でも、対の紙 D の浅いハンドルの穴を段付きで h_{c'}..h_c に覆える（その紙は D のハンドル h_l で穴なので、D を隠さない）。持ち上げた後では、こうした列の一番上は D に隠れて取れない。
  - 候補は D の列以外の全列の、深さ 3 までの紙（すでに置いた穴埋め紙が覆うハンドルの列は除く）。組は hole-level と同じ区間スケジューリングの DP で選ぶ。
  - 区間が D のハンドル h_l に届くもの（D より深い列の紙で段が l 以下）は、置くと D の列の一番上を隠すので、D を持ち上げた後に置く。それ以外は掘りと持ち上げの前に置く。
- 計画の費用: 列の外に残す紙（穴埋め紙）を 1 枚 1 手ではなく 0.8 手と数える（残した紙は、戻すより次の注文で再利用されることが多いため）。
- 前の穴埋め紙をその場に残す選択肢（fret_mode 4）: 新しい目標に害がない（新しい専用紙の列の一番上を隠さず、先に置いた深い段の穴埋め紙のハンドルに届かず、覆う穴で目標の色を見せている）前の穴埋め紙は、動かさずに残す。
- 列の外に残した紙が、持ち上げた専用紙をどけたときに見えている計画だけを採る（次の注文で戻せなくなるのを防ぐ）。
- 穴埋め紙を使わない計画は選ばれないので、計画の組み合わせから省いた（`UF_MIN` = 0 で戻る）。
- 列の 2 番目以降から取った穴埋め紙は、列の中の直前の紙のすぐ下へ戻すが、その直前の紙が持ち上げ中や穴埋め中で列にないときは、列の上端 / 下端へ戻す（何注文も列の外に残る紙が出てきたため）。
- 焼きなましの打ち切りを、プログラム開始から 1.15 → 1.10 秒にした。

## パラメータと指標

- 環境変数（hole-level2 のものに加えて）: `PRELIFT`（既定 1。0 なら持ち上げた後に選ぶ hole-level2 の方法）、`FILL_W`（列の外に残す紙 1 枚の費用、既定 0.8）、`KEEP_HARMLESS`（既定 1。0 なら fret_mode 4 を使わない）、`UF_MIN`（既定 1）、`HUB_TL`（既定 1.10）。
- stderr に足したもの: `pred_out_returns`（直前の紙が列になかったため、列の上端 / 下端へ戻した回数。試した全計画での延べ数）。
