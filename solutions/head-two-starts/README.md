# 2本の列設計を先頭利益で選ぶ

改良元: solutions/tight-thirty-eight。固定回数の研究はsolutions/early-select。

初期の共有・列配置から乱数を変えて2回探索し、取り出し・穴・汎用操作の模型から先頭紙の穴埋め利益を引いた値で1本を選ぶ。最後の穴埋め山登り・一括再割当・穴追加は選んだ配置だけに行う。

列探索の終了目安1.205秒を2回で共有し、1回目の後に残った時間を2回目へ渡す。候補選択の時間も全体の時計に含める。以後の時間配分と注文処理は改良元と同じ。ANNEAL_ITERS指定時は各半分（少なくとも8回）に分ける。

design_startsは開始数、selected_startは選ばれた開始番号0/1、selected_meritは選択した模型値/256。anneal_itersは両方の合計。全時計はCLOCK_SCALE倍、乱数は固定し、将来の注文は読まない。
