# 任意の白黒穴ゲートを学習する理由と、単窓変更の限界

この文書は `main.cpp` の設計根拠と今後の学習器の候補を説明する。以下の定理は表示可能性に関するもので、最終スコアの改善を保証しない。数値評価は同じケースでの現行解法との比較結果を参照する。

## 1. 比較器から一般の優先順位ゲートへ

6枚の汎用紙の並び順は720通りある。一つの窓に対し、どの紙を白・黒・穴にするかを指定すると、最上位にある不透明な紙の色を返す関数が得られる。この関数をここではゲートと呼ぶ。

白と黒を少なくとも1枚ずつ使うパターンは、包除原理で

\[
3^6-2\cdot 2^6+1=602
\]

種類ある。そのうち従来の2枚比較器は30種類である。任意のゲートは比較器より常に優れているわけではなく、ある注文に合う順序が増える代わりに、別の注文に合う順序が減る。

任意ゲートへ変更しても合法な操作グラフを維持するため、6枚の全15組について1窓ずつを2枚比較器のまま残す。この15窓により、どの順序でも最下位以外の各汎用紙には少なくとも一つの可視窓がある。残りの21窓を学習する。この保証は汎用層を操作するとき、その上に不透明な専用紙を置かない既存の運用を前提とする。

15窓の保護は、安い操作グラフを維持するための設計上の制約であり、到達可能性そのものの必要条件ではない。6枚の各紙が少なくとも一つの窓で不透明なら、最上位の紙は常に見える。「最上位を任意位置へ挿入」だけで720順序は全て相互到達可能で、最大距離も5以下である。逆操作の「任意の紙を最上位へ」は、目的順序の下から2番目以降の5枚を順に持ち上げれば任意順序を作れる。この経路を逆向きにすればよい。

従って、証人の比較窓を減らし、最後に実際の紙の模様から合法な操作グラフを作り直すことも理論上は可能である。ただし可視紙が減ると平均距離は増えうる。証人を減らした場合の距離の独立診断は `../astra-architecture/visibility_graph.cpp` にある。

## 2. 片方の色が一枚のゲートの互換集合

一つの窓だけを変え、他の汎用窓は全て2枚比較器だとする。対にした二商品の違う窓では要求色が逆なので、変更対象の窓を除く順序制約は、一方で関係 `R`、他方でその反転となる。

変更対象に白紙 `w` と黒紙 `b` があったとき、黒紙 `c` を追加することを考える。

- 新しいゲートが白になるには、`w` が `b` と `c` の両方より上である必要がある。
- 従って、新しい白の許容順序集合は、従来の白の許容集合の部分集合である。
- 従来の比較器で非互換だった対は、順序制約とその反転の両方が循環している。片側の許容集合を狭めても、その側を実現できるようにはならない。

**従来の2枚を残し、片方の色だけを追加する単窓変更では、従来非互換だった対を新たに実現できない。**

さらに、白1枚・黒k枚のゲートの互換対集合は、白紙と各黒紙から作るk個の2枚比較器の互換対集合の共通部分に等しい。白黒を逆にしても同じである。

理由は、少数色の紙が全ての多数色の紙より上に来る必要があるからである。`R` が非巡回で、黒紙のどれからも白紙へ到達できなければ、白紙から全ての黒紙への辺を同時に足しても循環しない。その順序を反転すれば反対側の商品も表示できる。逆に、どれかの黒紙から白紙へ既に到達できれば少数色を表示できない。

これは**互換対集合についての定理**である。合法操作距離の平均値まで一律に悪化すると主張するものではない。一方の目標順序集合が増え、他方が減るため、平均距離は別に測る必要がある。

## 3. 比較器の再割り当てでは得られない表現を狙う

単一の2枚比較器への再割り当てでは得られない互換対集合の拡張を狙うなら、最初の非線形候補は白黒をそれぞれ2枚以上含むゲートになる。6枚ではこの条件を満たすパターンが260種類ある。もう一つの方向は、複数窓を同時に変更して、前節の「残りが全て比較器」という仮定を外すことである。別の2枚比較器へ変更するだけでも、元の比較器では使えなかった対が使えることはある。この既存の探索との違いを問題にしている。

前節の「新たに実現できない」という結論は、旧2枚を残して片方の色だけを追加する変更に対するものである。
任意の3枚ゲートへの変更を、旧比較器に対して一律に劣るとする主張ではない。
また、互換対集合の支配は平均合法距離の支配ではないため、初手を260種類に制限することが距離やスコアの最適性を保つとは主張しない。

特に白2枚・黒2枚は、何が変わるかを明確に説明できる。変更窓以外の制約 `R` が非巡回であるとし、黒紙2枚から白紙2枚への到達可能性を2×2行列にする。

- 一方の商品で白を出せる条件は、いずれかの白紙について、どの黒紙からも到達されていないこと。つまり全て0の列が存在すること。
- 反対の商品で黒を出せる条件は、いずれかの黒紙から、どの白紙にも到達しないこと。つまり全て0の行が存在すること。

2×2の場合、全て0の行と列が両方あることは、行列の1が高々1個であることと同値である。従来の比較器に使っていた白黒の組がその唯一の禁止関係でも、残る紙を勝者に選ぶことで両側の商品を表示できる。この「商品対によって勝者の紙を変えられる」自由度が、単なる2枚比較器の再割り当てにはない部分である。

### 固定した他窓の下で、比較器では表せない小さい例

白を紙0・1、黒を紙2・3、穴を紙4・5に印刷する。上からの順序を次の4通りとする。

|種類|順序|
|---|---|
|A|4, 0, 2, 1, 3, 5|
|B|5, 1, 3, 0, 2, 4|
|C|0, 4, 3, 1, 5, 2|
|D|1, 5, 2, 0, 4, 3|

このゲートは4通りの全てで白を出し、その4通りの反転順序では全て黒を出す。一方、6枚から選ぶどの2枚も、表の4通りの中で上下関係が両方出現する。従ってどの2枚比較器を使っても、4通り全てで同じ白を出すことはできない。

他の比較窓が各商品対に対してこの順序と反転順序を一意に要求している場合、2白2黒の窓は4対全てを表現でき、どの2枚比較器も全ては表現できない。これは固定した他窓の下で表現能力が厳密に増える例であり、一様ランダムな実入力で同程度の利得が頻繁に発生するという主張ではない。

## 4. 一つの窓の602候補をまとめて調べる

ゲートを一つずつランダムに試すより、一つの窓の候補をまとめて調べる方が有利になる余地がある。

順列 `s` ごとに、その順列で黒を出すゲート602種類のビット集合 `B[s]` を事前計算する。602ビットは64ビット整数10個で持てる。

商品対の違いが窓 `j` を含むとする。`j` の要求だけを外し、他の穴窓の要求を満たす順列集合を、`j` で白を要求する側について `F0`、黒を要求する側について `F1` とする。この対の両側を実現できるゲートの集合は厳密に

\[
\left(\bigvee_{s\in F_0}\neg B[s]\right)
\land
\left(\bigvee_{s\in F_1}B[s]\right)
\]

である。補集合は602ビットの範囲だけで取る。`F0` または `F1` が空なら、一窓だけの変更ではその対を救えない。

この式は、他の窓が既に任意ゲートになっていても成立する。従って、各窓の全候補を調べる反復に利用できる。可否の一括計算と、候補ごとの70対の貪欲マッチングを分離し、有望候補だけ720状態上の合法距離で正確に評価すればよい。

注意点として、目標順序の**個数**だけでは平均操作距離は決まらない。同じ個数でも、操作グラフ上で近い場所に集中している集合と、広く分散している集合では距離が異なる。個数やその対数は候補の選別用に使い、最終的な採否は両側それぞれの最短合法距離を計算して判断する。

### 平均合法距離も集合演算で計算できる

6枚の合法な順序グラフの最大距離は5である。始状態の最下位紙を動かさず、残り5枚を必要な場所へ1回ずつ動かせば、任意の終状態にできる。

終状態 `g` と距離 `d=0,...,4` ごとに、`g` へ `d` 手以内で到達できる始状態のビット集合 `R[g][d]` を前計算する。向きは必ず既存の `dist[s][g]` とし、`dist[g][s]` とは取り違えない。

非空の目標集合 `F` への平均最短距離は、整数値確率変数の裾確率を足す恒等式から

\[
\frac{1}{720}\sum_{d=0}^{4}\left(720-
\left|\bigcup_{g\in F}R[g][d]\right|\right)
\]

と厳密に計算できる。前計算の保存量は `720×5×12×8=345600` バイトであり、各候補の評価は主にビット集合のORとpopcountになる。`d=0` は `|F|` を直接使える。これは近似の変更ではなく、同じ合法距離の計算方法の候補である。採用時には既存の距離行列による直接計算との一致を検査する。

## 5. 単窓探索が停滞した後の候補

現時点で有効性を確認したものではなく、次に切り分けて測る候補である。

1. **二窓の破壊と再最適化。** 一窓だけでは `F0` または `F1` が空の対も、二窓を外せば両集合が非空になる場合がある。元の非互換対について、循環を壊す窓の組を候補として選び、一方を仮置きして他方を全列挙する。
2. **対の選択を変えた状態でのゲート学習。** 現在の70対を全て維持する条件は、より良いハンドル差を持つ対への移動を妨げる可能性がある。少数の対を入れ替えることを許すが、最後は全256商品を186専用紙で正しく表示できるマッチングに戻す必要がある。
3. **距離を保つ候補選別。** 単なる許容順序数ではなく、現在の720状態それぞれから目標集合までの距離分布、またはその一部を使い、上位候補の取りこぼしを減らす。

いずれも、追加の設計時間、汎用層の実操作数、補助紙の使いやすさへの影響を含めて評価する。互換な対が増えたことだけを、最終スコアの改善とは扱わない。
