# astra-structural

改良元: solutions/astra-search4

六枚の汎用紙を、二枚の白黒比較だけでなく、三枚以上の最上位色を使う辞書に変える実験。
六枚の全十五組について一窓ずつ比較の証人を残すため、汎用紙は従来どおり最下段以外が必ず可視になる。
残りの窓の `0/1/.` を変更し、従来の DAG では表せなかった対を含めて商品対と列を再設計する。

- 汎用表示は六枚の全 720 順序で厳密に列挙する。対の両側を別々に判定し、相補・逆順対称性を仮定しない。
- 目的となる表示集合までの合法最短距離を、設計費用と注文処理に使う。
- 初期の窓割当は改良元から引き継ぎ、その後で証人以外の窓の符号を変更する。対を固定して変更を試す方式ではない。
- 専用紙の予算は 186 枚のまま。紙の取り出し・回収・全窓の修復は改良元と同じ費用として実行する。
- `CLOCK_SCALE` を全時計に維持する。新しい時計を別に設けない。

## 符号の学習

一つの変更可能窓を選び、六枚の印刷として白黒が両方ある全 602 通りを評価する。
全商品のうちハミング距離 26 以下の対を候補とし、当該窓の制約を外した許容順序から、
どの印刷なら対の両商品を表せるかをビット集合で一括計算する。
70 対の貪欲マッチングを各印刷で作り直し、粗い費用の上位四候補だけを合法最短距離で評価する。
粗い順位付けは許容順序数の対数を使い、最終評価は両側それぞれの 720 開始順序からの平均距離を使う。
この近似順位付けと一窓ずつの学習は探索上の制限であり、602 通り全ての最適費用を求めているわけではない。

第一変更は白二枚以上・黒二枚以上を必須にし、少なくとも一窓は非線形にする。
これにより、旧比較器へ戻るだけで評価を終えない。
この初手の制約は、単一比較器の再割り当てでは得られない互換集合の拡張を試すためのもの。
一色が一枚のゲートの互換集合が構成比較器の互換集合の共通部分となる理由は [THEORY.md](THEORY.md) を参照。
別の比較器への再割り当てでも初期には非互換だった対を実現できるし、互換集合の支配だけでは平均距離の大小は決まらない。

## 計算時間と指標

窓割当は 0.40 秒、割当の最後の探索は 0.46 秒まで。
辞書探索は 0.75 秒まで、その後の列設計・補助表・注文処理の期限は改良元と同じ。
環境変数 `DECODER_ITERS` を正数にすると辞書探索の窓数を固定できる。

- `decoder_gate_trials`: 候補にしたゲートの延べ数（除外候補も含む）。
- `decoder_accepted`: 印刷を変更した回数。
- `decoder_nonlinear_windows`: 三枚以上が不透明な窓の個数。
- `decoder_proxy_before` / `decoder_proxy_after`: 辞書探索の開始・終了時の 70 対の費用を 256 で割った値。
- `decoder_end_sec`: 辞書探索終了時の倍率込み時計。

評価結果は同ディレクトリの報告書と trial_log.md に記録する。
