# 実際の注文処理で紙の入れ替えを評価する

改良元: solutions/eject-lean。研究用の保存設計と再割当部品は solutions/map-handle。

紙の列配置を評価する模型の誤差を調べる。単独・共有の種類と各列の先頭色を保つ2枚の入れ替えを候補にし、模型の費用と先頭利益から候補を絞る。その後、独立模擬注文で得た途中の重なりを保存し、各候補の紙の模様で同じ注文を実際の計画器に解かせる。手数と終了状態の費用の差分から候補を選ぶ。

変更した紙が前注文の商品紙・穴埋め紙になっている状態や、印刷の変更で開始表示が変わる状態は選択用の比較から除く。これは定常状態の厳密評価ではないため、選んだ配置は別乱数の長い模擬注文で最初から制御して検査する。選択に使う注文と検査する注文を分け、入力末尾の注文列は読まない。

現段階は改善余地を測る高価な研究用。main.cppは基準のコピーで、提出用に組み込まない。全表示・可視性・担当商品の保存を検査し、全時計はCLOCK_SCALE倍。
