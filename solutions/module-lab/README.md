# 取り出しと複数窓の表示を兼ねる小さな部品

改良元: solutions/tiny-model の厳密な MDP。時計は solutions/as6-canon と同じ `CLOCK_SCALE` 倍率を使う。

3個の取り出し窓を1つの部品にし、紙の不透明な位置を自由に選ぶ案の分析用コード。提出用の解法ではない。
従来の小さな模型は「その紙の商品を表示する注文」が中心だったが、この模型では、ほかの商品の紙に空いた穴の色を合わせる注文と、部品内の指定した紙を取り出す注文を混ぜる。

- 状態は部品内の紙の全順列。見えている紙だけを任意の深さに差し込める。
- 表示の注文は、3窓の8通りの色から一様に選ぶ。
- 取り出しの注文は、紙から一様に選ぶ。指定紙を取り出し、その紙に残る穴を商品の色に合わせ、その後に紙を好きな位置に無償で戻せる。持ち上げと返却の定数費用を省き、返却をすぐに行える点は本番より有利なので、結果は構造を絞るために使う。
- 取り出しの割合 `q` を変え、紙の色を固定したまま不透明・穴の配置を焼きなます。
- 比較基準は紙を3列に分け、各列の紙が自分の列までを覆う階段配置。同じ模型の最適方策で比較する。

`module.cpp` は全順列の合法移動グラフと相対価値反復で平均費用を求める。`g_lo` と `g_hi` がその上下界。`q`、紙の枚数 `K`、色の乱数seed、探索回数を引数で指定する。
`triangle=1` は階段の列への割り当てと窓の順だけを探索する対照。`access_only.cpp` / `run_search.py` は、取り出した紙の穴の修正を省いた最初の模型。`run_closed.py` は穴の修正を含めて階段型と自由な不透明配置を比較する。
`search_seed` は商品の色を保ったまま探索の乱数だけを変える指定。`restart_triangle.py` は、小さい差が探索の取り残しから来ていないかを調べる。
実験結果は trial_log.md に記す。
