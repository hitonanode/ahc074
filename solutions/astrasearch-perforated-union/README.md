# astrasearch-perforated-union

改良元: `solutions/astrasearch-perforated`。

新対を救済する補助紙の評価を、汎用紙の先頭集合を1つに固定した距離から、加工後の補助紙で使える全終状態の和集合への距離へ改善する。
各方向について、ハンドル列への配置も考慮した費用で有望な補助紙・加工マスクの組を既定24個選ぶ。
その各組を汎用紙720順序と `RELAX_MIN_DEPTH` 以上の全挿入位置（既定0ならすべて）で再検査し、すべての有効終状態を始点とする逆向きBFSで一様な開始順序からの平均合法最短手数を求める。
これにより、先頭集合を固定したために必要だった余分な並べ替えを設計費用から取り除く。

汎用窓とハンドル窓の穴化、補助紙自身の担当商品のDAG検査、最大1交換、補助紙必須の注文処理は改良元と同じ。
各補助紙で最初に選ぶ加工マスクは、従来の先頭集合固定の評価で選んだ1個に限る。
そのため全マスクを対象にした最適化ではなく、現版は距離評価を正す切り分け実験。

## 初期設計の一致の確認

紙を作る処理を `materialize_design` にまとめ、穴化前と穴化後の両方で同じ関数を呼ぶ。
`initial_design_hash` と `final_design_hash` は、実際の窓座標に戻した192枚の64文字と各行末のLFに対する FNV-1a64。
offset basis は14695981039346656037、primeは1099511628211、64bitで折り返す。
固定回数の `imp-gla` の出力先頭192行を同じ方法でハッシュ化すれば、穴化前の設計が一致することを機械的に検証できる。

## 指定と診断

`RELAX_FORCE/RELAX_PAIRS/RELAX_MIN_DEPTH` と既存の設計反復固定の環境変数は改良元と同じ。
`RELAX_UNION=n` は各方向で和集合距離を厳密評価する補助紙・加工マスク数（既定24）。
`relax_union_calls` は逆向きBFSの回数、`relax_union_saved` は1回あたりの「従来の先頭集合固定距離 − 和集合距離」の平均。
他の設計・必須注文の診断値も維持する。

強制採用モードは設計探索と注文処理の時間打ち切りを外す研究用。
通常モードの実行時間と、同一初期設計の純効果は分けて評価する。
