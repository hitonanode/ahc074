# 先頭候補の商品紙に補助用の穴を追加する

改良元: solutions/stay-cover。穴の設計は solutions/perforated-fixed の8標本版。

通常の共有・列の設計後、各列の白黒について先頭になりやすい紙を1枚ずつ選ぶ。その紙の自分の取り出し窓より浅い印刷に、追加の穴を開ける。誤色が消えることで、他の商品の複数の穴をまとめて覆いやすくする。自分の商品に増える穴の費用も数える。

各商品の先頭色を固定乱数で8標本作り、重ならない穴埋めの区間DPで利益を測る。紙ごとの独立利益で事前選別し、区間DPの利益に係数0.5を掛けて追加・復元を1巡回する。評価用の先頭候補は固定するが、実際の操作では候補を制限しない。

元の探索時間配分は保ち、穴追加は倍率込み経過1.49秒で打ち切る。補助表の上限1.55秒、注文処理の軽量化開始1.80秒も元と同じ。全時計はCLOCK_SCALE倍。main.cpp単独で完結し、表の大きさはハンドル数が増える場合にも対応する。

追加のstderr指標: perforation_holesは追加穴数、perforation_trialsは試した1穴変更数、perforation_acceptsは受理数、perforation_secとperforation_end_secは穴追加の所要時間と終了時刻。
