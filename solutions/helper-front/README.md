# 前の紙を補助紙として取り出しやすく戻す

改良元: solutions/eject-lean。

前の商品紙または穴埋め紙を今回の汎用層の補助紙に使える場合、その紙を自分の列の先頭へ戻す計画も作る。従来の補助計画は全ての古い紙を通常の期待費用で返却してから補助紙を選ぶため、使いたい紙を深く戻してしまうことがある。専用の返却位置で余分な掘りを省き、通常の後処理で返却そのものが不要なら削除する。

研究条件は元の制御、先頭返却と汎用手数の減少が必要な条件、汎用手数が1手多くても許す条件、古い紙を含む補助紙2枚の計画も許す条件。全計画で実際の可視性・表示・終了状態を確認する。設計・時間配分・CLOCK_SCALEは改良元と同じ。main.cppの既定は先頭返却だけ。
