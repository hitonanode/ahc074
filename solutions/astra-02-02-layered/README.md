# astra-02-02-layered

改良元: solutions/astra-02-01-prefix

## 改良元との差分

構造を大きく変えた。01 の接頭辞部品（と埋め込みの遷移表）は下位の窓の「下地」としてだけ使い、上位の窓には多数の窓を一度に覆う学習した模様の紙を置く。

- 窓の分担: 窓 0〜LB−1（LB = 28 か 35）は 7 窓ずつの接頭辞部品（8 枚 × LB/7 個。01 の窓の割り当て・反転の焼きなましは使わず、窓 7b〜7b+6 に固定）。窓 g = LB〜63 には窓ごとの「グループ」を置き、各グループに最低 2 枚、余りの紙を上位 top 個（16 か 20）のグループに順に配る（計 192 枚）。
- グループ g の紙: 窓 g（持ち手）に色を必ず印刷し、g より大きい窓は穴、g より小さい窓には 256 商品から学習した模様を印刷する（mine_layer: 商品をまとめていき、まとめた商品で色が一致する窓を印刷し、覆える窓数の増分で貪欲に選ぶ）。初期の重ね順は 部品 → グループ LB → … → 63 で、各グループの先頭の紙が持ち手の窓で見えている。
- 注文ごと: グループを g = 63 から下へ走査するビームサーチ（幅 128）で、各グループから紙を 1 枚「上層」に出すかを決める。出す紙は、目標と違う窓がその差し込み位置（cut）より下に来るように、cut の位置の部品・グループの直上へ差し込む（cut より下の窓は上の紙に隠れる）。評価は、グループ内で紙を掘り出す手数、前の注文で出した紙を戻す手数、覆われずに残った窓の修正手数の合計。下地の部品は「覆われる窓は 0・1 どちらでもよい」目標（3^7 = 2187 通り）の最短手数の表 partial（遷移表から作る）で評価する。前の注文で出した紙をそのまま残す・位置だけ移す選択肢もある。
- 覆われずに持ち手の色が違うグループは、先頭の紙を色の違う紙が先頭に来る位置へ回す（並びは使用頻度の重みつきの深さが小さくなるように選ぶ）。
- 設計の選び方: 4 つの構成（(LB, top, fee) = (28, 16, 4), (35, 16, 4), (35, 20, 3.5), (28, 20, 4)）それぞれで模様を学習し、内部の乱数で作った 384 注文（商品だけから作る。ビーム幅 16）の手数で最良を選ぶ。

## パラメータ

- 注文時のビーム幅 128（CPU 時間 1.55 秒を超えたら 32、1.70 秒を超えたら 8）。新しく出す紙の費用 newfee = 1.5、学習の fee = 4。

## 移植について

外部の agent（astra-02。この repo の文脈を共有しない）が作った解法を取り込んだもの。元のソースと報告は main checkout の other_agents/astra-02-02.md, astra-02-02-layered.cpp。元から提出用の reactive 形式なので、変更は `#include <bits/stdc++.h>` を個別の include に置き換えただけ（アルゴリズム・出力は不変）。実行引数で設定を変える部分と stderr への統計は `-DLOCAL_VERIFY` のときだけで、提出の構成では既定値で動き、何も出さない。
