# 穴埋めの重複を除いて商品紙に穴を開ける

改良元: solutions/perforated-head。

紙ごとの穴埋め利益を足す代わりに、同じ穴を複数の紙の利益へ重複して数えない区間DPで穴の追加を決める。各商品の列先頭の色を4または16組標本化し、先頭紙の取り出し0手・逆色紙の取り出し1手・配置返却1.6手で覆える区間を選ぶ。利益係数は0.5と1.0。1巡回だけ追加・復元を試す。

自身の担当商品で増える穴の費用は元と同じく数える。標本は固定乱数で、検査に使う模擬注文列とは独立。研究用で、main.cpp単独は基準のまま。最初の模擬1本の可視性・順序、差分の利益を独立に検査する。全時計にCLOCK_SCALEを掛ける。
