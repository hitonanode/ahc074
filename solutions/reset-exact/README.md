# 列への返却頻度を紙の移動ごとに更新

改良元: solutions/perforated-eight。

穴の費用に使う返却頻度t=2×担当商品数を、焼きなまし区間の開始時だけでなく、列を移る紙の変更ごとに更新する。1枚・2枚の列移動、列全体の交換、共有相手の組み替えを含む。tの変わる列だけ差分を作り、全窓の穴費用を既存のAVX2計算で更新する。受理しない場合はtも戻す。

研究条件は、従来の4区間、移動ごとの更新・4区間、固定頻度を16区間で更新、移動ごとの更新・1区間。各2000万候補、先頭山登り65000回、再割当4回、補助穴8標本を共通にする。独立した16本の模擬注文で比べる。全表示・1本の可視性と、VERIFY_RESET_COSTで差分費用の再計算を確認する。時計はCLOCK_SCALE倍。
