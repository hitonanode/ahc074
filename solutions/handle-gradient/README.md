# 穴埋め利益の微分で先頭色の費用を補正

改良元: solutions/perforated-eight。比較する限界費用模型は solutions/handle-marginal。

区間DPの色標本を列ごとに反転して解き直す代わりに、独立な穴埋め利益の先頭黒確率に対する微分を計算する。先頭の紙そのものが白黒で入れ替わる効果と、その紙が他列で埋める誤色数の変化を含む。誤色0個・1個の確率を前後の積で求める。

返却順と終了状態の白黒費用の差へ係数0.125/0.25/0.5/1で加え、総需要は保つ。負の需要は0.001へ丸める。DPの限界費用を0.5混ぜた対照も比較する。設計・紙・注文時の他の制御は同じ。独立した模擬16本で測り、全表示と1本の全操作の可視性を確認する。全時計はCLOCK_SCALE倍。
