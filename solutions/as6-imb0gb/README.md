# as6-imb0gb: as6-imb0 + 汎用層の底を一番深い汎用紙にする

改良元: solutions/as6-imb0

## 変えたこと

- 注文処理で「汎用層の下か」を判定する基準を、汎用紙 0 から、今いちばん深い汎用紙に変えた（generic_bottom）。使う所は次の 2 つ。
  - gen_harm: 列の外に残した古い紙が、次の D の汎用窓の穴に色を見せて害になるかの判定。
  - move_to_level の below_generic: 穴埋め紙を汎用層の下に置くときの位置。
- 汎用紙 0 は、汎用層が土台の紙 + 反転紙だった時代（clean-base）の土台の紙 F の名残。比較器では、汎用紙 0 は 6 枚の中のどこにでも来る。
- 汎用紙の並べ替え（set_generic）は 6 枚が連続していることを要する。そのため、汎用紙の間に紙を残す計画は、D に汎用窓の穴があれば必ず不可能になる。元の判定は、それを害なしと見ていた。
- 頻度: 注文の始めに汎用紙の間に列の紙がある注文は 8.8%、そのうち D に汎用窓の穴があるのは 4.9%（as6-majtop、seed 0〜19）。
- 根拠: 設計を固定した模擬（solutions/steady-probe/knobs.cpp の GEN_BOTTOM、seed 24〜87、注文列 4 本）で −0.016 ± 0.005%（43/1/20）。
