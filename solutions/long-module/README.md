# 実際の枚数を持つ3〜5列の自由な印刷と順序

改良元: solutions/as6-canon。`main.cpp` は比較元のコピー。

隣接する3〜5列の紙をひとつの部品として扱う研究模型。保存設計の紙数・商品色・共有関係と、全256商品から来る部分一致の要求を使う。各紙は元の取り出し窓を残し、他の窓には担当商品の色が共通なら印刷できる。部品の中の順序は自由に変える。

- 指定紙の取り出しは、不透明な各窓について上にある紙をどける手順を比較する。どける紙は常に可視で、指定紙より下へ入れる。
- 色合わせは、可視紙を動かす短いビーム探索。到着後の値には、各紙を取り出す最小深さと、窓ごとの指定色までの深さを使う。
- 指定紙の持ち上げと即時の返却は無料。ただし指定紙に残る穴の修正を数える。部品外の穴埋め紙は含めず、同じ制御で元の印刷と比較する。
- 印刷の探索と評価の注文列は固定乱数で別々に生成し、実際の注文列は使わない。模型内の可視性と目標表示を検査するが、公式スコアではない。

`profile.py` が保存設計から模型の入力を作り、`model.cpp` が探索する。既定の研究では幅8以上のビームを使う。`profile.py` の第3引数で窓数を選ぶ。`model.cpp` の引数は入力、探索回数、探索に使う注文数、検査に使う注文数、ビーム幅。時計には `CLOCK_SCALE` を掛ける。

第8引数を1にすると、元の取り出し窓も除去できる。ただし各紙には最低1つ不透明な窓を残し、その紙を除いた表示の可否も検査する。元の列への所属を保つ制約を外した研究である。

差し込み位置全ての元の将来費用は、窓ごとの最小深さを達成する集合と、その後ろにある紙の寄与の和で O(KW) で計算する。`verify_insert.cpp` で単純な再計算との一致を検査する。第9引数は将来費用の変更（0:元の式、1:下記を半分混ぜる、2:全て下記）、第10引数は高速差し込みを使うかを指定する。変更式は1操作で到達する全表示を列挙し、次の要求の修正費用を2手で打ち切って評価する。`verify_value.cpp` はこの表示集合を全操作との独立照合で検査する。

将来費用のモード3は、深い紙の元の費用を保ち、1操作で複数窓を直せる利得だけを引く。モード4はその利得の半分を引く。
