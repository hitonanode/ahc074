# as6-imb0: 列の費用から色の釣り合いの罰を外す

改良元: solutions/as6-majtop

## 変えたこと

- 設計の模型の列の費用（colcost_of、焼きなまし用の整数版 colcost40、SIMD 版 colcost_pair）から、色の釣り合いの罰 0.1·imb²（imb = max(0, |nc − 2·n1| − 1)、列の自分のハンドルの色の偏り）を外した。
- この罰は、列を巡回させていた時代の名残。今の設計は、ハンドル h_c で要求の少ない色の目標を列 c に集めて、h_c の穴の要求を多数派の色に寄せることで得をしている。罰はその偏りに逆らっていた。
- 「上 2 枚に両方の色がある」仮定（掘りの項の補正）と、「1 色だけの列の禁止」（1e5 の罰）はそのまま残す。
- 根拠: 設計の回数を固定した模擬（solutions/steady-probe/knobs.cpp の IMB40、seed 24〜87、注文列 4 本）で、罰を外すと −0.419 ± 0.064%（50/0/14）、1/4 にすると −0.205 ± 0.074%。
