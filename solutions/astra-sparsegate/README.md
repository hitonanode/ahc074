# astra-sparsegate

改良元: solutions/astra-structural-fast

汎用紙の全15組を可視性の証人として固定する制約を外し、二部グラフ K3,3 の9組だけを固定する。
残り27窓で白・黒・穴の優先順位回路を学習する。紙数は6+186のままである。

- 紙0,1,2と紙3,4,5の間の9比較器について、それぞれ最初の一窓だけを固定する。
- 汎用紙を動かせるのは、反対側の3枚のうち少なくとも1枚が自分より下にある場合に限る。この条件なら固定した証人窓で必ず見える。
- 学習した窓が追加で可視性を与えていても、今回はそれを動作可能性には利用しない。常に合法な操作の部分集合を使う。
- この制限付き有向グラフの720状態間距離を全BFSで正確に求める。従来の完全グラフの距離表は再利用しない。
- 任意目標集合までの平均距離は距離球の和で正確に計算し、表現の自由度が増える利益と操作制限が厳しくなる損を両方目的関数に入れる。
- 注文処理もこのグラフの最短経路を用いる。表示と実際の操作の可視性は既存計画器と独立テスターで検査する。

窓割当の初期解だけは6枚比較器の探索を流用するため、新しい操作費用に対して初期割当が最適とは限らない。
単窓学習、強制初手、時間配分は改良元と同じ。これは証人窓の節約という別の構造仮説を切り分ける実験である。
`witness_graph_diameter` は制限付き720状態グラフの直径。
評価結果は trial_log.md と astra-frontier/REPORT.md に記す。

## 完成した印刷の可視性を回収

学習中の費用は固定証人だけで保証できる保守的なグラフを使う。
学習終了後は全汎用窓の実際の印刷から720状態の可視紙を列挙して、操作グラフと全点対距離を一度作り直す。
列の設計と注文処理はこの実際のグラフを用いる。追加の比較窓や任意ゲートが与える可視性を捨てない。
`actual_graph_diameter` がこの最終グラフの直径。学習の費用は保守的なので、最終費用そのものを直接最適化しているわけではない。
