# 良い共有対の閉路を2窓同時に直す

改良元: solutions/post-two。

汎用窓の割当探索で、現状では表示できない近い商品対を選び、その対を表示可能にする最小の色反転を求める。6枚の紙の部分集合DPを使い、各順序に逆らう物理窓の数を最小化する。必要な反転がちょうど2窓なら、両方を同時に反転する候補を試す。1窓だけの反転では通れない割当へ移ることを狙う。

通常の提案の1/64をこの候補に使う。対象対は不適合な対8個から、ハンドル差の費用が小さいものを選ぶ。既存の共有を3対以上失う変更は除き、それ以外は従来と同じ全商品対の費用・マッチング・焼きなましで判定する。紙の構造、後続の設計と注文処理、時間配分は改良元と同じ。

MAP_REPAIR_RATEで提案頻度の逆数を変更できる。repair_trialsは対象対を選ぶ試行数、repair_twoは最小反転数が2の試行数、repair_evalsは全商品対の評価へ進んだ回数、repair_acceptedは受理数。全時計はCLOCK_SCALE倍。
