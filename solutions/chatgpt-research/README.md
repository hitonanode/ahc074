# 表現とアクセスの制約を外す検証

改良元: なし（研究報告と容量のプローブ。提出用解法は隣の `chatgpt-structure` と `chatgpt-novel`）。

`REPORT.md` に数理的な仮説、同じ生成ケースでの比較、採否、次の実験をまとめる。
`gate_witness.cpp` は 6 枚の全 720 順列を列挙する独立した容量のプローブである。
実行には `g++ -std=c++23 -O2 gate_witness.cpp -o gate_witness` を用いる。
出力は JSON で、2 紙比較では不可能な相補パターン対が、2 白・2 黒の 4 紙先着ゲートでは可能になる反例を示す。

3 窓を比較 `0<1`, `1<2`, `2<0` にすると `111` と `000` はどちらも有向閉路なので表示できない。
最初の窓を、黒の紙 `{0,3}` と白の紙 `{1,4}` の最上位の色へ変えると、残りの 2 窓を変えずに両方を表示できる。
これは新しい表現が実際に増えることの証明であり、本番 64 窓・256 商品でスコアが改善する証明ではない。
