# 表示検査を短縮し修復成功後だけ磨く

改良元: solutions/eject-lean。表示検査はsolutions/post-filter、追加後処理はsolutions/eject-polish。

最終順序を上から読む際、初めて見える色が誤っていればすぐに候補を捨てる。ここで表示を確認済みの候補は、可視性付き再生後の同じ表示確認を省く。判定と候補集合は変えない。

途中修復が成功した注文だけ、通常の削除・差し込み先変更をもう1回行い、その後に途中修復をもう1回行う。後処理へ残す計画は上位2案。最後の途中修復は選んだ1案だけに行う。

紙の設計と時間配分は改良元と同じ。列探索1.205秒、穴埋め山登り1.26秒、再割当1.345秒、補助穴1.39秒、補助表1.45秒、軽量処理1.80秒。全時計はCLOCK_SCALE倍。eject_accepts等の指標には追加の修復も含む。
