# deval-sharedclimb10

改良元: solutions/deval-best8。

元の4分岐・climb50k・再割当て2回・穴あけ8サンプル・最終再割当てを実行し、4完成候補を残す。完成Vが良い上位3分岐の「climb50kを済ませた時点」を再利用して、固定saltを変えた再割当て1回・穴あけ・最終再割当てを計6回追加する。climbを繰り返さず、独立したmatchingと穴あけの結果を安く比較する。

全部で10完成候補からVで選ぶ。窓割当て・焼きなまし・注文処理の予算は親と同じ。時間不足の切替えはない。DesignStoreは採用設計を保存し、ログ・@paper/@ops・目次・段の目印を維持。
