# legal-tie-short（後処理する計画の選び方にも同点の補正を使う）

改良元: `solutions/legal-tie-fix`。設計は変えない。

## 改良元との差分

- 計画の選択肢のうち、ふつうの後処理（post_optimize）にかける上位 3 個（future_candidates）を、plan_cost ではなく「plan_cost + 同点の補正」（tie_choice と同じ一次式を、その計画の終状態で計算した値）で選ぶ。最良の計画・広げた候補（expanded_candidates）・後処理の中の採否は今までどおり plan_cost のまま。
- なぜ: 最後の選び直しは、記録した仕上がった計画の中からしか選べない。どの計画を仕上げるかの段階で補正を使えば、補正が好む計画が仕上がった候補に入りやすくなる（補正を plan_cost 全体に入れると悪化したので、ここだけに使う）。
- 時間不足の打ち切りなどはない。
