# chatgpt-free-triples

改良元: solutions/imp-combo

紙の設計は改良元と共通。注文処理を、隣接する3列の紙を一つの順序として扱う方策に置き換えた実験版。
3列内では列の境界を保たず、紙の順番を次の注文へ引き継ぐ。同じ紙が複数のハンドルを表示し、1操作で複数の穴を直せることを狙う。

- 前の専用紙は、その3列のブロック内で次回の掘り費用の見積りが最小になる位置へ戻す。
- 注文の紙は、3ハンドルのうち最少枚数の紙を除けば見える窓から掘り出す。掘った紙の移動先も同じ見積りで決める。
- 汎用紙は元の6枚の比較器を使う。
- 専用紙を一番上へ移した後、各ブロックに残る1〜3窓の部分目標を独立に解く。合法な紙の挿入をビーム探索し、ブロック内の最終順序は固定しない。
- 探索の初期上界は「残る窓で全一致する紙を固定し、その前で不一致の見える紙を、その紙より下の将来費用が小さい位置へ送る」という同じ自由順序の修正手順で作る。旧解法の列単位の方策や穴埋め方策は使わない。

主な定数は3列/ブロック、ビーム幅8、深さ4。ビームの到達状態は「手数 + 4 × 将来費用」で選ぶ。将来費用は、各紙の可視化に必要な最少掘り数の注文頻度による重み付き和と、要求される各色が初めて現れるまでの深さから計算する。時計は元と同じ `CLOCK_SCALE` を使う。実行後半にはビームの展開を省き、同じ修正手順で処理する。
stderr の `free_retrieval` は掘り出す操作数、`free_repairs` は穴を直す操作数、`free_beam_saved` は初期上界より減った操作数、`free_max_group` は最大ブロック枚数を表す。

因果比較用にコンパイル定数 `FREE_BLOCK_WIDTH` を1〜3で変更できる（既定3）。1では各列が独立になり、自由順序の効果を消せる。`solutions/chatgpt-fixed-columns` は同一実装の幅1版。

これは構造変更の検証用であり、旧解法の高度な穴埋め・汎用層への補助紙挿入を失う。小模型の改善が本番の長い列でも残るかを検証するため、結果は `trial_log.md` と検証レポートに記録する。
