# astra-sparse12

改良元: solutions/astra-sparsegate

K3,3の9証人に代えて、K6から互いに頂点を共有しない3辺01,23,45を除いた12証人を使う。
それぞれ最初の一窓を固定し、残24窓で優先順位回路を学習する。

従来の全15証人に比べて追加で見えなくなる紙があるのは、最下位2枚が除いた3組のどれかの場合だけである。
一様な720順序の20%に限られ、そのときも追加の不可視紙は1枚だけ。
学習できる窓を3個増やす利益と、合法操作が減る損を、変更後の720状態グラフの厳密距離で比べる。

他の設計・時計・注文処理は改良元と同じ。単一main.cppに全実装を含む。
結果は trial_log.md と astra-frontier/REPORT.md を参照。

## 完成した印刷の可視性を回収

学習中の費用は固定証人だけで保証できる保守的なグラフを使う。
学習終了後は全汎用窓の実際の印刷から720状態の可視紙を列挙して、操作グラフと全点対距離を一度作り直す。
列の設計と注文処理はこの実際のグラフを用いる。追加の比較窓や任意ゲートが与える可視性を捨てない。
`actual_graph_diameter` がこの最終グラフの直径。学習の費用は保守的なので、最終費用そのものを直接最適化しているわけではない。
