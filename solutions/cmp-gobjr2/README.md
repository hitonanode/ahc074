# cmp-gobjr2

改良元: solutions/cmp-gobjr

緊急設計（1 窓に白黒 1 枚ずつ、1 ケース約 32700 点）に落ちる時間の閾値を直し、割り当ての後の山登りを時間制にした。

- cmp-gobjr の 500 件（095454）で 3 件（seed 237, 239, 251）が緊急設計になった。割り当て（0.52 秒まで）+ 回数固定の山登り（3000 回、24 並列では 0.15〜0.2 秒）の後の初期化が、移植元の閾値（倍率込みの壁時計で 0.90 秒を過ぎたら初期化を打ち切り、0.85 秒を過ぎていたら再試行せず緊急設計、焼きなましの前に 1.05 秒を過ぎていたら緊急設計）に負荷の揺れでかかったため。cmp-gobj でも初期化の終わりは最大 0.81 秒で、同じ危険があった。
- 閾値: 初期化の打ち切り 0.90 → 1.20 秒、緊急設計への切り替え 0.85 → 1.15 秒、焼きなましの前の判定は削除（遅れても焼きなましが短くなるだけ）。
- 山登り: 割り当ての焼きなましを 0.45 秒まで、山登りを 0.55 秒まで（時間制。空いた状態で約 2500 回）にして、割り当ての段の終わりをマシンの速さによらず抑えた。
- Comparator::mean_moves を閉包の関係（6 × 6 ビット）ごとにメモ化し、最小の探索を距離 0 で打ち切る（同じ値）。
- 実験用: `GOPT_STEPS`（山登りを回数固定に、−1 でなし）。stderr: `gopt_steps`（山登りの回数）。
