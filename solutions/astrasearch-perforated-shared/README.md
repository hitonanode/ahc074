# astrasearch-perforated-shared

改良元: `solutions/astrasearch-perforated-union`。

補助紙へ穴を開ける費用を、複数の商品対で共有する実験。
最大1交換だった設計を既定4交換まで進め、以前加工した補助紙を新しい対の救済にも使うことを許す。
追加する穴と補助紙自身の汎用処理の費用は、現在の加工済み模様からの増分だけを数える。

## 変更の管理と保証

- 新しい対になった紙、変更した3枚、選んだ補助紙は、その後の商品割り当ての変更から保護する。
- 保護された補助紙を再び補助紙として選ぶことはできる。過去に救済した紙自体は補助紙候補にしない。
- G穴を追加する候補について、その補助紙を使う過去の全救済商品が引き続き表示可能か検査する。
- 1交換を設計のコピーへ適用し、実際の192枚を再生成する。すべての元の商品のG穴の半順序、すべての過去・新規救済商品の指定補助紙による終状態、H誤色の不存在、各紙自身のハンドルを検査する。
- 検査が失敗した変更は全体を戻す。途中の不正な設計は出力しない。

採用後には、過去を含む全救済商品の汎用紙の平均距離を全終状態の和集合から再計算し、補助紙を掘る深さのモデルと覆うH穴数も更新する。
穴の加工費だけを小さく数えて、過去の利用者へ増えた費用を無視することを避ける。
半順序とgoalの存在は厳密な検査。掘る深さ・回収費用・H穴の価値は引き続き近似モデル。
また、各roundの候補を順位付けする `best.delta` には、過去の救済商品へ増えるG距離・H被覆の減少・列内深さの変更を含めていない。
これらを反映するのは変更後の全サービス再計算であり、最良prefixの比較は更新後の費用を使うが、各roundで選ぶ候補自体は近似評価である。

## 探索とモード

最初の加工費が単独では損でも、後続の再利用で取り返せる可能性を調べるため、内部では有効な交換を最大4回まで続ける。
通常モードでは、その途中までの設計のうち累積モデル費用が最小のものを出す。1.35秒はround間・候補間で確認する目安であり、厳密な打ち切りではない。
進行中の候補・roundの処理や、必須補助紙の終状態の初期化・注文処理はそれを超えて続く場合がある。
2秒制限を満たす保証はなく、通常モードの実行時間も実測で確認する必要がある。
初期設計のFNVハッシュと最終設計のハッシュは改良元のまま残す。

- `RELAX_ROUNDS=n`: 交換回数の上限。1〜8、既定4。
- `RELAX_FORCE=1`: 時間の打ち切りを外し、最良prefixではなく、成立した全交換を出す研究用モード。2秒制限を超え得る。
- `RELAX_PAIRS/RELAX_UNION/RELAX_MIN_DEPTH` と設計の反復回数固定の環境変数は改良元と同じ。

`shared_attempted/explored/selected` は試行round数・内部で成立した交換数・出力した交換数。
`shared_helpers` は使用した補助紙の種類数、`shared_reuse_events` は以前のroundで使用済みの補助紙を再利用した回数。
`shared_rollbacks` は最終実紙検査で戻した変更数。
`shared_punched_handles/generic` は出力設計に追加した穴の総数。
`shared_explored/best/selected_model_delta` は最終探索点・最良prefix・出力設計の初期設計に対するモデル差。
`mandatory_targets` は出力した新対の数の2倍になる。

これは加工費の共有が得点へつながるかを測る版であり、手数や時間の改善は実測比較で判断する。
