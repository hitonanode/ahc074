# cmp-probe2（計測用）

改良元: solutions/cmp-ret

解法としては cmp-ret と同じで、設計の係数を環境変数で変えられるようにしただけ。指定がなければ cmp-ret と同じ値。

- `D_HSHAL` / `D_HDEEP`（×100）: 焼きなましのハンドルの穴の重み kHoleWeight に掛ける倍率を、最も浅いハンドルから最も深いハンドルまで直線で変える（深さで穴の値段が違うかの確認）。
- `M_GW`（×100）: 窓の割り当ての焼きなましで、対の違いが汎用窓にある方を好む度合い kGenericWeight（既定 0.70）。
- `M_HDQ` / `M_RELQ`: 割り当て後の山登り（gobj）で対を並べる鍵の、ハンドル窓の違い 1 個と閉包の関係 1 個の重み（4 分の 1 単位、既定 4 と 2）。
