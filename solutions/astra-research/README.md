# 七枚比較器の厳密費用による再設計

改良元: `solutions/astra-search4`。

汎用紙を六枚から七枚へ増やし、汎用窓も既定で38個に増やす。専用紙は185枚、共有する商品対は71対となる。七枚化は以前の近似目的関数では不利だったが、今回は七要素の全2045非同型半順序について、5040順序からの**合法な最短操作距離**を厳密に前計算する。その表を提出用の単一C++へ埋め込み、窓割り当てと商品対の評価の両方に用いる。

- `generate_posets.cpp` は六要素の既存表から最大元を追加して七要素の半順序を列挙し、合法操作グラフの逆BFSで距離和を求める。提出時には実行しない。
- 窓の割り当ては、近い商品対（ハミング距離26以下）から71対を貪欲マッチングした厳密費用を焼きなます。現在選ばれた対のうち三対以上を不適合にする近傍は除く。
- 最上の専用紙、ハンドル列、列内の適応挿入、穴埋めと後処理は改良元を引き継ぐ。七枚の操作は合法な最大保持部分列を用いて求める。
- 六枚専用の補助紙テーブルと汎用層の先読みは使わない。七枚の全点対最短路を提出時に作る負担を避けるためであり、この差は評価で明記する。

時計は `CLOCK_SCALE` 倍。乱数は固定。`RESEARCH_G` をコンパイル時に指定すると汎用窓数を変更できる。既定は38。通常のstderr指標に加え、`map_full_evaluations` は事前判定を通った割当近傍数、`poset7_cache_misses` は半順序の同型正規化を行った回数を表す。

比較結果と採否はルートの `trial_log.md`、詳細な検証は本PRの報告へ記載する。
