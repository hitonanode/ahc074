# 比較器の全点対距離を一回のBFSから作る

改良元: `solutions/astra-search4`。

六枚の比較器の距離表を、720始点でBFSする方法から、恒等順序を始点にする一回のBFSと紙番号の付け替えへ変更する。

全紙対に証人窓があるので、常に最下以外の紙が可視。この合法移動グラフは紙の名前を任意に置き換えても同じである。開始順序 `s` の各紙をその位置番号へ置き換える写像を `rho_s` とすると、`d(s,t) = d(identity,rho_s(t))`。向き付きの距離をそのまま保ち、最下の紙の直接移動を許さない。

他の処理を変えないため、求めた値は元と同じ720²要素の `dist` へ展開する。窓割り当て、専用紙の設計、各計画の探索順、距離参照、先読み、タイブレーク、時計区切り、`CLOCK_SCALE` は改良元と同じ。固定した探索回数・軽量モード条件での操作列は同一になるはずであり、その一致を別に検査する。

`verify_distance.cpp` は全720始点から独立にBFSし、全518400有向距離を表と照合する。実行時間の短縮は、通常の同時比較でスコアへの影響も測る。

`verify_fixed.py` は探索回数を固定し、診断用に全時計を停止して、初期紙と1024注文の操作列を含むstdout全体を改良元と比較する。これはアルゴリズムの同一性の検査であり、時間制約下のスコア評価ではない。
