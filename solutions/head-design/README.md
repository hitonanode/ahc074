# 先頭に残る紙の穴埋め利益で配置する

改良元: solutions/head-excess。研究版 solutions/design-head の配置最適化を提出用へまとめた。

設計の最後に、列内の紙の平均的な穴埋め性能ではなく、先頭に残りやすい紙の性能で紙2枚の所属列を交換する。白黒それぞれについて、直接使われる頻度が最大の種類（共有紙があれば共有紙）のうち、全商品の穴埋め利益が最大の紙を先頭候補とする。列の色は、その窓の穴の要求色の割合で重み付けする。

穴埋め利益は、直せる窓数から配置・返却の1.6手を引いた正の部分の期待値。誤色は窓間で独立と近似し、三角形の深い穴と共有紙の浅い穴を含める。模型費用−係数1.0×先頭候補の期待利益が下がる交換を受理する。共有・単独の種類と各列の白黒枚数を保つ。

時間配分、汎用窓と商品対の探索、操作計画は改良元と同じ。山登りは時計倍率込み1.36秒までで打ち切る。`climb_iters` は交換候補数、`climb_accepted` は採用交換数、`proxy_before` と `proxy_after` は新しい穴埋め利益の合計。時間の指標は `CLOCK_SCALE` 倍。
