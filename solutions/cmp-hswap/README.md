# cmp-hswap

改良元: solutions/cmp-fast2

焼きなましのハンドルの順の交換を差分で評価できるようにし、その率を 0.5% から 8% に上げた。あわせて列の費用 colcost の値をキャッシュした（cmp-fast3 の変更。同じ回数なら出力は cmp-fast2 と同じで、焼きなましが約 10% 速い）。

- 交換 a ↔ b で変わるのは、h_a と h_b の穴の数（色ごと）と、列 a, b のハンドルの色の数だけなので、それらを全単位について数え直して cur を差し引きする（元は全体の数え直し rebuild を 2 回）。焼きなましの後の cur と数は全体の数え直しと一致する（確認用の版、seed 1〜3）。
- 模擬（回数固定、seed 24〜87、率 0.5% 比）: 率 0.1% / 2% / 5% / 10% / 20% / 30% で +0.18 / −0.26 / −0.36 / −0.44 / −0.49 / −0.48%。交換は 1 回が普通の手より重い（600 万回で率 0.5% 0.33 秒、10% 0.45 秒、20% 0.56 秒）ので、同じ時間なら 5〜10% が最良（約 −0.35%）と見て 8% にした。
- 実験用: 環境変数 `HS_RATE`（交換の率、千分率）。
