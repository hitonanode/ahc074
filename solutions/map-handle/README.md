# 列設計後に汎用窓と取り出し窓を交換する

改良元: solutions/eject-one。共有再割当の研究部品は solutions/reset-exact。

最初の窓割当では、後でどの商品をどの列に置くかがまだ決まっていない。そのため、列の設計後に汎用窓1個と取り出し窓1個を交換し、既存の全共有対を表示可能なまま保つ候補を全列挙する。交換した列の両色も保つ。比較の白黒方向は両方を試す。

実際の列枚数・穴の色分布・合法な汎用平均距離で費用を計算する。候補はこの模型で選ぶ条件と、上位8個を先頭紙の穴埋め利益まで数えて選ぶ条件を比べる。交換後は全共有候補を再価格付けし、基準と同じ短い列探索・穴埋め山登り・再割当・補助穴追加を行う。

研究用。main.cppは改良元のコピー。実際の注文列は読まず、独立模擬注文で比較する。全表示・可視性・共有の成立・模型の差分を検査する。時計はCLOCK_SCALE倍。
