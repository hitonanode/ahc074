# 実積層状態を用いるペア割当の再生模型

基準は `20261106-113548_nogen-perf-reuse` の保存設計。列、列のアクセス色、既存の追加穴を固定し、各ペアの片方を固定して、残り185商品をHungarian割当で移す。候補の費用は、固定乱数の軽量注文処理から採った積層状態上で、候補紙に所有者を要求したときの実操作と終了状態価値を計算した。商品紙の色は各所有者の共通色だけとし、窓63の例外以外の色違反を許さない。

模型の候補設計を実際の出力へは使わない。独立した固定乱数の注文列で、軽量2048注文・通常処理512注文を再生して、実手数へ移るか確認した。実注文の未来は読んでいない。

8標本×8設計の初期版 `20261106-121044_nogen-pair-rollout-model` は、無罰則で予測0.0972手/注文の改善に対し、独立軽量列では0.0649手悪化した。標本不足を疑い、64標本×32設計へ増やしたのが `20261106-121222_nogen-pair-rollout64-model`。

この割当は不採用。標本を増やしても予測と実再生の符号が逆になるため、8標本の雑音だけでは説明できない。変更後の紙が他商品へフィラーとして与える価値、変更後の定常的な列・色分布を局所要求費用だけでは捉えていない可能性がある。原因は未確定であり、これを実列費用一般の否定や改善余地の上限とはしない。実装へ進める前の独立再生が、G34と同じ誤採用を防いだ。
