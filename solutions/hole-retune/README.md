# 新しい設計式と制御で穴の重みを再確認

改良元: solutions/eject-lean。

列先頭の返却による偏りと先頭候補の一括再割当を入れた現在の模型で、ハンドルの穴費用の重みを0.40から0.36/0.38/0.42/0.44へ変える。保存設計の同じ窓割当から、列・共有の焼きなまし2000万候補、山登り65000候補、再割当4回、補助穴設計を各条件で行う。

別乱数の模擬16本で全表示を検査し、各条件1本は全操作の可視性と最終順序も照合する。入力末尾の注文は使わず、CLOCK_SCALEを全時計へ適用する。main.cppの既定値は比較元と同じ0.40。研究用の可変値で、提出用への変更は結果を見て決める。
