# 商品用の紙を、穴を追加して補修紙にもする

改良元: solutions/as6-canon。`main.cpp` は比較元のコピー。

浅い列に置かれた単独商品用の紙に、汎用窓の穴を追加する。自身の表示には比較器を使う代わりに、他の共有紙の穴で間違った色を出さないようにする。比較器だけで表示できない対にも、商品紙1枚を途中に挟めば表示できる組が増えるかを調べる。

`probe.cpp` は保存済み設計を使う研究模型。補助に使う紙自身の商品は共有から除外し、追加の穴による汎用操作の増加を費用に加える。比較器の閉路を残す窓に対して、補助紙が正しい色だけを覆い、その下の比較制約が非巡回なら使用できる。最初の選別では補助紙の取り出し・配置・返却の費用を仮定し、公式スコアとは分ける。乱数は固定し、時計には `CLOCK_SCALE` を掛ける。
