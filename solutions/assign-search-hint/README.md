直前の採用状態で厳密評価した窓交換の増分費用を、次の状態の候補順位に再利用する。交換元の辺に属する窓集合と極性が同一である場合だけ使う。未評価・不一致の候補の見積りは0とし、見積りの小さい候補から試す。推定値では受理せず、従来の全商品対の評価とmatching_costで費用を計算し直す。全状態の一致を必要とする目的値キャッシュではなく、1回の受理を挟んだ近隣状態間の提案順位である。

AS_HINT=1（既定）は有効、0は元の候補選択。AS_WORK=1（既定）は窓割り当ての反復倍率。AS_PROFILE（コンパイル時、既定0）は1で演算子別の時間・改善量を計測する。
hint_options / hint_knownは順位検討した候補数・条件が一致して増分費用を再利用した数。hint_shortlists / hint_removedは順位を付けた回数・初回の候補集合から順位で一時的に外した候補数。既存の全ログ・設定・プロファイラ・CLOCK_SCALE・LOCAL_BENCH・DesignStore・@paper/@opsを保持する。
