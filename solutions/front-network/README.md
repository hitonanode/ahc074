# 先頭3窓の印刷を全体で組み替える

改良元: solutions/post-two。部品の操作模型は solutions/front-star/approx.hpp を複製する。

先頭3窓に属する9〜10枚について、担当商品と共有相手の両方で色が一致する窓の、空でない任意の部分集合へ印刷する。1枚ずつの局所変更に限らず、許される印刷の組合せを列挙する。同じ担当要求を持つ紙の入れ替えは除く。外部商品の部分表示と、部品内の指定紙の取り出しが全て可能な候補だけを調べる。

短い固定乱数列と幅8のビームで選別し、窓順を変えた従来の階段状構造で説明できる候補と、説明できない候補を別々に保存する。それぞれ上位64案を独立16384注文・幅32で検査し、上位8案を別の262144注文・幅64で再検査する。許される組合せが多い場合は固定乱数で一様に抽出する。最終的に有望な候補だけ、全順列による平均費用MDPで確認する。

これは構造の研究用模型で、指定紙自身の持ち上げ・即時返却は無料、外部の穴埋め紙は省略する。公式スコアとは区別する。main.cpp は基準のコピーで、新構造は未統合。入力は公開されたバーコードから作った部品だけを使い、隠された注文列は読まない。乱数を固定し、時計へ CLOCK_SCALE を掛ける。
