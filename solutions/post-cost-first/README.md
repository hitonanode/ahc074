# 最終状態の費用を可視性の再生より先に計算する

改良元: solutions/eject-single-window。

後処理の最終表示が一致した候補について、最終の紙順から記録と将来費用を先に再構築する。費用が最良以上なら途中の操作を再生する前に捨てる。改善候補だけ全操作の可視性を検査し、検査を通った場合に保存済みの最終状態を採用する。無操作を除いた操作数もリンク操作で先に数える。

研究用early_state_costで順序だけを切り替え、同じ紙・注文の全操作列・最終順序のハッシュを照合する。可視性・表示・計画失敗も検査する。全時計はCLOCK_SCALE倍。速度とスコアを確認するまで提出候補として採用しない。
