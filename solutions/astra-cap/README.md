# astra-cap

改良元: `solutions/astra-search4`。

物理窓63をハンドルから外し、その窓だけ黒いキャップ紙を1枚使う。
比較器6枚・汎用窓36は保ち、残りはハンドル27窓・専用紙185枚（共有71対と単独114目標）とする。
窓63は比較器の割り当て・共有対の距離・ハンドルの目的関数に含めない。既存のCAPWINの「汎用窓の整合条件を1つ除く」実験とは、減らす窓の役割が異なる。

専用紙はキャップ窓でも不透明とする。単独または共有2目標が同じ色なら、その色を印刷する。共有目標の色が違う場合は白を印刷する。
現在の目標色と専用紙の印刷色が合うときは、従来どおり一番上へ持ち上げる。印刷色が白で目標が黒のときは、キャップの直下へ持ち上げる。いずれも通常の持ち上げ1手で済む。

キャップはID6、比較器はID0..5とし、最初の注文でだけキャップを最上部へ移す1手を追加する。この時点では比較器が窓63で全て穴なのでキャップは可視である。以後キャップを動かさない。
補助紙の配置と汎用層の操作はキャップの下で行う。後処理では汎用紙がキャップの上へ移る候補を禁止し、最終表示・各操作の可視性を従来どおり検査する。

設計の時間配分とその他の方策は改良元と同じ。`cap_window=63`、`model_cost`、`model_col`、`model_hole`、`model_gc` を診断用に出す。モデル費用には最初のキャップ移動1手や専用紙の通常の持ち上げ/返却の定数分を含めない。
