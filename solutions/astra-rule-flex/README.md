# 可視性を保ちながら比較窓も選び直す一般ルール探索

改良元: `solutions/astra-nonlinear`

元の一般ルール版では、各比較組の最初の窓を固定し、残り 21 窓だけを変更した。
本版は全 36 窓を探索対象にする。
ただし、15 組それぞれに少なくとも 1 つの「2 枚だけが不透明な比較窓」が残ることを要求する。
ある比較組の最後の窓を変更するときは、その比較組のまま色を反転する変更だけを許す。
別の窓に同じ比較組を作ってからなら、元の保証用窓を一般ルールへ変更できる。

これにより保証用の 15 窓自体を選び直せる一方、どの状態でも底以外の 5 枚が見えるため、
720 状態の合法遷移・正確な距離の前提は保たれる。
候補ルール、目的関数、`RULE_SWEEPS` / `RULE_MAX_OPAQUE`、時間配分、診断指標は改良元と同じ。
同じ 1 巡回でも対象窓が多く、評価候補数と計算量は増える。
