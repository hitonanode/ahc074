# 残した穴埋め紙の継続利用を評価

改良元: solutions/stay-value（制御の基準は solutions/post-repair）。

終了時に残す穴埋め紙について、次の256商品でその位置に残せる割合と、無料で覆える穴の期待深さを前計算する。次の商品紙の取り出し窓を隠す場合や、穴に誤色を見せる場合は利用不可とする。

残存確率による紙1枚0.6手の補正と、無料の被覆による次注文費用の補正を両方係数0.25で有効にする。複数の紙が同じ窓を覆う効果は最大値だけを数える。汎用層より上や間の紙は対象外。

元の研究版にあった25窓固定の表を、設計のハンドル数に応じて確保し、少ない汎用窓での初期化にも対応する。紙の設計、探索時間、注文計画の候補は同じ。全時計にCLOCK_SCALEを適用する。提出用はmain.cpp単独で完結する。
