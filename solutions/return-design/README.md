# 前の商品の紙を穴埋めへ回す利益を設計する

改良元: solutions/reset-majority。

最後の列交換で、列の先頭から新しく取り出す穴埋め紙の利益に加え、前の注文の商品紙をそのまま穴埋めへ移す利益も数える。前の紙は既に列の外へ出ているので、取り出し費用は不要。元の列へ返す代わりに穴埋めへ置き、後で返す費用を0.6手と近似する。

前の紙が次の商品紙の取り出し窓を覆う場合は、その列より下へ置く。覆う窓の不一致数を独立な誤色確率で数え、「修正数−0.6」の正の部分の期待値を使う。前の紙に選ばれる頻度は、単独なら1/256、共有なら2/256。係数0・0.5・1・2を研究模型で比較する。

共有関係・列の枚数・列内の白黒枚数は変えない。紙の印刷・注文時の制御も改良元と同じ。研究用の `probe.cpp` は保存設計と独立した模擬注文を使い、実際の注文列は読まない。全時計はCLOCK_SCALE倍。
