# astra-02-03-freeorder

改良元: solutions/astra-02-02-layered

## 改良元との差分

- 取り出す順と重ねる順を分けた。上層に出す紙は持ち手の窓の小さい順に取り出せば互いの持ち手を隠さないが、差し込む位置は自由なので、出した紙どうしの上下は別に決められる。02 では持ち手の大小で上下も決めていた。
- ビームサーチを「グループを g の順に走査」から「上から置く紙を 1 枚ずつ選ぶ」形（最大 6 層、各層で未使用の任意のグループから選ぶ）に変えた。選んだ順（sequence）が表示の優先順になり、注文の実行では、優先順が後の紙は先の紙より下に差し込む。上の紙が隠す窓では、下の紙の色が目標と違ってもよい。
- 前の注文の紙を残す選択肢は 1 枚まで、残す紙の覆う窓が今回選んだグループの持ち手に重なるものは除く。
- 構成の候補を 3 つ（(LB, top) = (14, 20), (21, 16), (21, 20)、fee = 4）に変更（下地の部品を 2〜3 個に減らし、グループを増やした）。学習時のビーム幅 12、注文時のビーム幅 32（1.55 / 1.70 秒で 32 / 8 に下げるのは同じ）。
- 模様を作り直す関数 refine_dictionary を追加したが、呼ぶ条件（phase ≥ 1）が満たされないので使われない（元のまま）。

## 移植について

外部の agent（astra-02）の解法。元のソースと報告は main checkout の other_agents/astra-02-03.md, astra-02-03-freeorder.cpp。変更は、`#include <bits/stdc++.h>` の個別 include への置き換えと、Clang でビルドするための 1 か所の書き換え（ビームの比較関数の `a.rank<b.rank` を同値の `b.rank>a.rank` に。`using namespace std` の下で Clang が `rank<` を `std::rank<...>` と解釈するため）。アルゴリズム・出力は不変。実行引数と stderr の統計は `-DLOCAL_VERIFY` のときだけ。

- 報告された成績（02 と同じ独自生成 20 ケース）: 1 注文 13.843 手（ケースごとに 13.49〜13.995、20 ケースすべてで 02 より改善）、誤り 0、手元での最大 1.67 秒。
