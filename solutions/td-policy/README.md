# 実際の遷移から推定した終了費用

改良元: solutions/tight-thirty-eight。係数の収集はsolutions/state-learning。

独立な学習入力32件で得た16注文先のTD方程式を、標準化した係数への正則化0.01で解く。自然に訪れる状態だけでは深さの2係数が不安定だったため、この2係数は基準の1に固定し、残る6係数を推定する。直接注文の深さ、穴埋め需要の深さ、穴の色合わせ、汎用層の下/上の穴埋め紙数、据え置き確率、無料被覆、紙の組数の8項を使う。選ぶ計画の終了費用と列への返却位置に同じ係数を用いる。現在の係数と推定係数の混合率0/0.25/0.5/1を、学習に使っていない入力で比較する。

研究用。紙の設計は全条件で同じ。実際の隠された注文は読まず、独立な一様模擬16本で検査する。全時計はCLOCK_SCALE倍。main.cpp単独は基準の係数で動作し、probe.cppだけが推定値を使用する。
