`main.cpp` は、同じ設計状態で棄却済みの交換を再計算しない仕組みによって、既存の restricted filler climb を４倍長く回す版。`CLIMB_LAMBDA` の既定値は比較基準と同じ 0.5。

- 棄却された２単位の組を、最後に受理した交換の回数（世代番号）と一緒に保存する。同じ世代で同じ組を引いたら、穴埋め効用と模型費用の再計算を省く。
- 交換を受理すると世代番号を進め、全記録を無効にする。移動したターゲットは他の列の紙の効用も変えるため、離れた交換の記録も再利用しない。
- 候補を引く乱数は従来どおり消費する。従来と同じ反復数なら、同じ探索経路と設計を得ることを狙った厳密な重複除去であり、近似による枝刈りはしない。
- 各色の先頭資格を持たない紙の効用は、先頭の最大値に寄与しないので計算しない。交換で紙を移したときは、新しい列での資格を調べて効用を全ターゲットから計算し直す。各列の資格条件自体は交換で変わらない。
- 反復数は 38,500 → 154,000。受理基準、交換可能な組、焼きなまし、再割り当て、穴あけ、注文処理は変えない。

`CLIMB_CACHE=0` で重複除去、`CLIMB_HEADS_ONLY=0` で資格による計算の省略を無効化できる。`CLIMB_ITERS` と `CLIMB_LAMBDA` は改良元と同じ環境変数で上書きできる。追加指標 `climb_evaluated` は効用差を計算した交換数、`climb_cached` は計算を省いた重複数。CLOCK_SCALE、DesignStore、LOCAL_BENCH、紙の属性と操作ラベルは継承する。

比較用の `anneal.cpp` は焼きなましへ先頭の価値を加える実験。４区間の後ろ３区間の末尾各 1/16 を、同種・色保持の交換に置き換え、総反復数を保つ。その区間ではペアとハンドル順を固定し、列・単位ごとの穴埋め効用と、固定した先頭候補がターゲットを覆う効用を表にする。各列・各色の資格のある最大効用を先頭の価値とし、受理と最良状態の保存に `model_cost − 0.5 × 近似価値` を使う。先頭の資格を得ない行は計算しない。

実験版の設定は `HEAD_STEER`（既定 1）、`HEAD_WEIGHT`（0.5）、`HEAD_TAIL_DIV`（16）、`HEAD_RECIPIENT`（1、0 はターゲット側の項を省く比較）。`head_table_sec` は表作成時間、`head_trials` / `head_accepts` は交換の評価数 / 受理数、`head_model_change` は限定した探索の前後の模型費用差（全ターゲットの和）。実験版の climb は既定 38,500 回、キャッシュは既定無効。
