# 浅い列の商品紙を選択可能な補助紙の集合にする

改良元: solutions/post-repair。必須補助紙の制御は solutions/head-weave から。

最初の3列を各色1枚ずつの商品紙6枚に割り当てる。この6枚は汎用窓と自分の取り出し窓だけを印刷し、他のハンドル窓は穴にする。他の商品は残りの列に置く。これによって、汎用紙だけでは表せない商品対にも、6枚のうち使いやすい補助紙を挟んで対応する。

共有の費用は汎用紙の全720順序と補助紙3列の全8先頭色について、通常の表示または補助紙1枚を使う最小費用を平均する。補助紙は配置・返却1.6手と、取り出し0/1手を数える。補助紙の担当商品を固定し、残りの共有・列・ハンドル順を通常の焼きなましで最適化する。新しい対は商品間のハミング距離26以下を調べる。

研究用。main.cppは操作制御と制約を備え、probe.cppが保存設計から新しい構造を組み立てる。紙を選ぶ情報はバーコードのみ。隠された実注文は読まず、定数seedの一様模擬注文で調べる。CLOCK_SCALEを適用し、模擬の最初の1本は可視性を独立再生して検査する。

補助紙集合の別案では、汎用紙だけを正しい色の上から取り除いた残りの窓を各補助紙が覆えるかを前計算する。新しく表示可能になる商品対の数を距離に応じて重み付けし、6枚の選択を3万回焼きなます。その後に全720順序の価格と列設計を計算する。
