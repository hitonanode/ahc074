穿孔後、追加穴を物理紙に固定し、商品の再割当をHungarian法で1回行う。列・自身のハンドル色・背景6枚は固定し、背景比較で両商品を表示できる組だけを使う。追加穴を含むハンドル費用と列先頭のフィラー価値（係数1.05）を使い、実際の模型費用が減る循環だけを受理する。割当後に全印刷色・ペア穴・所有者を再構成し、背景補完証明を検査する。

d2_rematch_*は反復・循環・変更単位数・模型改善・時間、d2_model/filler_*は再割当前後の費用、d2_extra_remainingは残る追加穴、d2_certificate_failsは背景補完証明失敗数。1.28秒以後は追加再割当を始めない。他の予算・軽量注文・監査・DesignStore v2は維持する。

採用経路には、nogen-v6-balancedから次を積み上げている。

- 後処理の区間判定をSOTAのfilterblocksへ更新する。
- 通常の区間DPに加えて、正の利得を持つフィラーの状態価値を使う候補と、局所ハンドル修正後の価値を使う候補を比較する。
- 背景所有者との最小不一致数を厳密にキャッシュする。
- 商品紙の通常ハンドルだけに条件付き穿孔を行い、その追加穴を考慮して再割当する。

標準予算は背景窓36、窓探索300k+60k、列探索11M、フィラー探索100k、穿孔前再割当4回、穿孔後1回。後処理は通常候補2・拡張候補3・追加計画1、neutral 1巡。PC_REMATCH等の既存の実験用設定を残すが、比較は環境変数を使わず標準設定で行う。
