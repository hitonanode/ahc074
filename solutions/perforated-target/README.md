# 覆いたい商品を選んで複数の穴をまとめて作る

改良元: solutions/perforated-fixed。注文制御は solutions/stay-cover。

先頭候補の紙と、その紙で覆いたい商品を選び、ある深さより下で色が違う印刷を2〜3個まとめて穴にする。無作為に穴を選ぶ方法と違い、1個ずつでは利益が出ない被覆を直接作る。重複する穴集合は除き、自分の取り出し窓は残す。穴の増加費用と8標本の区間DPで採否を決める。最後に通常の1穴変更も行う。

2穴・3穴、利益係数0.5・0.35、1穴変更の前後を比較する。模型用の乱数は固定。検査は独立した模擬注文16本と、過去の選別とは異なるseed88〜119を使う。全表示一致を検査し、各模擬1本は可視性も再生する。

研究用のprobe.cppで動作する。main.cpp単独は制御の比較元。隠された実注文は使わず、全時計はCLOCK_SCALE倍。
