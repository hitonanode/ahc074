# 8枚の比較符号

改良元: solutions/as6-canon。7枚の比較器の研究コード（solutions/astra-decoder/seven.cpp）の写像探索と、半順序の同型判定も参照する。

比較器を6枚から8枚に増やし、比較できる紙の組を15通りから28通りに増やす。商品用の紙は183枚となり、73組を共有する。比較の重複を減らして良い商品対を選べる利点と、汎用紙の並べ替えが増える費用を比較する。

`generate.cpp` は研究用。8要素の半順序を7要素の全同型類から列挙し、8枚の全40320順序と合法移動を使った多始点BFSで、部分表示にする最短手数の平均を求める。この汎用の表は入力ケースや将来の注文に依存しない。
既存の6枚・7枚の費用表との照合も行う。

提出用実装は `main.cpp` にまとめる。表は同型類16999個を可変長整数で圧縮してソースに埋め込む。注文時には8枚の部分集合256通りを調べ、現在の順序を最大限残す最短の合法な並べ替えを行う。6枚版に固有の補助紙と先読み表は使用しない。
汎用窓は既定40個、ハンドル23個。`EIGHT_G` は研究用の窓数指定。設計の時間配分は0.50秒まで写像の焼きなまし、0.61秒まで写像の山登り、1.305秒まで商品の割り当て、1.36秒まで穴埋めの改善。1.80秒から同じ紙構造の軽い注文処理にする。旧構造への切り替えは行わない。
`MODEL_ONLY=1` は設計の指標を出して終了する研究用の指定。固定反復数の指定は改良元と同じ。
`verify.cpp` は独立な移動グラフのBFSと費用表、ラベル入れ替え、注文時の並べ替えの可視性を照合する。
時計には `CLOCK_SCALE` を掛ける。評価結果と採否は trial_log.md に記す。
