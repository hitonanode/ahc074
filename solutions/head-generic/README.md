# 汎用層の補助紙としての需要も返却順序へ加える

改良元: solutions/head-excess。

汎用紙の間へ挟む補助紙として役立つ紙にも、追加の取り出し需要を与える。商品ごとの汎用の穴を補助紙なしで直す費用と、各補助紙を使う場合の費用を、汎用紙の開始順24通りで比較する。さらに、補助紙が正しく覆うハンドルの修正費用を加え、配置と返却に相当する1.8手を引いた正の利益を平均する。

追加需要は列内で規格化して平均を引き、`HELPER_DEMAND_WEIGHT`（既定0.1）を掛ける。`helper_demand_spread` は追加重みの標準偏差。既存の穴埋め需要はそのまま使う。初期化の後に一度だけ計算し、実際の注文列は読まない。時計は比較元と同じ。
