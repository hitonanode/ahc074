# 将来費用のどの項が効くか分けて比べる

改良元: solutions/td-policy、紙の設計はsolutions/tight-thirty-eight。

学習した係数の効果を、穴の色合わせ、汎用層の下/上の穴埋め紙数、据え置き確率と無料被覆、穴埋め紙の組数へ分けて比較する。汎用層の間にある紙は次に返す場合が多いため、その料金だけ1にする条件と、層の下の料金だけ0.9にする条件も加える。基準と全係数半分混合を含む8条件。

研究用。全条件の設計は同じで、未使用の32入力・独立模擬8本で比較する。具体的な係数はweights.jsonとprobe.cppに保存。main.cpp単独は基準の係数。実際の隠された注文は読まず、全時計はCLOCK_SCALE倍。
