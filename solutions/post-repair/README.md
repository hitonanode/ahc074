# 前注文の紙で列の色合わせを肩代わりする

改良元: solutions/post-rewrite。

1操作の削除と差し込み先変更の同時探索を、前注文の商品紙・穴埋め紙が、削除する操作の列の窓を正しい色で覆える場合に絞る。今回の商品紙を取り出す列は除く。さらに、その列より深い紙の下への差し込みを省く条件、同じ列の操作だけは除外しない条件を比較する。

狙いは、前の紙を穴埋めに回すことで個別の色合わせを省く組合せの多くを、少ない候補で残すこと。全候補の最終表示を双方向リストで先に確認し、合う候補だけ完全再生で可視性・終了費用を検査する。main.cppの既定は両方の除外あり。既存設計と固定乱数の模擬注文で比較し、隠された注文は使わない。CLOCK_SCALEを適用する。
