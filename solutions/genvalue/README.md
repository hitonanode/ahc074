# 計画の費用に汎用層の終わりの並びの価値を入れる（genvalue）

改良元: solutions/esw-climb4

## 改良元からの差分

- 計画の費用 `plan_cost`（手数 + 列の外の紙の費用 + 列の状態の価値）に、**汎用層（比較器 6 枚）の終わりの並びから、次の注文で汎用層を動かす期待手数**を足した（`Solver::generic_next_cost`）。値は `generic_share × future[並び]`。future は imp-gla（PR 49）以来の look-ahead の表（汎用の穴を持つ目標について、その並びから満たす並びまでの最少手数の平均）、generic_share はその目標の割合。手数と同じ単位なので重みは 1。
- 理由: future は汎用層を並べ替えるとき（set_generic）の同点の決め方にしか使われておらず、計画どうし・中立探索の候補どうしの比較（plan_cost）では、汎用層の終わりの並びの違いが見えていなかった。中立探索は多くの候補を plan_cost で比べるので、状態の価値の抜けが選択の誤りになる（trial_log 2026-11-05、列 MDP と中立探索の相乗効果）。
- `GENVALUE=0` で改良元と同じ。
