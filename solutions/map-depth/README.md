# map-depth

改良元: solutions/map-curve（solutions/imp-combo の計測用コピー。提出用ではない）

窓の割り当ての目的関数で、対のハンドル窓での違いの重み（一律 1800）を、ハンドルの深さで変える試み。

- 対の違いは、その対の列より深いハンドルなら穴として無料になる。そこで、深いハンドルでの違いほど安くする。
- ハンドル窓を `order` の中の位置（設計の初期のハンドルの順）で 4 段に分ける。
- 段 k の違いの重みは SW × 0.945 / 0.760 / 0.511 / 0.204（その深さの穴を払う対の割合）。
- 2 つのハンドルの段を入れ替える手を、焼きなましと山登りの 10%（RANKRATE）に足す。
- `RANKW=1` で有効になる。`RANKW=0` では map-curve と出力が同じ。
