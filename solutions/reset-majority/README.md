# 取り出しで更新される列の色を設計に使う

改良元: solutions/head-design。研究版 solutions/reset-cost の係数を固定した提出用。

従来の穴の色合わせ費用2xy/(x+y)を、商品の取り出しと返却によって先頭色が更新される効果を入れた (2xy+t min(x,y))/(x+y+t) に変える。x,yは白黒の穴要求数、tはその列の担当商品数の2倍。取り出し後の返却で、要求の多い色へ先頭を戻せることを近似する。穴費用の係数0.8はそのまま。

tは焼きなましの4区間それぞれの開始時、および最後の列交換の開始時に計算して、その区間では固定する。直接取り出し費用は、列の両色の先頭を固定したときの最小費用を使い、従来のランダム順との混合15%を外す。

印刷・枚数・注文時の操作制御は改良元と同じ。時間配分は写像0.50秒・写像山登り0.61秒・配置1.305秒・穴埋め山登り1.36秒。全時計はCLOCK_SCALE倍、乱数seedも改良元と同じ。

評価結果はtrial_log.mdへ記録する。
