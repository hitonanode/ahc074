D2の測定・実験用。まず保存済みの設計と出力から、非head紙のフィラー利用と列頭への露出を調べる。
`exposure.py` は穿孔前の紙を復元し、現行Perforationと同じ頻度・フィラー効用でheadを選ぶ。
保存出力の操作ラベル、注文終了時の可視ハンドル、列の先頭紙を集計する。
この事後解析の注文列は解法へ渡さず、実装の設計処理は未来の注文を読まない。

基準と同じhead穿孔の後、第2候補の紙にだけ追加の穿孔を試す。
効用順は頻度、次に穿孔前のフィラー効用で固定する。
各列・色のheadが第2候補に置き換わる確率を置き、8サンプルの区間DPをその紙で評価する。
自分の目標に増える穴費用は頻度に応じて全て数える。未来の注文は使わない。

- `ARGON_D2_RATE`（既定0.25）: 同色の非head紙が先頭にいる確率。
- `ARGON_D2_WIDTH`（既定2）: 列・色ごとに調べる候補数。非headの確率は均等分配。
- `d2_trials` / `d2_viable` / `d2_accepted`: 追加穿孔の試行、一次判定通過、受理数。
- `d2_cost_delta` / `d2_profit_delta`: 追加の穴費用と区間DPの利益（手/注文）。
- `d2_sec`: 追加段の時間。既存のperforation指標は両段の合計。

既存ログ・スイッチ・プロファイラ・段の目印を維持する。

実装と診断の共通記録は solutions/argon-des-perforation/REPORT.md。
