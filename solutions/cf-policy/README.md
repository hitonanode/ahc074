# 別の操作の将来費用から係数を決める

改良元: solutions/td-policy。係数の収集はsolutions/counterfactual-value、紙の設計はsolutions/tight-thirty-eight。

自然に訪れる状態のTD式の代わりに、同じ注文で別の合法な計画を選んだ状態どうしを比べる。24入力・1199組を、同じ8系列・16注文先まで処理した将来費用の差へ当てはめる。深さ2係数は1に保ち、残り6係数を正則化0.01で推定する。元との混合率0/0.25/0.5/1を未使用の32入力で比較。

研究用。main.cpp単独は基準の係数で、probe.cppだけ推定値を使う。実際の隠された注文は読まず、全時計はCLOCK_SCALE倍。
