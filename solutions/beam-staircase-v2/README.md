# beam-staircase-v2: ビーム完成案と連動最適化（研究用）

改良元：`solutions/beam-staircase-v1`。v1の固定容量を外し、ビーム完成案を初期値にして `esw-clean` の構造焼きなまし等を再利用する。

- ビームの完成案を、紙の列容量・ペア・列所属・ハンドル順序を一体で動かせる `Design` に変換する。
- ペア＋2枚の単独紙の置換も含む焼きなましで、頻繁に使う紙の深さ・ハンドル補修費用を最適化する。
- 補助紙の利用価値を重視した列交換と、4回のハンガリアン再割当を続ける。
- 品質優先は初期ビーム2×5、連動探索14.9M回。`-DBEAM_FAST=1` はビーム1×3、連動探索4M回の研究設定。

あくまでハイブリッドであり、焼きなましを使わず純粋ビームだけで既存最良を達成したわけではない。詳しい実験条件は [v2ノート](../../docs/beam-staircase-20261106/notes_v2.md)。
