# chatgpt-choice-potential

改良元: `solutions/chatgpt-multiroute`

重複した代表紙を持つ商品の将来費用を、固定の経路選択率による加重平均から、現在の列内順位を使った2経路の最小費用へ変更する。
紙の設計と実際の注文処理の候補生成は改良元と同じ。`MULTIROUTE_MIN_GAIN` の既定値は -100 とし、利益が正の候補がなくても互換性のある上位8組までを試す。
これは多経路を実際に使わせて将来費用の差を測るための実験設定であり、追加経路が得だとは仮定しない。

経路 d の予測費用は「その紙の現在の列内順位 + 汎用層の平均操作数 + 穴の取っ手を直す費用」とする。
列外に出ている紙の順位は0。取っ手の色については、その色の列外紙があれば0、なければ列内で最初にその色が現れる順位を使う。
2経路の商品は線形な利用重み・穴の重みから除外し、2経路の予測費用の最小値を256分の1だけ加える。
これにより、一方の紙が深くなっても、もう一方が浅ければ将来費用をほとんど増やさないという利点を表現する。

紙を列へ戻す際にも同じ最小費用を評価する。変更される列の順位と先頭色の順位だけを差分計算し、候補の挿入位置ごとに2経路のどちらが有利かを選び直す。
当該紙を列外扱いから外すこと、同じ列の後続紙の順位が1増えること、列外の別紙が取っ手の色を供給できることを計算に含める。

## 厳密な部分と近似

- 固定した紙・列・候補挿入位置に対する列内順位、2経路の最小値、挿入によるこのモデルの差分は厳密に計算する。
- 汎用層の費用は、その商品の実際の穴の条件について全720順列を一様に仮定した正確な平均最短距離。現在の汎用層の順序や将来の定常分布は使わないため、将来費用としては近似。
- 穴の取っ手の費用は改良元の単独掘りモデルであり、穴埋め紙の同時被覆・将来の戻し・経路間の依存は表現しない。2経路を持たない商品の再挿入の評価は改良元と同じ。
- 次の注文の予測は256商品一様とする。直前と同じ商品が来ない制約や、さらに先の注文は扱わない。
- `CHOICE_CHECK` を定義すると、挿入位置ごとの非線形費用を実際に並びを作り直した全計算と照合する。通常ビルドでは含まれない。

追加の診断値 `choice_targets` は2経路を持つ商品数、`choice_checks` は `CHOICE_CHECK` で確認した挿入候補数。
経路・時間・探索回数の診断値と環境変数は改良元と同じ。捨てた経路の探索も計画回数に含む。
評価結果は `trial_log.md` と[検証レポート](../../docs/chatgpt-multiroute-rescue-study.md)を参照。
