# 後処理のリンク・位置配列の短縮を組み合わせる

改良元: solutions/eject-quick。計算方法はsolutions/post-byteとsolutions/post-index。

紙番号と番兵をuint8_tにしたリンク配列と、可視性付き再生の位置配列を組み合わせる。操作の候補と評価式は変えない。

probe.cppは元の方法・1バイトだけ・位置配列だけ・両方を比較し、実行順をseedごとにずらす。各条件は同じ量の検査と記録を行い、測定中に基準だけ操作列を保存する負担が入らないようにする。全注文の表示・可視性を検査し、操作列・最終順序の全体ハッシュも比較する。個別変更の全操作列一致は各元の研究で検査済み。隠された注文列は使わず、CLOCK_SCALEを適用する。
