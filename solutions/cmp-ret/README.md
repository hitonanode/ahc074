# cmp-ret

改良元: solutions/cmp-base2

注文処理で、列の外の紙（前の注文の専用紙・古い穴埋め紙）を列に戻すとき、その列に今回の注文の専用紙 D がまだ在位しているなら、D より下にだけ入れる（adaptive_insert の barrier を D にする）。

- 動機: 注文処理の取りこぼしを、最初の 1 手を総当たりで変えて計画探索をやり直して調べると（cmp-base2、22 件 × 128 注文）、17% の注文でより良い計画があり平均 0.037（計画の費用/注文、約 0.34%）。その中に「D と同じ列へ戻した紙が D より上に入り、D を掘るときにもう一度動かす」型があった（例: seed 3 の注文 100）。
- 設計が同じ模擬（回数固定、32 本）で cmp-base2 比 −0.037 ± 0.006%（seed 24〜87、50/14）、−0.038 ± 0.004%（seed 88〜215、95/31）。
- 残りの取りこぼし（修正後 0.033/注文）は、列の上端の紙を DP が候補にしない段へ置く穴埋め（0.016）、前の専用紙・古い穴埋め紙・列の紙を列の中の別の位置へ（各 0.003〜0.004）などに散らばる。
