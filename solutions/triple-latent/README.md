# 3商品共有から汎用紙の印刷を設計する

改良元: solutions/reset-majority。研究の初期の共有グループは solutions/triple-bound の理想化模型から作る。

商品3個を共有するグループを先に作り、汎用8枚の印刷と各商品の表示順序を交互に最適化する。各汎用窓は2枚の比較とし、商品紙はグループの共通色を印刷する。3商品のどれかが違う窓では、それぞれの汎用順序が要求色を出す必要がある。

現在の印刷に対し全8!順序を調べて不一致の少ない順序を選ぶ段階と、選んだ順序を満たす比較組・色・汎用窓の集合を選ぶ段階を交互に行う。途中は温度を付けて不一致を許す。全比較組を最低1窓に割り当て、最下段以外が常に見える形を保つ。

窓の割り当ては、各比較組を1回使う枠・自由な汎用窓の枠・ハンドル窓の枠への最小費用割当で決める。追加の joint 指定では、グループの人数を保ちながら商品を交換する。部分集合DPで各候補の最少不一致数を求め、窓の割り当てと共有相手を同時に変える。7〜9枚を指定できる。

`dp_search.cpp` は全順列の代わりに部分集合DPで誤り数の最小値と、温度を付けた順序の分布を計算し、11枚まで調べる。比較組が窓数を超える場合は、最初の6枚の全比較と、追加紙ごとの2比較だけを必須にする。この疎な比較グラフでは可視性による操作費用をまだ測っていない。3商品共有の数を5〜20組に減らし、余った単独商品を対にして総紙数を守る条件も調べる。`build_dp.py` は生成手順。

`unique_search.cpp` は、比較組の数が汎用窓数以上なら、各窓を異なる比較組へ割り当てる。窓と比較組への長方形の割当問題で、同じ組の逆向きの要求が衝突することを避ける。`build_unique.py` は生成手順。

`export_model.py` と `model.cpp` は得られた印刷で表示可能な全ての対・近い3商品を列挙し、共有と列を再設計する。汎用費用は固定32開始順から測り、完全比較グラフでは合法な最少手数、疎なグラフでは可視性を無視した下限を使う。後者は構造を有利に見積もった選別模型。`build_model.py` は生成手順。

これは構造の可解性を調べる研究用。実際の注文列は読まず、乱数は固定する。設計に成功した場合だけ、合法な汎用操作の費用と列配置を別途調べる。CLOCK_SCALEを全時計へ掛ける。main.cpp は比較元のコピーで、提出用の新構造は未統合。
