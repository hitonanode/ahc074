# 穴埋めの期待利益を紙の配置へ入れる

改良元: solutions/head-excess。

設計の最後の紙の交換で、穴埋め紙が実際に直せる窓数の期待利益を使う。各窓が誤色である確率は、要求色の比率から求め、窓間は独立と仮定する。直す窓数から配置・返却の1.6手を引いた正の部分の期待値を、各列の紙で平均する。

- mode 1: 元と同じ、商品紙の列より深いハンドルだけを見る。
- mode 2: 共有紙の違いによる浅い穴も含める。穴埋め紙は、自分の列の窓を直す利得には数えない。
- mode 0: 比較元の目的をそのまま使う。

模型費用−係数×期待利益を下げる紙2枚の交換を行う。係数は研究時に0.3/0.6/1.0を比較する。主な制御・設計時間は改良元と同じ。`probe.cpp` は保存設計を復元し、同じ初期順の作り方と固定乱数の模擬注文で比較する。入力末尾の実際の注文列は読まない。時間の指標には `CLOCK_SCALE` を掛ける。
