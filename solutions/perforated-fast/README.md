# 穴追加の区間DPを差分で評価する

改良元: solutions/perforated-interval。

変更した紙が先頭候補になっている列が1列だけなら、区間DPで変わるのもその列で終わる辺だけになる。変更前の前向き・後ろ向きの最良値と、その列を使わない最良値を保存し、新しい辺を1本通る案と比較する。自身の担当商品で穴が増える場合や、複数列の先頭候補が変わる場合は全DPを計算する。変更を受理したときに表を作り直す。

目的関数・候補・乱数は改良元と同じ。VERIFY_FAST_PERFORATION付きの検査では、全候補の差分値と元の全再計算を照合する。研究用で、main.cpp単独は基準のまま。保存設計と独立の模擬注文で検査し、全時計へCLOCK_SCALEを掛ける。
