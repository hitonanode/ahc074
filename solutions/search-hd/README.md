# search-hd

改良元: solutions/astra-search

窓の割り当ての目的関数（70 対の貪欲マッチングの費用）で、対のハンドル窓での違い 1 つの重みを 2340 から 1800（1/3600 手単位。0.65 → 0.5 手）に下げただけ。対のハンドル窓の違いは、後の焼きなましがハンドルの順序を決めるときに、その対の列より深いハンドル（もともと穴）へ寄せられれば無料になるので、一律 0.65 手は高すぎる、という見立て。模擬（night-probe4、192 件）で重み 1000 / 1400 / 1800 / 2900 が +0.180 / −0.047 / −0.074 / +0.177%。
