# 紙が列へ戻る深さの負担も評価する

改良元: solutions/td-policy。新しい特徴の収集はsolutions/return-deficit、紙の設計はsolutions/tight-thirty-eight。

列外へ出ている紙が戻ると復活する、頻度順で最小の重み付き深さを終了費用に加える。現在の列内枚数と共有紙数から各列の値を計算する。紙の並び自体への係数は正のまま保ち、紙を外に置く一時的な利益だけを補正する。

24入力・1199組の別計画の比較から係数を推定し、元との混合率0/0.25/0.5/1を未使用入力で比べる。追加特徴だけ半量にする条件も設ける。係数はlearned.jsonに保存。main.cpp単独は基準の係数、probe.cppは独立模擬16本による検査用。隠された注文は読まず、全時計はCLOCK_SCALE倍。
