# 2操作を削除し途中の1操作で修復する

改良元: solutions/post-eject-once。提出用の比較基準は solutions/perforated-eight。

通常の上位2計画の後処理を終えて1案を選んだ後、その操作列から2操作を取り除き、代わりの紙を1回動かして表示を直す。代わりの紙は最終状態で見えるものだけでなく、操作途中で見えるものも使う。最終表示の必要条件、動かない紙に隠れ続ける紙の除外、必要になった時だけの途中可視性計算で候補を絞る。全候補を可視性付きで再生し、表示と次注文への状態を確認する。

solver-arraysの固定長一時配列も使う。設計の列探索以降の締切を0.10秒早め、追加の操作探索に充てる。列探索は1.205秒、穴埋め山登り1.26秒、先頭再割当1.345秒、補助穴設計1.39秒、補助表1.45秒まで。軽量計画への切替は1.80秒で従来通り。全時計はCLOCK_SCALE倍。

eject_pairsは削除2操作の組数、eject_trialsは修復を挿入して検査した数、eject_acceptsは終了費用が下がった候補数、eject_insideはそのうち末尾以外に挿入した数。評価結果はtrial_log.mdに記録する。
