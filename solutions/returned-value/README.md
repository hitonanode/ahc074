# 列外の紙を戻した後の状態を予測する

改良元: solutions/return-deficit。main.cppは基準制御のままの研究用。

列外にある紙を、その列の重み付き深さと先頭色の費用が最小になる位置へ仮に戻し、深さの増分と色合わせの増分を特徴へ追加する。実際の紙の順序と印刷を使うため、枚数だけの戻り負担に含まれない差を調べられる。順序は変えず、将来の注文も使わない。

同じ24入力・同じ別計画を再生成して特徴だけを計算し、既存9特徴と注文番号の完全一致を確認して、保存済み8系列・16注文先の教師値を再利用する。推定の正則化・交差検証はreturn-deficitと同じ。全時計はCLOCK_SCALE倍。
