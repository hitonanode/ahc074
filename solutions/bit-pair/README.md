# bit-pair

改良元: なし

窓ごとに白い紙と黒い紙を 1 枚ずつ用意し、色の違う窓だけを 1 手ずつ直す解法。誤りは出ない（E = 0）。

## 紙の設計

- 紙 j（j = 0..63）は窓 j だけが不透明で、その色は 256 個のバーコードでの窓 j の多数決の色（最初の注文に対する最尤の推定）。紙 64 + j は窓 j だけが不透明で、もう一方の色。
- 残りの 64 枚（紙 128..191）は全面が穴で、見えることも動かすこともない。
- 初期の並びは紙 0, 1, ..., 191 の順なので、最初は全窓に多数決の色が見えている。

## 注文ごとの操作

- 窓 j で不透明なのは紙 j と紙 64 + j の 2 枚だけで、上にある方が見えている。欲しい色の紙はその下に隠れていて動かせない（見えていない紙は動かせない）ので、見えている方の紙を一番下（深さ K−1）へ送る。この操作は窓 j の表示しか変えない。
- 今の表示と目標の色が違う窓ごとに 1 手ずつ行うので、1 注文の手数は直前の表示とのハミング距離に等しい（平均ほぼ 32 手）。
- 時間で打ち切る探索はない。

## stderr の指標

- `moves`: 操作の総数 T。
- `first_moves`: 最初の注文の手数（多数決の初期値の効果を見るため）。
