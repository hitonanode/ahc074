# 動かさない紙をまとめた操作列の再生

改良元: solutions/post-rewrite。最良の提出用の比較基準は solutions/post-prune。

後処理で移動しない連続した紙を1個のブロックにまとめ、不透明な窓の和集合と見える色を保存する。移動する紙、差し込み先、列の境界は単独の節点にし、候補の操作は双方向リストで再生する。可視性と最終表示はブロックを使って元と同じ規則で判定する。表示が一致した候補だけ紙の全順序へ戻し、終了費用を計算する。

差し込み先がブロックの内部になった候補は元の完全な再生へ渡す。良い候補の出力深さは元の192枚の順序から計算する。削除と差し込み先変更を同時に試す探索も含む。研究では同じ探索を圧縮あり・なしで比べ、手数と採用数の一致、独立した可視性再生を検査する。時計はCLOCK_SCALE倍。

compact_trialsは圧縮を試した候補数、compact_fallbackはブロック内部の差し込みで完全再生へ渡した数、compact_nodesは後処理ごとの節点数の合計。main.cppの既定は圧縮あり・同時変更の全差し込み先。
