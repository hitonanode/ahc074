解法の比較

スコア = 2KE + T（K = 192、E = 誤った注文の数、T = 操作の総数。小さいほど良い）。 相対スコア = 100 × 基準のスコア ÷ その run のスコア（ケースごとに計算して平均、高いほど良い。WA は 0）。 勝-分-負 = 基準よりスコアが良い・同じ・悪いケースの数。行をクリックして選んだ run が、下の表の列になります。
